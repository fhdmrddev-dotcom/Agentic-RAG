Direction C adds exactly one atom — the one-line purpose — and it lands inside column 1, beneath the name. No column is added, none is renamed, none is dropped. The name stays the row's primary anchor, which is what UI-SPEC § Surface 2 already requires in both shapes.

3⭐ The fix for the thing C broke — provenance is not a state

In the Stitch density render, Uncurated appeared in the State column, in place of Connected — so a reader could not tell whether deepwiki was connected at all. Provenance had eaten the connection state. They are two independent axes and each keeps its own slot: provenance is a quiet mono tag beside the name; State stays State.

State columnBeside the name
Slack — curated, connected Connected—
deepwiki — uncurated, connected Connected ADDED BY URL
deepwiki — uncurated, not connected Not connected ADDED BY URL
Notion — curated, not connected Not connected—

Both axes are readable at once, and neither costs the other. The tag is quiet enough to be provenance and never reads as a warning.

4Density — twelve rows, the aspirational state

It does — because it sits in column 1 under the name and truncates on one line, so the row height never changes and the list keeps its rhythm. Two uncurated rows, deliberately, to check they still read as peers when more than one sits in the list.

6What this sketch does NOT settle

The mark is still open

Brand marks come from @lobehub/icons — the monograms here are placeholders and must not be built. The real design problem is the generic mark for an uncurated service, drawn here as ◈ in primary-dim. That is a proposal, not a decision.

“Sends to” prints the mechanism

The locked column shows a host, with the always-on 🔒 (024-A). The catalog language says a person adds Slack without learning what a protocol is. Both are deliberate and they pull against each other. Not resolved here — it goes to the builder as a question.

The empty and flag-off states

Not drawn. live_connectors ships cold as off and this install has it flipped on, so the off state is unexercised here and still owed.

The paste-a-URL door

Its five stages are direction only, in 212-stitch-catalog/. They are new surface and were not re-expressed here — the door deserves its own sketch.
