Every line on this picture

Rules every variant keeps: the picture is computed from the workflow definition and nothing else — no run data, no second canvas, read-only. The orchestrator is the engine, not a step: it runs steps in phase_index order and keeps the shared record (every step reads all earlier outputs). Steps never link to each other — the definition has no such field — so no step-to-step line is ever drawn. The only step-to-step mark is ⤳, and only where a check's on_failure says skip_to_phase. A judge is a llm_judge_rubric gate on one step: it has no node of its own in the Steps view, so here it sits beside the step it grades and draws one line to it. Other gates are checks, not judges. A parallel step shows up to N seats from max_parallel_agents — a cap, not a headcount.
