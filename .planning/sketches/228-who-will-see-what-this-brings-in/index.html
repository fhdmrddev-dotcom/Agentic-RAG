228 · Who will see what this brings in

Phase 231 · VIS-02. A connection is about to start placing documents into the knowledge base that nobody chose to upload. The sentence naming who can then read them is the deliverable — not decoration around it.

SC#1, verbatim: “A person setting up a connection reads one plain sentence saying who will be able to see everything it brings in — before it brings anything in. There is no configuration path where that sentence is absent.”
→ The deciding axis is therefore coverage, not eloquence. A variant that reads beautifully on the happy path but can be skipped loses.
A

The always-on scope footer

The 024 pattern: you can never pick a scope without reading who it means.

🔒 Documents this connection brings in will be visible to you only. Nobody else in Acme Corp will see them in the Library, in search, or in an answer the agent gives. ingest_visibility = private · 4 enforcement sites
Why it wins on the criterion
The sentence is bound to the control, not to a step. Every path that can set a scope renders the footer by construction, because the footer is part of the scope field — there is no path to check.
Precedent
Sketch 024's always-on 🔒 endpoint footer, adopted for exactly this reason: “you can never pick a model without seeing where it runs.”
Cost
It is quiet. A person clicking through fast may not read it — coverage is guaranteed, attention is not. That is the gap C exists to close.
Widening reads louder
Selecting “Everyone in Acme Corp” turns the footer amber and names the audience — see B's second row for the copy. Colour is reinforcement, never the only carrier.
B

The sentence is the option

069-A audience rows: each choice states its own consequence.
▲
Google Drive
fhdmrd@gmail.com
Only me Nobody else in Acme Corp will see these documents in the Library, in search, or in an answer the agent gives.
Everyone in Acme Corp All 26 people in Acme Corp will be able to read these documents and the agent will quote them in answers — including to people who cannot open the original in Google Drive.
The strongest copy
There is no separate sentence to go missing, because the sentence is the label. You cannot choose without reading the consequence of the thing you are choosing.
It names the real hazard
“…including to people who cannot open the original in Google Drive” is Pitfall 2 stated on screen: the connecting user must not silently become a gateway. A footer can omit this; a row that is the choice cannot.
Cost
It only covers surfaces that render this control. A settings screen that edits a connection without re-showing the audience picker has no sentence — the coverage hole A closes structurally.
D-5, honestly
There is no department row, on purpose. The stored value is enum-shaped (private | org | dept) and the resolver has a dept branch, but a scope nobody can grant must not be offered. Inert means invisible.

It earns attention
A and B guarantee the sentence is present; only C guarantees a moment where it is the only thing to read. It is also the only variant that can state the real count — 148 files — because by then the preview has run.
Weight, not friction
Sketch 025's rule. No type-to-confirm: this is reversible (narrowing later is one setting) so the guard is a clear consequence, not an obstacle course.
Alone, it FAILS the criterion
A gate fires on first sync. Editing a connection's scope afterwards is a configuration path with no gate and therefore no sentence — precisely the “configuration path where that sentence is absent” SC#1 forbids.
Reads on the Phase 233 preview
C shares a surface with the preview phase. If it is built, the two must be one screen, not two.

What I think, and what the operator must decide

  • Recommendation: B as the control, A as the guarantee — they are not rivals. B writes the copy (the sentence is the option, and it names the gateway hazard); A is the rule that the copy appears on every path, including the edit-later screens B does not reach. Together they satisfy the “no configuration path where the sentence is absent” clause by construction rather than by audit.
  • C is the open question. It is the only variant that earns attention and the only one that can name a real file count — but it duplicates the Phase 233 preview surface. Building it here risks two screens that say the same thing. Recommend deferring C to 233 and letting the preview carry the moment.
  • The department row is deliberately absent (D-5). The stored value is enum-shaped private | org | dept and the resolver carries a dept branch, but no UI offers it. This is 069-A's extensible-audience contract applied inbound: never booleans, one swappable resolver.
  • Copy is not settled. “Everyone in Acme Corp” vs “All 26 people in Acme Corp” — the count is more honest and more alarming. Both are drawn above; the operator picks.
  • Not drawn, and owed: the revoked state. When a connection is disconnected, D-4 says its documents freeze rather than vanish — that sentence has no home yet on this surface.
