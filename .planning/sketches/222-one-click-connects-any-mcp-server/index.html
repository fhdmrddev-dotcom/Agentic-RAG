Probing Endpoint
Checking server authentication... Discovering RFC 9728 / 8414 metadata and authentication requirements.
✓ Kind: Open
No credentials required This server allows direct connection. No API key or sign-in needed.
⚡ Kind: OAuth (DCR)
Authentication required Sign in with accounts.notion.com to connect. Client credentials will register automatically.
🔑 Kind: OAuth (BYO)
Client credentials required This server requires client credentials registered on auth.enterprise.com.
🔒 Kind: Token Fallback
Static Token Required This server did not advertise an authorization server. Enter a Personal Access Token or API key.
⛔ Policy Refusal (422)
Connection refused by security policy The target server address is not public or belongs to a restricted internal network (address_not_public).
