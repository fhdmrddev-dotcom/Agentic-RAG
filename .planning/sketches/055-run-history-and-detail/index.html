055 · Run history & detail

A — Full-replace drill-in (005-A)

The run list is the resting view. Clicking a run replaces it with that run's detail — ‹ Runs returns. One thing on screen at a time; the detail gets the full width for its side-by-side arms. Every run in the list is clickable — including the honest ones (interrupted, running).

Try it: open each run — the verdicts differ honestly per run: all-pass, pass-with-a not_measured arm, a fail + a judge_error, an interrupted run, and a live one. "Your rating" thumbs are separate from the judge's verdict — two different truths, labeled.

B — Expandable rows

The run row expands in place — the detail unfolds under it while the other runs stay visible above and below. No navigation state at all; scanning multiple runs is one scroll. The cost: a long detail pushes the other rows far down, and two expanded runs make the page very tall.

Try it: expand the gemini run (1/2 + judge error) and then the claude 3/3 above it — compare how it feels to flick between two runs' details versus A's back-and-forth.

C — Master-detail split

Runs stay as a persistent left rail; the detail owns the right. Selection is always visible — you never lose your place in history while reading a run. The natural shape if the shell winner gives the studio real width (053-A or 053-C); impossible inside a 384px panel.

Try it: click through all five runs in a row — this is the fastest run-to-run comparison of the three. Note the side-by-side arms compress slightly to pay for the rail.
