Workflows

Search is always there.
🔎
Search matches the name and the purpose sentence (the soul's business_requirement), highlighting the hit — so clause, assessments and sign-off all find workflows whose titles don't contain them. Stated honestly: this is substring matching, not meaning. A paraphrase you'd expect to work — “the thing that checks vendors” — returns 0 results, because those words appear in that order nowhere. Try it. Whether SC#1 (“typing part of its name”) is the real bar, or whether the purpose sentence should be searched at all, is a decision for this sketch — not something to discover after shipping.
