Shared by both variants: a run is attributed to the Expert that was active when the run started, and that is stored on the run. It is not read from the thread's current Expert, so a later swap does not rewrite history. Sub-agent runs and paused-then-continued runs count toward their parent run's Expert. No Expert is always a row, even when it is $0. The per-Expert lines always add up to the org total, and the footer checks that sum. Unpriced runs keep their amber flag inside each Expert line. The dollar figure comes from the one token-to-USD calculation built in 257; there is no second formula.
What you are choosing: A adds an Expert filter that every card follows (KPIs, charts, ledger), plus a "Spend by Expert" table. B adds a Group by Model / Expert switch on the breakdown chart and table, and leaves the KPIs org-wide.
