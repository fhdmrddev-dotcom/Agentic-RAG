⚠ Two save models on one screen

Everything above this line is a single app_settings form — you edit fields, then press one Save Integrations button (SettingsPage.tsx:1354-1365). A connection is a row: it is created, edited and deleted one at a time, each write its own transaction, each carrying a write-only secret. Nesting rows inside the tab means either the tab-level Save silently does nothing for them, or a row edit is lost when you navigate away without pressing it. This variant exists to make that visible, not to win.
