## Priority carry-forward (build first, when triggered)

### 180 — Agent-Loop Behavior Honesty (LOOP-01 / LOOP-02 / LOOP-03)
- **Delivers:**
  - **LOOP-01** — the agent HONORS an explicit "do this step by step" / todo-loop request instead of collapsing it into one turn.
  - **LOOP-02** — Anthropic's end-of-cycle output shows a user-facing **summary**, not a raw action list.
  - **LOOP-03** — excessive tool iterations on multi-step tasks are **bounded / honest** (stops spinning its wheels).
- **User value:** the highest-value STRETCH item — it's the "the agent didn't listen / rambled / over-iterated" class of everyday annoyance. Directly improves the felt quality of every chat.
- **Owns these deferred reported-bugs:** `agent-ignores-step-by-step-request-no-todo-loop`, `anthropic-end-of-cycle-shows-actions-not-summary`, `anthropic-excessive-tool-iterations-on-multi-step-tasks`, `BUG-260626-02` (phase-120 baseline leak on final-emit), `BUG-260626-03` (todos stuck — no run-end finalizer), `BUG-260722-02` (gpt5.6 reasoning empty response in tool loop). Also relates to SEED-094 (backend run-end honesty).
- **Depends on:** nothing new — but it is the **most careful** STRETCH: touches `backend/app/services/agent_loop.py` + `backend/app/services/anthropic_service.py` (both G-5 hot-file rows) and is under the **D-14 red line** (Deep byte-identical; provider differences stay at the service boundary). May warrant careful decomposition (small waves).
- **Why deferred:** these are "deferred majors" that have slipped several times; none is a blocker, and the milestone budget went to the org-surface polish + the Canvas pivot. Riskiest surface to touch, so not worth rushing before a big build.
- **Re-open trigger:** the step-by-step/summary/over-iteration behavior becomes a **recurring daily-use complaint**, OR a paying/prospective user flags agent-loop behavior. Good candidate to slot as a **standalone reliability phase** (not bundled) given the hot-file risk — or fold as the tail of a future reliability pass.
- **Build approach when revived:** SC#10 cross-provider mandate (touches the agent loop — the shared path). Provider-docs-first (Anthropic native SDK end-of-cycle behavior). Keep every fix at the service boundary; never fork the shared Deep path (D-14). Consider a dedicated phase per LOOP-0x if decomposition proves large.

- **Delivers:** extends the shipped v3.3 Phase-154 plain-language layer (`termMap`) onto the **new org + chat surfaces** so jargon doesn't creep back in.
