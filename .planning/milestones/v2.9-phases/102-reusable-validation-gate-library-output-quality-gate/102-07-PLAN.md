<objective>
Close the two remaining GATE-01 validator live-path gaps plus the ask_user honesty warning, all on `validator_kinds.py` + `harness_engine.py`.

- **WR-01 (blocker):** the freshness live path reads `getattr(ctx,"scope_folder_ids") or getattr(ctx,"folder_scope")` — both are `None` on every real ctx bag (which carries `folder_subtree_ids`), so it ALWAYS fails "no KB scope context" (verification truth #2 FAILED). Add `or getattr(ctx, "folder_subtree_ids", None)` as the third fallback.
- **WR-07 (security):** `output_file_valid`'s `config["path"]` branch passes the author-controlled path straight to `assert_integrity` (a raw local-file open) — an unscoped filesystem existence/type oracle driven by definition JSONB. Resolve `config["path"]` through the run's workspace (the `get_file_by_path(pool, thread_id, path)` pattern), and genericize the error message.
- **WR-08 (honesty):** the ask_user version-ambiguity choices "Use newest version"/"Use as-is" both route identically to Proceed but imply version-scoped retrieval that does not exist. Present honest choices ("Proceed despite version ambiguity" / "Abort"), matching the staleness pair, and note the v1 cut in the receipt metadata.

Purpose: WR-01 makes the GATE-01 freshness preflight actually fire on a live run; WR-07 removes an unscoped filesystem oracle from definition JSONB; WR-08 keeps the governance trail honest (the receipt no longer asserts an unimplemented semantic).
Output: A freshness validator that resolves the real ctx scope; a workspace-scoped output_file_valid; honest version-ambiguity choices + a v1-cut receipt note; one live-shape freshness test, one path-oracle test, one choice-set test.
