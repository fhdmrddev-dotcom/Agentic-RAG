## Decisions Made

All implementation followed the LOCKED decisions D-09 (flat field-map + scoped gate/driver re-touch with tests) and D-11 (emit sub-events + 5 failure states), the WR-04 discipline, and A5 (render on the existing rail). The substantive judgement calls (also in frontmatter `key-decisions`):

- **One normalizer, three call sites (WR-04):** the third branch normalizes-then-falls-through to the existing envelope walk via the shared dict normalizer — the strongest "two copies cannot drift" guarantee (one code path produces the legacy shape).
- **Structural shape discrimination:** `_is_flat_emit_field_map_dict` distinguishes the flat EmitFieldMap from the flat spike-style shape by inspecting whether `scalars` is a list / rows carry the `collection`+`cells` wrapper — preventing a regression where the spike shape was misrouted.
- **GAP-C render scope = PhaseCard only:** `Phase.emitSubStep`/`emitFailure` are additive-optional wire fields; the demux wiring (api.ts/StreamsProvider, a G-5 hot file) is the deferred run-legibility phase. This plan ships the render contract on the existing rail.
- **Best-effort sub-event emit:** `_emit_phase_substep` lazy-imports the canonical `_emit` and short-circuits on a missing redis — a run-honesty event never crashes the deliverable.
