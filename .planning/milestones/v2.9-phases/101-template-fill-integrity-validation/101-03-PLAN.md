```python
    *, pool, supabase, thread_id: str, user_id: str,
    asset_ref=None,   # AssetRef | None — library path (trusted)

    """Resolve template bytes by PROVENANCE (D-02/D-09).

    Returns {"bytes": bytes|None, "filename": str|None, "provenance": "library"|"template_input"|None,
             "mime": str|None, "error": str|None}. On any failure returns bytes=None +
             a relay-able error string — NEVER raises a raw 404 / never returns another user's bytes.
    """
```

| Boundary | Description |
|----------|-------------|
| user → workspace_files (template_input) | The ephemeral upload is untrusted; resolution must be user-scoped + expiry-gated |
| workflow definition → AssetRef.asset_id | The Storage path comes from a published (immutable) definition — trusted, but still user-scoped on fetch |
| cross-user request → template bytes | Another user's thread/template must never resolve to bytes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-101-03-01 (T-097-06) | EoP | ephemeral template query | mitigate | Every query filters by `user_id` (RLS backstop); a cross-user thread → no row → clean "no template" error, never another user's bytes (V4, 404-not-403) |
| T-101-03-02 | Information disclosure | expired template read | mitigate | The read gate `(expires_at IS NULL OR expires_at > now())` (100 D-10) keeps an expired template unreadable; expired → relay-able "expired" error, never stale bytes |

| T-101-03-04 | DoS | blocking Storage call in async handler | mitigate | Storage download wrapped via `_read_from_storage` (run_in_threadpool) per CLAUDE.md D-v2.5-01 — never blocks the event loop |
