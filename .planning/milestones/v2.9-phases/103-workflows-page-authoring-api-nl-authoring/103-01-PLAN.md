<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → POST/PATCH/DELETE /workflows | untrusted draft body + a definition_id a caller may not own crosses here |
| route → DB (service-role asyncpg) | the engine bypasses RLS, so every query MUST self-scope `created_by=$N` |
| DB trigger → route | the immutability trigger (23514) is the source of truth for the published-row freeze |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-103-01-01 | Elevation of Privilege | list_draft_workflows / update / delete | mitigate | Owner-scope `created_by=$N` on EVERY new DB fn; a second user's draft is absent (Task 2/3 tests assert it); cross-user PATCH/DELETE returns None->404 (no existence leak — the get_definition precedent) |
| T-103-01-02 | Tampering | update/delete a published row | mitigate | The DB trigger `workflow_definitions_block_published` raises 23514; the route catches `CheckViolationError` -> HTTP 409, never a silent overwrite or a 500 (Pitfall 5); re-read-unchanged asserted (Task 3) |
| T-103-01-03 | Spoofing/Tampering | client sets status='published'/is_global on create | mitigate | The route forces `status='draft'`, `is_global=false`, `created_by=user_id` server-side in `create_workflow_definition` — never trusts the client body's status/ownership |
| T-103-01-04 | Tampering | injected/hallucinated keys in the draft body JSONB | mitigate | `WorkflowDefinition`/`PhaseSpec` are `_StrictBase` (`extra="forbid"`) — an unknown key is a 422, not silently stored |
| T-103-01-05 | Information Disclosure | SQL injection via the draft/definition_id | mitigate | `$N` positional placeholders ONLY; only the placeholder INDEX is f-string-built (the in-file rule); `definition_id: UUID` path param -> 422 on malformed |
| T-103-01-06 | Tampering | Tweak fork UPDATEs the frozen published row | mitigate | Tweak = `create_workflow_definition` INSERT with `version=N+1` (Pitfall 6); the published row is never UPDATEd; UNIQUE(slug,version) enforces version distinctness |
</threat_model>
