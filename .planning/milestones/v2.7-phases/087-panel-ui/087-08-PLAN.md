- **Tampering / Information disclosure:** none new — no new inputs, endpoints, or storage. The seam reload path renders already-persisted run data (no new exposure).

Mitigation: the negative key-link assertion (zero `onToggleWorkspace`), the updated controlled-API test, and the live cross-provider gate.
