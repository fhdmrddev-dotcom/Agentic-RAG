## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user free-text→submit | ask_user free-text answer is user input POSTed to the run resume endpoint |
| agent ask_user prompt→render | The prompt text + options come from the agent (untrusted) |
| run_id→resume authority | run_id identifies which run to un-pause; backend scopes by user_id |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-087-11 | Tampering (XSS via prompt / answer) | PendingAskCard / SeamCard | mitigate | Prompt + options + answered value rendered as plain React text children (no `dangerouslySetInnerHTML` — grep =0). Free-text answer sent as JSON, never rendered as HTML. |
| T-087-12 | Spoofing (answering another user's run) | answerAskUser submit | mitigate | run_id sourced only from the GET-reconciled PendingAsk (own-thread, RLS-scoped); backend `runs` query scoped by user_id → 404 on foreign run. A2 gate ensures we POST a real reconciled run_id, not a guessed one. |
| T-087-13 | Information Disclosure (raw-JSON leak in seam) | SeamPointer / SeamCard | mitigate | Components render only summarized known fields; `JSON.stringify` of tool payload is grep-banned (=0). Single-source-of-truth (D-05) prevents duplicate rich rendering. |
| T-087-14 | Tampering (G-5 regression) | MessageItem additive mount | mitigate | Additive sibling renders only; existing RunCard call shape preserved (grep + diff review); BUG-260529-02 surface untouched. |
