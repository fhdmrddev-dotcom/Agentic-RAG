Use `:focus-visible` (not `:focus`) so the ring stays off mouse clicks:
```css
@layer base {
  :where(a, button, input, select, textarea, [tabindex]):focus-visible {
    outline: 2px solid hsl(var(--ring));
    outline-offset: 2px;
  }
}
```

<span className="sr-only" aria-live="polite">

</span>
