**Imports:**
```python
from fastapi import APIRouter, Depends, HTTPException, status
from supabase import Client

from app.dependencies import get_current_user, get_supabase
from app.models.skill import SkillCreate, SkillUpdate, SkillResponse
```

**Router declaration:**
```python
router = APIRouter(prefix="/skills", tags=["skills"])
```

**Endpoint 1 — GET /skills (SKIL-01 list):**
- Signature: `async def list_skills(current_user: dict = Depends(get_current_user), supabase: Client = Depends(get_supabase))`
- Response model: `list[SkillResponse]`
- Query: `supabase.table("skills").select("*").or_(f"user_id.eq.{current_user['id']},is_global.eq.true").order("name").execute()`
- Dedup by id (same pattern as `list_folders`): iterate `result.data`, track `seen` set of ids, append unique rows to `skills` list
- Return `skills`

**Endpoint 2 — POST /skills (SKIL-01 create):**
- Signature: `async def create_skill(body: SkillCreate, current_user: dict = Depends(get_current_user), supabase: Client = Depends(get_supabase))`
- Response model: `SkillResponse`, status 201
- Insert dict: `{"user_id": current_user["id"], "name": body.name.strip(), "description": body.description, "instructions": body.instructions, "is_global": body.is_global}`
- Call `supabase.table("skills").insert({...}).execute()`
- Return `result.data[0]`

**Endpoint 3 — PATCH /skills/{skill_id} (SKIL-02):**
- Signature: `async def update_skill(skill_id: str, body: SkillUpdate, current_user: dict = Depends(get_current_user), supabase: Client = Depends(get_supabase))`
- Response model: `SkillResponse`
- Build update dict from `body.model_dump(exclude_none=True)` — if `"name"` key present, strip whitespace: `update_data["name"] = update_data["name"].strip()`
- If `update_data` is empty, raise 400 with detail "No fields to update"
- Call `supabase.table("skills").update(update_data).eq("id", skill_id).eq("user_id", current_user["id"]).execute()`
- If `not result.data`, raise 404 "Skill not found"
- Return `result.data[0]`

**Endpoint 4 — DELETE /skills/{skill_id} (SKIL-03):**
- Signature: `async def delete_skill(skill_id: str, current_user: dict = Depends(get_current_user), supabase: Client = Depends(get_supabase))`
- Status 204, no response model
- Step 1: Fetch all file_paths — `supabase.table("skill_files").select("id, file_path").eq("skill_id", skill_id).eq("user_id", current_user["id"]).execute()`
- Step 2: Remove each from storage — `for f in files.data: try: supabase.storage.from_("skill-files").remove([f["file_path"]]) except Exception: pass`
- Step 3: Delete skill row — `supabase.table("skills").delete().eq("id", skill_id).eq("user_id", current_user["id"]).execute()`

**Endpoint 5 — PATCH /skills/{skill_id}/toggle-enabled (SKIL-04):**
- Signature: `async def toggle_enabled(skill_id: str, current_user: dict = Depends(get_current_user), supabase: Client = Depends(get_supabase))`
- Response model: `SkillResponse`
- Step 1: Fetch current — `supabase.table("skills").select("*").eq("id", skill_id).eq("user_id", current_user["id"]).maybe_single().execute()`
- If `not current.data`, raise 403 "Skill not found or you are not the owner"
- Step 2: Compute `new_value = not current.data["is_enabled"]`
- Step 3: Update — `supabase.table("skills").update({"is_enabled": new_value}).eq("id", skill_id).eq("user_id", current_user["id"]).execute()`
- Return `result.data[0]`

**Endpoint 6 — PATCH /skills/{skill_id}/toggle-global (SKIL-05, SKIL-06):**
- Identical structure to toggle-enabled but toggles `is_global` instead of `is_enabled`
- Same 403 error for non-owners
- Return `result.data[0]`
