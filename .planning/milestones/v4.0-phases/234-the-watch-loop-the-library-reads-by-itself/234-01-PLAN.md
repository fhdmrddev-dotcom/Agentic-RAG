<task_id>234-01-02</task_id>
<description>Create backend/app/db/watches.py with atomic claim and CRUD operations</description>
<action>
Author `backend/app/db/watches.py`:
- `claim_due_watches(pool: asyncpg.Pool, limit: int = 10, lease_seconds: int = 600) -> list[dict]`:
  Runs in transaction with `FOR UPDATE SKIP LOCKED`.
  Queries `connector_watches` where `is_active = true AND next_run_at <= now() AND (leased_until IS NULL OR leased_until < now())`.
  Updates `leased_until = now() + interval '1 second' * lease_seconds`, `last_run_at = now()`.
  Returns claimed watch records.
- `release_watch(pool, watch_id, status, error=None, next_run_at=None)`: Clears `leased_until`, sets `last_status`, `last_error`, advances `next_run_at`.
- `get_watch_items(pool, watch_id)`: Reads all items for a watch.
- `upsert_watch_items(pool, watch_id, items: list[dict])`: Bulk upsert on `(watch_id, external_id)`.
- `update_item_states(pool, item_ids, state, missing_since=None)`: Updates lifecycle status.
- `record_skipped_still_running(pool, watch_id)`: Records observable status when lease is active.
</action>
