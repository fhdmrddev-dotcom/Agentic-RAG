<objective>
Implement security fences, lifecycle policies, and rule retirements for Phase 234:
1. Classification Access Fence (`H-4` / `VIS-06`): In `backend/app/api/documents.py:1847` (`accept_classification`), check if the document originated from a connection (`source_connection_id IS NOT NULL`). If document's `ingest_visibility` is `'private'` and destination folder has `is_org_shared == True` (queried from `folders`), reject the automated move unless `force=True`.
2. Anti-Injection Trifecta Defense (`TRUST-03`): In `backend/app/services/tool_dispatcher.py` (`dispatch_connector_tool`), if `_is_write` is True and the current run's retrieval context contains connection-sourced content (`source_connection_id IS NOT NULL`), force `posture = 'ask'`, triggering the shipped Redis pubsub approval checkpoint naming the source connection. (Leaves `agent_loop.py` byte-identical, completely avoiding SC#10 invocation).
3. Disconnect Freeze Policy (`VIS-05` / `D-4`): In `backend/app/api/connectors.py`, when a connection is disconnected or revoked, mark its watches `is_active=false` and mark its documents `source_state='source_disconnected'`.
4. Standing Rule Retirement (`SEED-142`): Retire `CLAUDE.md` line 34 ("Ingestion is manual file upload only...") in this same commit, documenting automated watching as an active platform capability.
5. Author dedicated test suites for each security fence.
</objective>
