       class MintResult:

    2. Implement `mint_document_row`:
       - Signature (G-2):
         ```python
         def mint_document_row(
             *,
             raw: bytes,
             filename: str,
             mime_type: str,
             user_id: str,
             supabase: Client,
             folder_id: str | None = None,
             metadata: dict | None = None,
             org_id: str | None = None,
             on_conflict: Literal["raise", "link"] = "raise",
         ) -> MintResult:
         ```
       - Validation (G-1):
         - If `folder_id`: query `folders` table `(id, user_id)`. If missing, raise HTTPException(404, "Folder not found"). If `folder.user_id != user_id`, raise HTTPException(403, "Cannot upload to a folder you do not own") — byte-for-byte parity with `documents.py:610-617`.
       - Hashing: `content_hash = hashlib.sha256(raw).hexdigest()`.
       - Deduplication query:
         - Query `documents` where `user_id == user_id`, `content_hash == content_hash`, `status == 'completed'`, `is_latest == True`.
         - If `folder_id`: `.eq("folder_id", folder_id)`. Else: `.is_("folder_id", "null")`.
         - If existing match found: return `MintResult(document=existing.data[0], is_duplicate=True, storage_path=existing.data[0].get("file_path", ""), version_number=existing.data[0].get("version_number", 1))`.
       - Versioning:
         - Query `documents` for `(user_id, filename)` ordered by `version_number` desc limit 1.
         - If found: `next_version = existing[0]["version_number"] + 1`; update prior records with `is_latest=False` for `(user_id, filename)`.
         - Else: `next_version = 1`.
       - Document INSERT (G-4: omit created_at/updated_at to preserve DB default timestamps):
         - Generate `document_id = str(uuid4())`.
         - Canonical `storage_path = f"{user_id}/{document_id}/{filename}"`.
         - Build `doc_data`:
           ```python
           doc_data = {
               "id": document_id,
               "user_id": user_id,
               "filename": filename,
               "file_path": storage_path,
               "file_size": len(raw),
               "mime_type": mime_type,
               "status": "pending",
               "content_hash": content_hash,
               "folder_id": folder_id,
               "version_number": next_version,
               "is_latest": True,
           }
           if metadata:
               doc_data["metadata"] = metadata
           ```
         - Execute `insert(doc_data)`. Catch `Exception` containing `"23505"`:
           - If `on_conflict == "link"` (G-2):
             Re-query `documents` table for `user_id == user_id`, `content_hash == content_hash`, `status.neq."failed"`, and matching `folder_id`. If found, return `MintResult(document=existing.data[0], is_duplicate=True, storage_path=existing.data[0].get("file_path", ""), version_number=existing.data[0].get("version_number", 1))`.
           - If `on_conflict == "raise"`:
             raise HTTPException(409, "File already exists in this folder").
         - Return `MintResult(document=result.data[0], is_duplicate=False, storage_path=storage_path, version_number=next_version)`.
    3. Implement `async_mint_document_row`:
       - Calls `run_in_threadpool(lambda: mint_document_row(...))`.
    4. Implement `splice_document` (G-3: pin intermediate status/ingestion_step sequence):
       - Step 1: If `storage_path`: attempt `supabase.storage.from_("documents").upload(path=storage_path, file=raw, file_options={"content-type": mime_type})`. Catch `Exception` and log warning (non-blocking, D-14).
       - Step 2: Set `status='processing', ingestion_step='extracting'` before extraction. Run Layer 2 extraction with wall-clock timeout (`130.0`s) via `extract_composable`.
       - Step 3: Call `ingest_document(document_id, text, user_id, supabase, raw, mime_type, filename, None, extracted_doc, extract_duration_ms)`. `ingest_document` advances step to `'embedding'` during chunking/embedding, `'multimodal'` during table/image chunks, and finalizes with `status='completed'`.
       - Step 4: Catch unhandled exception: `supabase.table("documents").update({"status": "failed", "ingestion_step": "failed", "error_message": str(exc)[:250]}).eq("id", document_id).execute()`.
