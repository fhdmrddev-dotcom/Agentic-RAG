<objective>
Refactor the email attachment cascade in `backend/app/api/documents.py` to use The One Ingest Splice, isolating per-attachment failures and resolving duplicate collisions (TRUST-01, SC#3, D-06, D-09..D-12, D-16, G-2, G-5, G-6):
1. Replace the blanket outer `try...except` in `documents.py` with an isolated per-attachment loop.
2. Delegate attachment row creation to `mint_document_row(..., on_conflict="link")`:
   - If duplicate (including 23505 collision with pending rows): link existing document via `document_relationships` ('attached_to') without re-ingesting or colliding.
   - If new: upload to storage, link relationship, extract and ingest.
3. Record full attachment outcomes (`status`, `doc_id`, `error`) in parent email's `metadata["attachments"]` manifest.
4. Mark failed child attachment documents as `status='failed'` with `error_message` rather than leaving orphaned `pending` rows.
5. Author integration test suite `backend/tests/integration/test_email_attachment_cascade_splice.py` proving SC#3 and the BUS-106 identical attachment deduplication inference, drivable through the real email upload door (`POST /documents/upload` with `.eml`).
</objective>

    3. Around line 2367 (`if mime_type in ("message/rfc822", "application/vnd.ms-outlook", "application/x-msg"):`):
       - Initialize `attachment_manifest = []`.
       - For each `att` in `parsed_email.attachments`:
         - If not `att.raw` or not `att.filename`: continue.
         - Wrap processing for this individual attachment in `try...except Exception as att_err:`:
           - Resolve `att_mime` with extension overrides.
           - If `att_mime not in ALLOWED_MIME_TYPES`:
             - Record in manifest: `{"filename": att.filename, "status": "skipped", "error": f"MIME type {att_mime} not allowed"}`.
             - Continue.
           - Call `mint_result = mint_document_row(raw=att.raw, filename=att.filename, mime_type=att_mime, user_id=user_id, supabase=supabase, folder_id=None, on_conflict="link")`.
           - `att_doc = mint_result.document`.
           - `att_doc_id = att_doc["id"]`.
           - If `mint_result.is_duplicate`:
             - Create `document_relationships` link: `{"user_id": user_id, "source_doc_id": att_doc_id, "target_doc_id": document_id, "rel_type": "attached_to"}`.
             - Record in manifest: `{"filename": att.filename, "status": "linked", "document_id": att_doc_id, "is_duplicate": True}`.
             - Continue to next attachment (skips redundant extraction/chunking, resolves G-2).
           - If new document:
             - Upload to storage: `supabase.storage.from_("documents").upload(path=mint_result.storage_path, file=att.raw, file_options={"content-type": att_mime})`.
             - Create `document_relationships` link: `{"user_id": user_id, "source_doc_id": att_doc_id, "target_doc_id": document_id, "rel_type": "attached_to"}`.
             - Extract text: `att_text = extract_text(att.raw, att_mime)`.
             - Call `ingest_document(document_id=att_doc_id, text=att_text, user_id=user_id, supabase=supabase, raw=att.raw, mime_type=att_mime, filename=att.filename, engine_override="legacy")`.
             - Record in manifest: `{"filename": att.filename, "status": "completed", "document_id": att_doc_id}`.
         - In the `except Exception as att_err:` block:
           - Log detailed warning: `log.warning("Email attachment '%s' processing failed for parent %s: %s", att.filename, document_id, att_err)`.
           - If child `att_doc_id` was minted: update `supabase.table("documents").update({"status": "failed", "error_message": str(att_err)[:250]}).eq("id", att_doc_id).execute()`.
           - Record in manifest: `{"filename": att.filename, "status": "failed", "error": str(att_err)[:250]}`.
           - Continue (DO NOT break or re-raise; process subsequent attachments!).
       - When updating parent document metadata at completion (around line 2535):
         - Include `metadata_dict["attachments"] = attachment_manifest`.
