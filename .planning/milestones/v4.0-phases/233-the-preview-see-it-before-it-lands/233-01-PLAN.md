<objective>
Build the diff pass. One classifier, run twice: once with `dry_run=True` for the preview, once for
real at confirm.

1. **`preview_service.py`**
   - `Bucket = Literal["add", "here", "uns", "unk"]`.
   - `PreviewItem` — `external_id, name, mime_type, size, modified_at, bucket, fragment (<=24 chars),
     reason (full sentence), destination (str|None), rule_suggested (bool)`.
   - `SourcePreview` — `items`, `counts` (four keys), `total`, `folder_id`, `folder_name`,
     `wrote = {"documents":0,"chunks":0,"jobs":0,"folders":0}`.
   - `classify_source_file(file, known: dict[str, str], supported: set[str]) -> (bucket, fragment, reason)`
     — PURE. `known` maps `external_id -> source_version` for documents already in the Library.
     Rules, in order:
       1. `known.get(id) == file.modified_at` → **here** · fragment `same file, unchanged` ·
          reason names *"Matched by source file, not by content: the bytes have not been compared."*
          ⛔ the word `hash` must not appear.
       2. Google native Docs/Sheets (`application/vnd.google-apps.document|spreadsheet`) → **unk** ·
          `no hash for Docs` · exported at read time, Drive publishes no content hash for natives.
       3. `application/vnd.google-apps.shortcut` → **unk** · `shortcut, target unread`.
       4. `application/octet-stream` or no extension → **unk** · `no extension`.
       5. `application/pdf` → **unk** · `may have no text` (image-only PDFs are only knowable on read).
       6. mime in `ALLOWED_MIME_TYPES` (imported from `app.api.documents`) → **add**.
       7. otherwise → **uns** · fragment is the mime · reason says nothing is imported.
   - `build_preview(connection, folder_id, folder_name, user_id, org_id, supabase, page_size)` —
     lists via `SourceRegistry.get_adapter(connection).list_files(...)`, builds `known` from
     `documents` where `metadata->source->>system` matches and `source_connection_id` = this
     connection, evaluates routing rules as a READ (`classification_rule_service.list_rules` +
     `classification_matcher.match_metadata` over `{filename, mime_type, date}`), sets
     `destination` + `rule_suggested`. ⛔ No insert, no upsert, no folder mint, no audit write.
   - `confirm_preview(...)` — re-runs `build_preview`, then for each item:
     `add` → import; `unk` → read it and let `mint_document_row`'s tier-2 `sha256` settle it
     (duplicate ⇒ `here`, mint/extract failure ⇒ `refused` with a named cause); `here`/`uns` →
     carried through as `here`/`refused`. Returns `{outcomes: [...], accounted, unaccounted,
     preview_said_added, actually_added}`. `unaccounted` must be 0.

2. **`import_service.import_single_file`** — accept `external_id` + `source_version` and stamp
   `metadata.source`. `preview_service` reuses it rather than growing a second mint call.

3. **Routes in `connectors.py`** — `POST /connections/{id}/preview` and
   `POST /connections/{id}/preview/confirm`, both org-scoped through `connector_service.get_connection`.

4. **Response models in `models/connector.py`** — `SourcePreviewResponse`, `SourcePreviewItem`,
   `SourceConfirmResponse`, `SourceConfirmOutcome`. `outcome` is `Literal["added","here","refused"]`.

5. **Two pytest suites** — the classifier's four buckets + no-shrug rule; the service's
   writes-nothing receipt + preview/confirm agreement.
</objective>
