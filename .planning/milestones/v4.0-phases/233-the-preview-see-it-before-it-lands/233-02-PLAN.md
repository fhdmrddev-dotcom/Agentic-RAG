<objective>
Build the surface the operator locked, and give `SourceFolderPicker` its first home.

1. **`previewVocabulary.ts`** — a strict leaf, zero imports. The four verbatim labels, the
   *by source file, not content* qualifier, the zero-write sentence, the Cancel toast, the
   reconciliation template, and the three outcome words. ⛔ The string `hash` must not appear.

2. **`SourcePreviewPanel.tsx`** — 229-C at rest, 230-A on confirm.
   - **The bar** — four segments (`add` / `here` / `uns` / `unk`) whose widths are the counts as a
     percentage of the total. The `unk` segment is **hatched and animating**; the others settle.
   - **The legend** — four items, each a count + label; the `here` item carries the qualifier.
   - **The accordions** — four `<section>`s rendered unconditionally, each header showing
     `label + count` **always visible**, body toggling open. `unk` opens by default.
   - **Rows** — name, extension mark, a 3-4 word fragment; the full reason is a `title=`/tooltip,
     never printed at rest. `add` rows show their destination and a `rule` mark when suggested.
   - **The footer** — the zero-write line, `Cancel`, and `Add N · read M`.
   - **On confirm** — POST to the confirm route, then dissolve: `unk` width shrinks, a red
     `refused` segment appears, each refusal row shows its named cause, and the reconciliation
     line renders. `outcome` is typed to exactly three values.

3. **`IngestionTab.tsx`** — a new *From a connected source* block under **Add files**: a connection
   select (source-capable connections only), `SourceFolderPicker`, and `SourcePreviewPanel` for the
   chosen folder. ⛔ Not a new tab, and the existing four sub-tabs are untouched.

4. **`LibraryPage.tsx`** — `max-w-6xl w-full mx-auto` on the page container (D-233-07). ⚠ Eyeball
   the Documents tab: its 7-column table sheds columns 3-5 by `nth-child` and must keep doing so.

5. **`lib/api/connectors.ts` + `types/index.ts`** — `previewSource()` and `confirmSourcePreview()`
   beside `browseSourceFolders`, with `SourcePreview` / `SourcePreviewItem` / `SourceConfirmOutcome`
   wire types.

6. **Two vitest suites**, mirroring the sketches' `drive.cjs` invariants against the React build:
   verbatim labels · no hash claim in the `here` region · four sections with no removal control ·
   collapse hides files not counts · every `unk` row carries a full reason · every `add` row carries
   a destination · counts sum to total · the zero-write footer + Cancel toast · a refusal names a
   cause · `outcome` has exactly three values.

7. **`scripts/vitest-count-gate.cjs`** — add both suites to `TARGETS` **and** pin both in
   `BASELINE`, in this same commit. A `BASELINE` key naming a file that does not exist makes the
   gate ERROR; a `TARGETS` entry without a `BASELINE` pin makes the suite run and guard nothing.
</objective>
