# 239-01 — McpSourceAdapter and Universal Conformance

**Goal (SC#1, SC#2, SC#3):** Deliver `McpSourceAdapter` implementing the `SourceAdapter` contract (`browse`, `list_files`, `read_file`, `check`) by delegating to `mcp_client.call_tool` and `mcp_client.list_tools`, with tool bindings stored as **data in `config["source_tools"]`**, protocol-level resolution in `SourceRegistry` without vendor branching above `adapters/`, and full membership in the universal conformance test suite.

## Why this is one plan and not two

The adapter, its protocol resolution in `SourceRegistry`, the `McpConfig` model allowance for `source_tools`, and the conformance suite must land together. An adapter without registration is unresolvable; registry changes without the adapter fail import; and `McpConfig` without `source_tools` raises `ValidationError` under `extra='forbid'` (the SEED-239 outage mode). One atomic plan in Wave 1.

<threat_model>
<trust_boundaries>
External MCP Server (Untrusted / Semi-trusted) -> McpClient (SSRF & egress fence) -> McpSourceAdapter -> WatchService / PreviewService / Ingestion
</trust_boundaries>
<threats>
- threat_id: TM-239-01
  category: Server-Side Request Forgery (SSRF) / Egress Bypass
  component: McpSourceAdapter / McpClient
  disposition: mitigated
  mitigation_plan: All outbound communication funnels through `McpClient.call_tool` and `list_tools`, which enforce `validate_mcp_destination` (blocking RFC1918 private IPs and cloud metadata). No raw HTTP clients.
- threat_id: TM-239-02
  category: Privilege Escalation via Untrusted Annotations
  component: McpSourceAdapter / tool discovery
  disposition: mitigated
  mitigation_plan: Server-advertised hints (`readOnlyHint`, annotations) are informational only and NEVER used to grant permissions or bypass confirmation fences.
- threat_id: TM-239-03
  category: Denial of Service / Memory Exhaustion
  component: McpSourceAdapter.read_file
  disposition: mitigated
  mitigation_plan: Enforce `MAX_FILE_BYTES` ceiling (25MB, matching google_drive and microsoft_graph) on decoded text/binary payloads.
- threat_id: TM-239-04
  category: Denial of Service / Schema Validation Crash (SEED-239)
  component: backend/app/models/connector.py (McpConfig)
  disposition: mitigated
  mitigation_plan: Explicitly add `source_tools: dict[str, str] | None = None` to `McpConfig` so valid JSONB configurations do not violate `extra='forbid'` and crash list queries.
</threats>
</threat_model>

<action>
Create `backend/app/services/sources/adapters/mcp_source.py`:
- Decorate class with `@SourceRegistry.register("mcp")` and `@SourceRegistry.register("custom_mcp")`.
- Constants: `MAX_FILE_BYTES = 25 * 1024 * 1024`, `DEFAULT_LIST_TOOL = "list_directory"`, `DEFAULT_READ_TOOL = "read_file"`.
- Extraction helper `_get_mcp_params(connection)`:
  - Extracts `server_url` from `connection.mcp_server_url` or `config.get("mcp_server_url")`.
  - Extracts `secret` if present (or None).
  - Extracts `auth_scheme` from connection auth type if known.
  - Extracts `source_tools` dict from `connection.config.get("source_tools", {})`.
  - Resolves `list_tool = source_tools.get("list_tool") or DEFAULT_LIST_TOOL`.
  - Resolves `read_tool = source_tools.get("read_tool") or DEFAULT_READ_TOOL`.
- Result parser `_parse_tool_listing(raw_result, folder_path)`:
  - If output is JSON or structured list, parse items: `name`, `path`, `type` (`"file"` vs `"directory"`), `size`, `modified_at` / `mtime`.
  - If output is text string, parse line-by-line: recognize `[DIR]`, `[FILE]` or standard `ls` outputs.
  - Compute fallback deterministic `modified_at` (e.g. `f"size:{size}"` or hash) when timestamp is absent.
- `browse(connection, folder_id=None, page_token=None) -> BrowsePage`:
  - Calls `mcp_client.call_tool(server_url, list_tool, {"path": folder_id or ""})`.
  - Filters and returns `BrowsePage(items=[SourceNode(...)])`.
- `list_files(connection, folder_id=None, recursive=False, page_token=None, query=None, page_size=30) -> FilePage`:
  - Calls `mcp_client.call_tool(server_url, list_tool, {"path": folder_id or ""})`.
  - Filters and returns `FilePage(files=[SourceFile(...)])`.
- `read_file(connection, file_id) -> tuple[str, bytes, str]`:
  - Calls `mcp_client.call_tool(server_url, read_tool, {"path": file_id})`.
  - Extracts content: decodes `TextContent` or base64 resource. Enforces `MAX_FILE_BYTES`.
  - Returns `(filename, content_bytes, mime_type)`.
- `check(connection) -> SourceHealth`:
  - Calls `mcp_client.list_tools(server_url)`.
  - Returns `SourceHealth(ok=True, details={"tools_count": len(tools)})` or `SourceHealth(ok=False, error=str(err))`.
- Keep file concise and modular (target ≤ 350 lines).
</action>
