# 239-03 — Honesty Fix for BUG-260907-01 (Ready as source)

**Goal (BUG-260907-01, D-239-08):** Stop displaying `⚠ Not usable` on working source connections that have zero action tools (e.g. OneDrive or MCP file servers). Derive `"source-only"` verdict when `toolCount <= 0` and `isSourceCapable === true`, and render an emerald `✓ Ready as source` badge in Settings → Connections.

## Why this is one plan and not two

The verdict derivation (`connectionRowVerdict.ts`), state word mapping (`connectionsCopy.ts`), source capability check (`sourceCapability.ts`), and list row display (`ConnectionsTab.tsx`) form a unified presentation seam. A verdict type without display mapping causes render errors; copy changes without verdict derivation leave the bug open.
