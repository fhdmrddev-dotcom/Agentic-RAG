       - `EMBED_MAX_INPUTS_PER_BATCH = 512` (well under 2,048 limit)

    4. Execution:
       - If only 1 batch, call `client.embeddings.create(model=effective_model, input=batch)` directly.
       - If multiple batches, execute sequentially (or gather), appending embeddings to a combined result list.
    5. Invariant assertion:
       - `if len(all_embeddings) != len(texts): raise ValueError(f"Mismatched embedding count: got {len(all_embeddings)} for {len(texts)} inputs")`
       - Return `all_embeddings`.
