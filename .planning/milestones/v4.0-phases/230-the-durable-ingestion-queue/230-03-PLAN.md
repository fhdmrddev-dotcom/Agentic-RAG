  <action>
    Create `backend/app/services/ingestion_queue_service.py` implementing `IngestionQueueService`:
    1. Properties:
       - `pool: asyncpg.Pool`
       - `supabase_factory: Callable[[], Client]`
       - `semaphore: asyncio.Semaphore` (bounded by `settings.ingest_max_concurrent_jobs`)
       - `worker_id: str`
       - `circuit_breaker: CircuitBreaker`
       - `is_running: bool`
       - `last_sweep_at: float`
    2. Poller loop (`_poll_loop`):
       - While `self.is_running`:
         - Periodic stale-claim sweep (G-1 mechanism):
           If `time.time() - self.last_sweep_at > 60`:
             `await reclaim_stale_ingestion_claims(self.pool, lease_timeout_seconds=settings.ingest_lease_timeout_seconds)`
             `self.last_sweep_at = time.time()`
         - If `self.circuit_breaker.is_tripped`:
           - Run probe check (half-open test). If provider recovers, reset breaker and call `resume_paused_jobs(self.pool)`.
           - Else sleep and continue.
         - Acquire semaphore slot.
         - Claim due jobs via `claim_due_ingestion_jobs(self.pool, limit=available_slots, worker_id=self.worker_id)`.
         - For each claimed job, spawn `asyncio.create_task(self._process_job(job))`.
         - Sleep `settings.ingest_poll_interval_seconds`.
    3. Job execution (`_process_job`):
       - Fetch document row from Supabase.
       - Read checkpoint stage and chunk offset from `job["progress"]`.
       - Execute `splice_document` with checkpoint recovery.
       - On success: call `record_job_success(self.pool, job["id"])`.
       - On failure:
         - Inspect error: Is it 429/insufficient_quota/provider outage?
           - Identify provider name (e.g. "openai").
           - Attempt same-model alternate endpoint if configured (never cross-provider per D-2).
           - If failover exhausted: trip `self.circuit_breaker`, call `pause_jobs_for_provider(self.pool, refusal_reason=f"{provider}: {exc}")`.
         - Else (transient): calculate backoff delay (`min(60, 2 ** retry_count + jitter)`) and call `record_job_failure(self.pool, job["id"], is_transient=True)`.
       - Release semaphore slot in `finally`.
  </action>

  </verify>
</task>
