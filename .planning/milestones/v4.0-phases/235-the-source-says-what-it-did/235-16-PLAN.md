<objective>
Close gap G1a — the BLOCKER, and this closure round's reason for existing.

Purpose: the run history renders `Checked {ago} · {N} files`, where `N` is the sum of all six stored counts. The
approved design (sketch 233 `renderRun`, `index.html:478-491`, binding via the generated BUILD-CONTRACT) renders
a per-category breakdown. The six counts are ALREADY stored, ALREADY on the wire, and ALREADY in the component's
props — they are simply summed on arrival. This is ROADMAP failure mode #3 stated word for word — *"the run
history shows counts but not the reason a file failed, so the one action that fixes it cannot be chosen"* —
realised inside the phase written to prevent it. ⛔ This is pure rendering. No endpoint, no column, no fetch.

Output: `RunHistoryList` renders what each check actually did, and a suite that fails on CONTENT drift rather
than on a missing element.
</objective>
