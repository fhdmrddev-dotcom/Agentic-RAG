<objective>
Close two small truth defects the verification found: the Library gets stuck on its Health tab forever after one
badge click, and a docblock asserts an invariant the shipped tree breaks.

Purpose: `App.tsx:176-180` sets `libraryTab = "health"` and never resets it. `LibraryPage` unmounts on navigation
away and re-seeds its reducer from `initialTab` on EVERY return, so after a single popover click the Library
opens on Health forever — contradicting `App.tsx`'s own comment (*"`undefined` means 'the page decides', so the
Library keeps its own default on every other entry into it"*). Separately, `attentionConditions.ts` states that a
second `useSourceAttention()` in the same tree means *"two disagreeing answers"*; the shipped tree HAS two, and
they cannot disagree, because the threshold is applied on the server. A docblock that is wrong in a scary
direction is worse than either fix — it will send a future author chasing a divergence that cannot happen.

Output: a one-shot handoff with a test that can actually fail, and a docblock that says what is true.
</objective>
