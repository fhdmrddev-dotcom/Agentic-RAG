Give the counts dict a home, and make every release of a watch write one row into it.

can see what a sync actually did"* — is unanswerable until that dict is stored. This plan builds the table,
the writer and the two reads; Plan 05 threads the real values in at the four seams.

Output: `172_connector_sync_runs.sql`, a `release_watch` that writes and prunes in one statement, an
owner-predicated history read, a windowed multi-watch read for the verdict, and the retention knob.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated user JWT → PostgREST | a user reading their own sync history through Supabase |
| FastAPI route → asyncpg pool | ⚠ **NOT RLS-gated** — ownership is enforced in SQL by this DAL |
| background watch loop → asyncpg pool | writes history for a user it is acting on behalf of |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-235-01 | Information disclosure | `list_sync_runs` over the pool | mitigate | `AND user_id = $2` in the SQL itself, matching `get_watch:96-103`; a `watch_id` guess returns zero rows |
| T-235-02 | Information disclosure | `connector_sync_runs` via PostgREST | mitigate | RLS Shape A, four policies, predicate copied verbatim from migration 168 |
| T-235-03 | Denial of service | unbounded history growth | mitigate | prune-on-write to `watch_run_history_retention` (200) in the same statement as the insert |
| T-235-04 | Tampering | SQL injection through the retention bound | mitigate | `retain` is an int from `config.py`, bound as `$n`, never interpolated into the statement |
| T-235-05 | Repudiation | a failed insert silently losing history | accept | inherits `release_watch`'s swallow-and-log; losing a history row must never fail a real sync. Logged via `logger.exception`; the visible consequence is a gap the UI renders honestly |
| T-235-SC | Tampering | package installs | n/a | **This plan installs no npm/pip/cargo package.** No legitimacy gate applies |
</threat_model>
