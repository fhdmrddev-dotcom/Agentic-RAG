Close gap G2: `/sources/health` computes `last_good_at` over a five-row window, so a source that has failed more
ticks than that window is deep reports `None` — and every surface then renders NOTHING. SC#2's sentence is
*"says when it last succeeded"*, and silence is not that answer.

unbounded run list proves it), so the residual defect is silence rather than a lie. Fixing it on the SERVER fixes
BOTH surfaces at once — the source card and the Library Health row — with no client derivation and no second
verdict, which is what D-235-05 exists to protect.

Output: one aggregate query, called only for sources already judged stopped, and the corrected docblock.
</objective>
