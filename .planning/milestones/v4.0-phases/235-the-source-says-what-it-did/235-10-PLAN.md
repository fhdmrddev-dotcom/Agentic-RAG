<objective>
Build the surface the sketch settled: a healthy source is one line, a stopped source says what happened and
offers the one thing that fixes it, and every run it has made is one click away.

Purpose: this is the card SC#1 and SC#2 are written about. Today it renders `Last check error:
{watch.last_error}` — a raw exception string — decides "disconnected" by substring-sniffing that same string,
says `Sync scheduled for ...` after a click that may reach nothing, and falls back to
`window.location.href = "/settings/connections"` in an app with no router (measured: `IngestionTab` mounts this
component WITHOUT `onNavigateToConnections`, so that fallback is the LIVE path).

Output: the variant-B card, the run-history expansion, the one control per cause, the pending state, the
degraded row, and the instance statement once above the tabs.
</objective>
