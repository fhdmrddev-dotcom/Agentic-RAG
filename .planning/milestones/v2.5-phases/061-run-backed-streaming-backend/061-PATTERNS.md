**Existing `_BACKGROUND_TASKS` registry** (lines 50-64):
```python
# WR-05: retain strong references to fire-and-forget background tasks so the
# event loop does not garbage-collect them mid-execution (Python docs:
# asyncio.create_task only weakly references the returned task). Without a
# strong reference, audit-log and memory writes can be silently dropped with
# the warning "Task was destroyed but it is pending!". Tasks self-evict from
# the set via the done-callback so it never grows unbounded.
_BACKGROUND_TASKS: set[asyncio.Task] = set()


def _spawn(coro) -> asyncio.Task:
    """Schedule a fire-and-forget coroutine and retain a strong reference."""
    t = asyncio.create_task(coro)
    _BACKGROUND_TASKS.add(t)
    t.add_done_callback(_BACKGROUND_TASKS.discard)
    return t
```

  all entries. 062's DELETE /runs/{id} will look up the run_id here.

  Single uvicorn worker (D-v2.5-02) means one registry per process.
  """
  import asyncio
  import uuid

  RUN_TASKS: dict[uuid.UUID, asyncio.Task] = {}
  TERMINAL_TYPES = frozenset({"done", "error", "cancelled"})


  def register(run_id: uuid.UUID, task: asyncio.Task) -> None:
      RUN_TASKS[run_id] = task
      task.add_done_callback(lambda _t: RUN_TASKS.pop(run_id, None))


  def get(run_id: uuid.UUID) -> asyncio.Task | None:
      return RUN_TASKS.get(run_id)


  async def cancel_all() -> None:
      for task in list(RUN_TASKS.values()):
          if not task.done():
              task.cancel()
      if RUN_TASKS:
          await asyncio.gather(*RUN_TASKS.values(), return_exceptions=True)

### `asyncio.shield`-protected end-of-stream finalizer

**Source:** `backend/app/api/threads.py:1817-1845` (the existing 058/059 shielded persist).
**Apply to:** the new shielded finalizer that does (a) `_persist_assistant_message`, (b) terminal sentinel XADD, (c) `runs` row UPDATE, (d) `EXPIRE` + ZREM.
**Pattern:**
```python
async def _shielded_finalize():
    try:
        await _persist_assistant_message()
        # Phase 061 additions:
        await _emit(redis, run_id, terminal_type, error=err_value)
        await aexec(supabase.table("runs").update({...}).eq("run_id", str(run_id)))
        await redis.expire(f"run:{run_id}", ttl)
        await redis.zrem("runs:active", str(run_id))
        await redis.zrem(f"runs_by_thread:{thread_id}", str(run_id))
    except BaseException:
        logger.exception("Shielded finalize failed")
try:
    await asyncio.shield(_shielded_finalize())
except asyncio.CancelledError:
    raise
finally:
    RUN_TASKS.pop(run_id, None)
```
**Why this pattern:** the producer is a background task whose lifetime outlives the route handler; without shield, app-shutdown CancelledError (lifespan close) would skip the persist/finalize. **CRITICAL ORDERING (RESEARCH.md pitfall):** terminal sentinel XADD MUST precede `EXPIRE` — otherwise a 60s TTL on a `failed` run can race the consumer's BLOCK 5000 and the consumer never sees the terminal type.
