1. **D-067.4-R3-01 branch (b) fix** — bump `max_completion_tokens` 200→2000 at `backend/app/services/suggestion_service.py:70` AND `:87` (the NotFoundError fallback retry). Reason: `gpt-5.4-mini` (the resolved sub-agent default for `active_provider="openai"`) is a GPT-5+ family reasoning model whose `max_completion_tokens` is a UNIFIED budget for visible content + chain-of-thought. At 200 tokens the chain-of-thought consumes the cap → `content=""` → empty `questions`. 2000 is the empirical floor.
2. **D-067.4-R3-02 always-emit-empty fix** — at `backend/app/api/threads.py:2487-2526`, change the `if questions:` gate to UNCONDITIONAL emit. Removes the SSE-replay ambiguity dimension (3 states → 2 states). The frontend gate at `MessageItem.tsx:93-98` already short-circuits empty arrays via `message.suggestions.length > 0` — no frontend change needed.
3. **D-067.4-R3-03 `run_in_threadpool` wrap** — same line edit; wrap the synchronous `generate_suggestions(...)` call in `await run_in_threadpool(generate_suggestions, body.content, full_content, user_settings)`.
