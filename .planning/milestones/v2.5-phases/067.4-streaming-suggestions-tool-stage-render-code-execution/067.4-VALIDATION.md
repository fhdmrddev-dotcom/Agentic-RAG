## Sampling Rate

- **After every task commit:** Run targeted `pytest tests/<file> -x` (backend) AND `npx vitest run <pattern>` (frontend if touched). ≤30s per task.
- **After every wave merge:** Run full `pytest -x` (backend) + full `npm run test` (frontend).
- **Before `/gsd-verify-work` (Plan 05 entry):** Both full suites must be green.
- **Phase gate:** Both full suites green AND Plan 05 closing UAT 12/12 GREEN before phase closes (cross-phase closure to 067.2 + 067.3).
- **Max feedback latency:** ~30 seconds per task commit.
