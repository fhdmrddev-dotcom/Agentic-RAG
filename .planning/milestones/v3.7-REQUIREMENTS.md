# Requirements — v3.7 Workflow Product Completion

**Milestone:** v3.7 · **Opened:** 2026-08-10 · **Closed:** 2026-08-24 · **Status:** Completed (20/20 Satisfied)

**Goal:** make the workflow product built across v2.8→v3.6 usable end to end — find it, understand
the door, build it with the right vocabulary, stop it, see what it produced.

**Provenance:** every requirement below traces to a seed the operator planted during earlier UAT, or
to a measured finding from the 2026-08-10 product review.

---

## v3.7 Requirements

### Library — finding and choosing a workflow (LIB)

- [x] **LIB-01**: A user can search the Workflows page by name and filter the list, instead of scanning three unlabelled shelves. *(SEED-136 — Satisfied Phase 192)*
- [x] **LIB-02**: A workflow card shows what the workflow is for, at a glance, without the reader having to decode internal vocabulary. *(SEED-136 — Satisfied Phase 192)*
- [x] **LIB-03**: A user can predict what each card action does before clicking — in particular, "Tweak" must not silently open a full edit surface. *(SEED-136 — Satisfied Phase 192)*
- [x] **LIB-04**: The create affordance is findable without scrolling past two shelves of existing workflows. *(SEED-136 — Satisfied Phase 192)*
- [x] **LIB-05**: A user can tell one workflow from another at a glance — which row is which when many share a name, whose it is and what it was copied from, and which one changed most recently. *(Phase 192.1 — Satisfied)*
- [x] **LIB-06**: A user can tell from the library whether a workflow actually **works** — when it last ran and whether that run succeeded. *(Phase 192.2 — Satisfied)*

### Presentation — how the workflow product reads (DES)

- [x] **DES-01**: Every surface of the workflow product is presented in the language of the adopted design mindset — hierarchy and composition carry the meaning. *(Phase 199 — Satisfied)*
- [x] **DES-02**: A person watching or reviewing a workflow run can tell **how long each step took and how much it handled** — the run is measurable. *(Phase 200 — Satisfied)*

### Authoring — the doors and the journey (AUTH)

- [x] **AUTH-01**: A user can tell the two authoring doors apart and predict what each will do, before choosing. *(Phases 193/193.1 — Satisfied)*
- [x] **AUTH-02**: A user drafting from a description is guided through the decisions that matter, rather than getting one shot at a prompt and a finished draft. *(Phase 197 — Satisfied)*
- [x] **AUTH-03**: A user attaches a template to a workflow **when authoring it**, and every run fills that same template with current information. *(Phases 193.1/193.2 — Satisfied)*
- [x] **AUTH-04**: A user selects the model for a step from the live model registry, rather than typing a model name or slug by hand. *(Phase 196 — Satisfied)*

### Run control and results (RUN)

- [x] **RUN-01**: A user can stop a running workflow at any point, and the run reports honestly that it was stopped. *(Phases 194/194.1 — Satisfied)*
- [x] **RUN-02**: A workflow that produces a file shows that file to the user when the run finishes, from the run surface. *(Phase 195 — Satisfied)*
- [x] **RUN-03**: Where a produced file is shown, it reuses the shipped output-file presentation rather than a second one. *(Phase 195 — Satisfied)*
- [x] **RUN-04**: A person who opens a finished run is told what it produced — **whichever KIND of thing that was**. *(Phase 200.1 — Satisfied)*
- [x] **RUN-05**: A person reading a finished run sees, in one column, WHAT the run produced and what each step YIELDED — not the right-hand panel's list of step names. *(Phase 200.2 — Satisfied)*

### Node vocabulary & Publishing (NODE / SEED)

- [x] **NODE-01**: An author can express a deterministic step between two AI steps without writing a prompt for it. *(Phase 198 — Satisfied: 0-reshape invariant confirmed, `execute_code` incumbent)*
- [x] **NODE-02**: A workflow can collect structured input from a person mid-run. *(Phase 198 — Satisfied: `llm_human_input`)*
- [x] **SEED-164**: Publish and test run workflows with human input steps without blocking. *(Phase 200.3 — Satisfied)*
