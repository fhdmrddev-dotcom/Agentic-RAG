<objective>
Build `skill_embedding_service.py` — the D-01 embed-source builder + a `reembed_service`-shaped background
backfill/refresh job that populates `skill_embeddings` (Plan 01's table) with one vector per stale skill.

Purpose: Keep skill vectors fresh OFF the hot path (the request thread never embeds skills). It also exposes
`kick_skill_backfill` — the fire-and-forget self-heal primitive Plan 04 fires when the over-budget path
finds a stale/absent (NULL-similarity) vector (Blocker-1), so a newly-created/edited skill re-vectorizes
within ~one turn instead of being silently starved. The job is the data-population half of the pre-filter;
it is EXERCISED for real in the [BLOCKING] Plan 05 (after the table is applied). This plan authors +
unit/mock-tests the code.

Output: `backend/app/services/skill_embedding_service.py` + `backend/tests/integration/test_140_skill_embedding_service.py`.
