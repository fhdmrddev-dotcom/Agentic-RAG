operator's `pm-*` rows. `UNIQUE(slug,version)` is global, and the operator's local dev DB already holds

violation at apply time (ON CONFLICT (id) does NOT catch a slug/version conflict). Use `risk-register`,
`weekly-status-report`, `compliance-gap-report`.
