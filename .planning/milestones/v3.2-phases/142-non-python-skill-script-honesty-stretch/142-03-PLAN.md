<objective>
Make the two skill-file READ surfaces honest about non-Python scripts (SC#3, D-11)
and add the proactive per-skill runtime flag on `load_skill` (D-05b). Both are
additive, model-facing, non-blocking (D-07/D-12): (1) extend the shared
`_decode_skill_file_bytes` so `.js`/`.sh`/… decode as reference text with a
"not executable here" caveat instead of the false "binary — upload a text version"
message — and because that one function is shared by the live read path AND the
099 snapshot path, byte-symmetry is automatic (Pitfall 3); (2) compute a runtime
note from the loaded skill's file extensions and ride it along the `load_skill`
result like `lint_warnings`.

Purpose: `read_skill_file` stops lying that a `.js` is unreadable binary, and the
model is told at load time that a skill bundles a script this sandbox cannot run.
Output: the decoder branch + the `_skill_runtime_note` flag + two unit test files.
</objective>
