# Phase 134.1 — Evals Run Silently

**Eval runs no longer pollute the chat sidebar.** The agent-loop execution thread the eval runner
must create is now flagged `is_eval=true` and hidden from `GET /threads`; the eval's user-visible
outputs stay where they belong — `eval_results` + the eval panel, retrieved per run.

## Context (why this exists)

Surfaced by the user during Phase 134 live UAT: the chat sidebar was full of `[eval]` chats — "some
empty, some populated." Confirmed against the live DB: **34 `[eval]` threads = 10% of all 338
threads, 17 empty / 17 populated.** Root cause (BUG-260702-01): `_create_eval_thread` inserts a real
`public.threads` row per run because `run_agent_loop` reads folder_id + history from the DB (no
in-memory path). That thread is pure execution exhaust but was indistinguishable from a real chat, so
the sidebar listed it. `public.threads` had no hide/kind column.

The user's framing — "record it only in the database, retrieve by case" — was exactly right: the
results already live in `eval_results`; the chat thread should never be user-visible.

## What shipped

1. **Migration 082** — additive `threads.is_eval boolean NOT NULL DEFAULT false`; one-time backfill
   flags the 34 historical `[eval]` rows (hidden, NOT deleted — transcript preserved); partial index
   `idx_threads_user_visible (user_id, updated_at DESC) WHERE is_eval=false` for the sidebar hot path.
   Applied live to `:54322` (no reset); `full-schema.sql` regenerated from the live dump.
2. **`_create_eval_thread`** sets `is_eval=True` on the ephemeral eval thread (the marker is the
   source of truth going forward, not the title).
3. **`list_threads`** gains an additive `.eq("is_eval", False)` narrowing filter — the sidebar's
   entire thread list is this one query. G-5 hot file (threads.py), but the change only SHRINKS the
   same-user result set: no widened rows, no IDOR. No frontend change (the flag isn't even exposed in
   the payload; the Thread type never needed it).
4. **`test_eval_thread_marked_is_eval`** guards the upstream contract the filter keys off.
