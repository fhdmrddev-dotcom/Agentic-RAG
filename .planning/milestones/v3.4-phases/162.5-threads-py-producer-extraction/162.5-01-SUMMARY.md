## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug / Rule 3 - Blocking] Patch surface for the moved bodies' internal collaborators**
- **Found during:** Task 1 (empirical baseline run before editing) + Task 2.
- **Issue:** The plan's literal instruction — "bring imports: `get_llm_client` (Task 1); `load_all_model_overrides` / `get_model_capability_async` / `override_provider` (Task 2)" as normal module-scope imports into the new leaves — would BREAK the acceptance-gate tests. `test_mdl_verification` and `test_threads_title_gen` `patch("app.api.threads.get_llm_client")` and drive `generate_thread_title` directly; `test_149` `monkeypatch.setattr(threads_mod, "load_all_model_overrides"/"get_model_capability_async", ...)` and drive the moved fallback helpers directly. A function whose body lives in a new module resolves those names in the NEW module's namespace, so the `app.api.threads.*` patches would no longer intercept the relocated code — the currently-passing `[anthropic]`/`[openrouter]`/`[ollama]` title params would have regressed to `IndexError` (mock never called) and `test_149` would have fallen back to the real (unpatched) collaborators.
- **Fix:** The moved bodies resolve those specific test-patched collaborators via a LATE import from `app.api.threads` (e.g. `from app.api.threads import get_llm_client` at the top of `generate_thread_title`; `from app.api.threads import load_all_model_overrides` in `_resolve_enabled_model`; etc.). This is the exact `run_lifecycle.py` late-import discipline the plan endorses (D-A4) and is byte-identical in production (`threads.X` IS the re-exported real callable). Orchestrator-level collaborators (`generate_thread_title`, `_emit`) stay dependency-injected from `send_message` as the plan specified.
- **Files modified:** backend/app/services/thread_title.py, backend/app/services/run_model_resolution.py (+ the kept collaborator imports/comments in threads.py).
- **Verification:** Combined acceptance set = 9 failed / 25 passed = pre-extraction baseline (zero regressions); `test_149` 15/15 green; the get_llm_client-dependent title params still pass; 2803 tests collect with 0 errors.
- **Committed in:** `1f3ab7ef` (Task 1) + `d4973de5` (Task 2).
