<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| login page (pre-auth) → /org/sso/route | Unauthenticated (NO auth dependency — never 403s an anonymous caller); must leak only a boolean keyed on domain presence, never provider internals or account existence |
| org-admin → /org/sso/providers | Untrusted write; require_sso_manage + mig-104 RLS + server-pinned org_id is the wall |
| authenticated SSO user → /org/sso/provision | Org comes from the authenticated provider identity, never a client claim |
| operator → approval | Only an operator (not the creating org-admin) can flip a connection to active |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-168-01 | Spoofing/Elevation | domain routing before approval | mitigate | `/org/sso/route` + `/org/sso/provision` filter `status='active'`; a pending/hijack-attempt domain routes nobody until an operator approves |
| T-168-10 | Info Disclosure | pre-auth /org/sso/route | mitigate | a FULLY PUBLIC route (no auth dependency — never 403s an anonymous caller); returns a bare `{"sso": bool}` keyed on domain→active-config presence only (no provider_id/org_id, never whether an account exists); lowercased exact-domain match; consider rate-limiting (noted for ops) |
| T-168-06 | Info Disclosure/Tampering | /org/sso/providers cross-org | mitigate | require_sso_manage (strict active org) + writes on the user-JWT connection so mig-104 RLS scopes to current_user_org_ids; server-pinned org_id |
| T-168-02 | Elevation | public-domain at create | mitigate | `is_public_domain` rejected with 422 before the provider call (Control 1) |
| T-168-03 | Elevation | provision role | mitigate | delegates to `provision_sso_membership` which hardcodes `member` (Plan 03) — the endpoint passes NO role |
| T-168-09 | Tampering | delete | mitigate | DELETE calls `sso_provider_service.delete_provider` before the row delete — no orphaned GoTrue provider |
</threat_model>
