<threat_model>
### Security & Reliability Invariants (ASVS L1)
1. **GUC Name & Value Injection (T-241-14):**
   - Invariant: GUC name `hnsw.ef_search` remains hardcoded in query literals; only numeric integer values are passed as parameterized arguments `$1`.
   - Bounding: `ef_search` values are bounded by `HNSW_EF_SEARCH_FLOOR` (10) and `HNSW_EF_SEARCH_CEILING` (1000). Out-of-bounds values issue nothing (preserving lines 131/154).
2. **Transaction Leakage & Pool Poisoning (T-241-15 & Finding 2a):**
   - Invariant: `set_config('hnsw.ef_search', $1, true)` continues to enforce `is_local=true`, ensuring rollback/commit auto-reverts session parameters.
   - Probe Isolation: Probing server default (`SELECT current_setting('hnsw.ef_search', true)`) must execute on a clean connection outside of any active transaction so a prior borrower's `SET LOCAL` cannot poison the probe.
3. **Graceful Degradation (Finding 2b):**
   - Invariant: When pgvector is not installed or `current_setting` returns NULL, the probe resolves to `None`. No unhandled exceptions are raised; the search continues untuned.
4. **Cache Staleness Window (Finding 2c):**
   - Invariant: Server default caching uses a 60-second TTL rather than process lifetime, preventing persistent desync if an operator tunes postgresql.conf live.
</threat_model>
