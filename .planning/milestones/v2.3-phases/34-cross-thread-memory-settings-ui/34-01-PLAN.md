interface MemoryEntry {
  id: string

**Component: `export function MemorySection()`**

State variables:
- `entries: MemoryEntry[]` — loaded from Supabase
- `loading: boolean` — initial load spinner
- `error: string | null` — load error
- `editingKey: string | null` — which entry key is being edited (per D-07, only one at a time)
- `editValue: string` — controlled input value during edit
- `saving: boolean` — edit save in progress
- `deleteTarget: MemoryEntry | null` — entry pending delete confirmation (per D-09)
- `deleting: boolean` — delete in progress
- `actionError: string | null` — transient error for edit/delete failures (per D-18)

**Load effect (per D-03, D-04):**
```typescript
useEffect(() => {
  setLoading(true)
  setError(null)
  supabase
    .from("user_memory")
    .select("id, key, value, created_at, updated_at")
    .order("updated_at", { ascending: false })
    .then(({ data, error: err }) => {
      if (err) setError(err.message)
      else setEntries(data ?? [])
    })
    .finally(() => setLoading(false))
}, [])
```

**Action error auto-dismiss (per D-18):**
```typescript
useEffect(() => {
  if (!actionError) return
  const t = setTimeout(() => setActionError(null), 4000)
  return () => clearTimeout(t)
}, [actionError])
```

**Edit handlers (per D-05, D-06, D-07, D-08):**
- `startEdit(entry: MemoryEntry)`: sets `editingKey = entry.key`, `editValue = entry.value`
- `cancelEdit()`: sets `editingKey = null`
- `saveEdit()`: if `editValue.trim()` is empty, return. Set `saving = true`. Call `supabase.from("user_memory").update({ value: editValue.trim() }).eq("key", editingKey).eq("user_id", (await supabase.auth.getUser()).data.user?.id)`. On success, patch `entries` state by mapping over and replacing the matching key's value and updated_at. Set `editingKey = null`. On failure, set `actionError`. Finally set `saving = false`.

Note: The RLS policy enforces user_id = auth.uid(), so the `.eq("user_id", ...)` is technically redundant but adds safety. Alternatively, since RLS handles it, you can omit the user_id filter on UPDATE/DELETE — the RLS policy will scope it. Use this simpler pattern:
```typescript
supabase.from("user_memory").update({ value: editValue.trim() }).eq("key", editingKey)
```

**Delete handlers (per D-09, D-10, D-11):**
- `confirmDelete()`: Set `deleting = true`. Call `supabase.from("user_memory").delete().eq("key", deleteTarget!.key)`. On success, filter out the entry from `entries` state. Set `deleteTarget = null`. On failure, set `actionError` and `deleteTarget = null`. Finally set `deleting = false`.

**Entry list (per D-13, D-14):**
```tsx
<div className="divide-y divide-border/30">
  {entries.map((entry) => (
    <div key={entry.id} className="group flex items-center gap-3 py-3">
      {/* Key chip per D-14 */}
      <span className="font-mono text-xs bg-muted/30 px-2 py-1 rounded ghost-border shrink-0">
        {entry.key}
      </span>

      {/* Value — display or edit per D-05 */}
      <div className="flex-1 min-w-0">
        {editingKey === entry.key ? (
          <div className="flex items-center gap-2">
            <input
              type="text"
              value={editValue}
              onChange={(e) => setEditValue(e.target.value)}
              className="flex-1 text-sm bg-transparent border-b border-primary/40 focus:outline-none px-1 py-0.5"
              autoFocus
              onKeyDown={(e) => {
                if (e.key === "Enter" && editValue.trim()) saveEdit()
                if (e.key === "Escape") cancelEdit()
              }}
            />
            <Button
              variant="ghost"
              size="sm"
              className="h-6 w-6 p-0 text-primary"
              onClick={saveEdit}
              disabled={!editValue.trim() || saving}
            >
              {saving ? <Loader2 className="h-3.5 w-3.5 animate-spin" /> : <Check className="h-3.5 w-3.5" />}
            </Button>
            <Button
              variant="ghost"
              size="sm"
              className="h-6 w-6 p-0 text-muted-foreground"
              onClick={cancelEdit}
              disabled={saving}
            >
              <X className="h-3.5 w-3.5" />
            </Button>
          </div>
        ) : (
          <span className="text-sm truncate block">{entry.value}</span>
        )}
      </div>

      {/* Created date */}
      <span className="text-xs text-muted-foreground shrink-0 hidden sm:block">
        {new Date(entry.created_at).toLocaleDateString("en-US", { month: "short", day: "numeric", year: "numeric" })}
      </span>

      {/* Action icons per D-14 — visible on hover */}
      {editingKey !== entry.key && (
        <div className="flex items-center gap-1 opacity-0 group-hover:opacity-100 transition-opacity shrink-0">
          <Button
            variant="ghost"
            size="sm"
            className="h-6 w-6 p-0 text-muted-foreground hover:text-foreground"
            onClick={() => startEdit(entry)}
          >
            <Pencil className="h-3.5 w-3.5" />
          </Button>
          <Button
            variant="ghost"
            size="sm"
            className="h-6 w-6 p-0 text-muted-foreground hover:text-destructive"
            onClick={() => setDeleteTarget(entry)}
          >
            <Trash2 className="h-3.5 w-3.5" />
          </Button>
        </div>
      )}
    </div>
  ))}
</div>
```
