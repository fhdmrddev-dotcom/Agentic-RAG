The component receives feedbackStats as a prop (data is fetched in KnowledgeHealthPage, not inside this component — keeps the component pure and testable, matches HealthPanel pattern where data is passed in).

```tsx
import { ThumbsUp } from "lucide-react"
import { Card, CardContent, CardHeader, CardTitle } from "@/components/ui/card"
import { HealthDocumentRow } from "./HealthDocumentRow"
import { HealthEmptyState } from "./HealthEmptyState"
import type { FeedbackStats, DownvotedDocument } from "@/lib/api"

interface Props {
  stats: FeedbackStats
  onRemoveDownvoted: (id: string) => void
}

export function FeedbackStatsPanel({ stats, onRemoveDownvoted }: Props) {
  const positivePercent = Math.round(stats.positive_rate * 100)
  const hasRatings = stats.total_ratings > 0
  const hasDownvoted = stats.downvoted_documents.length > 0

  return (
    <Card className="ghost-border bg-card/50 shadow-sm mb-6">
      <CardHeader className="flex flex-row items-center justify-between pb-2">
        <div className="flex items-center gap-2">
          <ThumbsUp className="h-4 w-4 text-primary" />
          <CardTitle className="text-base font-headline font-bold">User Feedback</CardTitle>
        </div>
        <span className="text-xs text-muted-foreground">
          {stats.total_ratings} {stats.total_ratings === 1 ? "rating" : "total ratings"}
        </span>
      </CardHeader>

      <CardContent className="p-0">
        {!hasRatings ? (
          <HealthEmptyState
            icon={ThumbsUp}
            heading="No feedback yet"
            body="Thumbs up and down ratings will appear here once users start rating responses."
          />
        ) : (
          <>
            {/* Positive rate stat */}
            <div className="flex items-baseline gap-2 mb-4 px-4 pt-2">
              <span className="text-3xl font-bold font-headline tabular-nums leading-none text-primary">
                {positivePercent}%
              </span>
              <span className="text-sm font-medium text-muted-foreground">positive rating</span>
              <span className="text-xs font-medium text-muted-foreground">
                all-time &middot; {stats.total_ratings} total ratings
              </span>
            </div>

            {/* Most downvoted section heading */}
            <p className="text-xs font-medium text-muted-foreground px-4 pb-2">
              Most downvoted (last 30 days)
            </p>

            {/* Downvoted documents list or empty state */}
            {!hasDownvoted ? (
              <HealthEmptyState
                icon={ThumbsUp}
                heading="No downvoted documents"
                body="No documents have been downvoted in the last 30 days."
              />
            ) : (
              <div className="divide-y divide-border/30">
                {stats.downvoted_documents.map((doc: DownvotedDocument) => (
                  <HealthDocumentRow
                    key={doc.document_id}
                    doc={doc}
                    metricChip={
                      <span className="text-xs px-2 py-0.5 rounded-full bg-destructive/10 text-destructive shrink-0 tabular-nums">
                        {doc.downvote_count} &#8595;
                      </span>
                    }
                    onRemove={onRemoveDownvoted}
                  />
                ))}
              </div>
            )}
          </>
        )}
      </CardContent>
    </Card>
  )
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GET /feedback/stats response -> FeedbackStatsPanel render | downvoted_documents filenames come from the backend. Rendered as text content inside React (not innerHTML), so XSS is not possible. |
| onRemoveDownvoted callback -> state mutation | document_id is a server-supplied UUID. The filter callback only removes from local UI state — no DELETE API call, no server mutation in this component. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-040-08 | Information Disclosure | GET /feedback/stats | accept | Backend enforces RLS — users see only their own feedback stats. Frontend renders what the API returns without cross-user exposure. |
| T-040-09 | XSS | FeedbackStatsPanel filename render | accept | doc.filename rendered as React text child (not dangerouslySetInnerHTML). React escapes all text children. Filenames come from DB, not from user-typed free text. |
| T-040-10 | Spoofing | getFeedbackStats fetch | mitigate | Uses getAuthHeaders() which attaches Bearer token — same auth pattern as all other API calls. Unauthenticated requests return 401 from backend. |
| T-040-11 | Denial of Service | Large downvoted_documents list | accept | Backend returns top-5 by count (documented in 039-CONTEXT.md D-10). Frontend renders the full list returned — no pagination needed for 5 items. |
| T-040-12 | Tampering | onRemoveDownvoted state update | accept | Client-side state mutation only — removes document from the displayed list optimistically. No API call is made. The real data persists in the backend; refresh restores it. This matches the existing HealthPanel removeFromPanel pattern. |
</threat_model>
