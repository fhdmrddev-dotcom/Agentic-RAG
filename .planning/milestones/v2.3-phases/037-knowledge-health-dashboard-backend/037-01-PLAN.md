```python
"""Knowledge Health Dashboard — Backend (Phase 37, HLTH-01–HLTH-04)."""
from collections import defaultdict
from datetime import datetime, timedelta, timezone

from fastapi import APIRouter, Depends, Query
from supabase import Client

from app.dependencies import get_current_user, get_supabase

router = APIRouter(prefix="/knowledge-health", tags=["knowledge-health"])

TOP_N = 10
LOW_CONF_THRESHOLD = 0.40   # D-02: avg similarity below this = low-confidence
WINDOW_DAYS = 30             # D-07: most-retrieved and low-confidence window


def _now_utc() -> datetime:
    return datetime.now(timezone.utc)


def _window_cutoff(days: int) -> str:
    """Return ISO 8601 UTC string for (now - days)."""
    return (_now_utc() - timedelta(days=days)).isoformat()
```

Then implement four private helpers and one endpoint:

**`_fetch_most_retrieved(supabase, user_id)`** (D-01, D-07, D-11):
1. Query `audit_log` for `action_type = search.query` and `created_at >= _window_cutoff(WINDOW_DAYS)` and `user_id = user_id`.
   - Select: `metadata, created_at`
   - `.eq("user_id", user_id).eq("action_type", "search.query").gte("created_at", _window_cutoff(WINDOW_DAYS))`
2. In Python: for each row, read `row["metadata"].get("document_ids", [])` — unnest into a flat list. Count occurrences per document_id using `defaultdict(int)`. Track `max(created_at per doc)` for `last_retrieved_at`.
3. Sort by count descending, take top TOP_N document_ids.
4. Fetch document metadata: query `documents` with `.in_("id", top_ids).eq("user_id", user_id).eq("is_latest", True)`. Select: `id, filename, folder_id, created_at, file_size`.
5. Return list of dicts: `{document_id, filename, folder_id, created_at, file_size, retrieval_count, last_retrieved_at}`. Sort by retrieval_count descending.

**`_fetch_never_retrieved(supabase, user_id)`** (D-08, D-11):
1. Fetch all active user documents: `documents` table with `.eq("user_id", user_id).eq("is_latest", True)`. Select: `id, filename, folder_id, created_at, file_size`.
2. Fetch all document_ids ever referenced in audit_log: `audit_log` with `.eq("user_id", user_id).eq("action_type", "search.query")`. Select: `metadata`.
3. In Python: collect all doc_ids from all `metadata["document_ids"]` lists into a set `retrieved_set`.
4. Filter: documents whose `id` is NOT in `retrieved_set`.
5. Return the never-retrieved documents as list of dicts: `{document_id (= row["id"]), filename, folder_id, created_at, file_size}`. Take first TOP_N.

**`_fetch_low_confidence(supabase, user_id)`** (D-01, D-02, D-03, D-11):
1. Query `messages` for the current user in the 30-day window: `.eq("user_id", user_id).gte("created_at", _window_cutoff(WINDOW_DAYS))`. Select: `source_refs, confidence_avg_similarity`.
2. In Python: for each message row that has `source_refs` (not None/empty):
   - For each entry in `source_refs` array: read `entry["document_id"]` and `entry.get("avg_similarity", row["confidence_avg_similarity"] or 0.0)`.
   - Accumulate: per document_id, collect a list of similarity scores.
3. Compute per-document avg similarity. Keep only those with avg < LOW_CONF_THRESHOLD.
4. Sort by avg_similarity ascending (worst first), take top TOP_N document_ids.
5. Fetch document metadata from `documents` with `.in_("id", top_ids).eq("user_id", user_id).eq("is_latest", True)`. Select: `id, filename, folder_id, created_at, file_size`.
6. Return list of dicts: `{document_id, filename, folder_id, created_at, file_size, avg_similarity}`.

**`_fetch_stale(supabase, user_id, stale_days)`** (D-04, D-05, D-11):
1. Compute cutoff: `_window_cutoff(stale_days)`.
2. Query `documents`: `.eq("user_id", user_id).eq("is_latest", True).lt("created_at", cutoff)`. Select: `id, filename, folder_id, created_at, file_size`.
3. In Python: compute `days_stale = (now - doc["created_at"]).days` for each. Note: parse ISO string with `datetime.fromisoformat(created_at.replace("Z", "+00:00"))`.
4. Sort by days_stale descending (stalest first), take first TOP_N.
5. Return list of dicts: `{document_id (= row["id"]), filename, folder_id, created_at, file_size, days_stale}`.

**Endpoint:**
```python
@router.get("/summary")
async def knowledge_health_summary(
    stale_days: int = Query(90, ge=1, le=3650),
    current_user: dict = Depends(get_current_user),
    supabase: Client = Depends(get_supabase),
):
    """Return four library health metric arrays (D-09)."""
    user_id = current_user["id"]
    return {
        "most_retrieved": _fetch_most_retrieved(supabase, user_id),
        "never_retrieved": _fetch_never_retrieved(supabase, user_id),
        "low_confidence": _fetch_low_confidence(supabase, user_id),
        "stale": _fetch_stale(supabase, user_id, stale_days),
    }
```

Key implementation notes:
- All four helpers are synchronous (Supabase client is sync) — no async def needed for helpers
- Guard against None/missing metadata: `row.get("metadata") or {}` before accessing keys
- Guard against None source_refs: `row.get("source_refs") or []`
- Guard against empty `top_ids`: if empty list, skip the `.in_()` query and return []
- The `.lt()` filter method is used for stale (less-than on created_at) — add `b.lt.return_value = b` to conftest if missing (check first)
