<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage → activeTab state | Tab index string read at mount |
| Per-tab save body → updateSettings API | Each handler submits a partial SettingsUpdate |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-043-02-A | Tampering | localStorage key `settings_active_tab` | accept | Value controls UI tab position only; invalid values default to tab "0" — no security impact |
| T-043-02-B | Tampering | Per-tab save handlers sending KEY_PLACEHOLDER | mitigate | Each handler uses `|| KEY_PLACEHOLDER` fallback — empty string is never sent to backend; backend ignores KEY_PLACEHOLDER values as "no change" per existing pattern |
| T-043-02-C | Information Disclosure | API keys in Integrations tab save body | accept | API keys flow through the same `updateSettings()` path as before; no new attack surface introduced |
| T-043-02-D | Spoofing | Audit log export error display | accept | Error message is static string "Export failed. Please try again." — no server-supplied content rendered as HTML |
</threat_model>
