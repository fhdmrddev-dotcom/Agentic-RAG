## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-043-03-A | Tampering | Mobile drawer thread selection | accept | selectThread callback already authenticated via useThreads hook / Supabase RLS — no new vector |
| T-043-03-B | Denial of Service | z-50 drawer overlapping interactive elements | mitigate | Drawer has `md:hidden` — only rendered on mobile; backdrop z-40 intercepts all taps outside drawer; drawer z-50 ensures correct stacking with MessageInput (which has no explicit z-index, sits below z-40) |
| T-043-03-C | Information Disclosure | Thread titles in mobile drawer | accept | Same thread list data as desktop NavPanel — no additional disclosure |
| T-043-03-D | Elevation of Privilege | onOpenDrawer prop injection | accept | onOpenDrawer is an optional callback with no parameters — cannot be used to inject data or escalate permissions |
