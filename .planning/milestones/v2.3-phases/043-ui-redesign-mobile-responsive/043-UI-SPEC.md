## Spacing Scale

Declared values (multiples of 4px only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, indicator bars, tight inline padding |
| sm | 8px | Button padding, icon-button gaps, thread list row padding |
| md | 16px | Section padding, card internal spacing, tab panel padding |
| lg | 24px | Settings section separation, panel column gaps |
| xl | 32px | Page-level horizontal padding, major layout gaps |
| 2xl | 48px | Tab strip + content vertical rhythm |
| 3xl | 64px | Not used in this phase |

**Exceptions:**
- Nav icon buttons (collapsed and expanded): 40px × 40px touch target (w-10 h-10), per existing AppDock pattern
- Mobile drawer menu button: 44px × 44px minimum touch target (md:hidden, top-left of ChatArea header)
- Active thread left indicator bar: 2px wide (w-0.5) — intentional design accent, not spacing

**Source:** CONTEXT.md D-04, D-05; existing AppDock.tsx pattern

## Typography

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Body | 14px (text-sm) | 400 (regular) | 1.5 | Inter | Thread titles, settings field values, tab labels |
| Label | 12px (text-xs) | 600 (semibold) | 1.4 | Inter | Section labels ("Chat" uppercase header, field labels in SettingsPage) |
| Caption | 10px (text-[10px]) | 400 (regular) | 1.4 | Inter | Logo subtitle ("Powered by AI"), section category headers (uppercase tracking-wider) |
| Heading | 14px (text-sm) | 600 (semibold) | 1.2 | Manrope (font-headline) | Logo wordmark ("Agentic RAG"), settings section titles |

**Notes:**
- Section category headers use: `text-[10px] font-semibold uppercase tracking-wider text-muted-foreground/60`
- Logo wordmark uses: `font-headline font-semibold text-sm tracking-tight`
- Tab strip labels: `text-sm font-medium` — uses shadcn Tabs default
- Visual hierarchy between Heading (14px/600) and Label (12px/600) is established through size difference alone, not weight escalation. Caption (10px/400) sits below both via both size and weight.

**Weight constraint:** Exactly 2 weights are used — 400 (regular) and 600 (semibold). No `font-bold` (700) anywhere in this phase.

**Source:** Existing Sidebar.tsx logo block + AppDock.tsx patterns

## Color

All colors use CSS custom properties via HSL notation. Both light and dark modes defined in index.css.

| Role | Light Mode | Dark Mode | Usage |
|------|-----------|-----------|-------|
| Dominant (60%) | hsl(220 20% 97%) — near-white | hsl(216 45% 4%) — deep navy | Page background (`bg-background`) |
| Secondary (30%) | hsl(220 15% 95%) — cool light grey | hsl(220 40% 5%) — dark sidebar | NavPanel background (`bg-sidebar`), settings tab content panels |
| Card/Panel | hsl(0 0% 100%) | hsl(220 30% 7%) | Settings card panels (`bg-card/50`), tab content wrappers |
| Accent (10%) | gradient 239→258° indigo-violet | gradient 239→258° indigo-violet | See reserved-for list below |
| Destructive | hsl(0 84% 60%) | hsl(0 72% 51%) | Delete thread button hover, destructive confirmation text |

5. Active thread row background — `bg-primary/10` (10% opacity primary)
6. Active thread row background (Wave 3 upgrade) — `bg-primary/15`
7. Settings Save button — `gradient-primary text-white` per tab

**Primary focal point:** gradient-primary active nav icon pill in collapsed state; New Chat button in expanded state.

**Tonal patterns used in this phase:**
- NavPanel container: `bg-sidebar border-r border-border/20`

## Interaction Contracts

### NavPanel: Collapse / Expand

| State | Width | Trigger | Persistence |
|-------|-------|---------|-------------|
| Expanded (default) | w-64 (256px) | Page load / localStorage restore | `localStorage.getItem('nav_panel_collapsed') !== 'true'` |
| Collapsed | w-14 (56px) | Click toggle button only — no hover expand | `localStorage.setItem('nav_panel_collapsed', 'true')` |

**Toggle button:**
- Collapsed: ChevronRight icon, positioned top of icon rail
- Expanded: ChevronLeft icon, positioned top of right sub-column (or top of full panel)
- Button: `w-10 h-10 rounded-xl text-muted-foreground hover:text-sidebar-foreground hover:bg-accent/40 transition-colors`

**Panel animation:**
- CSS width transition: `transition-[width] duration-200 ease-in-out`
- No JS-driven animation — Tailwind arbitrary transition class

**Collapsed state anatomy (top to bottom):**
1. Sparkles icon (gradient-primary container, no wordmark)
2. Toggle button (ChevronRight)
3. 5 nav icon buttons with Tooltip side="right" — Chat, Documents, Library Health, Skills, Settings
4. [flex-1 spacer]
5. Sign Out icon button (LogOut, hover:text-destructive)

**Expanded state anatomy:**
- Left sub-column (w-14): same icon rail as collapsed; tooltips hidden in expanded state (labels visible in right sub-column NOT needed — nav icons have no labels in expanded state, but tooltips disabled per current pattern)
- Right sub-column (flex-1): logo block (top), New Chat button, scrollable thread list, theme toggle footer
- Visual separator between sub-columns: `border-r border-border/10`
- Toggle button (ChevronLeft) at top of right sub-column

**Source:** CONTEXT.md D-01 through D-08

### SettingsPage: Tab Strip

| Tab | Label | Has Save Button | Scope |
|-----|-------|----------------|-------|
| 0 | AI Model | Yes | provider + model config |
| 1 | Search & Retrieval | Yes | embedding + reranking + retrieval weights |
| 2 | Integrations | Yes | API keys + sandbox toggle |
| 3 | Memory | No | inline save per entry (existing) |
| 4 | Audit Log | No | read-only + CSV export |

**Tab persistence:** `localStorage.getItem('settings_active_tab')` — default: `"0"` (AI Model)

**Save button spec (per editable tab):**
- Label: "Save [Tab Name]" — e.g. "Save AI Model", "Save Search Settings", "Save Integrations"
- Style: `gradient-primary text-white shadow-md shadow-primary/20 hover:opacity-90 transition-all border-none font-semibold`
- Positioned: bottom-right of tab content panel
- Loading state: `<Loader2 className="h-4 w-4 animate-spin" />` replaces icon during save
- Success state: `<Check className="h-4 w-4" />` for 2 seconds post-save, then resets

**Tab strip component:** shadcn `<Tabs>` — `import { Tabs, TabsList, TabsTrigger, TabsContent } from "@/components/ui/tabs"`

**Tab content panel wrapper:** `bg-card/50 ghost-border rounded-xl p-6` per tab panel

**Source:** CONTEXT.md D-09 through D-13
