**Step 2 — Wrap the component return in Collapsible:**

Current pattern (schematic — read the actual file for exact JSX):
```tsx
<div>
  <button onClick={() => setIsOpen(!isOpen)}>
    {chevronIcon} {N} source(s)
  </button>

    <div>
      {citations.map(c => <CitationCard ... />)}
```

Replace with Collapsible pattern:
```tsx
<Collapsible open={isOpen} onOpenChange={setIsOpen}>
  <CollapsibleTrigger asChild>
    <button /* keep all existing className and content exactly as-is */>
      {chevronIcon} {N} source(s)
    </button>
  </CollapsibleTrigger>
  <CollapsibleContent
    className="data-[state=open]:animate-in data-[state=closed]:animate-out data-[state=open]:fade-in-0 data-[state=closed]:fade-out-0 data-[state=open]:slide-in-from-top-1 data-[state=closed]:slide-out-to-top-1 duration-200 ease-in-out"
  >
    <div /* keep existing wrapper div classes if any */>
      {citations.map(c => <CitationCard ... />)}
    </div>
  </CollapsibleContent>
</Collapsible>
```

Rules:
- The trigger `<button>` element and all its existing className, aria-*, and children are UNCHANGED — only wrap it in `<CollapsibleTrigger asChild>`
- The `{isOpen && ...}` conditional render becomes `<CollapsibleContent>` — remove the conditional entirely
- The outer `<div>` wrapper of the entire component becomes `<Collapsible open={isOpen} onOpenChange={setIsOpen}>`
- Do NOT change: useState hook, variable names, citations.map logic, CitationCard props, any other className
  </action>
