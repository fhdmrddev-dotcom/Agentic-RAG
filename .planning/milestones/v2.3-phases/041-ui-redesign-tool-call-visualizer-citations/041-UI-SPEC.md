## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), inline padding |
| sm | 8px | Compact element spacing (`gap-2`, `p-2`) |
| md | 16px | Default element spacing (`px-4`, `gap-4`) |
| lg | 24px | Section padding (`px-6`) |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- MessageInput outer wrapper bottom air: `mb-3` (12px) — between 8px and 16px; approved per D-04
- MessageInput outer wrapper side air: `mx-4` (16px) — standard md token
- CitationCard gradient accent strip: `w-0.5` (2px) — decorative strip, not a layout unit; exempt from 4px grid

|------|------|--------|-------------|

- Content area wraps in inner `<div className="pl-3 flex-1">`

**Change 2 — File-type icons:**
- Replace current `<FileText className="w-3 h-3 flex-shrink-0" />` with type-specific icon
- Icon selection (Claude's discretion — per CONTEXT.md):
  - PDF: `<FileText className="w-3 h-3 flex-shrink-0 text-red-400" />`
  - DOCX/DOC: `<FileText className="w-3 h-3 flex-shrink-0 text-blue-400" />`
  - Markdown: `<FileCode className="w-3 h-3 flex-shrink-0 text-purple-400" />`
  - Default: `<FileText className="w-3 h-3 flex-shrink-0 text-muted-foreground" />`
- Add import: `FileCode` from lucide-react

**File type detection helper (add to CitationCard.tsx):**
```
function getFileType(filename: string): "pdf" | "docx" | "md" | "default" {
  const ext = filename.split(".").pop()?.toLowerCase() ?? ""
  if (ext === "pdf") return "pdf"
  if (ext === "docx" || ext === "doc") return "docx"
  if (ext === "md" || ext === "markdown") return "md"
  return "default"
}
```

### C. CitationList — Collapsible Animation (SC-3, D-07 through D-09)

**Target file:** `frontend/src/components/chat/CitationList.tsx`

**Install:** `npx shadcn add collapsible` (adds `frontend/src/components/ui/collapsible.tsx`)

**Change:** Replace `useState(false)` + conditional render with Radix Collapsible:
- Import: `Collapsible, CollapsibleContent, CollapsibleTrigger` from `@/components/ui/collapsible`
- Wrap reveal section in `<Collapsible open={open} onOpenChange={setOpen}>`
- Move trigger button into `<CollapsibleTrigger asChild>`
- Wrap cards list in `<CollapsibleContent>`

**Animation classes on `<CollapsibleContent>`:**
```
className="data-[state=open]:animate-in data-[state=closed]:animate-out
           data-[state=open]:fade-in-0 data-[state=closed]:fade-out-0
           data-[state=open]:slide-in-from-top-1 data-[state=closed]:slide-out-to-top-1
           duration-200 ease-in-out"
```

**Animation approach (Claude's discretion — per CONTEXT.md):**
Use Tailwind animate-in/animate-out classes (provided by `tailwindcss-animate` already in `tailwind.config.js`) rather than a custom `slideDown` keyframe. This avoids adding any new CSS to `tailwind.config.js`. The `tailwindcss-animate` plugin already handles `--radix-collapsible-content-height` via its built-in data-state classes.

## Animation Contract

| Animation | Duration | Easing | Trigger |
|-----------|----------|--------|---------|
| Collapsible reveal | 200ms | ease-in-out | Click "N sources" toggle |
| Tool slide-in | 250ms per item, 80ms stagger | ease-out | Tool call appears (existing `animate-toolSlideIn`) |
| Check pop | 350ms | cubic-bezier(0.34, 1.56, 0.64, 1) | Tool completes (existing `animate-checkPop`) |
| Pulse glow | 2s loop | ease-in-out | Active tool spinner (existing `animate-pulseGlow`) |
| Progress shimmer | 1.8s loop | ease-in-out | Tool running state (existing `.tool-progress-bar`) |

**Collapsible animation spec:** `data-[state=open]:animate-in data-[state=closed]:animate-out` with `slide-in-from-top-1 fade-in-0` / `slide-out-to-top-1 fade-out-0` and `duration-200 ease-in-out`. Uses `tailwindcss-animate` plugin (already installed) — no new keyframes required.
