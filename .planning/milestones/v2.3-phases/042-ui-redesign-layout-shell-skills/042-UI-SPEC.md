### Modified: SkillCard — Toggle Glow (D-09)

**Toggle switch track:**

Before: `bg-primary` (solid)
After: CSS background-image gradient on the checked track element.

Implementation — replace the track `div`'s `checked ? "bg-primary"` with an inline style or a Tailwind `bg-[image:...]` approach:
```tsx
// Track div when checked:
className="relative inline-flex h-5 w-9 items-center rounded-full transition-colors"
style={localEnabled ? {
  backgroundImage: "linear-gradient(135deg, hsl(239 84% 67%), hsl(258 90% 66%))"
} : undefined}
// Add fallback className for unchecked: "bg-muted"
```

Note: Tailwind cannot apply arbitrary gradients to background-image with opacity modifiers — inline style is correct here for the checked gradient track. The `gradient-primary` CSS class defined in `index.css` uses `background: linear-gradient(...)` (shorthand), which also sets background-image — equivalent approach.

**Toggle thumb:** `bg-white` rounded-full — unchanged.

**Toggle transition:** `transition-colors` on the track — the `transition-colors` property does not animate gradients in all browsers. Add `transition-all duration-200` to ensure the opacity-fade between enabled/disabled is smooth.

## Interaction Contracts

### AppDock Navigation

| Trigger | Response |
|---------|----------|
| Click active-view icon | No-op (already on this view) |
| Click inactive icon | `onNavigate(view)` — same as Sidebar nav |
| Click Sign Out | `onSignOut()` — same as Sidebar |
| Hover any icon | Tooltip appears on right side (`side="right"`) after 300ms default Radix delay |
| Keyboard: Tab through icons | Focus ring using `ring-2 ring-primary/30` |

### SkillsPage 3-Pane

| Trigger | Response |
|---------|----------|
| Click SkillCard | Sets `selectedSkill` state; right pane transitions in with `animate-fadeSlideUp 0.2s` |
| Click Pencil icon on SkillCard | Same as clicking SkillCard (sets selection, opens inline form) |
| Click "Discard Changes" in right pane | Clears `selectedSkill` state; right pane returns to empty state |
| Click "Save Skill" in right pane | Calls `onSave()`, on success clears selection, shows success state for 2s |
| Click "New Skill" button in header | Clears `selectedSkill`, right pane renders empty form for create mode |
| Skill save success | Right pane stays open showing updated skill — does NOT auto-collapse |
| Right pane panel scroll | Independent of center pane scroll (`overflow-y-auto` on right pane) |

### Toggle Switch (SkillCard)

| Trigger | Response |
|---------|----------|
| Click toggle | Optimistically flips `localEnabled` state immediately; track gradient animates via `transition-all duration-200` |
| Toggle API fails | `localEnabled` reverts; `"Failed to update skill."` appears for 3s |
| Toggle disabled → enabled | Track: `bg-muted` → `gradient-primary` (indigo→cyan) |
| Toggle enabled → disabled | Track: `gradient-primary` → `bg-muted`; card opacity: 1 → 0.5 |
