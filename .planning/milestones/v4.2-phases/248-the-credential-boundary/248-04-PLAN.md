<objective>
**CRED-04: Supabase Security Advisor check script and deployment workflow parity.**

Implement `scripts/check-security-advisors.sh` to query Supabase Management API for project security advisors, failing on ERROR findings while displaying WARN findings. Update `docs/DEPLOYMENT-WORKFLOW.md` and add a reminder hook to `scripts/check-deploy-drift.sh`.
</objective>

<threat_model>
### Security & Reliability Invariants (ASVS L1)
1. **Unnoticed Security Regressions (TM-248-04):**
   - Invariant: Deployments must not introduce unmonitored security advisor errors (e.g. `rls_disabled_in_public`).
2. **Failure Honesty & Usability (D-248-14):**
   - Invariant: ERROR findings fail the promotion check; existing WARN findings (e.g. `extension_in_public`, `function_search_path_mutable`) print clearly without breaking the pipeline, preventing alert fatigue and skipped checks.
3. **Credential Discipline (D-248-12):**
   - Invariant: Management token is consumed from environment variables (`SUPABASE_ACCESS_TOKEN`), never hardcoded or stored in client-accessible tables.
4. **Deploy Parity Rule:**
   - Invariant: The token variable name (`SUPABASE_ACCESS_TOKEN`) must be identical across the script, `backend/.env.example`, and `OMITTED_FROM_ONEBOX` in `scripts/check-deploy-drift.sh`.
</threat_model>

<action>
Create `scripts/check-security-advisors.sh`:
- Include why/usage/notes header, strict bash mode (`set -euo pipefail`).
- Read `SUPABASE_ACCESS_TOKEN` and `SUPABASE_PROJECT_REF` from environment.
- If token or ref is missing, print usage and instructions, exiting with 1.
- Query `https://api.supabase.com/v1/projects/${SUPABASE_PROJECT_REF}/advisors/security` with `Authorization: Bearer ${SUPABASE_ACCESS_TOKEN}`.
- Parse JSON response:
  - Count findings by level (`ERROR`, `WARN`, `INFO`).
  - Print all findings with title, description, and remediation.
  - If any findings have level == 'ERROR', exit 1 with summary of blockers.
  - If only WARN/INFO findings or zero findings, exit 0 with summary.
- Make script executable (`chmod +x scripts/check-security-advisors.sh`).
</action>
