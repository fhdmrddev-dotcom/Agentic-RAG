## Typography

Marker/footer/peek are a small render layer INSIDE the existing chat answer. **Exactly two real size steps** carry the feature — the app body (`text-sm` = 0.875rem/14px) and the app's real `text-xs` (`0.75rem` = 12px) — plus the marker's locked inline sub-grid exception. **Exactly two weights** — 400 regular + 600 semibold. Do not introduce new size or weight siblings.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Answer body (host, unchanged) | `text-sm` = 0.875rem (14px) | 400 | 1.6–1.7 |
| **Superscript marker** `¹` | `0.62em` of body, `vertical-align: super`, `line-height: 0` — *locked-by-sketch inline exception (see note)* | 600 (`--font-mono`) | 0 |
| Footer header "References · N sources" | `text-xs` = 0.75rem (12px) | 400 | 1.4 |
| Ref `[n]` number | `text-xs` | 600 (mono) | 1.4 |
| Ref filename | `text-xs` | 600 (semibold) | 1.4 |
| Ref location (`· Chunk 4 · 0.63`) | `text-xs` | 400 | 1.4 |
| Ref passage (italic) | `text-xs` | 400 (italic) | 1.45 |
| Peek head `[n] filename` | `text-xs` (mono) | 600 | 1.4 |
| Peek snippet (italic) | `text-xs` | 400 (italic) | 1.55 |
| Peek footer (loc · Open document) | `text-xs` | 400 / 600 (link) | 1.4 |
| Absence ⓘ inline label | `text-xs` | 400 | 1.5 |
| Absence ⓘ popover body | `text-xs` | 400 (600 lead sentence) | 1.5 |

**Two-size discipline (Dimension 4 fix):** every micro-copy element — footer header, `[n]`, filename, location, passage, peek head/snippet/footer, and BOTH absence-ⓘ strings — renders at the ONE real `text-xs` (0.75rem/12px). The earlier draft's `0.72rem` / `10px` / `11px` / `11.5px` near-siblings are collapsed into this single step (they sat within ~1.5px of each other — no legible hierarchy) and `0.72rem` is reconciled to the real Tailwind `text-xs` = 0.75rem. Body stays `text-sm` (14px). **That is two size steps.**

**Marker size exception (locked by sketch 074-A):** the `¹` renders at `0.62em` with `vertical-align: super` / `line-height: 0` — a relative inline sub-grid value, the same class of locked exception already registered for the marker/peek padding under Spacing. It is a superscript scaled off the body, **not** a fourth type-scale step.

**Two-weight discipline (Dimension 4 fix) — resolution chosen = 2-weight collapse:** **400 regular** (all prose, location, passage, snippet, absence copy) and **600 semibold** (the `¹` marker, the `[n]` ref-number, filenames, peek head, the "Open document" link). The sketch CSS renders the mono identifiers at 700; this contract **collapses them to 600** so the feature uses exactly two weights and stays self-contained — the delta between 600 and 700 on a tiny superscript mono chip is visually negligible and the `¹` still reads as a distinct raised identifier at 600. (The app-wide `mono-identifier-bold` 700 convention exists, but this phase deliberately does not invoke it, to keep the 2-weight cap clean and avoid a cross-phase design-doc dependency.)

## Marker Contract (074-A — LOCKED)

- **Form:** `<sup>` superscript numeral chip. JetBrains Mono, `font-size: 0.62em`, `font-weight: 600` (collapsed from the sketch's 700 per the Typography 2-weight discipline), `vertical-align: super`, `line-height: 0`, `color: --primary`, `background: --primary/15%`, `border-radius: 4px`, `padding: 1px 4px`, `margin-left: 1px`, `user-select: none`, `cursor: pointer`.
- **States:** hover → bg `--primary/35%`, ink `#fff`; focus-visible → same peek as hover + a visible focus ring (see A11y); active/pinned (`.active-ref`) → bg `--primary-strong`, ink `#fff`.
- **Density:** sparing — one marker per **load-bearing claim** only; framing prose and general-knowledge sentences carry none. The model is prompted for this density (marker-density wording is Claude's Discretion per CONTEXT); the UI never adds a marker the model didn't emit.
- **Set-membership guarantee (render consequence of D-02/D-03):** marker `n` = `citations[n]` by construction. Backend strips non-members and renumbers survivors `1..k` to match the footer, so the frontend renders only valid, clickable markers keyed 1:1 to footer rows.

### Streaming → Settle (074 + D-05 — LOCKED)
- During the token stream the answer body renders **calm and unmarked** (existing behavior; do not inject markers mid-token — never speculative).
- Markers attach **on settle** — the moment `unique_citations` is finalized and the `citations` SSE fires (`agent_loop.py` ~L2790), which is exactly sketch 074's "attach on settle."
- **Attach animation:** `markerPop` — `@keyframes { 0% { opacity:0; transform: translateY(-3px) scale(.6) } 100% { opacity:1; transform:none } }`, `--dur-base` (200ms), `--ease-bounce`, staggered `animationDelay = index * 60ms`.
- `prefers-reduced-motion: reduce` → drop the bounce/stagger; markers appear via a plain opacity fade (feeds Phase 155).
- **G-5 constraint:** injection happens after `dedupParagraphs` in the assistant `MarkdownRenderer` path; it must NOT alter the streaming-narration path (`StreamingNarration`) nor the dedup output. Re-run the replay/render tests.

## References Footer Contract (075-A — LOCKED)

- **Structure:** today's `CitationList`/`CitationCard`, now numbered `[n]`. Header: `▾/▸ References · {N} sources` (caret toggles; the sketch's `numbering net-new` wire-flag is a mockup-only honesty tag — **not shipped**).
- **Open-by-default rule:** the footer opens by default **when valid inline markers exist** on the message; otherwise it keeps today's collapsed default (`useState(false)`). This is the ONE behavior change to the footer's default open-state.
- **Row:** `[n]` (mono, 600, primary) · filename (semibold) · loc (`· Chunk 4 · 0.63` or `· Full document`) · passage (muted italic) · `↗ Open document` (primary link). `padding: 8px 10px`, `border-radius: --radius-sm (6px)`, bg `--muted`, `scroll-margin-top: 70px`, `cursor: pointer`. Hover → bg `--accent`.
- **Flash (marker→row):** clicking/activating a marker smooth-scrolls its row into view and blooms it — `background: --primary/15%` + `box-shadow: inset 3px 0 0 --primary, 0 0 0 1px --primary/35%`; auto-clear after **~1700ms**.
- **Bidirectional (row→marker):** clicking/activating a row highlights its marker (`.active-ref`) — the set-membership link reads two-way.
- **Full-doc rows (D-09/D-10):** render `· Full document` with no chunk/score; reuse the existing `is_full_doc` branch in `CitationCard`.

## Click-through Contract (075-A — LOCKED)

- **Primary target = hover-peek → click-to-pin** (winner A; NOT the workspace panel of variant C, NOT scroll-only of variant B).
- **Peek card:** `position: absolute`, `z-index: 60`, `width: 320px`, bg `--popover` (`--color-surface-hi`), `border --border`, `border-radius --radius-md (10px)`, `box-shadow --shadow-lg`, `padding: 12px 14px`. Enter/exit: opacity + `translateY(4px)`, `--dur-fast` (120ms).
- **Peek content (chunk):** head `[n] {filename}` + pin control; snippet = `passage` (italic muted); footer divider + `{loc}` left, `↗ Open document` right.
- **Peek content (full-doc, D-10):** head `[n] {filename}` + pin control; body = "Full document" affordance line (no snippet); footer = `↗ Open document` only (no loc/score).
- **Pin:** clicking the marker (or pressing Enter on focus) pins the peek (`.pinned` → border `--primary/35%` + extra ring); the pin toggle shows 📌. Pinned peeks persist until unpinned, Esc, or an outside click. Hovering another marker while unpinned re-peeks; while pinned it stays.
- **Positioning:** below the marker, `top = markerRect.bottom + scrollY + 8`, `left = min(markerRect.left, viewportWidth − 340)` (keeps it on-screen). On viewport-edge/mobile, clamp within the chat column.

## Accessibility (load-bearing — feeds Phase 155 / A11Y-01, WCAG 2.1 AA)

- **Keyboard-reachable markers:** each marker is a real `<button>` (or `role="button"` + `tabindex="0"`) with `aria-label="Citation {n}: {filename}"`. Enter/Space opens the peek and pins; it must NOT be hover-only (touch has no hover — the Phase 117 HIGH-fail lesson).
- **Non-hover peek path:** focusing a marker surfaces the peek (same as hover); Enter pins it; **Esc** unpins/closes and returns focus to the marker.
- **Peek focus management:** on pin, the peek is a focus-manageable container (`role="dialog"`, `aria-modal="false"`, labelled by its `[n] {filename}` head); Tab reaches the pin toggle and "Open document"; Esc closes and restores focus to the originating marker.
- **Pin toggle accessible name (Dimension 2 fix):** the 📌 pin control is icon-only — it MUST carry a state-toggled accessible name: `aria-label="Pin citation {n}"` when unpinned, `aria-label="Unpin citation {n}"` when pinned. Never ship the pin icon without a name.
- **Open/close announced:** the peek + the footer expand/collapse announce to AT — peek open/pin via the dialog role + focus move; footer via `aria-expanded` on the existing `CollapsibleTrigger` (already present) + an optional `role="status"` on the attach-on-settle transition.
- **Footer rows keyboard-operable:** each row is a `<button>`/focusable with `aria-label` (filename + location); the bidirectional flash must be triggerable by keyboard, and the flashed/active state is `aria-current` (or an `aria-live` polite announcement) in addition to the visual bloom.
- **Never color-alone (WCAG 1.4.1):** the marker's meaning is the numeral itself; the ref row leads with `[n]`; the active/flash states pair `--primary` with a structural `inset 3px 0 0` bar + ring — no state is signalled by hue alone.
- **Contrast ≥4.5:1 (WCAG 1.4.3) — citation-scoped AA:** meaningful muted text (ref passage, ref location, peek snippet, ⓘ label) MUST clear 4.5:1 on its surface. **Do NOT use the global dim token** `--muted-foreground-dim` (`.dark` 220 16% 45% ≈ 3.6:1 — fails), the exact trap Phase 117/088-05 flagged. Use `--muted-foreground` (`.dark` 220 16% 65%) or a citation-scoped AA token verified ≥4.5:1 on `--muted`/`--popover`. Verify each meaningful string against its actual surface.
- **Reduced motion:** `prefers-reduced-motion: reduce` disables `markerPop` bounce/stagger and the ref-row flash animation (state still conveyed structurally).
- **Focus-visible ring:** markers and rows get a visible focus ring (`--ring` = `239 100% 82%`) distinct from the hover wash.
