<objective>
Make the backend the sole author of citation truth. A new pure module strips
non-member / out-of-range `[n]` markers from the answer and renumbers survivors
1..k to the finalized retrieval set (D-02/D-03) at the settle point (D-05), and
injects a retrieval-turns-only citation-density instruction + numbered source
manifest into BOTH the native `system_prompt` and the compat `messages[0]`
channel (D-12/SC#10) so every provider is prompted uniformly while non-retrieval
turns stay byte-identical (D-14).

Purpose: the honesty core — a rendered marker can only ever point at something the
agent truly retrieved this run. All frontend work in later plans renders what this
plan validates; nothing downstream re-derives attribution.
Output: `citation_markers.py` (pure helpers), two additive seams in `agent_loop.py`,
and two Wave-0 backend test files.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model free-text answer → persisted `messages.content` | the model's emitted `[n]` markers are untrusted claims about attribution; they must be validated against the finalized retrieval set before persist |
| retrieved document content → model prompt (manifest) | retrieved passages/filenames are attacker-influenceable (a poisoned doc) but only ever surface as a numbered manifest; they cannot create a marker that points outside the real set |
| shared Deep agent-loop path → per-provider adapters | the citation instruction must not fork the provider-uniform path (SC#10/D-14) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-153-01-01 | Spoofing / Repudiation | model-emitted `[n]` markers | mitigate | `normalize_citation_markers` strips every out-of-range / non-member marker before persist (D-02); survivors renumber to `unique_citations` (D-03). A marker can only point at a truly-retrieved source (Pitfall 14) |
| T-153-01-02 | Tampering | shared citation path (SC#10/D-14 break) | mitigate | injection applied only via the provider-uniform `(active_system_prompt, messages[0])` pair; NO `provider ==` branch; a mid-list system message is explicitly NOT used (Anthropic drops it) |
| T-153-01-03 | Tampering | non-retrieval Deep turns (byte-identical guarantee) | mitigate | `apply_citation_instruction` is a no-op when `retrieved_citations` is empty — the prompt is byte-identical (D-12/D-14); unit-asserted |
| T-153-01-04 | Elevation of scope | workflow `llm_emit` answers (out of scope, D-08) | accept | injection is gated on the Deep agent-loop `retrieved_citations`; workflow answers keep their existing `citation_policy` gate — not touched this phase |
| T-153-01-05 | Tampering | prompt-injection via poisoned retrieved doc content in the manifest | mitigate | the manifest is advisory only; set-membership strip (T-153-01-01) means a poisoned instruction cannot fabricate a marker outside the real `unique_citations` set |
| T-153-01-SC | Tampering | pip installs | accept | NO package installs this phase (pure-Python helpers over already-vendored deps) — Package Legitimacy Gate not triggered |
</threat_model>
