<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| citation `document_id` (from another surface) → documents view | a chat citation carries a document_id; opening it must not bypass the user's document visibility |
| DOM flash helper input `n` → querySelector | `n` originates from validated citation indices; must not enable selector injection |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-153-02-01 | Information Disclosure | "Open document" deep-link | mitigate | `openDocument` only sets `setActiveView("documents")` + `setSelectedDocId(id)`; the EXISTING owner/RLS-scoped `DocumentDetailPanel` fetch is the gate — no new unscoped fetch by raw `document_id` (RESEARCH V4 / Open Question #1) |
| T-153-02-02 | Tampering | flashCitation* querySelector | mitigate | `n` is coerced to an integer and matched against `[data-citation-*="${n}"]` within a scoped container; a missing/invalid `n` is a no-op, never an unscoped/global selector |
| T-153-02-03 | Tampering | shared render tokens (index.css) | mitigate | citation CSS is an additive block; existing `:.dark` tokens and keyframes are untouched (verify via scoped diff) |
| T-153-02-SC | Tampering | npm installs | accept | NO package installs (context/CSS over already-vendored React) — Legitimacy Gate not triggered |
</threat_model>
