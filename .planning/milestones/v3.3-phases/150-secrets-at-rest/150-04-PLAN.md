| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-150-09 | Denial of Service | eager sweep on boot | mitigate | Idempotent enc:v1: prefix check + rotate-only-when-needed (Pitfall 3); best-effort try/except so a sweep blip never blocks startup (D-150-03). |

| T-150-10 | Repudiation | silent failed save (false success) | mitigate | update_settings raises 500 on save_app_settings==False before the audit write, so no false success/false audit row (D-150-07; Phase 147 CR-02). |
| T-150-02 | Information Disclosure | sweep/boot logging | mitigate | Sweep + warning logs name column names + counts + the env-var NAME only, never a key/value/token (T-081.1-04). |
