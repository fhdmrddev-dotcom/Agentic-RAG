<objective>
Add the D-06 maintenance/read-only write-block as a single FastAPI middleware seam:
mutating requests are rejected with a plain 503 while reads and the off-switch stay
reachable (auth + all /admin/* + self-cancel), in-flight runs finish, and a cold-cache
read defaults OPEN (D-Q4) so a settings blip can never wedge the platform. Expose the
maintenance boolean on the PUBLIC /health payload so the end-user banner has a
non-admin flag source.

Purpose: One correct write-block seam (not a per-route dependency that a future endpoint
would forget), with an allowlist that can never lock the operator out of turning
maintenance back off.
Output: `middleware/maintenance.py` + main.py wiring + public /health flag + tests.
</objective>
