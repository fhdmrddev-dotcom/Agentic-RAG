**Decision: fix ONLY the folder_scope (A4) path; leave the general no-folder_scope bound path as shipped.** Reasons:

2. **The confirmed BLOCKER is specifically the REGRESSION 152-06 introduced in the folder_scope composition branch** — a `necessary` check that WAS present was removed.
