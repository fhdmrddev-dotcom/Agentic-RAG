## Tests

### 1. New Chat always reachable (SC#1)
expected: On a non-chat view (Settings/Documents), the thin left icon rail still shows the New Chat (+) button; clicking it starts a fresh chat and switches to the chat view. New Chat can never be hidden.
result: pass

### 2. Inline thread filter (SC#2, tier 1)
expected: In the chat-history column, typing in the "Filter this list…" box narrows the thread list live, highlights the matching text, folds away empty date groups, and shows an honest "No chats match your search." empty-state when nothing matches.
result: pass

### 3. Global ⌘K / Ctrl+K finder (SC#2, tier 2)
expected: Pressing ⌘K (Ctrl+K) from any view — including a non-chat view like Documents/Settings — opens a centered command palette over your whole backlog. Typing filters it; ↑↓ move the selection; Enter opens the thread and lands you on chat; Esc closes and restores focus. The filter-box ⌘K chip opens it too.
result: pass

### 4. Date + folder grouping (SC#3)
expected: The thread list shows Today / Yesterday / Last 7 days / Last 30 days / Older headers with per-group counts; empty buckets are hidden. The Date⇄Folder toggle switches grouping cleanly — folder mode groups by folder name with "Unfiled" last, every thread preserved.
result: pass

### 5. Rail no longer starves history + no horizontal overflow (BUG-260711-01 relief)
expected: The thin rail and the dedicated history column are separate regions — the rail's nav icons never grow to crowd or squeeze the chat-history list (the old crowding bug is gone). No horizontal scrollbar appears on the desktop layout even with the workspace panel open at a narrower width.
result: pass

### 6. Preserved row behaviors + keyboard a11y (do-no-harm)
expected: In the history column, selecting / renaming / deleting a thread all still work; the running-dot + Stop button + options menu behave as before. Row actions (Rename/Delete/options) reveal on BOTH mouse-hover AND keyboard focus (Tab) — never only on hover.
result: pass

### 7. Mobile drawer search (D-08)
expected: At a narrow (mobile) viewport the desktop rail hides and a drawer opens; its "Search chats…" box narrows the list live with highlights. The bottom nav-icon row, New Chat, folder picker, and operator shield are unchanged; there is no ⌘K on mobile.
result: pass

### 8. Collapsible rail — pinned ☰ expand (REFINEMENT)
expected: A pinned ☰ toggle expands the 58px icon rail to ~210px labels and back. It is NOT hover-driven — hovering the collapsed rail keeps it at 58px (only the ☰ click expands it). New Chat and the operator shield are reachable in both states, and the expanded/collapsed choice survives a page reload.
result: pass

### 9. Fold-away chat history + ▷ reopen (REFINEMENT)
expected: A header handle (⟨|) on the history column folds it fully away, widening the conversation area. A ▷ "Show chat history" handle then appears in the chat top-bar to reopen it. The folded/shown choice survives a page reload; inline filter, ⌘K, grouping, and mobile drawer are all unchanged.
result: pass
