The sub-agent max_steps loop (task_service.py:513-589 run_task_sub_agent):
```python
for step in range(max_steps):
    content, tool_calls = await _stream_one_iteration(...)
    if not tool_calls:
        summary = content or ""   # ← terminal answer; break
        break
    # ... dispatch tools, append assistant + tool messages, loop ...
else:
    # max_steps exhausted WITHOUT a tool-free final answer (the GLM symptom):
    summary = content or "Sub-agent reached max_steps without producing a final answer."
```
