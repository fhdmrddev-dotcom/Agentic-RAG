## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated user → workflow_definitions/_runs/_phases/harness_audit rows | Each user may only read/write their own rows (or global definitions); RLS at the Postgres row is the sole isolation mechanism (CLAUDE.md). |
| regular user → is_global publishing | A regular user must NOT be able to publish a workflow everyone sees; only the seed migration may create globals (D-03 operator tier deferred). |
| append-only audit → tamper | A user must not be able to hide/alter a recorded tool refusal or phase transition. |
