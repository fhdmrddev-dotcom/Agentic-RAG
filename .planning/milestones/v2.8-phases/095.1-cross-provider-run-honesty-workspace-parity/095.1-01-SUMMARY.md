- `frontend/src/lib/workspacePanel.ts` — pure, reload-safe selector that decides deterministically whether a run earns a workspace panel (`shouldPopulate`: write_todos OR ≥2 deduped MEANINGFUL tools) and derives read-only items from activity (`deriveWorkspacePanel`), with the locked label precedence `write_todos > execute_code.description > code-inferred > "Run code"` (`inferLabel`). ## Decisions Made

- `MEANINGFUL_TOOLS` as a `Set<string>` for O(1) membership; the spike-007 keyword rules ported verbatim as a typed `ReadonlyArray<readonly [RegExp, string]>` (`LABEL_RULES`).
- `inferLabel` capitalizes a leading-comment label with JS semantics matching Python's `.capitalize()` (first char upper, remainder lower) to keep the spike's `"Build the quarterly report"` expectation exact.
- Billing detection (`_has_insufficient_quota`) reads only the structural `insufficient_quota` code or a structured `body` dict — never the message text — so a rate-limit message containing "quota" can never be mislabeled.
- SDK imports in `errors.py` are wrapped in `try/except ImportError`; `_isinstance_any` filters to only the classes that imported, so the module degrades gracefully to the numeric `.status_code` path if a provider SDK is absent.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Test ToolCall factory type clash with nested `args` shapes**
- **Found during:** Task 1 (workspacePanel test — first GREEN attempt)
- **Issue:** The plan's prescribed `tc(partial)` factory typed `args` via `Partial<ToolCall> & { args?: Record<string, unknown> }`. The intersection re-applied the stricter `ToolCall['args']: Record<string, string>` to the call-site literals, producing 3 net-new `tsc` errors (TS2322) where test fixtures pass nested `{ todos: [...] }` / `{ description, code }` args. This breaks the acceptance criterion "tsc reports zero NET-NEW errors vs baseline 37."
- **Fix:** Restructured the factory to `Omit<Partial<ToolCall>, "args"> & { args?: Record<string, unknown> }` and destructure-then-cast `args` through `unknown`, so the loose fixture bag is accepted while the returned object remains a valid `ToolCall`. This is purely a test-harness typing fix — no production code or fixture data changed.
- **Files modified:** frontend/src/lib/__tests__/workspacePanel.test.ts
- **Verification:** `npx tsc -b` returned to baseline 37 (zero net-new); all 31 tests still green.
- **Committed in:** 702eb3f5 (Task 1 GREEN commit)
