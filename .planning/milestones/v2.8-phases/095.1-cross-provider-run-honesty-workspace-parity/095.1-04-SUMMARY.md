## Accomplishments

- **`backend/app/services/agent_loop.py`** — the outer `except (APIError, anthropic.APIError, google_errors.APIError)` catch (the terminal-classification site) now classifies structurally. The keyword if-ladder (`if any(kw in err_lower for kw in ("credit balance", "billing", "quota", …))` → … → `else`) is gone. It is replaced by:
  ```python
  err_lower = err_str.lower()
  if any(kw in err_lower for kw in ("context", "maximum context", "too long", "token limit")):
      kind = "context_overflow"
  else:
      kind = classify_provider_error(_resolved_provider, e)
  user_msg = message_for_kind(kind, err_str)
  ```
  keyed on the in-scope `_resolved_provider` (set at `run_agent_loop` top, line 956, `ctx.resolved_provider`). **429 → `rate_limit` ALWAYS precedes billing** (the classifier's order guard) so Google's `RESOURCE_EXHAUSTED` can never read as billing again. Billing is claimed ONLY when an `insufficient_quota` structural signal proves it; an uncertain error → neutral truthful copy + bounded raw detail.
- **Context-overflow preservation:** context-overflow has no reliable structured status code (it usually arrives as a 400 `bad_request`), so it is retained as a SINGLE narrow text pre-check BEFORE the classifier — a targeted retention of the one keyword case with no reliable structured code, NOT the billing-first soup. Documented inline.
- **Import added** at the top of the file alongside the other `app.services` imports: `from app.services.provider_gateway import classify_provider_error, message_for_kind` (the existing function-scoped `provider_gateway` import at ~1473 for `GatewayRequest`/`open_stream` is untouched).
- **3 wiring-guard tests** added to `test_errors.py` exercising the exact composition the consumer performs — Google 429/RESOURCE_EXHAUSTED → rate_limit copy (no "billing"), OpenAI 429-with-"quota"-text → rate_limit, and an unknown error → neutral message with bounded raw detail.
- **Byte-identical shared path:** the emit/raise tail (`full_content += user_msg`; `await _emit(redis, run_id, 'delta', content=user_msg)`; `await _emit(redis, run_id, 'error', message=err_str)`; `raise`) is unchanged. No adapter generator touched, no new SSE event, the request-too-large 429 branch (~1817) and the `_is_transient_provider_error` retry path (def @441 + use @1838) are byte-identical.

## Decisions Made

- **Context-overflow kept as a narrow pre-check** (per the plan's preferred action): the classifier only returns `context_overflow` if a structured signal proves it (rare — overflow usually arrives as a 400), so to avoid regressing the helpful context-overflow copy, a single `if any(kw in err_lower for kw in ("context", "maximum context", "too long", "token limit"))` pre-check sets `kind = "context_overflow"` before falling through to the classifier. This is the one keyword case with no reliable structured code.
- **Wiring test lives on `test_errors.py`** (not a streaming-harness agent_loop test): the plan offered this as the lighter alternative. The guard exercises `message_for_kind(classify_provider_error(provider, exc), str(exc))` — the identical 2-call composition — so the BUG-260606-01 fix is guarded at the wiring contract without a full agent-loop streaming harness.
- **Fake exception classes over `MagicMock(spec=[])`** for the wiring guards: a spec'd MagicMock raises `AttributeError` when you try to set `__str__`, and the wiring guard needs a controllable `str(exc)` (the `err_str` fed to `message_for_kind`). `_FakeGoogleError` (`.code` + `.status`, no `.status_code`) and `_FakeOpenAIError` (`.status_code` + optional `.code`/`.body`) mirror the real SDK shapes with a real message string (per `feedback_mock_completeness`).
