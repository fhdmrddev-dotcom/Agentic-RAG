# Phase 095.1 Plan 03: Run Honesty — Model Attribution & True Reload Timer Summary

**Every assistant run now shows WHO answered (`{provider} · {model} · turn N` from the real `runs.model`/`runs.provider`) and HOW LONG it truly took (`completedAt − startedAt`, identical live and on reload), via one additive runs↔messages SELECT threaded through the full type chain — closing BUG-260606-02 (the day-old "1440m" reload-timer lie) with zero migration and a byte-identical shared SSE path.**

## Accomplishments

- **D-04 model attribution (RUN-HONESTY):** the RunCard run-sub line — a "model OMITTED" stub since 095-07 — now reads the REAL resolved `runs.model`/`runs.provider` and renders `{provider} · {model} · turn N` (e.g. `google · gemini-3.5-flash · turn 1`), visible at rest on every assistant response, graceful (`turn N` only) for legacy/no-run messages.
- **D-05 true reload timer (RUN-HONESTY):** a finished run's duration is the persisted wall-clock `completedAt − startedAt` — identical live and on reload — never `Date.now() − created_at`. A finished run with NO `completedAt` shows NO duration (the honesty rule). Closes BUG-260606-02 (a day-old run reading "1440m").
- **One additive backend SELECT, zero migration:** `_enrich_messages_with_runs` gains 4 COLUMNS (`model, provider, started_at, completed_at`) with a BYTE-IDENTICAL WHERE clause (`thread_id` + `user_id` + RLS) — no widened row set, no IDOR, no new write (the data already lives in `runs`). Flows to both `/messages` and `/snapshot` (shared helper).
- **Cross-provider safety held:** the threads.py diff is confined to the enrich helper (two hunks) — NO provider-branch, NO SSE event-name change, NO chunk-handler/event_consumer touch (grep-proven). The shared path stays provider-agnostic across all 8 providers.

## Decisions Made

- **No migration:** confirmed `runs.model`/`provider`/`started_at`/`completed_at` already exist in `supabase/full-schema.sql` (lines 555-558; model/provider NOT NULL, started_at DEFAULT now() NOT NULL, completed_at written on finalize). D-04/D-05 are SELECT-only.
- **`wasStreamingRef` guard:** the cleanest way to distinguish a run that flipped terminal live THIS session (gets a legitimate `Date.now()` frozen end) from a reloaded already-terminal run (was never streaming this session → must NOT fabricate an end-time). Without it, a reloaded run with `startedAt` but no `completedAt` would re-create the 1440m lie.
- **`showElapsed` on RunStatusStrip:** the strip is one component carrying ⏱/Step/verb. Rather than render an empty `⏱` for a no-duration terminal run, an additive `showElapsed` flag omits the whole duration segment — honest, and backward-compatible (defaults true so every existing caller is unchanged).
