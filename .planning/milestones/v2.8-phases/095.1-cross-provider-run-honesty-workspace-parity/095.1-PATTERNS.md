Note the `import type { JSX } from "react"` at `fileIcon.tsx:31` — the convention that dodges TS2503 when a helper returns `JSX.Element`.

### Pattern C — Gateway-package module conventions (no import cycle)
**Source:** `provider_gateway/events.py` + `__init__.py`
**Apply to:** `errors.py` (D-03).
**Why:** Every gateway module opens with a D-0x role docstring + the no-import-cycle invariant, uses `from __future__ import annotations`, types with `Literal`, declares `__all__`, and is re-exported from `__init__.py`. The classifier is a PURE helper called from the consumer catch — NOT inside the adapter generators (preserves the byte-identical Deep stream).

### Pattern D — Additive SELECT through the runs↔messages enrich (null-graceful end-to-end)
**Source:** `_enrich_messages_with_runs` (threads.py) → `MessageResponse` (message.py) → `_mapMessageResponse` (api.ts) → `Message` (types/index.ts)

**Source:** the 095/087 invariant T-095-01-01 (RESEARCH Security Domain V5)
**Apply to:** the derived panel labels (`tc.args.description`/inferred code labels), the run-sub `{provider} · {model}`, filenames.
