<objective>
Make every run honest about WHO answered and HOW LONG it took (D-095.1-04/05) via ONE
additive runs↔messages SELECT threaded through the full type chain, then derived in RunCard:

- D-04 model attribution: the run-sub line becomes `{provider} · {model} · turn N`, reading
  the REAL resolved `runs.model` / `runs.provider` (finishing the 095-07 "model OMITTED" stub).
- D-05 true reload timer: a finished run's duration = `completedAt − startedAt` (persisted
  wall-clock, identical live and on reload), never `Date.now() − created_at` (the BUG-260606-02
  "1440m for a day-old run" lie). A finished run with no completedAt → NO duration.

Purpose: closes BUG-260606-02 (reload-timer-inflated). NO migration, NO new write — the data
already lives in `runs` (model/provider NOT NULL; started_at DEFAULT now() NOT NULL;
completed_at written on finalize). The change is additive-SELECT-only on the G-5 hot file
`threads.py` (do NOT touch the shared chunk handler).

Output: 1 backend SELECT + 4 Pydantic fields + 4 mapper fields + 4 type fields + RunCard
render (run-sub + timer) + backend enrich test + RunCard timer test.
</objective>
