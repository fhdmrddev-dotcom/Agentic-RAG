<objective>
Add the agent mode selector to the chat frontend: thread the agent_mode parameter from the UI dropdown through the hook and API layer to the backend POST body.

Purpose: Makes the explorer sub-agent accessible to users from the main chat interface. Without this, the backend explorer mode has no way to be triggered.
Output: A mode toggle (General / Explorer) appears in the MessageInput toolbar. Selecting Explorer and sending a message includes agent_mode="explorer" in the request. Mode resets on thread switch (known v1.0 behavior).
</objective>
