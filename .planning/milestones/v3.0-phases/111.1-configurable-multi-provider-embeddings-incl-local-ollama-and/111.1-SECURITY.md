## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Settings UI → settings API | Untrusted provider/model/base_url/dims/bucket values cross here | provider config (non-secret), API keys (secret) |
| settings API → app_settings (DB) | `save_app_settings` writes the stored embedding/extraction config | provider config + key sentinel |
| **app config (model/provider) → external LLM endpoint** | **THE EGRESS BOUNDARY** — document text leaves the app here; a mis-resolved provider would ship local document text to a cloud endpoint | user document text (private) |
| ingest path → embedding provider | Chunk text leaves to the configured embedder; must use the SAME creds as the query path | chunk text (private), embed creds |
| query path → `match_document_chunks` (DB) | Vector-space integrity boundary — must compare only same-model vectors | embedding vectors (private) |
| migration file → live DB schema | A destructive apply (db reset/push) would wipe the ~19–30 dev docs | full corpus |
| settings API → background re-embed job → `document_chunks` | A long-running, vector-mutating job over a user's chunks; must stay RLS-scoped + never block the loop | user vectors + tags (private) |
