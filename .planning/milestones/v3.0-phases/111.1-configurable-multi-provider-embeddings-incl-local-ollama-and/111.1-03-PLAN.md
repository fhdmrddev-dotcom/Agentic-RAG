<objective>
Fix the EMBED-04 credential bug (the headline retrieval-correctness bug) and wire the D-10
per-chunk model tag end-to-end, plus lift the D-12 confidence buckets into settings.

Today `documents.py:1475` calls `embed_chunks(..., model=...)` but never threads `user_settings`,
so a configured non-default embedder embeds CHUNKS via env creds while QUERIES go via configured
creds → two vector spaces → silent retrieval failure. The query path (`retrieval_service.py:42-44`)
is already correct; this plan makes the chunk path match, tags each chunk with its embedding model
(D-10), filters stale-model chunks out of search, and reads the confidence buckets from settings.

Purpose: One configured embedder must embed chunks AND queries identically; a half-finished
re-embed must never compare across vector spaces; confidence labels stay honest after a switch.
Output: edits to `embedding_service.py`, `documents.py`, `retrieval_service.py`, `agent_loop.py`.
</objective>
