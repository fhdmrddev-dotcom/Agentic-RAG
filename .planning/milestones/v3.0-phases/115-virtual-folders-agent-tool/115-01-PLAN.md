`_build_field_meta` + `_build_whitelist`) out of the FastAPI route module
`backend/app/api/document_views.py` into a new injectable service module
`backend/app/services/document_view_resolver.py`, so the Phase 115 agent tool (Plan 02/03) can

whole phase.

secure-phase two-user test exists to catch (D-115-6 / RESEARCH §"Don't Hand-Roll" key insight).

behavioral change is WHERE validation failures raise: the extracted core raises a plain
`ResolveError`; the route re-wraps it to `HTTPException` (byte-identical route behavior); the
agent handler (Plan 02) will map it to a calm `ToolResult` string.

Output: `document_view_resolver.py` (new), `document_views.py` routes as thin wrappers, and 10
Wave-0 test files (5 unit + 4 integration) matching the VALIDATION.md / RESEARCH Wave-0 gap list.
