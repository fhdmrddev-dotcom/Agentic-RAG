## Done entry (paste under "### ✅ Done")

**Phase 115 — Your assistant can use your smart folders** &nbsp; 🟢 Use it now (in chat)
You can now just **ask the assistant, in plain chat, to pull up documents by their properties** — the way you'd ask a colleague. It turns the smart folders and filters you built on the Documents page into something you can talk to:

- *"Open my Invoices view."*
- *"How many contracts expire in the next 90 days?"*
- *"List every document tagged 'Project Meridian', then summarize the risks in them."*

It answers right in the conversation with **the actual matching documents** (newest first), so it can then open, read, and **cite** them in a follow-up. It's **honest about totals** — if 47 match but it shows the 20 newest, it says so, never passing a partial list off as the whole thing. Not sure what you've got? Ask *"what saved views and filters do I have?"* and it lists them back. It only ever reaches **your own documents** (and anything shared with everyone) — never someone else's, even on a shared view.

*Honest scope note:* this is a **new ability of the chat assistant, not a new screen** — the Documents page and sidebar are unchanged. One known rough edge being watched (not introduced here): one AI provider (MiniMax) occasionally fumbles complex filter requests; the others handle it cleanly and it's on the test checklist.
