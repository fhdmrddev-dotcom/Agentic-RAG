## Spacing Scale

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, chip internal padding (`px-2 py-1`) |
| sm | 8px | Compact row padding, filter control gaps, pill horizontal padding (`px-2`) |
| md | 16px | Default element spacing, card content padding |
| lg | 24px | Section gaps between filter row and table |
| xl | 32px | Vertical spacing between SectionCards |

- Table row cells use `py-2 px-3` (8px / 12px) — compact data-density pattern
- Timestamp column fixed at 160px width; action type column fixed at 160px width; details column takes remaining flex width

Accent reserved for:
1. Active date-range filter pill: `bg-primary/10 text-primary border-primary/30`

No accent on: table rows, column headers, inactive filter pills, Prev/Next buttons (use `variant="ghost"` shadcn Button).

Primary visual anchor: Export CSV button (gradient-primary, card header right).

## Layout Contract

### SectionCard placement
- Position: bottom of SettingsPage, below the Code Execution SectionCard
- Card: `<Card className="ghost-border bg-card/50 shadow-sm">`
- CardHeader: left = title "Audit Log" + description; right = Export CSV button (absolute or flex justify-between on header row)

### Card header (two-column)
```
[ "Audit Log"                    ] [ Export CSV ↓ ]
[ "Your account activity — all…" ]
```
- Achieved via `<CardHeader className="flex flex-row items-start justify-between">`
- Export CSV button: `<Button size="sm" className="gap-2 gradient-primary shrink-0">` with `<Download className="h-3.5 w-3.5" />`

### Filters row (inside CardContent, above table)
```
[ All ][ 7d ][ 30d ][ 90d ]     [ Action type ▼ ]
```
- Left cluster: date-range pills — `<button>` elements, not shadcn Button, to match existing chip pattern
  - Inactive: `text-xs bg-muted/30 text-muted-foreground px-2 py-1 rounded-full ghost-border`
  - Active: `text-xs bg-primary/10 text-primary border border-primary/30 px-2 py-1 rounded-full font-bold`
- Right: action type `<select>` — `text-sm rounded-md bg-muted/30 ghost-border px-2 h-8 focus:outline-none focus:ring-2 focus:ring-primary/30`
- Row gap: `gap-2` between pills, `ml-auto` to push select to right end
- Container: `<div className="flex items-center gap-2 mb-4 flex-wrap">`

### Table
```
Timestamp         | Action Type      | Details
──────────────────────────────────────────────
Apr 14, 2026…    | document.upload  | report.pdf (2.4 MB)
Apr 14, 2026…    | search.query     | "How does the system handle…"
```
- `<table className="w-full text-sm">`
- `<thead>`: `<tr className="border-b border-border/30">` with `<th className="text-xs font-bold text-muted-foreground text-left pb-2 pr-4">`
- Column widths: timestamp `w-40` (160px), action type `w-40` (160px), details `flex-1` (remaining)
- `<tbody>`: rows use `<tr className="border-b border-border/30 hover:bg-muted/20 transition-colors">`
- `<td className="py-2 pr-4 text-muted-foreground font-mono text-xs">` for timestamp
- `<td className="py-2 pr-4">` for action type (use a monospace chip: `font-mono text-xs bg-muted/30 px-2 py-1 rounded ghost-border`)
- `<td className="py-2 text-muted-foreground">` for details — plain text, no chip

### Pagination row (below table)
```
                    ‹ Prev   Page 1 of 4   Next ›
```
- Right-aligned: `<div className="flex items-center justify-end gap-2 mt-4">`
- Prev / Next: `<Button variant="ghost" size="sm" className="h-7 gap-1 text-xs">` with ChevronLeft/Right icon
- Disabled state: `disabled` prop when on first/last page (shadcn Button handles opacity automatically)
- Counter: `<span className="text-xs text-muted-foreground">Page {page} of {totalPages}</span>`

## States Contract

### Loading state
- Spinner replaces table content (not skeleton rows) — per CONTEXT.md Claude's Discretion
- Implementation: conditional render — if `loading`, show centered `<Loader2 className="h-5 w-5 animate-spin text-muted-foreground mx-auto my-8" />`
- Filters row remains visible during loading so user can adjust while loading
- Export CSV button is `disabled` during loading

### Empty state
- Centered in the table area, replacing `<tbody>` rows
- Implementation: `<tr><td colSpan={3} className="py-10 text-center text-sm text-muted-foreground">No entries found for this period.</td></tr>`
- No icon, no call to action — matches existing SettingsPage muted pattern

### Error state
- Replaces table area (same container)
- `<p className="text-sm text-destructive bg-destructive/10 px-4 py-2 rounded-lg">Failed to load audit log. Refresh the page to try again.</p>`
- Matches the SettingsPage main error pattern (line 386)

## Interaction Contract

### Filter interaction
- Selecting a date pill or changing the action type dropdown **immediately** triggers a new API fetch (`page` resets to 1 on any filter change)
- No "Apply" button — filters are reactive
- Active date pill is visually distinguished with accent styling (see Layout Contract)
- Default state on mount: "All" date range selected, "All types" dropdown selected, page 1

### Pagination interaction
- Clicking Prev/Next changes `page` state, triggers API fetch with new `page` param
- Prev is disabled when `page === 1`
- Next is disabled when `page === totalPages`
- Filter change resets `page` to 1 before fetching

### Export CSV interaction
1. User clicks "Export CSV"
2. Button enters loading state (spinner replaces Download icon, button `disabled`)
3. Frontend calls `GET /audit-logs/export` with current `since` + `action_type` params, JWT auth header
4. Response received as blob → create object URL → programmatic `<a download>` click → revoke URL
5. Button returns to normal state after download triggered
6. On error: button returns to normal, show a brief `text-destructive` message beneath the card header (auto-dismissed after 4 seconds or on next interaction)

### Timestamp display
- Local time, formatted as: `Apr 14, 2026 10:32 AM`
- Use `new Date(ts).toLocaleString('en-US', { month: 'short', day: 'numeric', year: 'numeric', hour: 'numeric', minute: '2-digit', hour12: true })`

### Details column rendering
- Per-action-type one-liner as specified in D-04
- `search.query` text truncated at 60 chars with ellipsis if longer
- `thread.create` and `thread.delete` render an em-dash (`—`) in the details cell
- No tooltip expansion in this phase — plain truncation only
