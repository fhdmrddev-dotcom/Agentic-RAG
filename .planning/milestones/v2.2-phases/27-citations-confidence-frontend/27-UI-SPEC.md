## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps (`gap-1`), chevron-to-text gaps (`gap-1.5`) |
| sm | 8px | Passage inner top margin (`mt-2`), card-to-card gap (`gap-2`) |
| md | 16px | Default element spacing between message regions |
| lg | 24px | Section padding between tool calls / message text / citation block |
| xl | 32px | Layout-level gaps (not used in new components) |
| 2xl | 48px | Major section breaks (not used in new components) |
| 3xl | 64px | Page-level spacing (not used in new components) |

Exceptions:
- Citation card left padding: `pl-3` (12px) — intentional visual indentation for quoted-block style
- Citation card vertical padding: `py-2` (8px) — compact to avoid heavy visual weight
- Confidence badge top margin: `mt-2` (8px) — slim gap between message text and badge row
- "N sources" toggle top margin: `mt-3` (12px) — slightly more separation below confidence row

Source: CONTEXT.md D-05, D-06; confirmed in existing `ExecuteCodeBlock.tsx` spacing patterns.

## Interaction Contract

### CitationList — Section Toggle

| State | Visual | Trigger |
|-------|--------|---------|
| Collapsed (default) | `> N sources` — ChevronRight + count label, `text-muted-foreground` | Initial render |
| Expanded | `v N sources` — ChevronDown + count label, `text-muted-foreground` | User clicks toggle |
| Expanded, cards visible | All CitationCard instances rendered, `flex flex-col gap-2 mt-2` | After toggle click |

Toggle button: plain `<button>`, no shadcn Button — keeps visual weight at `text-xs text-muted-foreground hover:text-foreground transition-colors`. No border, no background.

### CitationCard — Passage Toggle

| State | Visual | Condition |
|-------|--------|-----------|
| No passage | Filename + location label only. No toggle rendered. | `citation.passage == null` or `citation.is_full_doc === true` |
| Passage collapsed (default) | 2-line clamp via `line-clamp-2`. "Show more" + ChevronRight below. | `hasPassage && !expanded` |
| Passage expanded | Full passage text (up to 400 chars). "Show less" + ChevronDown below. | `hasPassage && expanded` |

No server round-trip on expand — passage in Citation object IS the full payload (Phase 26 truncates at 400 chars server-side).

### ConfidenceBadge — Render Conditions

| Condition | Renders |
|-----------|---------|
| `message.confidence` is set | Badge row + optional disclaimer |
| `message.confidence` is undefined | Nothing rendered (non-RAG turns) |
| `confidence.disclaimer` is non-null | Disclaimer line below badge |
| `confidence.disclaimer` is null | Badge only, no disclaimer line |

Badge appears mid-stream when SSE `confidence` event fires — this is correct behaviour. The spread update pattern `{ ...m, confidence: result }` in `useMessages.ts` preserves the field through subsequent `delta` events.

### Rendering Order in MessageItem

```
1. ToolCallPanel           (existing — unchanged)
2. Skill activated row     (existing — unchanged)
3. Message text            (existing — MarkdownRenderer)
4. ConfidenceBadge         (NEW — only if message.confidence is set)
5. CitationList            (NEW — only if message.citations?.length > 0)
```

## States Inventory

| Component | States to Handle |
|-----------|-----------------|
| CitationList | collapsed (default), expanded |
| CitationCard | no-passage, passage-collapsed (default), passage-expanded |
| ConfidenceBadge | high (green), medium (amber), low (red), low-with-disclaimer |
| MessageItem | existing states unchanged + new: confidence-present, citations-present |

Loading / streaming states: CitationList and ConfidenceBadge can appear while the message is still streaming. No skeleton loaders needed — they appear only after SSE events fire (which already carry the data).

Historical messages: ConfidenceBadge does NOT render (confidence is not persisted). CitationList renders from `source_refs` mapped to `citations` on DB load — handles null `passage` gracefully (no passage toggle rendered).

## Accessibility Notes

- Citation card `<button>` elements must have accessible labels. Use `aria-expanded` on the toggle buttons.
- Colour-coded confidence badge (green/amber/red dot) is supplemented by the text label (`High confidence`, `Medium confidence`, `Low confidence`) — not colour-only.
- `line-clamp-2` CSS truncation approach is accessible; screen readers receive full text regardless of visual truncation.
- All interactive elements have `hover:` and `focus-visible:` states via Tailwind defaults.
