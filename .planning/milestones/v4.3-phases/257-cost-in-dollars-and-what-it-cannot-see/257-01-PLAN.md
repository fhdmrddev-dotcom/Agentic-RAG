<threat_model>
### ASVS L1 Threat Model

1. **TM-257-01: Float Precision Drift / Financial Residue**
   - Threat: Using IEEE-754 binary floating-point numbers (`float`) for token multiplication introduces cumulative sub-cent rounding drift across high-volume runs.
   - Mitigation: Strict `Decimal` arithmetic in `pricing_service.py` and PostgreSQL `numeric(12, 6)` column type; quantized explicitly to `0.0001` USD with `ROUND_HALF_UP`.

2. **TM-257-02: Silent Free-Run Fabrication ($0.00 Fallback)**
   - Threat: An unrated model or None token count is coalesced to 0 or $0.00, causing billing/audit systems to treat unrated runs as free.
   - Mitigation: `CostResult.cost_usd` is typed as `Decimal | None`, returning `None` whenever `rate is None`. The AST fence forbids external math that might default to zero.

3. **TM-257-03: Multi-Home Conversion Drift**
   - Threat: Developers author ad-hoc token-to-dollar math in new endpoints or UI controllers, causing divergent spend numbers.
   - Mitigation: AST fence in `test_257_single_token_conversion_home.py` automatically scans all backend ASTs in the unit test suite and fails CI if any duplicate conversion is created.
</threat_model>
