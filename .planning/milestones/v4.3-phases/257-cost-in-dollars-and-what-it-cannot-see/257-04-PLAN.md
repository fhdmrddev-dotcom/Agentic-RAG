### ASVS L1 Threat Model

1. **TM-257-09: Financial Misrepresentation on Run Inspection Surfaces**
   - Threat: Operators inspecting a run see an empty or zero cost and assume execution was gratis.
   - Mitigation: Strict ternary badge state in `RunCostBadge.tsx` ensures unrated runs explicitly show `Unrated` badge in amber, and partial coverage runs show warning footnote.

2. **TM-257-10: Inadvertent Historical Recalculation**
   - Threat: Running an automated reprice script rewrites financial analytics for prior accounting periods.
   - Mitigation: Effective-dating logic strictly enforces `effective_from <= run.created_at ORDER BY effective_from DESC LIMIT 1`, verified by Scenario 2 in `uat_257_scenarios.py`.
</threat_model>
