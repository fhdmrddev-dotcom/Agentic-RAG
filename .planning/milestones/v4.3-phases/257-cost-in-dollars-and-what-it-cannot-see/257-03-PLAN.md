<threat_model>
### ASVS L1 Threat Model

1. **TM-257-07: Cross-Site Scripting (XSS) via Model ID or Error Strings**
   - Threat: Malicious or unvalidated model ID strings rendered into HTML or SVG tooltips unsafely.
   - Mitigation: React automatic string escaping on all interpolated text and SVG text elements.

2. **TM-257-08: Client-Side Number Truncation / False Precision**
   - Threat: Frontend JavaScript `parseFloat` losing decimal precision or displaying scientific notation (e.g. `1e-5`).
   - Mitigation: Format dollar amounts using fixed 4-decimal formatting (`toFixed(4)`) or localized currency formatters.
</threat_model>
