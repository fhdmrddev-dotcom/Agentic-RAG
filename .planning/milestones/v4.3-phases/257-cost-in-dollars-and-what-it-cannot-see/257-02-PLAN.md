<threat_model>
### ASVS L1 Threat Model

1. **TM-257-04: Unauthorized Rate Mutation / Repricing Tampering**
   - Threat: A standard tenant user inserts or alters model rates, distorting historical or current billing totals.
   - Mitigation: `POST /rates` enforces strict org-admin or platform-admin permission check, verified in unit tests.

2. **TM-257-05: SQL Injection via Dynamic Model / Filter Strings**
   - Threat: Filter parameters (`model_id`, `provider`, `time_range`) interpolated dynamically into spend aggregation SQL.
   - Mitigation: Parameterized SQL queries using asyncpg positional parameters (`$1, $2, ...`), with zero string-concatenated SQL values.

3. **TM-257-06: Blind Spot Invisibility / Masked Data Gaps**
   - Threat: API endpoints omit the unrated run count or fail to expose incomplete coverage markers, making the UI report partial figures as complete.
   - Mitigation: API response contracts require `unrated_runs_count` and `incomplete_coverage_count` fields in `SpendSummary`, covered by endpoint assertions.
</threat_model>
