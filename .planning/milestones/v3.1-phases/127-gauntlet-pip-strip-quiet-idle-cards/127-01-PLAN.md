<objective>
Establish the icon foundation for the Phase-127 energized re-skin: install the build-time 3D-icon mechanism, upgrade the single shared `PHASE_GLYPHS` phase-type vocabulary from flat unicode to 3D fluent-emoji, and migrate the one existing test that asserts on literal flat glyphs so it survives the swap.
