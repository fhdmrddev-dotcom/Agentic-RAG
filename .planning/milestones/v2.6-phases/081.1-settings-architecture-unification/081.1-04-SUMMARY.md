## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed _build_providers crash on double-serialized JSONB string**
- **Found during:** Task 1 (test_no_json_reads_after_migration)
- **Issue:** `_build_providers()` called `.get()` on `provider_model_lists` assuming it was a dict, but the migration runner's `json.dumps()` before asyncpg's JSONB codec caused double-serialization, storing a JSON string literal instead of a JSONB object. `_build_providers` crashed with `AttributeError: 'str' object has no attribute 'get'`
- **Fix:** Added defensive string-to-dict deserialization in `_build_providers`: if `provider_model_lists` is a string, parse it with `json.loads()` before use
- **Files modified:** `backend/app/models/user_settings.py`
- **Verification:** All 8 integration tests pass; unit tests unaffected
- **Committed in:** `3b3f10b` (part of Task 1 commit)
