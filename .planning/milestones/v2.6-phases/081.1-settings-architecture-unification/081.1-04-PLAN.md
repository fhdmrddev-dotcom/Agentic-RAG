Create `backend/tests/integration/test_081_1_settings_migration.py` following the test_073 pattern.

**Setup:**
- PG skip guard (same `_check_pg_available_sync` pattern)
- `pg_pool` fixture (function-scoped asyncpg pool with JSONB codec)
- `cleanup_test_data` fixture that:
  - Before each test: saves current app_settings row state
  - After each test: restores original state (prevents test pollution)

**Tests (8 integration tests):**

1. `test_migration_writes_all_keys(pg_pool)`:
   - Create a temp JSON file with all 36 keys (copy from the actual `settings_override.json` fixture or create inline)
   - Monkeypatch `_migrate_settings_override` to use the temp file path
   - Call `await _migrate_settings_override()` (import from `app.main`)
   - Query `app_settings WHERE id='global'` via pg_pool
   - Assert: `llm_provider` is not NULL, `provider_model_lists` is not empty dict, `llm_model` has a value
   - Assert: temp file renamed to `.migrated`

2. `test_migration_idempotent_no_file(pg_pool)`:
   - Ensure no JSON file exists at the expected path
   - Call `await _migrate_settings_override()` -- should return without error
   - Verify no DB changes (no exception)

3. `test_migration_failsafe_db_error(pg_pool, monkeypatch)`:
   - Create a temp JSON file
   - Monkeypatch `get_pg_pool` to return a pool that raises on `execute`
   - Call `await _migrate_settings_override()`
   - Assert: JSON file still exists (NOT renamed)
   - Assert: error was logged (capture log)

4. `test_no_json_reads_after_migration(pg_pool)`:
   - After migration, verify that `load_app_settings_async()` does NOT read from any JSON file
   - Monkeypatch the `_settings_cache` to None and `_settings_cache_time` to 0 to force a DB read
   - Monkeypatch `get_pg_pool` to return the test pool
   - Call `await load_app_settings_async()`
   - Assert: returned `UserEffectiveSettings` has valid fields
   - Assert: no `FileNotFoundError` or JSON read occurred (verify by checking that `pathlib.Path.read_text` was NOT called on any settings file)

5. `test_hot_reload_write_then_read(pg_pool, monkeypatch)`:
   - Monkeypatch `get_pg_pool` to return test pool
   - Reset cache: `invalidate_settings_cache()`
   - Write a change: `await save_app_settings({"llm_model": "test-hot-reload-model"})`
   - Read back: `s = await load_app_settings_async()`
   - Assert: `s.llm_model == "test-hot-reload-model"`
   - This proves D-07 invalidate-on-write works

6. `test_4_tier_precedence_db_wins(pg_pool, monkeypatch)`:
   - Insert a row into `model_capabilities_overrides`: `model_id='test-model-081', provider='openai', llm_call_timeout_seconds=999`
   - Also set env CSV to have `test-model-081=111`
   - Also set `MODEL_CAPABILITIES['test-model-081'] = {..., 'llm_call_timeout_seconds': 222}`
   - Monkeypatch `get_pg_pool` to return test pool
   - Call `await get_per_call_timeout_async('test-model-081')`
   - Assert: returns 999 (DB wins over env and static)
   - Cleanup: delete the test row and restore MODEL_CAPABILITIES

7. `test_4_tier_fallthrough_to_static(pg_pool, monkeypatch)`:
   - Ensure no DB row for `gpt-4o` in model_capabilities_overrides
   - Ensure no env CSV override for `gpt-4o`
   - `gpt-4o` IS in MODEL_CAPABILITIES static dict
   - Call `await get_per_call_timeout_async('gpt-4o')`
   - Assert: returns the static dict value (not 999, not 300 default)

8. `test_4_tier_unknown_model_default(pg_pool, monkeypatch)`:
   - Use a model_id that is NOT in DB, NOT in env CSV, NOT in static dict: `"totally-unknown-model-xyz"`
   - Call `await get_per_call_timeout_async('totally-unknown-model-xyz')`
   - Assert: returns `DEFAULT_LLM_CALL_TIMEOUT_SECONDS` (300)

**Each test must clean up after itself** (delete any test rows inserted into model_capabilities_overrides, restore any monkeypatched globals).
