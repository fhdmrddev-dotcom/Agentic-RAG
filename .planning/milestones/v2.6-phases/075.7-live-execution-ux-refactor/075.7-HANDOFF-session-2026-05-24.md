## The operational mistake

`frontend/tests/e2e/fixtures/db-teardown.fixture.ts` has a `beforeEach` in every
`@075.7` scenario that calls `teardownTestUserData(TEST_USER_EMAIL)` —
`TEST_USER_EMAIL` defaults to `fhdmrd@gmail.com`, which is the operator's actual dev
login. Every Playwright run today wiped the operator's local chat history (runs,
messages, threads tables). Operator noticed "old chats disappeared" after refresh.

**Mitigations for next session:**
- Either create a dedicated test user (e.g., `playwright-e2e@test.local`) and set
  `E2E_USER_EMAIL=playwright-e2e@test.local` in env before running tests, OR
- Move the teardown to `afterAll` instead of `beforeEach` so a single Playwright
  run only wipes once at the end, OR
- Document the wipe risk prominently and require an explicit
  `--allow-data-loss` flag.
