## Plan Shape & Extraction Order

### Q1 — How many plans should this phase break into, and what's the shape?

| Option | Description | Selected |
|--------|-------------|----------|
| 3 plans, capability-grouped | P1 mechanical (9 bodies + ExecuteCodeBody rename, zero visual change), P2 RunCard wrapper, P3 Focus Mode + UAT. Each plan = one rollback boundary. Lowest blast-radius staging. | ✓ |

| Option | Description | Selected |
