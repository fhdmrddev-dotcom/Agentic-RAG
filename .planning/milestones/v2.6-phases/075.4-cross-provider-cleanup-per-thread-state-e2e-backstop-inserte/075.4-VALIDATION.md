## Sampling Rate

- **After every task commit:** Run the quick command scoped to the modified plan (unit + integration for that surface).
- **After every plan wave:** Run the relevant subset (Wave 1 = backend full unit + per-thread vitest; Wave 2 = vitest + Plan 04 unit; Wave 3 = full Playwright suite).
- **Before `/gsd-verify-work`:** Full suite must be green (or 44→0 triaged failures explicitly justified in 075.4-TEST-TRIAGE.md).
- **Max feedback latency:** ~30s for unit/integration; ~5 min for E2E.
