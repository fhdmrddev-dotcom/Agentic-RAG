## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing Critical] Added `tests/e2e/**` to vitest's exclude glob**

- **Found during:** Task 2 (Playwright bootstrap)
- **Issue:** Default vitest config matches `*.spec.ts` globally — Plan 06's `scenario-NN-*.spec.ts` files would be picked up by vitest and crash under jsdom because they import `@playwright/test`.
- **Fix:** Added `exclude: ["node_modules/**", "dist/**", "tests/e2e/**"]` to `vitest.config.ts`.
- **Files modified:** `frontend/vitest.config.ts`
- **Verification:** Plan acceptance criterion "ensure `tests/e2e/**/*.spec.ts` does NOT overlap vitest's glob" was implicit `<read_first>` rather than an `<acceptance_criteria>` row — addressed proactively.
- **Committed in:** `b1f590c` (Task 2 commit)

**2. [Rule 3 - Blocking] Set executable bit on `scripts/restart-backend.sh` via git update-index**

- **Found during:** Task 3
- **Issue:** The plan says `chmod +x after creation`. On Windows + git for windows, the filesystem chmod doesn't propagate to git's mode bits unless `core.fileMode` is true OR `git update-index --chmod=+x` is run.
- **Fix:** `git update-index --chmod=+x scripts/restart-backend.sh` before commit.
- **Files modified:** none additional (mode bit applied at index time).
- **Verification:** `git diff --cached --raw` shows mode 100755 for the .sh.
- **Committed in:** `262688e` (Task 3 commit)
