## Final shape of `_accumulate_chunk_usage`

Pure function at `backend/app/api/threads.py:550-590` — no closure capture, no I/O:

```python
def _accumulate_chunk_usage(chunk, provider, input_total, output_total):
    u = getattr(chunk, "usage", None)
    if u is None:
        return input_total, output_total
    _i = getattr(u, "prompt_tokens", 0) or 0
    _o = getattr(u, "completion_tokens", 0) or 0
    if provider == "google":
        return _i, _o          # CUMULATIVE — overwrite-last-wins
    return (input_total or 0) + _i, (output_total or 0) + _o   # OpenAI / OpenRouter / others — +=
```

`active_provider_name` is captured once per request at `threads.py:1841-1842` via `get_model_capability(model_id).get("provider", "unknown").lower()` and threaded into the chunk closure. The closure's early-return on `chunk.usage` is gone — chunks carrying both `usage` and `delta.content` flow through to delta processing.

Path A gate at `openai_service.py:886-893` reverted — `stream_options.include_usage` is once again unconditional across all OpenAI-compat providers. Defensive handler is the new source of correctness.
