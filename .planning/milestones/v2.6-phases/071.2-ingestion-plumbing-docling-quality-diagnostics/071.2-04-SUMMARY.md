## Decisions Made

- **Stringified forward-ref annotation** (`"ExtractedDocument | None"`) — no runtime import cost. `ExtractedDocument` added under the existing `TYPE_CHECKING` guard at the top of `multimodal_service.py` for IDE / type-checker support. Matches the pre-existing `UserEffectiveSettings` import pattern in the same file.
- **Conditional bbox spread on INSERT rows** rather than always writing `"bbox": None`. Rationale: keeps the DB write minimal when the upstream extractor doesn't produce bbox (LegacyExtractor still leaves `bbox=None`); matches the jsonb column's nullable default; symmetric across tables + images.
- **Bare `raise HTTPException(...)` (no `from e`)** on the 404 wrap — T-071.2-04-01 information-disclosure mitigation. Chained cause would leak `PostgrestAPIError` table names / internal error codes into FastAPI's default error response. Plan acceptance criterion explicitly verified via grep `except Exception:` + body asserting bare raise.
- **Preserve the 7-line TODO comment block removal as a single hunk per call site** — the 14-line deletion is symmetric across both multimodal calls; documents.py diff is cleanly readable as "two parallel changes."
