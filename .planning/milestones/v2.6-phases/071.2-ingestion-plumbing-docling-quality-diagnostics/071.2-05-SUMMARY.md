### 2. The Verbatim Docling XPath Port (zip_xpath_docx)

Source: `backend/venv/Lib/site-packages/docling/backend/msword_backend.py`

| Element | Source line(s) | Ported as |
| --- | --- | --- |
| `_BLIP_NAMESPACES` namespace map | 58-69 | `_DOCX_BLIP_NAMESPACES` |
| `blip_xpath_expr = etree.XPath(".//a:blip", namespaces=...)` | 78-80 | `root.iterfind(".//a:blip", _DOCX_BLIP_NAMESPACES)` |
| `vml_imagedata_xpath_expr = etree.XPath(".//v:imagedata", namespaces=...)` | 81-83 | `root.iterfind(".//v:imagedata", _DOCX_BLIP_NAMESPACES)` |
| rel-ID dereference for `a:blip` via `{...}embed` | 2122-2127 | `_BLIP_EMBED_ATTR` constant + `blip.get(_BLIP_EMBED_ATTR)` |
| rel-ID dereference for `v:imagedata` via `{...}id` | 2181-2186 | `_VML_IMAGEDATA_ID` constant + `vml_img.get(_VML_IMAGEDATA_ID)` |

Algorithm:

1. Open DOCX as ZIP, collect parts: `word/document.xml` + every `word/header*.xml` + every `word/footer*.xml`
2. For each part: parse with hardened `etree.XMLParser(resolve_entities=False, no_network=True)` (T-071.2-05-03)
3. For each part: read sibling `_rels/{name}.rels` to build `{rId: Target}` dict
4. For each `.//a:blip` match: get rId → resolve media path → check `seen_media` set (dedup) → read bytes → PIL decode → size filter `min_px=50` → b64 PNG re-encode → append ImageData
5. Same for `.//v:imagedata` matches

**Closes RAG-MM-LIFT-02 at unit level**: anchor-only DOCX fixture produces `inline_shapes_docx → 0` AND `zip_xpath_docx → ≥1`.
