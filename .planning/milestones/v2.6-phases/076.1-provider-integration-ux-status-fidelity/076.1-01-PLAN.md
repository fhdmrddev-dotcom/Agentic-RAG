<objective>
Register 4 curated direct providers (DeepSeek, Moonshot, MiniMax, Zhipu) across all backend config surfaces so they route through their own OpenAI-compatible APIs instead of OpenRouter.

Purpose: Eliminate the OpenRouter latency/reliability tax (DeepSeek 24min/893K tokens via OR, tool parse failures for Kimi, output truncation for MiniMax). All 4 providers have OpenAI-compatible APIs that the existing `openai_service.py` `get_llm_client` can use via `base_url` switching — zero new service code needed.

Output: Backend fully wired — any of the 4 providers can be selected in Settings (Plan 02 adds frontend entries) and used in chat. Sub-agents use cheap provider-specific defaults. Unknown model IDs infer the correct provider via regex patterns.
</objective>
