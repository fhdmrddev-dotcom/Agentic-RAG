## Decisions Made

- **flavor="stream" baked in (no per-call flavor override).** Plan 01 bench used stream-only; the thesis is borderless-dominant per Plan 01 results. A future enhancement could try both stream + lattice and merge, but Plan 02 follows the bench winner exactly. This decision is scoped to Plan 02; v3.0+ may add a lattice fallback path if SEED-021 plants.
- **Bbox 5-key dict shape `{l, t, r, b, page}`** — matches `TableData.bbox` schema established in D-071-08 (Phase 071). Page extracted as `int(t.page)` from camelot's Table.page (which is 1-indexed); failures to parse the bbox tuple downgrade gracefully (log warning, emit table with `bbox=None`) so partial failures don't lose the row.
- **Test contract is shape, not count.** Per D-071.3-17, recall variance is acceptable; the happy-path unit test asserts the TableData contract (str headers, str-list-of-list rows, dict-or-None bbox) but does NOT assert a minimum count. Hard-coded counts would couple the test to camelot-version recall quirks; that gate lives in Plan 05's UAT scoreboard against SC#6, not in Plan 02 unit tests.
- **Empty-PDF test uses reportlab-synthesized PDF, not the truly-broken `b"%PDF-1.4\\n%%EOF\\n"` from the plan's literal example.** Reason: camelot raises `PdfReadError` on the malformed minimal PDF, which would conflict with the plan's `assert out == [] or isinstance(out, list)` (no exception expected). The reportlab-synth PDF is structurally valid + table-free, lets camelot complete cleanly, and exercises the no-tables code path. The plan's intent ("call doesn't crash; returns list") is preserved; the literal byte-string is replaced with a more realistic fixture-free synth that uses an already-pinned dep (reportlab is in requirements.txt for Phase 069 fixtures).
