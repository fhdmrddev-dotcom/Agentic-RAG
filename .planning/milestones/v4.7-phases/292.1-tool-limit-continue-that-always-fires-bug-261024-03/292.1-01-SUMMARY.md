streamed or persisted for any provider; the deepseek-only adapter strip is retired.**

## Deviations from Plan

### Auto-fixed / judgement calls

**1. [Rule 3 - Blocking] Task order 1 → 3 → 2a → 2b instead of 1 → 2a → 2b → 3**
- **Issue:** `test_dsml_leak_signal.py` imported `DSML_LEAK_ERROR_MESSAGE` from `agent_loop`; deleting it
  in 2a would leave a collection error between commits (zero-headroom baseline, Pitfall 12).
- **Fix:** retired the adapter strip and both fences first (Task 3, `394bae740`), then deleted the
  constant in 2a. Every commit stays collectible.

**2. [Rule 1 - Bug] Live tail computed from the held suffix, not `len(TagHoldback.released)`**
- **Issue:** the plan's `settled.visible[len(_tag_holdback.released):]` would re-emit text that reached
  the browser through OTHER emit sites (STRUCTURED-holdback flush / failed-call notice, the TPM 429
  notice), double-streaming it.
- **Fix:** `_tag_held = _tag_holdback.finish()`; `_shown = full_content` minus that held suffix; emit
  `full_content[len(_shown):]` after the kind branch. Identical to the plan's form on the native path.

**3. [Rule 2 - Missing critical] Native drain abort path drops the held text too**
- Added a `try/except BaseException: drop_held(...); raise` around the native drain (273-REVIEW
  WR-06(b) parity), because the producer's sink persists `full_content` after an abort.

**4. Turn boundary pin interpreted (test B)**
- At the cap the paused round never reaches the native buffer path, so there is no `turn_boundary`
  there — matching a structured cap call. The "exactly one `turn_boundary` for PREAMBLE + F1" pin is
  on the MID-RUN parsed path (`test_b_a_preamble_before_a_mid_run_text_call_folds_exactly_once`).

**5. Save point: one `strip_markup(full_content)` computation, used at both content sites**
- `full_content` is a closure variable of `run_agent_loop`; `_persist_assistant_message` cannot
  reassign it without `nonlocal`. The plan's grep (`strip_markup(full_content)` count 2) reads 1;
  both `content=` sites use `_strip_nul(_saved_content)`.

**6. Markup-only cap pause (test D, markup-only)**
- The loop's pre-existing empty-answer sentence fires when a paused round leaves no text, exactly as
  for a structured cap call with no preamble today. Not changed (D-05 parity); the test asserts no
  markup and live == persisted instead of `persisted == ""`.
