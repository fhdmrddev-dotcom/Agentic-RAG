## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` hsl(216 45% 4%) ≈ #06090F | page surfaces |
| Secondary (30%) | `--card` hsl(220 30% 7%) ≈ #0C1017 | cards, panel, modal, report fact cells |
| Accent (10%) | `--primary` hsl(239 100% 82%) ≈ #A3A5FF | see reserved list |
| Destructive | `--destructive` hsl(0 72% 51%) ≈ #DC2828; text `hsl(0 80% 80%)` | genuine failures and alerts only |
| Warning (amber, shipped) | `--warning` hsl(38 92% 60%) ≈ #F7B23B | waiting-on-a-person + refusals that are not failures |

Accent reserved for (this phase): the focus ring on newly focusable elements (`focus-visible:ring-2
ring-primary/30`) — the Steps|Team tabs, the team-plane scroller, the picker trigger; the selected
Steps|Team tab (shipped `SWITCH_ON`); the shipped `▶ Run now` CTA in the publish strip. Nothing else
in 296 spends accent.

Tier rule (sketch 129-C, locked): **dim** = user-chosen or neutral (Stopped, withheld, unavailable
download, unknown engine) → **amber** = waiting on a person or a refusal with a reason (panel
Waiting, schedule refused) → **red** = a genuine failure only (watched-into-failed alert, schedule
launch error). Never colour alone: every state carries a glyph or a word.
