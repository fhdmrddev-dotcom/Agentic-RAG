## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| outside caller → /inbound/* | untrusted network caller; untrusted body text |
| caller-supplied input text → model prompt | text that may carry instructions |
| link holder → /inbound/files/{token} | anyone holding a URL for up to 300 s |
| unattended run → owner's knowledge scope | runs as the key's owner in the key's org |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-293-11 | Information disclosure | /inbound start + read (existence oracle) | mitigate | `_not_found()` byte-identical `Not found.` for not-on-key, unknown, foreign-org and other-key runs; tested by body equality |
| T-293-12 | Elevation of privilege | cross-org start | mitigate | thread insert stamps `org_id = key.org_id`; definition read scoped to key org or system-global; owner re-read via `get_definition(owner)` + `published` |
| T-293-13 | Tampering | inputs override caps / folder / kickoff | mitigate | `validate_inbound_inputs` admits declared fields only; `_`-prefixed and RESERVED keys refused as unknown; caps and `kickoff_prompt` are server-set |
| T-293-14 | Elevation of privilege | prompt injection through inputs | mitigate | tools, grants, steps, model from the definition snapshot (`model=None`); TRUST-03 envelope on the batch sub-question path; external actions stay approval-armed; no answering a pause through a key (D-10) |
| T-293-15 | Information disclosure | run read by another key | mitigate | `origin_kind='key' AND origin_ref=key.id AND user_id=owner` in the single access query (D-12) |
| T-293-16 | Information disclosure | file link leak | mitigate | 300 s one-time Redis token (GET+DEL in one transaction); on use, key liveness + run origin + file-in-thread re-checked |
| T-293-17 | Denial of service | start flood / runaway spend | mitigate | per-key start limit before any read; scheduler default caps armed before the run drives (A1) |
