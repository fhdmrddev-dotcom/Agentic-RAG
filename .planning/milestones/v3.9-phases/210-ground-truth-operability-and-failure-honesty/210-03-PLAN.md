<objective>
Implement embedding and retrieval failure honesty (RAG-09), closing BUG-260815-05 so that provider outages (429 quota exhaustion, auth errors) are never reported as "nothing was retrieved (0 sources)".
</objective>

<threat_model>
- T-210-07 (Conflation of Provider Outage with Empty KB): When embedding generation fails (429 insufficient quota, connection failure), `_handle_search_documents` catches the exception. If the validator gate only checks `output.citations` for non-emptiness, the gate reports *"nothing was retrieved (0 sources) — this step reads your documents and must show where its answer came from"*. Mitigation: `tool_dispatcher` packages `{"is_error": True, "error": "provider_error", "provider": "openai", "detail": str(exc)}` into `ToolResult.citations`; `task_service.py` and `phase_types.py:823` pass it through to `output["citations"]`; `_validate_citations_required` inspects this list, avoiding any need to touch `phase_types.py`.
- T-210-08 (Join Seam / Parallel Wave Deadness): If tool_dispatcher and validator_kinds are tested only in isolation, key naming mismatches fail open silently. Mitigation: Provide `test_retrieval_failure_honesty.py` executing `_handle_search_documents` into `_validate_citations_required` with zero mocking between them.
</threat_model>

         - When `mode == "retrieved_and_cited"`:
           - First check if `output.get("citations")` contains a provider error citation:
             ```python
             raw_citations = output.get("citations") or []
             provider_error = next((c for c in raw_citations if isinstance(c, dict) and c.get("is_error")), None)
             if provider_error:
                 provider_name = provider_error.get("provider") or "embedding provider"
                 err_msg = provider_error.get("detail") or "provider refused request"
                 return GateResult(
                     False,
                     f"citations_required: document search failed because the {provider_name} returned: {err_msg} — "
                     "this is a provider failure, not an empty knowledge base",
                 )
             # Valid non-error citations
             valid_citations = [c for c in raw_citations if not (isinstance(c, dict) and c.get("is_error"))]
             if not valid_citations:
                 return GateResult(
                     False,
                     "citations_required: nothing was retrieved (0 sources) — this step "
                     "reads your documents and must show where its answer came from",
                 )
             ```
