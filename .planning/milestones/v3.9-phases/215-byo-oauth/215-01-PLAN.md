# Plan 215-01: OAuth Token Storage Schema & Models

## Tasks

### Task 1: Migration 129 — `connector_tokens` Table
- Create `supabase/migrations/129_connector_oauth_tokens.sql`:
  - `public.connector_tokens` table with:
    - `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
    - `connection_id UUID NOT NULL REFERENCES public.connector_connections(id) ON DELETE CASCADE UNIQUE`
    - `account_email TEXT NULL`
    - `account_name TEXT NULL`
    - `access_token_ciphertext TEXT NOT NULL`
    - `refresh_token_ciphertext TEXT NULL`
    - `token_type TEXT NOT NULL DEFAULT 'Bearer'`
    - `scopes TEXT[] NOT NULL DEFAULT '{}'`
    - `expires_at TIMESTAMPTZ NOT NULL`
    - `refresh_claimed_until TIMESTAMPTZ NULL`
    - `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`
    - `updated_at TIMESTAMPTZ NOT NULL DEFAULT now()`
  - Index on `connection_id` and `(connection_id, expires_at)`.
  - Add `auth_type` (`'static_key' | 'oauth_byo' | 'mcp'`) and `status` (`'active' | 'revoked' | 'error'`) to `public.connector_connections`.

### Task 2: Pydantic Models for OAuth
- In `backend/app/models/connector.py`:
  - Add `OAuthConnectionConfig`: client credentials override (`client_id`, `client_secret`), redirect URI, custom scopes.
  - Add `OAuthTokenResponse`: safe public view (`account_email`, `account_name`, `token_type`, `scopes`, `expires_at`, `status`) strictly excluding all `*_ciphertext` fields.
  - Update `ConnectorConnectionResponse` to include `auth_type`, `account_email`, and `status`.

### Task 3: Unit Tests
- Create `backend/tests/unit/test_oauth_models.py`:
  - Verify `OAuthTokenResponse` strictly excludes ciphertext fields (T7 gate).
  - Verify validation constraints on client ID, scopes, and expiration timestamps.
