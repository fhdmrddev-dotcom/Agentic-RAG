# Plan 215-03: Claim-Based Token Refresh Lifecycle Engine

## Tasks

### Task 1: Atomic Lease Token Refresh Service
- Create `backend/app/services/connectors/oauth_refresh.py`:
  - `get_valid_oauth_token(db, connection_id)`:
    - Queries `connector_tokens` for the connection.
    - If `expires_at > now() + interval '5 minutes'`, decrypts `access_token_ciphertext` with `decrypt_secret` and returns token.
    - If expiring / expired:
      - Attempts atomic lease acquisition:
        ```sql
        UPDATE public.connector_tokens
        SET refresh_claimed_until = now() + interval '30 seconds'
        WHERE connection_id = :conn_id
          AND (refresh_claimed_until IS NULL OR refresh_claimed_until < now())
        RETURNING id, refresh_token_ciphertext, token_type;
        ```
      - If lease acquired:
        - Decrypts `refresh_token_ciphertext`.
        - Calls provider token refresh endpoint via `egress.send_pinned_http`.
        - If success: encrypts new `access_token` (and new `refresh_token` if rotated), updates `expires_at`, clears `refresh_claimed_until`, and returns fresh `access_token`.
        - If provider returns `400/401 invalid_grant` (revoked / expired credentials):
          - Sets `public.connector_connections.status = 'revoked'`.
          - Sets `public.connector_connections.error_message = 'OAuth authorization was revoked or expired at the provider'`.
          - Raises `OAuthRevokedError`.
      - If lease was held by another worker:
        - Waits up to 5 seconds (polling every 500ms) for the other worker to complete refresh, then reads and returns the refreshed token.

### Task 2: Tool Dispatcher Integration
- Update `backend/app/services/tool_dispatcher.py` to resolve valid OAuth access tokens before executing first-party Google / Microsoft connector tools.

### Task 3: Unit Tests
- Create `backend/tests/unit/test_oauth_refresh.py`:
  - Test valid non-expired token returned immediately without network call.
  - Test expired token acquires lease, calls refresh, and updates DB ciphertext.
  - Test concurrent lease race: worker 2 waits for worker 1's refresh without double-POSTing provider.
  - Test `invalid_grant` triggers connection revocation and sets status='revoked'.
