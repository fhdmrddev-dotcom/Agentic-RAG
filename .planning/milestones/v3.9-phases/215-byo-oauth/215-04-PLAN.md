# Plan 215-04: Settings & Connection Form OAuth UX

## Tasks

### Task 1: Frontend API Client
- In `frontend/src/lib/api/connectors.ts`:
  - Add `getOAuthAuthorizeUrl(provider: string, connectionId?: string, customClientId?: string, customScopes?: string[])`.
  - Update `ConnectorConnection` type with `auth_type`, `account_email`, `status`, `error_message`.

### Task 2: ConnectionFormPanel OAuth Flow
- In `frontend/src/components/settings/ConnectionFormPanel.tsx`:
  - For Google and Microsoft services:
    - Render a prominent **"Connect with Google"** / **"Connect with Microsoft"** button with service icon.
    - If platform credentials are not globally configured, provide an expandable **"Custom OAuth Application (Client ID & Secret)"** section.
    - Clicking Connect initiates authorization flow by navigating to backend `/api/connectors/oauth/authorize`.

### Task 3: ConnectionsTab Status & Badges
- In `frontend/src/components/settings/ConnectionsTab.tsx`:
  - Render connected account email (e.g. `Connected as john@acme.com`) under the connection title.
  - Render `REVOKED` badge in amber/red when `status === 'revoked'`.
  - Provide a single-click **"Reconnect"** button on revoked rows to re-trigger authorization.

### Task 4: Unit Tests
- Create `frontend/src/components/settings/__tests__/ConnectionFormPanel.oauth.test.tsx`:
  - Test rendering of OAuth Connect button for Google / Microsoft services.
  - Test rendering of account email badge when connected.
  - Test rendering of REVOKED badge and Reconnect button on revoked connections.
