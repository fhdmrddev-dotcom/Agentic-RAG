**The sub-tab question is already answered — do not invent a second pattern.**
`frontend/src/components/ui/tabs.tsx` (78 L, a thin Radix wrapper exporting `{Tabs, TabsList, TabsTrigger,
TabsContent}`) is reusable for nesting: Radix `Tabs` nests, and `KnowledgeHealthPage.tsx:5` already nests a
`By Document / By Query` sub-tab strip inside its outer `Tabs`. 217-06 spent a whole plan on this
primitive's contrast tokens, and `tabsContrast.test.ts` (14 cases, in both count-gate knobs) pins them.
Mount `<Tabs>` inside `<TabsContent value="ingestion">`, exactly as `KnowledgeHealthPage` does. Local
`useState` for the active sub-tab lives INSIDE `IngestionTab` — it is a *view* of the tab body, not a
Library selection, and must NOT enter `librarySelection`'s reducer.

**Folder picker analog — `components/health/MoveToFolderDialog.tsx:28-75`:**
```
listFolders() -> Select -> "root" sentinel
```
Copy this shape for `UploadFolderPicker.tsx`: fetch folders via `listFolders()` (already shipped in
`@/lib/api`), render a `Select`, and use the same `"root"` sentinel value the move-to-folder dialog uses
for "no folder" so the two pickers behave identically. The picker sets `folderId`/`folderName` state that
`IngestionTab` already threads to `DocumentUpload` (Wave 1's prop plumbing).

**`DocumentUpload`'s `variant` prop (added Wave 1, default `"band"`):** add `"hero"` as the second value.
The hero variant renders the sketch's `.dropbig` shape — cloud icon, `Drop files here`, `or`, a
`Choose files` button, and the accepted-formats line. ⚠ **The `accept` attribute and the formats line stay
computed from `acceptedFormats.ts`'s `acceptAttribute()` / `formatsSentence()` in BOTH variants** — never
a second transcription (this is the fence `D2`/`D3` in `drive.cjs` that 217-08 already had to repair once
after exactly this kind of fork).

**The relocation, not a rebuild:** Wave 1 (`217.1-02`) already mounted `<DocumentUpload variant="band" />`
directly in `IngestionTab`'s body with the six page-supplied props already threaded. This task moves that
same mount inside the new `<TabsContent value="add-files">`, changes its `variant` to `"hero"`, and adds
the `UploadFolderPicker` beside it. No new prop plumbing from `LibraryPage` is required.
