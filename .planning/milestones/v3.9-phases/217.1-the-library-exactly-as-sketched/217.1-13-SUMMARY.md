## Overview

Added the `governance_health` chip-level render gate to close T-217.1-04. The three Governance-sourced chips (Broken links, Unclassified, Unsure metadata) and their `getGov*` calls are now gated behind `governance_health === true`. The four retrieval-sourced chips (Most found, Never found, Weak matches, Stale) remain unconditional — the gate is chip-level, never tab-level.

## Decisions

1. **Chip-level, not tab-level.** The four retrieval-sourced chips render regardless of `governance_health`. Only the three Governance chips are gated.

2. **Call-gated, not catch-gated.** The `getGov*` calls never fire when `governance_health` is off — the gate prevents the call, not just hides the result (T-217.1-17a).

3. **`useSignalFetch` `enabled` param.** When `enabled=false`, the hook skips the fetch entirely and returns `{ count: 0, loading: false }` — the hook call order stays stable (React rules of hooks), but the side effect short-circuits.

4. **Server-side wall already correct.** `document_governance.py:61-65`'s `require_visible("governance_health")` router-level dependency is unchanged. This plan only proves it by test.
