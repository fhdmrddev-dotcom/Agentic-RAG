**The binding invariant — re-verify after this extraction, do not merely trust it:**
`LibraryPage.tsx:83-84`:
```
"[&_table_th:nth-child(n+3):nth-child(-n+5)]:hidden [&_table_td:nth-child(n+3):nth-child(-n+5)]:hidden"
```
Shipped has **seven** `<th>`s (chevron is already column 1: `<th className="px-2 py-3 w-8" />`,
`DocumentList.tsx:347`), so `nth-child(3,4,5)` = Type/Size/Chunks. The extraction must not add or remove a
`<th>`/`<td>`, and must not wrap cells in a `<td colSpan>`. Verify with: `drive.cjs` A1/A2 (reads the order
from `<th className="px-4 py-3…">` — the extraction must preserve that exact class string, not just the
column order), a jsdom count assertion (`thead th` length === 7, positions 3-5 = Type/Size/Chunks), and the
G-4 browser row for the visual shed (jsdom computes no styles).

**The expand chevron — already exists, stays version-gated (D-217.1-30):** `DocumentList.tsx:347`
(`<th className="px-2 py-3 w-8" />`) + `:369-379` renders the glyph only when `isExpandable(doc)`
(`version_number > 1`, Phase 112 D-01). The sketch draws `›` on every row with no expanded content defined
for a non-versioned row. **Do not build it on every row** — SC#1's composition asserts the column, not a
per-row glyph. Carry this behavior into `DocumentRow.tsx` unchanged.

**Folder pill — new prop needed.** `DocumentList` does not receive `folders` today. Add a `folders:
Folder[]` prop (threaded from `LibraryPage`, which already holds them), resolve `doc.folder_id` to a name,
and render a small pill under the filename, alongside the existing `v{n}` / `{n} tables` / `{n} imgs` pills
at `:391-406` (already shipped, untouched).

**Chunk proportion bar — role-match analog:** `ReembedStatusCard.tsx:146`'s width-proportion bar (already
shipped honesty primitive shape) OR `KnowledgeHealthPage.tsx:43-53`'s `ConfidenceChip` (track + fill +
tabular number) — build `ChunkProportionBar.tsx` as a small leaf: `{ value: number, max: number }` renders
a track, a fill sized to `value/max`, and the tabular chunk count. `max` is the highest `chunk_count` over
the currently loaded documents (computed once in `DocumentList`, passed down).

**Inline six-stage strip in the Status cell:** reuse `IngestionStrip` (Wave 1's now-visible-label version)
for an in-flight row (`doc.status === "processing"`), keyed on `doc.ingestion_step`. This is a SECOND mount
of the same component the Ingestion tab uses — one component, two places, not a fork.

**Failure sentence:** reuse `classifyIngestionError` from Wave 1's `ingestionErrorVocabulary.ts` — the
SAME mapper, not a second one.

**The extraction shape — role-match analog:** `components/health/HealthDocumentRow.tsx` (already shipped)
is the nearest "one row, several derived affordances" component to model `DocumentRow.tsx`'s prop surface
on: `document`, `folders`, `maxChunkCount`, `isExpandable`, `isExpanded`, `onToggleExpand`, `onSelect`,
`selectedDocId`, plus the existing per-row handlers (`handleReingest`, delete, move-to-folder) currently
inline in `DocumentList.tsx`.
