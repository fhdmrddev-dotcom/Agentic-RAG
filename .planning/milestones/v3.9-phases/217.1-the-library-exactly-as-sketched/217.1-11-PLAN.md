before any audit write, so a provider outage today writes NOTHING and is indistinguishable from "your

citation at `tool_dispatcher.py:781` — the thing actually thrown away is narrower than the inherited
wording claims: it never reaches `audit_log.metadata`) persists as `similarities: {document_id: score}` on
the same dict literal BE-4 edits.

lying about a value the system already has (LIB-07) — without corrupting a chart that already ships.

similarities key, and the `/queries` route change that surfaces it.
