## Decisions

1. **108 Shape A RLS** — copied from `124_workflow_schedules.sql`: membership + owner on every policy. No org-wide read branch (checked queries are private assertions about the caller's corpus).

2. **`aexec` not inline `.execute()`** — every database call uses `aexec` (wrap in `run_in_threadpool`), following the `document_queries.py` precedent and D-v2.5-01.

3. **BackgroundTasks, not scheduler** — the `/check` and `/check-all` routes queue via `BackgroundTasks.add_task`, returning immediately with the current snapshot. No Redis, no SSE, no run row.

4. **404, not 403, on existence hiding** — `_verify_owned_document` returns 404 to avoid leaking document existence, following the `skill_test_cases.py` pattern.

5. **User settings resolved for the evaluator** — `search_documents` requires the caller's own `user_settings` (hybrid_search_enabled, retrieval_top_k, etc.); passing `None` would measure a different configuration.
