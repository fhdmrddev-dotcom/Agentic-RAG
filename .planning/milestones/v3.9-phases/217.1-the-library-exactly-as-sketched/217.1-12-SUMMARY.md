## Decisions

1. **Governance chips UNGATED in this plan.** Per the phase's own sequencing (Wave 6 vs Wave 7 split, T-217.1-04). Plan 13 adds the chip-level `governance_health` gate in the next wave.

2. **`onNavigate` prop NOT threaded to HealthTab.** HealthTab doesn't navigate — it doesn't need it. The type mismatch (`ActiveView` vs `string`) was pre-existing for `IndexingTab` and not caused by this plan.

3. **`useSignalFetch` uses a stable ref** to avoid infinite fetch loops from inline arrow functions in the dependency array.

4. **`HealthTab` is a self-fetching component** with `useEffect` for overview and trend data. Each useEffect has its own cancellation flag.
