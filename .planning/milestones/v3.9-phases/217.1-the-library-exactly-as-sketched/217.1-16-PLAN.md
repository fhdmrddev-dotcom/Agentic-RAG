**Migration number: `141_checked_queries.sql`** (block `140-149`, `140` claimed by Plan 08's BE-1).

**The table, four policies, two triggers — copy `124_workflow_schedules.sql` almost verbatim:**
```sql
CREATE TABLE IF NOT EXISTS public.checked_queries (
    id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
    org_id uuid NOT NULL REFERENCES public.organizations(id) ON DELETE CASCADE,
    user_id uuid NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
    question text NOT NULL,
    expected_document_id uuid NOT NULL REFERENCES public.documents(id) ON DELETE CASCADE,
    last_rank integer, previous_rank integer, checked_at timestamptz,
    created_at timestamptz NOT NULL DEFAULT now(), updated_at timestamptz NOT NULL DEFAULT now()
);
ALTER TABLE public.checked_queries ENABLE ROW LEVEL SECURITY;
-- select/insert/update/delete, ALL on: org_id IN (SELECT current_user_org_ids()) AND auth.uid() = user_id
CREATE TRIGGER checked_queries_autofill_org_id BEFORE INSERT ON public.checked_queries
  FOR EACH ROW EXECUTE FUNCTION public.autofill_org_id_by_owner('user_id');
CREATE TRIGGER checked_queries_set_updated_at BEFORE UPDATE ON public.checked_queries
  FOR EACH ROW EXECUTE FUNCTION public.set_updated_at();
```
⭐ **`124`'s header states the argument to make in the threat model: "THE ABSENCE IS THE DECISION"** — no
org-wide read branch, no global escape branch. A sibling table having one would otherwise make the
omission read as an oversight.

**The CRUD router — `skill_test_cases.py` (197 L) is the exact analog. Copy:**
- the docstring structure: routes listed, then "OWNER-SCOPING IS BELT-AND-SUSPENDERS BEHIND RLS", then
  "`user_id` comes from the authenticated caller + the path, NEVER the request body", then "404 (never
  403) on a miss so existence is not leaked";
- `_verify_owned_skill` (`:63-79`) → `_verify_owned_document` for `expected_document_id` — LOAD-BEARING: a
  forged id pointing at another user's document would otherwise be probeable through the rank result;
- the four handler signatures with `Depends(get_current_user)` + `Depends(get_user_supabase_client)`.
⛔ **Do NOT copy `skill_test_cases.py`'s inline `.execute()`** — that file states its own SEED-097
exemption; this net-net-new module has no such licence. Wrap PostgREST calls in `aexec`
(`app/utils/db.py:47-58`).

**The evaluator — NOT `eval_runner_service.py` (959 L, wrong shape — drives the full agent loop twice
with an LLM judge; ~900 lines of machinery for a ~40-line answer). The correct analog is one level lower:**
```python
hits, avg = await search_documents(question, user_id, supabase, user_settings=user_settings)
rank = next((i + 1 for i, h in enumerate(hits) if h["document_id"] == expected_document_id), None)
```
`retrieval_service.py:290-297`'s signature. ⚠ **`user_settings` MUST be resolved and passed** —
`search_documents` reads `hybrid_search_enabled`, `retrieval_top_k`, `retrieval_match_threshold`,
`rerank_top_n` and five more from it; passing `None` measures a DIFFERENT retrieval configuration than the
user's actual chat, and would report a rank slip that is really a settings mismatch.
⚠ **Preserve the `None` arm**: not-found is `NULL`, never `0` and never a large sentinel — the same
honesty rule as `embedded_at`'s no-backfill. ⚠ **Take the FIRST matching index** (best rank) — `hits` are
enriched per chunk, so the same document can appear more than once.

**The background-kick analog:**
```python
background_tasks.add_task(start_reembed, supabase, current_user["id"], s, False)   # settings.py:601
```
`POST /checked-queries/{id}/check` and `/check-all` queue via `BackgroundTasks.add_task`, returning the
current snapshot immediately. No Redis, no SSE, no run row, no scheduler.

**Migration hygiene:** `CREATE TABLE IF NOT EXISTS`, `DROP POLICY IF EXISTS`, `DROP TRIGGER IF EXISTS` —
re-paste-safe. Applied via the Supabase SQL editor (see `user_setup`), then
`bash scripts/regenerate-full-schema.sh` (no `--reset`), migration + regenerated `full-schema.sql`
committed together.
