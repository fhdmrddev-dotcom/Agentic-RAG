## Decisions

1. **One fetch feeds both the RETRIEVAL summary and the sparkline.** The sparkline data is computed client-side by `bucketByWeek` from the same `asked_at` fields — no second request.

2. **100+ at the cap.** The backend caps at `MAX_ROWS = 100`; an exact count above 100 would lie. The frontend mirrors this: `rows.length >= 100` renders `100+`.

3. **Average relevance averages only non-null similarities.** Historic rows that predate BE-5 have no `similarity` key. When all rows lack one, the word is "not recorded yet", never "0%" or "0.00".

4. **Inline SVG over recharts.** Recharts is ~200 KB and kept as the app's one code-split out of the Library. The 32px sparkline uses a `<polyline>` — no recharts import.
