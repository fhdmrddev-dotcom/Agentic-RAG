<threat_model>
ASVS L1 Threat Assessment:
- Threat: Information disclosure or credential leakage via marketing page bundle (e.g. Supabase anon key, auth session handlers, internal API routes bundled on a public marketing surface).
  Mitigation: Strict architectural separation via separate Vite HTML entry points. Zero imports from `@/lib/api`, `@supabase/*`, or auth providers into `src/landing/`. Enforced by automated transitive import graph crawler in `landingBundleFence.test.ts`.
- Threat: Open redirect or path confusion on root routing (`/` vs `/app`).
  Mitigation: Filesystem precedence serves `index.html` at `/`. Vercel rewrite isolates SPA fallback to `/app.html`. Middleware in `vite.config.ts` enforces the exact same parity in local development and preview.
- Threat: Uncontrolled external redirects from CTAs.
  Mitigation: `VITE_DEMO_URL` and `VITE_APP_URL` are sanitized string environment variables; when unset, `VITE_DEMO_URL` falls back to internal anchor `#start` and `VITE_APP_URL` falls back to relative `/app`.
</threat_model>
