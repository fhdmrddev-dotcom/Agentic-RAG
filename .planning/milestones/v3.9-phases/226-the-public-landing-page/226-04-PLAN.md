<threat_model>
ASVS L1 Threat Assessment:
- Threat: Clickjacking, open redirects, or phishing links on public marketing page.
  Mitigation: All outbound links use sanitized `rel="noopener noreferrer"`. CTA buttons resolve to validated environment variables (`VITE_DEMO_URL`, `VITE_APP_URL`) or internal safe anchors (`#start`, `/app`).
- Threat: Cross-site scripting (XSS) via injected text or dynamic props.
  Mitigation: All copy and text nodes are rendered directly through React JSX escaping. No user-controlled HTML string rendering.
</threat_model>
