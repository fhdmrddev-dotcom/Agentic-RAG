# Plan 216-02: Backend Tool Approval Pause & SSE Stream Handling

## Goal
Implement chat stream pausing on tools requiring `ask` approval posture, emitting structured approval SSE events, and handling user allow/reject decisions.

## Tasks

### Task 1: Stream Pause & Approval Event
- In `tool_dispatcher.py`, when a connector tool has an `ask` posture, emit a `tool_approval_required` SSE event payload containing `call_id`, `service_id`, `service_name`, `tool_name`, and formatted `arguments`.
- Record the pending approval in the thread message state with status `pending_approval`.

### Task 2: Approval Response API
- In `backend/app/api/threads.py`, add `POST /threads/{thread_id}/tool-approval`:
  - Request body: `ToolApprovalDecisionRequest(call_id: str, decision: Literal["allow", "reject"])`.
  - On `allow`: Execute the tool, update message state with tool result, and resume streaming assistant response.
  - On `reject`: Append human refusal notice into thread context and resume agent loop.

### Task 3: Unit Tests
- Create `backend/tests/unit/test_chat_tool_approval.py` testing:
  - Stream pause on `ask` tool call.
  - Approval event schema.
  - Continuation on `allow` and rejection on `reject`.
