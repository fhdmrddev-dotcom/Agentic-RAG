# Plan 216-03: Backend Connected Cloud File Browser & Single-File Import

## Goal
Implement single-file browsing and user-initiated file fetching for connected Google Drive / Cloud storage without automatic sync crawlers.

## Tasks

### Task 1: Create `app/services/connectors/cloud_storage.py`
- Implement `list_cloud_files(connection, query=None, page_token=None)`:
  - For Google Workspace: Queries Google Drive `files.list` API using active refreshed OAuth access token.
  - Returns structured list of `CloudFileItem(id, name, mime_type, size, modified_at, icon_url)`.
- Implement `fetch_cloud_file(connection, file_id)`:
  - Downloads single file bytes from Google Drive API / Cloud source.

### Task 2: Connector Endpoints
- In `backend/app/api/connectors.py`:
  - Add `GET /connectors/connections/{connection_id}/files` to list browseable files.
  - Add `POST /connectors/connections/{connection_id}/files/{file_id}/import` to fetch and attach a single file to documents/thread.

### Task 3: Unit Tests
- Create `backend/tests/unit/test_connector_file_import.py` asserting:
  - File list parsing with Google Drive API mocks.
  - Single-file download and document ingestion payload creation.
  - Verification that no automatic background sync or recursive watcher is spawned.
