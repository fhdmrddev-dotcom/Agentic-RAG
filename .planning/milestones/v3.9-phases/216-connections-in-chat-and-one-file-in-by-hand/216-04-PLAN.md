# Plan 216-04: Frontend Plus Menu, Connectors Flyout, Active Chips Bar, and Starter Prompts

## Goal
Implement the Claude.ai-style `+` button with Connectors toggle flyout, active connector chips bar, `@` mention popover, and starter prompt suggestions.

## Tasks

### Task 1: Create `ConnectorsFlyout.tsx` & `MessageInput.tsx` Plus Menu
- Add `+` icon button to `MessageInput.tsx`.
- Implement `ConnectorsFlyout.tsx` displaying workspace connections with interactive toggle switches.
- Add quick links to `+ Add connector` and `Manage connectors` in `/settings`.
- Implement `@` mention autocomplete in textarea.

### Task 2: Active Connector Chips Bar
- Render dismissible chips above message input for active connectors in current thread: `[ 🌐 Google Workspace ✕ ]`.
- Clicking `✕` disables the connector for the thread (`CHAT-06`).
- Pass active connector IDs in `postMessage` payload.

### Task 3: Starter Prompts (`CAT-04`)
- Update `ChatEmptyState.tsx` to render clickable starter prompt pills derived from active/configured connections.
- Update `ConnectionsTab.tsx` to add a "Try in Chat" button on connection cards.

### Task 4: Tests
- Create `frontend/src/components/chat/__tests__/MessageInput.connectors.test.tsx` verifying:
  - Toggle switches update active connector set.
  - Active chips render and remove properly.
  - Starter prompt click triggers new thread creation.
