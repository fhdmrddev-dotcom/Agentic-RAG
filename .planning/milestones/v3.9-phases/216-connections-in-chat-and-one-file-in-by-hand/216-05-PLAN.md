# Plan 216-05: Frontend Tool Call Panel, Inline Approval Cards, and Cloud File Picker Modal

## Goal
Implement branded tool call status rendering with official service marks, inline stream approval cards, and the single-file cloud browser modal.

## Tasks

### Task 1: Branded Tool Calls & `ChatToolApprovalCard.tsx`
- In `ToolCallPanel.tsx`, resolve tool names and display service icons via `connectionMark.tsx`.
- Create `ChatToolApprovalCard.tsx`:
  - Renders when a tool requires approval (`status === "pending_approval"`).
  - Displays service icon, tool name, and formatted parameters.
  - Provides `[ Allow ]` and `[ Reject ]` buttons that call `POST /threads/{id}/tool-approval`.

### Task 2: Create `ConnectedFilePickerModal.tsx` (`ATTACH-01`)
- In `MessageInput.tsx` `+` menu, clicking "Add from Google Drive >" opens `ConnectedFilePickerModal`.
- Queries `GET /connectors/connections/{id}/files` with search filter and pagination.
- User selects one file -> calls `POST /connectors/connections/{id}/files/{file_id}/import` -> attaches document to the current draft/thread.

### Task 3: Full End-to-End Integration Suite
- Create `backend/tests/integration/test_chat_connectors_e2e.py` testing complete chat connector flow:
  - Thread creation with active connector.
  - Autonomous tool call by model.
  - Inline approval pause and resume.
  - Final response generation with source citations.
- Update vitest count gate in `scripts/vitest-count-gate.cjs`.
