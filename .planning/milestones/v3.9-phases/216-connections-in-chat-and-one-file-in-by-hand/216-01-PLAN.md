# Plan 216-01: Backend Chat Connector Tools & Prompt Injection Boundary

## Goal
Enable dynamic injection of active thread connector tools into the agent loop tool registry and wrap external responses in prompt-injection security envelopes.

## Tasks

### Task 1: Create `app/services/connectors/chat_tools.py`
- Convert granted tools from active `connector_connections` rows into standard LLM function descriptors (`build_chat_tools_for_connectors`).
- Filter out `deny` tools.
- Implement `wrap_untrusted_tool_result` to encapsulate third-party output in `<external_tool_result>` tags with security fences.

### Task 2: Update `agent_loop.py` & `tool_dispatcher.py`
- Accept `active_connector_ids: list[UUID] | None` on thread execution run context.
- Merge dynamic connector tools into `tools` parameter sent to provider streaming gateways (OpenAI, Anthropic, Gemini).
- Route namespaced `{service_id}__{tool_name}` tool calls through `dispatch_tool` with active connector credential resolution.

### Task 3: Unit Tests
- Create `backend/tests/unit/test_chat_connector_tools.py` asserting:
  - Tool descriptor schema conversion.
  - Omission of denied tools.
  - Execution and output isolation wrapping.
