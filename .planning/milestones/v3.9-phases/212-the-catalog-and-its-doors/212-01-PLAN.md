1. Update `backend/app/services/mcp_client.py`:
   - Import `from starlette.concurrency import run_in_threadpool` and `from app.security.egress import validate_mcp_destination, PinnedDestination`.
   - In `_send_jsonrpc`:
     - Wrap destination validation in `pinned: PinnedDestination = await run_in_threadpool(validate_mcp_destination, server_url)` (D-v2.5-01).
     - Rewrite `httpx.URL(server_url)` host to `pinned.ip` to prevent DNS-rebinding TOCTOU.

     - Stream and decode response body with strict byte bound (`MAX_MCP_BODY_BYTES = 2 * 1024 * 1024`), raising if payload exceeds limit.
     - Classify exceptions into clear, honest messages: distinguish SSRF security refusals from network timeouts and invalid JSON-RPC structures.
