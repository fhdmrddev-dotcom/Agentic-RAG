    Create `backend/app/services/oauth_state.py`:
    1. Define `OAuthStateError(Exception)` and `PENDING_TTL_SECONDS = 600`.
    2. Define `PendingOAuthState` dataclass:
       ```python
       @dataclass
       class PendingOAuthState:
           code_verifier: str
           client_id: str
           client_secret: str | None
           redirect_uri: str
           connection_id: str | None
           user_id: str
           org_id: str
           provider: str | None = None
           token_endpoint: str | None = None
           server_url: str | None = None
           created_at: float = field(default_factory=time.time)
       ```
    3. Define `save_pending_state(redis, state: PendingOAuthState, ttl_seconds: int = PENDING_TTL_SECONDS) -> str`:
       - Generates 32 bytes of entropy: `handle = secrets.token_urlsafe(32)`.
       - Serializes `state` to JSON dict.
       - Uses atomic `await redis.setex(f"oauth:pending:{handle}", ttl_seconds, payload_json)`.
       - Returns `handle`.
    4. Define `take_pending_state(redis, handle: str) -> PendingOAuthState`:
       - Primary key: `f"oauth:pending:{handle}"`.
       - Fallback key for in-flight legacy MCP consents: `f"mcp_oauth:pending:{handle}"`.
       - Single-use deletion: `raw = await redis.get(key); await redis.delete(key)`.
       - If not found or empty, raise `OAuthStateError("This sign-in link has already been used or has expired. Start the connection again.")`.
       - Deserializes JSON and returns `PendingOAuthState(**payload)`.
  </action>
  <verify>

  </verify>

    - Handle is generated via `secrets.token_urlsafe(32)`.
    - Key storage uses atomic `setex` with 600s TTL.
    - Consumption deletes key immediately on read.
  </acceptance_criteria>
