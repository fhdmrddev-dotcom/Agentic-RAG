<task type="auto">
  <name>Task 2: Wire opaque state in connectors.py with dual-mode cutover callback</name>
  <files>backend/app/api/connectors.py</files>

  <action>
    In `backend/app/api/connectors.py`:
    1. In `create_oauth_authorize_url` (`POST /connectors/oauth/authorize`):
       - Import `get_redis` from `app.dependencies`.
       - Pass `org_id=str(active_org)` and `redis=get_redis()` into `await build_authorization_url(...)`.
       - Return `OAuthAuthorizeResponse(authorization_url=auth_url, state=state)`.
    2. In `oauth_callback` (`GET /connectors/oauth/callback`):
       - Import `get_redis` from `app.dependencies`.
       - Import `take_pending_state`, `OAuthStateError` from `app.services.oauth_state`.
       - Implement dual-mode state resolution:
         ```python
         state_data = None
         code_verifier = None
         client_id = None
         client_secret = None
         provider = None
         connection_id = None

         # 1. New path: Opaque handle in Redis
         try:
             pending = await take_pending_state(get_redis(), state)
             provider = pending.provider
             connection_id = pending.connection_id
             code_verifier = pending.code_verifier
             client_id = pending.client_id
             client_secret = pending.client_secret
         except OAuthStateError:
             # 2. Legacy fallback path: In-flight HMAC-signed token
             if "." in state:
                 try:
                     state_data = verify_oauth_state(state)
                     logger.warning("[legacy-oauth-state-accepted] Verified in-flight signed OAuth state during deploy cutover")
                     provider = state_data["prv"]
                     connection_id = state_data["cid"]
                     code_verifier = state_data["cv"]
                     custom_client_id = state_data.get("cid_ovr")
                     custom_client_secret = state_data.get("sec_ovr")
                     client_id, client_secret = resolve_client_credentials(
                         provider=provider,
                         custom_client_id=custom_client_id,
                         custom_client_secret=custom_client_secret,
                     )
                 except ValueError as exc:
                     logger.warning("oauth callback: legacy state verification failed: %s", exc)
                     return RedirectResponse(url=f"{frontend_url}/?connections=1&oauth_error=invalid_or_expired_state")
             else:
                 logger.warning("oauth callback: invalid or expired opaque handle: %s", state)
                 return RedirectResponse(url=f"{frontend_url}/?connections=1&oauth_error=invalid_or_expired_state")
         ```
       - Proceed to token exchange using the extracted `(provider, code_verifier, client_id, client_secret)`.
    3. Ensure G-5 hot-file discipline is strictly maintained in `connectors.py`.
  </action>
