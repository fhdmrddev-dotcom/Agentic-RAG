# Plan 220-01: DXF CAD Extractor & Packaging Promotion

**Phase:** 220 — A Drawing Becomes Quantities — SPIKE  
**Goal:** Add `ezdxf` to production dependencies, implement native `.dxf` entity parsing (blocks, dimensions, annotations, layers, and `$INSUNITS`), and wire it into document ingestion so CAD files extract structured quantities into metadata.

## 2. Implementation Steps

### Step 1: Promote `ezdxf` Dependency
- Add `ezdxf>=1.3.0` to `backend/requirements.txt`.
- Document `ezdxf` in `docs/SANDBOX-PACKAGES.md` (License: MIT, Purpose: CAD DXF entity extraction for quantity takeoff spike).

### Step 2: Implement DXF Aspect Extractor
- Create `backend/app/services/extractors/aspects/dxf.py`:
  - `clean_cad_text(text: str) -> str`: Strips AutoCAD formatting codes (`\A1;`, `\P`, `\S1/2;`, `%%C`, etc.).
  - `extract_dxf_takeoff(file_bytes: bytes, filename: str) -> dict`:
    - Loads DXF via `ezdxf.read(io.BytesIO(file_bytes))`.
    - Reads `$INSUNITS` header. If `$INSUNITS == 0`, marks status `"refused: unitless drawing ($INSUNITS=0)"`.
    - Counts `INSERT` blocks with layer names and frequencies.
    - Extracts `DIMENSION` measurement values computed by CAD.
    - Extracts `MULTILEADER` and `MTEXT` annotation strings.
    - Computes raw layer line lengths (marked strictly as order-of-magnitude estimates).
    - Returns structured dictionary with `units`, `entity_counts`, `blocks`, `dimensions`, `annotations`, and `raw_line_lengths`.

### Step 3: Wire into Document Ingestion Pipeline
- Register `.dxf` / `application/dxf` / `image/vnd.dxf` in `backend/app/services/extractors/extractor_service.py` or `backend/app/api/documents.py`.
- Store the extracted takeoff payload in `document.metadata["_takeoff"]`.

---

## 3. Verification & Automated Tests

- Create `backend/tests/unit/test_dxf_takeoff_extractor.py`:
  - Test valid DXF with blocks and dimensions extracts correct counts.
  - Test unitless DXF (`$INSUNITS=0`) returns refusal and does not guess millimeters.
  - Test AutoCAD formatting regex strips `\P`, `\A1;`, etc. cleanly.
  - Test missing/corrupt DXF fails gracefully with honest error.
