# Plan 220-02: Rate Sheet Extraction & Grounded LLM Matching Engine

**Phase:** 220 — A Drawing Becomes Quantities — SPIKE  
**Goal:** Build the rate matching service that reads Excel rate sheets through the app's `extract_excel_tables()`, matches CAD items against rate sheet codes via an LLM in-context prompt, and enforces the anti-ambiguity rule (escalates candidate ambiguity to humans, never prices by list position).

## 2. Implementation Steps

### Step 1: Implement Takeoff Matcher Service
- Create `backend/app/services/takeoff/matcher.py`:
  - `load_rate_sheet_rows(file_bytes: bytes) -> list[RateLine]`:
    - Uses `app.services.multimodal_service.extract_excel_tables(file_bytes)`.
    - Parses columns: `item code`, `description`, `unit`, `rate`.
  - `match_takeoff_to_rates(takeoff_data: dict, rates: list[RateLine]) -> TakeoffBOQ`:
    - Distinctive keyword & LLM matching against rate lines.
    - If multiple rate lines match a CAD element (e.g. *1/2" Gypsum Board* matching *Ceiling* and *Wall*), classifies line as `status="ambiguous"` with `candidate_codes=["CL-GYP", "GB-12"]`.
    - If 1 rate line matches, classifies line as `status="matched"`, computes `amount = quantity * rate`, and records `basis="matched"`.
    - If exact block count, sets `basis="read"`.
    - If 0 rate lines match, classifies line as `status="unpriced"`.
    - Calculates total estimated cost only over unambiguous lines.

### Step 2: Add Takeoff Endpoints to FastAPI
- In `backend/app/api/documents.py` (or `backend/app/api/takeoff.py`):
  - `POST /documents/{id}/takeoff/match`:
    - Accepts `rate_sheet_document_id` (or uploaded rate file).
    - Runs `match_takeoff_to_rates()` and saves the resulting priced BOQ into `document.metadata["_takeoff"]["boq"]`.
  - `PATCH /documents/{id}/takeoff/resolve`:
    - Accepts `item_key` and `chosen_rate_code`.
    - Resolves an ambiguous item to the chosen rate code and recalculates totals.

## 3. Verification & Automated Tests

- Create `backend/tests/unit/test_takeoff_matcher.py`:
  - Test unambiguous item (e.g. *W250x33 Steel Beam*) matches single rate code with exact cost calculation.
  - Test ambiguous item (*1/2" Gypsum Board*) is NOT silently priced, returns `status="ambiguous"` with candidates.
  - Test resolving an ambiguous item recalculates the total correctly.
  - Test empty or malformed rate sheet returns an honest error without crashing.
