export type AvailabilityState = "ready" | "api_off" | "scope_missing" | "unknown"

export interface ApplicationAvailability {
  app: string
  state: AvailabilityState
  /** Present only when state !== "ready". The REMEDY, never a status. */
  remedy?: { sentence: string; action: { label: string; href?: string } }
}

/** ⚠ Scope is decided from the STORED token scopes — no network call.
 *  ⚠ An unreachable probe is `unknown`, never `api_off`. */
export function applicationAvailability(args: {
  app: string
  grantedScopes: readonly string[]
  probe?: { status: string; reason?: string; consoleUrl?: string } | null
}): ApplicationAvailability

## T1 — Backend: one probe per application, on the existing Check action

- `APPLICATION_PROBES`, declared beside the specs per `<interfaces>`.
- Extend the **existing** Check action to return `application_availability: [...]` for a Google row.
  ⛔ **No new route.** Check already exists on non-MCP rows and today only verifies credentials.
- The scope arm reads `connector_tokens.scopes` — **no network call.**
- The enablement arm makes one cheap authenticated GET per application and classifies via
  `_http.py`'s **existing** enum parser: `SERVICE_DISABLED` / `accessNotConfigured` → `api_off`
  (carrying the console URL it already builds); `ACCESS_TOKEN_SCOPE_INSUFFICIENT` → `scope_missing`;
  any 2xx **or any other 4xx** → `ready` (a 404 proves the API answered — that is exactly how Sheets
  and Docs were measured live on 2026-08-31); a transport failure or timeout → `unknown`.
- ⚠ **`error.message` is never read or returned.** It echoes the caller's query. Only `status` and
  `details[].reason` travel.

**Accept (`test_221_application_availability.py`), each arm against a RECORDED body:**
- `test_service_disabled_is_api_off_with_a_console_url`
- `test_scope_insufficient_is_scope_missing_and_carries_no_console_url` — the two remedies are
  opposite, so a test asserting they differ is the point of the file.
- `test_404_is_ready_because_the_api_answered`
- `test_unreachable_is_unknown_not_blocked`
- `test_error_message_never_travels` — plant a recognisable string in `error.message` and assert it
