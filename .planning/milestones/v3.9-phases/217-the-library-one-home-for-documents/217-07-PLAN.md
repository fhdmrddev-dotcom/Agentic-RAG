<objective>
LIB-02 / SC#2: make upload a real front door, and make the advertised formats true.

Purpose: the operator's own words — *"I did not see for example where I can upload documents."*
Today upload is a compact button in the top-right corner of a folder header, and the component's own
comment (`DocumentUpload.tsx:78-84`) records WHY it was made compact: the old full-width block
*"pushed the file list below the fold"*. SC#2 deliberately reverses that decision, so this plan must
answer that objection rather than re-create the problem it names.

And the accept list is a lie waiting to happen: the sketch's own fence caught an older dropzone
advertising `MSG`, which the shipped input rejects. A dropzone listing a format the input refuses
sends a person to a dead end.

Output: ONE exported constant behind both the `accept` attribute and the displayed formats, a
full-width dropzone that names its target folder, and a cross-language fence proving the frontend
list is a subset of the server's.
</objective>
