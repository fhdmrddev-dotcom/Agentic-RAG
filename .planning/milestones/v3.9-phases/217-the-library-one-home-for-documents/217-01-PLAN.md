server where the mime lists actually live.

transition fires — the D-v2.5-03 failure, invisible to any test that mocks the fetch. `extractor`
never leaves Postgres. And the strip cannot honestly strike out a conditional stage without knowing
whether the pipeline would ever have run it (D-217-24).

two pure predicates in `multimodal_service.py`, and a backend suite that asserts **population**, not
declaration.
</objective>
