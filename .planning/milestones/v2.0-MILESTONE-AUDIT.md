### Gap Details

**FILE-01 / FILE-02 — Skill File Management UI Missing**

The backend API for skill file upload (POST), list (GET), and delete (DELETE) was built in Phase 10 and is fully tested. However, Phase 12 (Skills UI) only implemented SKIL-07 and SKIL-08 — the file management UI components were never planned or built for any phase.

As a result:
- The user cannot upload files to a skill via the app
- The user cannot view or delete files from a skill via the app
- `api.ts` has no `uploadSkillFile`, `listSkillFiles`, or `deleteSkillFile` functions
- `SkillFormDialog.tsx` and `SkillCard.tsx` have no file section

The LLM-side tools (FILE-04 `load_skill` returns file list, FILE-05 `read_skill_file` downloads content) are functional — but without any files in the skills, they have nothing to operate on.

**Fix:** Add skill file management UI to `SkillFormDialog.tsx` or `SkillCard.tsx` (file input, list, delete), plus `uploadSkillFile`/`listSkillFiles`/`deleteSkillFile` in `api.ts`.
