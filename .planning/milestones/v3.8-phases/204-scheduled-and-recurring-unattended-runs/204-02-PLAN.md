<objective>
Implement hard spend-cap and execution duration circuit breakers (SCHED-02) for unattended workflow runs, stopping work immediately and recording durable audit logs when token or timeout limits are exceeded.
</objective>

<threat_model>
- Runaway Cost in Unattended Execution: Without active user monitoring, loops or excessive context can burn expensive API tokens; the circuit breaker must enforce a strict, un-bypassable token ceiling.
- Wall-Clock Stalls: Hanging network requests or third-party deadlocks must be killed by the wall-clock duration circuit breaker.
- Audit Evasion: All circuit breaker trips must write durable audit records with exact token and timing measurements before terminating the run.
</threat_model>
