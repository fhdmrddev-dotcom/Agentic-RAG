<objective>
Build the workflow scheduling engine (SCHED-01) with database migration 124, background poller service with distributed concurrency control, REST APIs, and frontend modal to schedule unattended workflow runs.
</objective>

<threat_model>
- Multi-Instance Duplicate Firings: Multiple backend workers must not trigger duplicate runs for the same scheduled event; enforce `FOR UPDATE SKIP LOCKED` or advisory locking.
- Unauthorized Schedule Creation: Non-owners or cross-tenant users must not schedule or view foreign workflow runs; enforce RLS policies and org checks.
- Invalid Cron Parsing: Malformed cron strings must be validated and rejected at API request boundary before persisting to the database.
</threat_model>
