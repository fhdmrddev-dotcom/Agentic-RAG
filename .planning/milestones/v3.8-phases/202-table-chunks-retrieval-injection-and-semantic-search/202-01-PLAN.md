<objective>
Transform extracted tables from document_tables into structured Markdown vector chunks and inject them into document_chunks with embeddings and schema headers (TAB-02).
This enables semantic vector search and hybrid search to retrieve specific cell values and tabular facts across PDF, DOCX, CSV, and Excel documents.
</objective>

<threat_model>
- Injection / Malformed Markdown: Pipe characters and linebreaks in raw cell values must be sanitized to prevent broken markdown tables.
- Token Overflow: Unbounded table rows per chunk could exceed embedding model token limits (e.g. 512-1000 tokens); strictly enforce batch limit (25-30 rows) with header repetition.
- Vector Space Alignment: Table chunk embeddings must use the same embedding model, dimensions, and user settings as text chunks (EMBED-04 / D-10).
- Multi-Tenancy: Table chunks must propagate the document's org_id and user_id to maintain RLS boundaries (TEN-04).
</threat_model>

<tasks>
1. **Task 1 (Format Table Markdown Chunks & Row Batching)**:
   Implement `format_table_markdown_chunks(table: dict, max_rows: int = 25) -> list[str]` in `multimodal_service.py`.
   - Generates schema prefix `[Table {table_index + 1} | Page {page} | Columns: {headers}]`.
   - Sanitizes cell contents (replaces raw newlines with spaces, escapes unescaped pipe characters).
   - Generates markdown header and delimiter rows (`| Col1 | Col2 |\n|---|---|`).
   - Batches rows into groups of `max_rows` (default 25), prepending the schema prefix and markdown header to each batch.

2. **Task 2 (Embed & Store Table Chunks on Ingestion)**:
   Implement `embed_and_store_table_chunks(document_id: str, user_id: str, table_dicts: list[dict], supabase: Client, app_settings=None)` in `multimodal_service.py`.
   - Converts `table_dicts` into formatted markdown chunks.
   - Queries `max(chunk_index)` from `document_chunks` for `document_id` to establish `base_idx`.
   - Embeds chunk texts with `embed_texts(texts, user_settings=app_settings)`.
   - Inserts chunk rows into `document_chunks` with `chunk_index = base_idx + i`, `embedding`, `embedding_model`, `embedding_dimensions`, `org_id`.
   - Call `embed_and_store_table_chunks` in `extract_and_store_tables` right after `document_tables` insert.

3. **Task 3 (Historical Table Chunks Backfill Helper)**:
   Implement `backfill_document_table_chunks(document_id: str, supabase: Client, user_id: str | None = None, app_settings=None) -> int` in `multimodal_service.py`.
   - Queries existing rows from `document_tables` for `document_id`.
   - Formats and embeds missing table chunks into `document_chunks`.
   - Expose as helper callable by tests and admin/reingest routines.

4. **Task 4 (Comprehensive Unit Testing)**:
   Create `backend/tests/unit/test_table_chunks_injection.py` covering:
   - `test_format_table_markdown_chunks_single_page`: single table markdown output with schema header.
   - `test_format_table_markdown_chunks_large_table_batching`: table with 80 rows partitioned into 4 chunks with repeated headers.
   - `test_format_table_markdown_chunks_sanitizes_pipes_and_newlines`: handles newlines and pipes safely.
   - `test_embed_and_store_table_chunks_inserts_with_correct_offsets`: offsets chunk_index from max text chunk.
   - `test_extract_and_store_tables_generates_chunks_automatically`: full pipeline produces both document_tables and document_chunks.
   - `test_backfill_document_table_chunks`: backfills table chunks for existing document.
</tasks>
