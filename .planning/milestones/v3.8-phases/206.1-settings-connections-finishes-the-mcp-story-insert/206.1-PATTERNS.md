## Analog 1 — the `*Copy.ts` sibling module (every user-visible string is an exported identifier)

**Verified real.** Three instances in `frontend/src/components/settings/`: `connectionsCopy.ts` (477 L), `connectionFormCopy.ts` (531 L), `connectionRefusalCopy.ts` (567 L). **These are the ONLY `*Copy.ts` modules in the whole frontend tree** (`find frontend/src -name "*Copy.ts*"` returns exactly those three) — so this surface's convention is local to it, and there is no fourth precedent to copy from.

### 1a · The idiom's own charter — `connectionsCopy.ts:1-34`

```ts
/**
 * Phase 190-16 (CONN-02, UI-SPEC §2c–§2h, §11d, §12) — the Connections tab's copy and
 * its pure derivations.
 *
 * ── WHY THIS FILE EXISTS, AND WHY IT IS A `.ts` AND NOT PART OF THE `.tsx` ──
 * UI-SPEC §11d makes every user-visible string on this surface a CONTRACT, and the way
 * this project keeps a contract honest is to make each string an exported identifier that
 * a suite asserts by CHARACTER IDENTITY (the `GovernanceSection.tsx:10-17` idiom): a
 * sentence that lives inline inside JSX is a sentence nobody can test for drift.

 * But a `.tsx` that exports both components AND constants trips
 * `react-refresh/only-export-components`, and plan 190-12 MEASURED the cost of ignoring
 * that: `eslint src/components/workflows/` went 5 → 10 on exactly this rule …
```

The `GovernanceSection.tsx:10-17` idiom it cites is real and reads:


## Shared Patterns (cross-cutting — apply to every plan in this phase)

### S1 · Removed, never disabled
**Source:** `ConnectionsTab.tsx:51-57` and `ConnectionFormPanel.tsx:292-295`.
**Apply to:** the MCP option under a non-admin / kill-switch-OFF render (item 1), and to `Check credential` on an MCP row (D-206.1-19).
```tsx
/** One editable text input, or — when the panel is read-only — the same value as static
 *  text. NOT a `disabled` input: a control that could never do anything is REMOVED, which
 *  is the shipped 185 rule and the one 190-16's plant C proved a `toBeDisabled()` assertion
 *  is unable to see. */
```
⚠ The ONE exception is the cipher-refusal Save (`:1128-1130`), and the MCP disabled-Save joins it — both need real DOM text wired by `aria-describedby`.

### S2 · The write receipt, identical in row and panel
**Source:** `ConnectionsTab.tsx:530-547`, re-used verbatim at `ConnectionFormPanel.tsx:628-646`.
**Apply to:** any new write affordance.
```tsx
/** One write, its receipt, and a retry on failure — the `UsersAndAccess.tsx:224-238`
 *  idiom. The RECEIPT is transient (062-A: a receipt, never a toast); the persistent
 *  state chip beside it is the CONSEQUENCE, and they are deliberately separate. */
async function runWrite(fn: () => Promise<void>, recorded: string) { … }
```

### S3 · Zero `[title]` attributes
**Source:** `ConnectionsTab.test.tsx:505-515`, `ConnectionFormPanel.test.tsx:740-753`.

### S4 · No secret-shaped needle in the rendered DOM
**Source:** `ConnectionsTab.test.tsx:517-526`.
**Apply to:** item 3 especially — inlined SVG markup is inside this scan.

```ts
for (const needle of ["secret", "ciphertext", "password", "xoxb-", "api_token", "enc:v1:"]) {
  expect(markup).not.toContain(needle)
}
```
