# Phase 206 Plan 01: MCP Connector Client — Workflow-Scoped

## Overview
Phase 206 implements the **MCP Connector Client** enabling workflows to reach external platforms like **Atlassian (Jira + Confluence)** and **GitHub** through their official remote Model Context Protocol (MCP) servers with granular per-tool permissions and **zero per-vendor adapter code**.

---

## Must-Haves & Invariants

1. **Stable Platform Asset Model (SEED-145, SEED-146)**: Connections are modeled as platform assets. No workflow-shaped foreign key on the connection, no run-scoped credential resolution, no requirement for a `workflow_id` during resolution.
2. **Provider-Shaped Schema (D-206-01, F-1)**: `connector_connections` table stores `mcp_server_url`, `tool_grants` (boolean map `{ [tool_name: string]: boolean }`), and `discovered_tools` (JSONB array).
3. **Per-Tool Permission Enforcement (D-206-06, F-1)**: External action phases can execute an MCP tool only if `tool_grants.get(tool_name) is True`. An absent key is strictly denied.
4. **SSRF Defense (D-206-04, F-5)**: Remote `mcp_server_url` endpoints must be HTTPS and validated against private IP ranges and loopback destinations using `app.security.egress.validate_destination`.
5. **Two-File Fence Retirement (D-206-07)**: `test_no_mcp_identifiers_in_backend_app` in `backend/tests/unit/test_189_no_egress.py` is retired in the same commit that adds `mcp_client.py`, and `backend/tests/unit/test_190_ssti_fence.py:475` is updated in that same commit.
6. **Zero-Hook Pin in `PhaseFormPanel.tsx` (F-7)**: Must maintain 0 `useState`/`useMemo`/`useEffect` hooks in `PhaseFormPanel.tsx` by isolating interactive tool picking into `McpToolPicker.tsx`.
7. **api.ts Escalated Decision (F-6)**: `api.ts` gains `discoverConnectorTools` and `updateConnectorGrants`. The split itself is **ESCALATED to ROADMAP Phase 207** by operator decision on 2026-08-25 — the ledger entry and the roadmap row both exist already, so this phase writes NEITHER. What it does owe is the **mock budget, spent in the SAME commit** across the 7 measured suites, censusing each factory's SHAPE rather than assuming one idiom (204-03 measured three forms across eleven factories, and one suite needed no change at all).
