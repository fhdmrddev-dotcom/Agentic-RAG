## Task 2 — the widening, exactly as it landed

Inside the existing `external_action` arm, after `allowed |= EXTERNAL_ACTION_CAPABILITIES`:

```python
        mcp_tool_name = getattr(phase.config, "tool_name", None)
        if isinstance(mcp_tool_name, str) and mcp_tool_name.strip():
            allowed.add(mcp_tool_name)
```

Everything else in the function is byte-identical: the subtraction at the top
(`allowed = set(tool_names) - EXTERNAL_ACTION_CAPABILITIES`, whose caller-independence
comment is load-bearing) and the comprehension are untouched, and
`assemble_grounding_bundle`'s `fidelity_tool_names` line is asserted unmoved
(`git diff -U0 | grep -c 'fidelity_tool_names'` == **0**; the line still resolves once).

**Why the guard is `isinstance(..., str)` and not truthiness:** `phase.config` is duck-typed
here — both presentations share this function and control B hands it a `SimpleNamespace` —
so a `str()` coercion of a non-string would admit a name nobody authored.

**Why the SOURCE and not the DERIVED list.** Admitting `available_tools` itself would make
rule 2 tautological on this type. That is not an argument, it is control B: a config whose
list disagrees with its `tool_name` must still be flagged, and `allowed |= set(available_tools)`
turns that case green for the wrong reason.
