|-----------|----------|-----------|-------------|-----------------|
| T-56-10 | Information Disclosure | ingestion_step value rendered for documents not owned by user | mitigate | Existing RLS on `public.documents` (`auth.uid() = user_id` for SELECT) ensures users only receive their own rows via Realtime. | T-56-11 | Information Disclosure | Realtime messages subscription leaks other threads | mitigate | The subscription filter `thread_id=eq.${threadId}` (existing in useMessages.ts line 116) scopes to the active thread only. | T-56-12 | Tampering | Malicious server emits `ingestion_step: "<script>alert(1)</script>"` to coerce XSS via the badge | mitigate | DocumentStatusBadge uses `ingestionStepLabel(step)` which only matches four exact string equalities; any other value falls through to the literal `"processing"`.
