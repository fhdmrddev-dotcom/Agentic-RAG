```tsx
"inline-flex items-center justify-center whitespace-nowrap rounded-sm px-3 py-1.5 text-sm font-medium ring-offset-background transition-all focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2 disabled:pointer-events-none disabled:opacity-50 data-[state=active]:bg-background data-[state=active]:text-foreground data-[state=active]:shadow-sm"
```

Replace `transition-all` with `transition-colors`. The result must be:

```tsx
"inline-flex items-center justify-center whitespace-nowrap rounded-sm px-3 py-1.5 text-sm font-medium ring-offset-background transition-colors focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2 disabled:pointer-events-none disabled:opacity-50 data-[state=active]:bg-background data-[state=active]:text-foreground data-[state=active]:shadow-sm"
```

This is a single token replacement: `transition-all` → `transition-colors`.

Effect: On tab activation, only color-related CSS properties (color, background-color, border-color, text-decoration-color, fill, stroke) will animate. Properties like box-shadow, transform, and positional layout will no longer animate, eliminating the "shaking" visual artifact on the Stale tab (and any other tab that has shadow-sm applied on activation).

This is a global change affecting all Tabs in the app (Settings page tabs, Library Health tabs, Low Confidence sub-tabs). The change is intentional and correct — no tab in this app needs transition-all behavior.

Do NOT change any other className strings in tabs.tsx (TabsList, TabsContent stay as-is).
