## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ASGI task cancellation → finally block | CancelledError thrown at await point; asyncio.shield prevents DB write loss |
| client disconnect → stop_event | _safe_send sets stop_event.set(); generator checks it between chunks |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-055-03-01 | Denial of Service | stop_event pre-set before stream starts | accept | If stop_event is set before first iteration, generator exits cleanly in finally block and persists empty message — idempotent, no resource leak |
| T-055-03-02 | Tampering | asyncio.shield + CancelledError swallow | accept | CancelledError is swallowed only in the finally persist block; all other CancelledError propagation is unaffected; DB write is the critical side effect being protected |
| T-055-03-03 | Information Disclosure | stop_event shared between route handler and SSEStreamingResponse | accept | stop_event is a boolean flag (asyncio.Event); no user data on the event object; scoped to single request lifetime |
</threat_model>
