**1. Add `clearMessages` to `useMessages.ts`:**

Add a `clearMessages` callback to the useMessages hook that resets the messages array to empty and cancels any in-flight streaming:

```typescript
const clearMessages = useCallback(() => {
  setMessages([])
  setIsStreaming(false)
  abortControllerRef.current?.abort()
  abortControllerRef.current = null
  isSendingRef.current = false
}, [])
```

Add `clearMessages` to the `UseMessages` interface and the return statement.

**2. Update `ChatArea.tsx` to clear messages when thread changes or is null:**

Modify the `useEffect` that loads messages. When `thread` is null, call `clearMessages()`. When thread changes (new ID), immediately clear before loading:

```typescript
useEffect(() => {
  if (!thread) {
    clearMessages()
    return
  }
  // Clear stale messages from previous thread before loading new ones
  clearMessages()
  loadMessages(thread.id).catch(console.error)
}, [thread?.id, loadMessages, clearMessages])
```

This ensures no ghost content flashes between thread switches. The `clearMessages` call is synchronous and instant, so the UI shows empty state immediately, then `loadMessages` populates with new thread's messages.
