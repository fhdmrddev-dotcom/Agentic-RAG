public.notifications
  id uuid PK DEFAULT gen_random_uuid()
  recipient_id uuid NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE
  org_id uuid NULL REFERENCES public.organizations(id) ON DELETE CASCADE      -- copied from workflow_runs.org_id
  run_id uuid NOT NULL REFERENCES public.workflow_runs(id) ON DELETE CASCADE
  kind text NOT NULL CHECK (kind IN ('question','approval'))
  tool_call_id text NULL
  created_at timestamptz NOT NULL DEFAULT now()
  closed_at timestamptz NULL
  closed_reason text NULL CHECK (closed_reason IS NULL OR closed_reason IN ('answered','run_ended'))
  UNIQUE INDEX notifications_one_open_per_recipient_run ON (recipient_id, run_id) WHERE closed_at IS NULL
  INDEX on (tool_call_id) WHERE closed_at IS NULL; INDEX on (recipient_id, created_at DESC)

public.notification_deliveries   (the outbox; deny-all to clients)
  id uuid PK DEFAULT gen_random_uuid()
  notification_id uuid NOT NULL UNIQUE REFERENCES public.notifications(id) ON DELETE CASCADE   -- D-20 one per notice
  channel text NOT NULL DEFAULT 'email' CHECK (channel = 'email')
  status text NOT NULL DEFAULT 'pending' CHECK (status IN ('pending','retry','sending','sent','failed',
         'suppressed','skipped_opted_out','skipped_answered'))
  attempts integer NOT NULL DEFAULT 0
  due_at timestamptz NOT NULL
  claimed_at timestamptz NULL
  subject text NULL, text_body text NULL, html_body text NULL, waited_seconds integer NULL   -- frozen at first claim (D-31)
  provider text NULL, provider_message_id text NULL, reason text NULL, sent_at timestamptz NULL
  created_at timestamptz NOT NULL DEFAULT now(), updated_at timestamptz NOT NULL DEFAULT now()
  INDEX on (status, due_at) WHERE status IN ('pending','retry')

public.app_settings (+columns)
  notification_email_delay_seconds integer NOT NULL DEFAULT 120, CHECK 60..3600   (D-07)
  email_from_address text NULL          -- NULL/empty = use env INVITE_FROM_EMAIL (D-08)

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| engine / answer route → messages INSERT | the trigger runs inside the engine's fail-closed prompt insert (engine_ask.py:1025-1038) |
| PostgREST (anon / authenticated) → notices, outbox | client roles must never read another user's notice or any outbox row |
| SECURITY DEFINER function → deny-all tables | elevated writes must not be reachable by clients or hijackable via search_path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-300-08 | Denial of service | notify_on_ask_row inside the engine's insert | mitigate | whole body in BEGIN … EXCEPTION WHEN OTHERS THEN RAISE WARNING … END; live test plants a failing CHECK and asserts the message row still lands |
| T-300-09 | Information disclosure | notifications / notification_deliveries | mitigate | RLS on both; REVOKE ALL FROM PUBLIC, anon, authenticated first; recipient-only SELECT policy; outbox has no policy; anon-role live test |
| T-300-10 | Elevation of privilege | SECURITY DEFINER functions | mitigate | SET search_path = '' with fully-qualified names; EXECUTE revoked FROM PUBLIC (not only anon) then granted to service_role; has_function_privilege test for public/anon/authenticated |
| T-300-11 | Spoofing / tampering | notice org | mitigate | org_id read from workflow_runs.org_id, never messages.org_id (the LIMIT-1 autofill); live test inserts a message carrying a different org and asserts the notice's org |
