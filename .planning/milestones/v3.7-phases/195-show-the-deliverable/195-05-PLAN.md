## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-195-05-01 | Information Disclosure | which thread's files the panel lists | mitigate | `useViewingThread()` stays at SECTION level and is not moved into the shared row. That is not only a fence-satisfying detail: a row that resolved its own thread could be mounted anywhere and would list the viewed thread's files on a surface showing a different thread — the exact hazard `WorkflowRunPage.tsx:146-149` already documents. Pinned by `grep -c useViewingThread` on `FileRow.tsx` returning 0 (plan 03) and ≥ 1 on `FilesSection.tsx` (this plan). |
| T-195-05-02 | Tampering (XSS) | `file.path` as the visible label | mitigate | Rendered as a React text child by the shared row; `FilesSection.tsx` must contain zero `dangerouslySetInnerHTML` (assert `grep -c` → 0). The row's markup-as-text case (plan 03) covers the sink; the label here is a full path, which makes it the longest attacker-influenced string on the surface and therefore worth naming. |
| T-195-05-03 | Denial of Service (render crash) | the icon lookup key | mitigate | `file.path` reaches `fileIcon`, whose `EXT_MAP` is a plain object literal — a file named `x.constructor` previously yielded the `Object` function and would throw. Plan 03's own-property guard covers it; this plan inherits the protection and must not bypass it by reintroducing a local map. |
| T-195-05-04 | Elevation of Privilege | the preview activation | mitigate | Click-to-preview stays in the section, gated on `selected && threadId`. The row receives only presentational props and cannot open a preview for a thread it was not handed — there is no code path from the row to `FilePreview` at all (`grep -c FilePreview` on `FileRow.tsx` → 0). |
| T-195-05-SC | Tampering | package installs | n/a | **No package installed.** `frontend/package.json` and `package-lock.json` untouched — assert `git diff --numstat` EMPTY. No `slopcheck` owed. |

**Honest scale statement:** the security-relevant content of this plan is a **boundary that must not
move** — the viewed-thread read and the preview activation stay in the section — plus two string/lookup
sinks that were already safe and are now pinned. No new attack surface is created.
