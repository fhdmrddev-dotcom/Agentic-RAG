<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server `definition` JSON → client predicate | `definition` is server-supplied JSON read by a pure client function. It is never executed, never interpolated, and never rendered as markup. |
| predicate return → render decision | The three-state union is the ONLY channel from definition content to the two consumer surfaces. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-193-05 | Tampering | Definition content reaching the DOM | mitigate | `templateAdmission` returns a **closed union**, never a string derived from definition content; no definition value is interpolated into any rendered string. Typechecked by the union, not by care. |
| T-193-06 | Spoofing (of fact) | A `does-not-admit` returned for a definition the wire never described | mitigate | Rules (1) and (2) route nullish / non-array / empty-`phases` to `"unknown"`, exercised by dedicated table rows; the exhaustiveness assertion fails if two states are ever collapsed. |
| T-193-07 | Information Disclosure | The predicate reading a field beyond the display read-shape | accept | `DefShape` is widened by exactly one optional `assets` member whose only consumed key is `kind`. No `asset_id` value is read, rendered or logged. Named here rather than left implicit. |
| T-193-08 | Denial of Service | A pathological `phases`/`assets` array walked per render | mitigate | Both walks are `some()` over arrays measured at ≤ 12 elements across 223 live rows; no nesting, no recursion, no regex. |
| T-193-SC | Tampering | npm/pip/cargo installs | mitigate | **Zero packages installed.** No JSON-schema library, no validator, no parser — `api/workflows.py` already `json.loads` the string scalar so the client receives an object. |
</threat_model>
