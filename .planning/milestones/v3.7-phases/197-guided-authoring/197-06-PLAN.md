<objective>
Carry D-13's server verdict across the one boundary that currently drops it.

Purpose: measured, the field's whole chain is five hops and **four of them are free**. The route
passes the dict through untouched (no `response_model`); `generateWorkflow` casts the body and needs
no code change; the page state is a two-line addition. The **real work is one hop**:
`useTemplateFirstDraft.ts:535-542` destructures `result.definition` and hands ONLY the definition to
`onDrafted`. Anything not carried past that line is lost.

Output: one type arm in `api.ts`, one widened callback in the hook, and the cases proving the
absent-verdict case is representable.

## Three rules this plan is built on

1. **A TYPE, never a runtime export, in `api.ts`.** That file is the hottest in the repository
   (**170 commits / 99 phases / 6154 lines**) and its ledger row was added only at Phase 196 — it was
   invisible to its own guardrail for 97 phases. G-5's refactor recommendation was produced first and
   is **honoured by minimality**: this plan adds a type-union arm and nothing else, taken as a named
   decision rather than left silent. ⚠ This also matters mechanically: `196-08` hit **249 real
   failures** because nine suites' explicit `@/lib/api` mock factories did not declare a newly-added
   **runtime** export. A type adds no runtime export, so that trigger should not fire. If it does,
   the plan has added something it should not have.
2. **The second callback argument is REQUIRED, not optional.** The hook's own rule
   (`useTemplateFirstDraft.ts:322-332`): *"REQUIRED, not optional, and the reason is the 192.1 rule:
   a required member makes the typechecker enumerate the call sites where a default would let one
   hide."* The VALUE may be `undefined` — the server may say nothing — but the PARAMETER is declared.
3. **Three arms, never two.** The type must make *"the server did not say"* representable and
   distinct from *"the server said it is fine"*. `soulData.ts:243-247`'s `TemplateAdmission` is the
   shipped precedent and its docblock is explicit that the third state is load-bearing and must not
   be collapsed to make one call site read nicer.

⚠ **D-05 is not at risk here and the plan says why.** This hook owns the describe text, the
pre-draft KB choice, the CTA rule AND the generate call — but every edit in this plan is on its
**output** boundary (the success block and the callback declaration). No control, no required input
and no gate is added to the screen. Plan `197-01`'s two baseline suites are the mechanical proof, and
this plan re-runs them.
</objective>
