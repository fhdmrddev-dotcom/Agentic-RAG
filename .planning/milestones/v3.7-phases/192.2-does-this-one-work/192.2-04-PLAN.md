<objective>
Carry the run facts from the wire to the card's vocabulary — with an **unknown** arm that cannot be
mistaken for success.

Purpose: D-08. The single most likely way to ship a lie here is to render a missing value as blank
or as a tick. This project has already paid for that shape once — the decisions list needed three
arms because *silence is not success*.

⚠ **THIS PLAN STILL CHANGES NO PIXEL.** It lands the data path and the vocabulary; Wave 4 changes
what the card draws. The characterization pin from 192.2-02 must still pass unedited.
</objective>
