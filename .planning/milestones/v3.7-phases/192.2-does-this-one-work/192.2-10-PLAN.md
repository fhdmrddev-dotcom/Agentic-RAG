<decisions>
**DEC-10-A — `hasAnyRun` is three-valued, and the third state is NOT a formality.**
`true` = somebody ran it. `false` = the backend looked and nobody has. **absent/`null` = the wire did
not say.** The two run fields beside it are already three-valued for exactly this reason, and the
normalizer comment at `libraryFilter.ts:117-124` argues it at length: collapsing the states *"erases
the difference between 'the backend says there is no run' and 'the backend never mentioned runs at
all'"*. ⚠ **Pass it through VERBATIM — no `??`, no default, no `Boolean(...)`.** A `?? false` here
manufactures the affirmative claim *nobody has run this* out of an absence, which is CR-01's exact
shape one layer down.

**DEC-10-B — WR-02 IS FIXED BY CROSS-REFERENCE, NOT BY RENAME, AND THE `api.ts` SEAM DECLINE HOLDS.**
`frontend/src/lib/api.ts` is the **hottest file in the repository** (`172/99/6227` at last re-derive)
and Phase 197 DECLINED its extraction seam on the recorded basis that its change was **type-only**,
with the re-open trigger being *the next phase adding a RUNTIME export or a second concern*.

- **This plan's change to `api.ts` is TYPE-ONLY plus comments: one optional interface member on two
  existing interfaces, and three docblock edits. ZERO new runtime exports.** So **the re-open trigger
  does NOT fire and the decline HOLDS** — stated explicitly rather than left as a silent cell.
  ⚠ **Prove it, do not assert it:** grep the diff for added `export ` lines and record the count as 0.
  If the count is non-zero, the trigger HAS fired and the SUMMARY must say so.
- Renaming the 192.2 timestamp to `last_run_created_at` was the review's alternative. **Rejected:** it
  is a wire rename across the backend, three serializers, two frontend interfaces and both
  normalizers, to make two names agree — a large blast radius for a readability defect, inside a
  closure round, on the hottest file in the repo. `last_run_at` is also the better name for what the
  library asks (*when did it last run*), where `last_run_created_at` names the column's provenance.

**DEC-10-C — the word is `Run by someone else`, and it lives in `libraryVocabulary.ts` and nowhere
else.** Business words are IMPORTED, never re-spelled — `cardFace.ts` and `runFacts.ts` both already
hold that line. ⚠ Note the neighbouring precedent: the starter word is **`Shared starter`**, not
`Starter`, because a plan once spelled it and the vocabulary already owned it.

**⚠ THE G-7 JUDGEMENT, RECORDED HERE TOO BECAUSE THIS IS WHERE THE NEW WORD IS BORN.** G-7 forbids a
closure round introducing new user-facing capability. This word is not new capability: **the card
already claims to report run truth and currently claims it FALSELY** on every world-readable row.
A correct claim in place of a false one is repair. The mechanical check does not trip — it fails only
