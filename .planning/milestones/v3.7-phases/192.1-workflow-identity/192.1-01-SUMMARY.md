## Deviations from Plan

### 1. [Rule 3 — Blocking] The plan's `r["updated_at"]` KeyErrors against a shipped test

- **Found during:** Task 1.
- **Issue:** The plan specified `r["updated_at"].isoformat() if r["updated_at"] else None`, citing
  a house `r[...]` vs `r.get(...)` split. Measured, that reading raises `KeyError` against
  `test_published_workflow_ownership.py::test_row_dict_missing_both_columns_serializes_with_defaults`,
  which exists specifically to pin that a pre-192 row dict still flows through both handlers.
  Applying it literally produced **9 failed, 8 passed** in that file.
- **Fix:** the builders read `r.get("updated_at")`. This also matches **every sibling optional
  column in the same expression** — `definition`, `created_by` and `is_system_global` are all
  already `.get(...)`; only `id`/`slug`/`name` are indexed, so the plan's premise about the local
  house split did not hold here.
- **The plan's intent was preserved, not dropped.** The "a silently-dropped column fails loudly"
  property is delivered instead by four SELECT-list assertions in `test_workflows_updated_at.py`,
  which fail **in CI** rather than at runtime — strictly earlier than a `KeyError`. That relocation
  was driven RED against a real dropped-column plant (table above), so it is a working guard rather
  than a substitution on paper.
- **Recorded in code** at the builder, so a later reader does not "restore" the plan's version.

### 2. [Rule 2 — Missing critical functionality] One shared `_iso_or_none` helper

- **Found during:** Task 1.
- **Issue:** three builders each needed the same `datetime → ISO str` coercion. Retyping it three
  times is precisely the failure `_caller_uuid`'s own docblock names — *"a retyped coercion is how
  the two endpoints silently disagree"* — and here it would be three endpoints, not two.
- **Fix:** `_iso_or_none` added beside `_caller_uuid`, with the same rationale recorded.

### 3. [Rule 3 — Blocking] `WorkflowCard.test.tsx` needed the new required field

- **Found during:** Task 2. `tsc` went 33 → **34**.
- **Issue:** `LibraryRow.updatedAt` is **required** (PATTERNS finding #2: the identity line is
  unconditional under D-06, so `tsc` enumerates the call sites). It enumerated one the plan's
  `files_modified` did not list — `rowOf` in `WorkflowCard.test.tsx:83`.
- **Fix:** added `updatedAt` to the fixture builder, `...over` still allows a case to pass
  `undefined`. `tsc` back to **33**; `WorkflowCard.test.tsx` count unchanged at 39.
- This is the mechanism working as designed, not a surprise.

### 4. [Scope] Test file target changed — the planned path does not exist

- `backend/tests/unit/test_workflows_routes.py` (named in Task 1 and Task 3 `files_modified`) does
  not exist in the repo. See the A5 section above for the measured routing.
