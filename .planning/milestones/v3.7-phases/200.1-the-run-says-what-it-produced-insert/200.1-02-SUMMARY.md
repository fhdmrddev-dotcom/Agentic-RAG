## Deviations from Plan

### `[Rule 1 - Bug]` The 187-24 trap fired TWICE in this plan, both observed RED

**1a. The `select("*")` criterion was unsatisfiable at its own base.**
- **Found during:** Task 1, running the new suite.
- **Issue:** the plan's criterion is `grep -c 'select("\*")' backend/app/api/workflow_runs.py` returns
  `0`. It returns **2**, and **both are comments** — one shipped at the base commit (*"A `.select("*")`
  would also 'work' and would WEAKEN the read; reject it"*). A whole-file text match cannot tell a
  refusal from an adoption. **Fifth recorded firing in this tree.**
- **Fix:** fenced the CODE with an **AST walk** and left the prose free to name what it rejects — the
  remedy `db/workflows.py`'s `json.dumps` fence already established. Strictly stronger than the grep
  would have been: a `select` argument composed from a variable is visible as a non-`"*"` constant.
  Positive control on both sides (a planted real call scores 1; the comment-bearing real source scores 0).
- **Files:** `backend/tests/unit/test_200_1_deliverable_text.py` · **Commit:** `810c2df2`

**1b. A page comment naming the raw-HTML escape hatch turned that page's own fence red.**
- **Found during:** Task 2, first run of the run-page suite (`1 failed | 161 passed`).
- **Issue:** the answer block's docblock spelled the prop while explaining that the page refuses it, and
  the shipped fence at `WorkflowRunPage.test.tsx:2259` sweeps **RAW** `pageSource` for exactly that
  identifier at zero occurrences. **Sixth recorded firing.**
- **Fix:** fixed in the **PROSE**, never by relaxing the guard. The prop is described and not named, the
  reason is recorded in the file so the next reader does not helpfully re-add it, and the same care was
  applied pre-emptively to `lib/api.ts`'s new docblock. ⚠ **The contrast is the lesson: two fences on
  the same file, one comment-stripped and one raw — only reading each one's source told you which prose
  was safe.**
- **Files:** `WorkflowRunPage.tsx`, `lib/api.ts` · **Commit:** `15b09157`
