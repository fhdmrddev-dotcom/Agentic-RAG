<!-- The house pattern for an honest failure signal ON THIS PAGE. Reuse it; do not invent one. -->

There is **no toast library in this repo** — verified at plan time: zero `sonner` imports, no
`components/ui/toast`. The shipped pattern is a page-level notice rendered between the header and the
toolbar, one per failed source:

```tsx
{failedSources.map((source) => (
  <p
    key={source}
    data-testid={`library-source-failed-${source}`}
    className="border-b border-warning/30 bg-warning/5 px-6 py-2 text-[12.5px] text-muted-foreground"
  >
    {sourceFailedMessage(source)}
  </p>
))}
```

The in-card announcement precedent (`WorkflowCard.tsx`, the draft-delete failure) uses
`role="status"`, which is what makes a message that appears after a click audible to a screen reader:

```tsx
<p data-testid="draft-delete-error" role="status" className="mt-2 text-[11.5px] text-destructive">
```

From `libraryVocabulary.ts` (added by plan `192-13`):

```typescript
export function forkFailedMessage(name: string, conflict: boolean): string
```
