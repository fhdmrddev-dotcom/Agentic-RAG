## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| toolbar copy → the user's model of what the filter does | D-17: a filter that silently drops or silently ignores a whole class of rows is a correctness defect the user experiences as a broken product. |
| toolbar copy → the user's model of what search does | D-08: substring, not meaning. A word that overstates capability is a false promise. |
| pointer-only affordances → touch users | D-14: `title=` is invisible on touch. An explanation only a hovering mouse can reach is not an explanation. |
