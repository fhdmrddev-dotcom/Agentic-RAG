**1. [Rule 1 — false premise in the plan] The base-SHA acceptance criterion cannot pass**
- **Found during:** Task 1
- **Issue:** The plan's acceptance reads *"`git rev-parse HEAD` printed and equal to `f9e55b6d…`"*. The
  plan set's own four commits moved HEAD past that SHA before any executor could run.
- **Resolution:** Used the property the plan's own `<action>` body states two paragraphs above that
  criterion, ratified by phase commit `186fa4a`: **descent + zero source drift**.
  `git merge-base --is-ancestor f9e55b6d… HEAD` → exit 0; `git diff --name-only f9e55b6d… HEAD --
  frontend/src backend/app scripts supabase` → **EMPTY**. Every `file:line` this phase quotes is valid
  as measured; nothing needed re-derivation. Original left standing in §0.

  returned `3781a3fe`. **HEAD did not descend from the dispatched base at all.** This is the failure
  this project has measured 12/12 times in Phase 192 and again on 2026-08-14.
- **Fix:** `git reset --hard a9e7d10c…`, then re-asserted `rev-parse` and an EMPTY source numstat.
- **Recorded in:** §0, because a silent correction is indistinguishable from it never happening.
