## The judging rule for every row

Two verdicts per row, not one:

1. **Presentation** — is it calmer / more consistent than before?
2. **⚠ Loss** — is any fact that used to be on screen now unreachable? A fact behind ONE
   obvious control is *moved*. A fact behind nothing is **LOST**, and that fails the row
   regardless of how good it looks.
