   - Single-line step cards in server order: status mark (`READING_FACE` glyph/ring) · step title · yield text.
   - Yield resolution replaces only `finished` (D-07): declared count takes precedence (`15 sources`), followed by `wrote an answer` for deliverable text, or outcome word for non-finished/empty rows.
   - Interactive disclosure (D-12): clicking a step card lazily fetches citation passages. When citations exist, renders them via `CitationCard` with chevron affordance; when empty or on error, degrades gracefully to a plain-text yield.
   - Zero Lucide imports (zero-glyph discipline) and zero `dangerouslySetInnerHTML`.

4. **Unit Test Suite (`RunStepList.test.tsx`)**:
   - 17 test cases covering all yield arms, count precedence, 0-count measurement, slug gate counter-test, empty degrade, error degrade, absence of similarity scores, absence of totals, tense rule, and source sweeps.
