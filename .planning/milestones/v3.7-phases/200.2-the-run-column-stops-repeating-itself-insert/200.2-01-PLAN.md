<objective>
The backend half of SC#3: one narrow, lazy, run+step-scoped citation-passage read.

Purpose: the run surface's step cards must reach the REAL citation passages from the step that
read them (D-09). The run read is POLLED while a run is live, so inlining ~38 passages × N phases
would repeat that payload every tick — the read is therefore a separate route, fetched only when a
person expands a step. This plan adds exactly that route and its fence suite, and NOTHING else: no
migration (the route reads existing columns), no serializer widening, no write path.

Output: `GET /workflow-runs/{workflow_run_id}/phases/{phase_slug}/citations` on the existing
router, a new four-field response model, the path template in `CANVAS_GATED_PATHS`, and
`backend/tests/unit/test_200_2_citations.py`.
</objective>
