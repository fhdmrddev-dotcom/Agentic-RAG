## SC#3 citation passages

| Option | Description | Selected |

**Notes:** Two facts decided this — RUN-04's written "ONLY `text` MAY REACH THE WIRE", and `RUN_POLL_MS` re-fetching the run read on an interval while live. The phase therefore HAS a backend half and the ROADMAP's restyle fence needs amending.

| Option | Description | Selected |
