<objective>
Build the room the run stands in.

Purpose: SPEC Req 6 and Req 7. A run needs a surface with the workflow's identity, its canvas run view
and its elapsed state — and a finished run needs to re-open by id and render its spine without
streaming. Almost every input already exists; the page's real job is the **join**: the definition gives
`phase_index → slug`, the slice gives `phaseIndex → status`, and composing them in the PAGE is what keeps
`phase_index` out of the canvas render path (Req 2) and the canvas diff inside its G-5 cap (Req 8).

Output: `getWorkflowRun`, `WorkflowRunPage`, and the integration suite for the run-reading half.
</objective>
