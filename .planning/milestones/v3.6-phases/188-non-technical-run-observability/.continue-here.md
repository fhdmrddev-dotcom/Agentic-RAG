Two F3 tests had the same shape. | blocking | On a red shipped test, verify its written rationale against the code before choosing a side. Record the measurement at the assertion when inverting one. |
| Synthetic events that do not bubble | I dispatched `new Event('visibilitychange')` (defaults `bubbles:false`), it never reached the `window` listener, and I published a wrong root cause ("`usePanelReconcile` is one-shot" — it is not). | advisory | Use `{ bubbles: true }` for document-dispatched events, and treat a negative synthetic-event result as inconclusive until the listener target is confirmed. |
| The vacuous grep fence | Recurred in 188-03, -06, -07, -08, -09: a `grep -c X == 0` criterion satisfied only by comment prose explaining X's absence, so it could be met by deleting an explanation. | advisory | Fence on stripped-comment code, pin the prose count separately, and test the stripper. |
