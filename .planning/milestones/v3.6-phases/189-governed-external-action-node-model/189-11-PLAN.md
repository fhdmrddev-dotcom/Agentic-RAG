<objective>
Close the D-05 loop: the approved external action records its intent, the row says so honestly, and the
run carries on.

Purpose: `189-RESEARCH.md` measured the exact seam. An executor signals a non-`completed` terminal by
putting a sentinel key on its ordinary output dict, and the engine branches on that key to choose which
status write to call — that mechanism already ships, invented at Phase 101.1 for exactly this class of
problem. 189 adds a THIRD branch beside it. Because the branch sits inside the same if/else, AFTER the
outcome checks, and that block falls through to `advance_current_phase` unconditionally, **D-05's "the
run CONTINUES" is satisfied by PLACEMENT rather than by new control flow.** The `fail_run` and `skip_to`
branches return or continue out of the loop BEFORE reaching it; a third branch here cannot accidentally
halt the run.

This plan also lands V20 — the phase's headline gate — because it is the first point at which every
piece exists.

Output: a fifth status write, one engine branch, one wire description, and an external-action workflow
that publishes.
</objective>
