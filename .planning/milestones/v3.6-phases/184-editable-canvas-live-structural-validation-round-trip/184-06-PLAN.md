  -> 200 {
       tools: string[],

       skills:  [{ id: uuid, name: string|null }],

Codes the route can emit, by owner (do NOT hardcode this list as a classifier — it is context only):
`reachability.LINT_CODES` = `bad_index` `input_unsatisfied` `no_terminal` `orphan_phase`
`unsatisfiable_skip`; `grounding.GROUNDING_VERDICT_CODES` = `folder_scope` `unregistered_tool`
`unregistered_skill`; route-minted = `business_requirement` (always `phase: null`) `interactive_phase`;
degraded = `grounding_unavailable`.
`no_terminal` is DUAL-SOURCE: `incomplete` when `phases == []`, `error` otherwise. The client must not
re-derive it — render `severity` verbatim. The route's `_severity` fails CLOSED: an unrecognised code
classifies `error` and logs a warning, and the client mirrors that by rendering every code it receives.

| 401 | token expiry | network-class |
| network / timeout | — | network-class |
| abort caused by a NEWER edit | — | **not an error** — dropped silently |
