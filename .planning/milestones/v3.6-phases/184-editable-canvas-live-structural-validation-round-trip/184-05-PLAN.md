<objective>
Add `fromCanvas` — the one client serializer — and prove the round trip over a committed corpus plus
generated shapes.

Purpose: R2 says any field the canvas does not model must survive an edit session. `toCanvas` reads
exactly six things off a phase and drops ~18 config fields, 3 validator fields and all 13
workflow-level fields, so a **field-by-field reconstruction can never** satisfy the property — it
re-materialises Pydantic defaults where the source had absence and silently drops `skill_snapshot`,
`validators[].timing` and `merge_strategy` on save. Carry-through by reference makes that whole class
of failure unrepresentable, and reference identity is a strictly stronger claim than deep equality.

Output: `fromCanvas` + three new source-purity guards + a committed provenance-bearing dump + a shape
generator + the property suite. Zero backend change, zero migration.
</objective>
