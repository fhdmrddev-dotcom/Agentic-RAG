## THE HEADLINE RESULT — B1 passed WITH a falsification control

This is the single most important thing in the plan, because it is the one claim that no instrument
in this repository could otherwise see. jsdom applies no CSS, computes no stacking contexts, and
`.click()` dispatches directly to an element **bypassing hit-testing entirely** — which is how
`BUG-260806-01` survived from `184-12` with every unit test green until an operator found it by hand
during 188.1's UAT.

With step 2 (`emit`) **selected** — computed `z-index: 1000`, the exact failing state from the bug
report's own measured table — and the affordance revealed by a **physical** pointer (computed
`opacity: 1`, `:hover` confirmed true, per
`reference_chrome_mcp_drive_css_hover_and_hit_test`), `document.elementFromPoint` at the centre of
`[data-testid="canvas-remove-emit"]` returned the control:

```
selected node   computed z-index          : "1000"      <- the failing state, reproduced
✕ control       rect  l 1007  t 382  w 41  h 41   -> centre (1027, 402)
                computed opacity          : "1"         <- revealed, not merely present
                computed z-index          : "1002"
document.elementFromPoint(1027, 402)
                -> <SPAN>, closest [data-testid] = "canvas-remove-emit"
                -> PASS_hitIsTheRemoveControl : TRUE
```

**A hit test that returns the `✕` proves nothing unless it is capable of returning something else.**
So with the node still selected, the control's own `z-index` was dropped to `999` — below
`@xyflow`'s `SELECTED_NODE_Z`, i.e. the pre-fix world — and the *identical* hit test re-run:

```
✕ z-index 999  ->  elementFromPoint(1027, 402) = "canvas-node-emit"   OCCLUDED: true
                   ^ the CARD, painting over its own remove control — the bug, reproduced
✕ z-index 1002 ->  elementFromPoint(1027, 402) = "canvas-remove-emit" reachable: true
                   ^ restored; the instrument swings both ways
```

**The defect was observed, and observed fixed, on one instrument in one session**, with the selected
node holding `z-index: 1000` throughout. B2 then passed **deselected** (node computed `z-index: 0`,
`✕` still `1002`, same hit test, still reachable) — which is what makes B1 a **comparison** rather
than a single observation: the node's elevation is the only variable that moved.

That pair is the evidence `188.2-RESEARCH.md` was waiting on to lift the fix's SUFFICIENCY above
MEDIUM, and it is the only ground on which `BUG-260806-01` was closed.
