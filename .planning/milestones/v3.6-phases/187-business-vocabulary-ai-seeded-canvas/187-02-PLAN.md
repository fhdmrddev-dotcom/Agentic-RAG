## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-187-02-01 | Tampering | `PhaseSpec` / definition JSONB | mitigate | The marker is additive-optional `bool = False` inside the `extra="forbid"` `_StrictBase` union; a misspelt key still 422s. No `@model_validator`, so nothing is baked into the JSONB — pinned by `test_grounding_declares_no_model_validator_in_CODE`. |
| T-187-02-02 | Spoofing | `name_seeded_by_ai` | mitigate | The marker is stamped **server-side after validation**, never taken from the model payload, so a model cannot claim a name was hand-typed. |
| T-187-02-03 | Denial of Service | provider budget | mitigate | A prompt-text change cannot alter control flow, but the budget assertion (1 / 2 / never 3) is pinned so a future edit that adds a shot fails loudly. |
| T-187-02-04 | Denial of Service | stored rows | mitigate | Zero migrations; `git diff --stat -- supabase/migrations` empty is an acceptance criterion on both tasks. |
| T-187-02-05 | Input Validation (V5) | emitted `name` | accept | `name` is rendered as a plain React text child downstream (React escapes text children; the raw-HTML prop is never used on the canvas — `ProblemsTray.tsx:40-53` states the same rule). No sanitisation is added. |
