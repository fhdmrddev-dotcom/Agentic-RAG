```
useDraftPersistence(args: {
  definition: BuilderDefinition | null   // the page's existing useMemo (identity = 1 per edit)
  enabled: boolean                       // drafted + canvas-enabled
  initialDraftId: string | null
  initialToken: string | null
  store: BuilderStore                    // read via getState(); markSaved() is the only writer of dirty:false
  publishInFlight: boolean               // D-186-12
  validationCause: "unreadable" | "unreachable" | null   // D-186-04 signal, DERIVED BY THE CALLER
  onDraftCreated: (id: string) => void
}): {
  state: PersistState
  draftId: string | null
  saveNow: () => Promise<boolean>        // the explicit Save-draft button (D-186-03)
  reload: () => Promise<void>            // conflict escape hatch — the DEFAULT
  overwrite: () => Promise<void>         // conflict escape hatch — a deliberate SECOND click
}

type PersistState =
  | { kind: "idle" }
  | { kind: "saving" }
  | { kind: "saved"; at: number }
  | { kind: "held"; sentence: string }
  | { kind: "conflict"; currentToken: string | null }
  | { kind: "error"; sentence: string }
```

`validationCause` is passed as a **primitive**, not the whole `ValidationState` object, on
purpose: `useLiveValidation` emits a NEW state object on every beat (including the
`CHECKING_MIN_VISIBLE_MS` flips), and a caller handing the object in would make the hold gate
churn. A `string | null` is value-stable across beats that do not change the answer.
