<objective>
Compose the hook into the page, and make the page smaller than it was.

Purpose: `WorkflowBuilderPage.tsx` is a G-5 firing row and 184 pre-authorised this exact
rewrite. This plan removes `onPersist`, `onSaveDraft`, `draftIdRef`, `creatingRef`,
`saveState`, `saveErrorMessage` and `savedTimerRef` from the page and replaces them with one
hook call plus the two surfaces the phase's UI budget allows — a quiet status line and a
conflict banner — both in the header's `actionGroup`.

Output: autosave visible in the product, a token that reaches the Builder from all four entry
paths, and measured evidence that the file shrank.

**Two deviations from RESEARCH, recorded in the open:**

1. **The `beforeunload` / `canLeave` pair STAYS on the page.** RESEARCH's G-5 table lists it
   among the things the extraction removes. It is a *navigation policy* driven by the store's
   `dirty`, not part of the write loop, and it consumes a `registerCanLeave` prop the page
   receives from `WorkflowsPage`. Moving a `window` listener into a data hook would mix
   navigation with persistence and make the hook need window plumbing to test. Its docblock is
   updated to record D-186-03's meaning change instead.
2. **`WorkflowCanvas.tsx` is NOT opened.** F12 is satisfied by extending the existing spy in
   `WorkflowCanvas.editing.test.tsx` — the *test* file, not the component. The component is a
   read-only fence (G-5, extraction due in Phase 188). If any step here seems to need a change
   inside `WorkflowCanvas.tsx`, that is a guardrail fire: stop and surface it.
</objective>
