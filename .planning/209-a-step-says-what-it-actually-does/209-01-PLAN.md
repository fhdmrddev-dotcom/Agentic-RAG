<objective>
Deliver Phase 209 ("A step says what it actually does") by implementing three key frontend improvements:
1. Node face displays the connection's service and the step's tool_name with its real service mark from `connectionMark.tsx`.
2. Effect banner accurately identifies read-only external actions as `ONLY READS` (dim tone) and mutating actions as `CHANGES SOMETHING OUTSIDE` (warning tone), with no softening of governance vocabulary.
3. Settings -> Connections filter chips switch from rigid capability verbs to state-based chips (`All` | `Connected` | `Not connected`), ensuring MCP connections remain accessible and filterable.

**Acceptance Bar:**
- Matches visual and architectural standards in `screenshots/` (Claude.ai Connectors, Plugins directory, xyOps editor).
- Preserves all invariants in `ORIENTATION-260825-connections-and-canvas.md` and `icon-convention.md`.
</objective>

### Task 1: Effect Banner Accuracy & Read Tool Detection (Item 2 / D-209-03)
1. In `frontend/src/components/workflows/nodeEffectBanner.ts`:
   - Export `EFFECT_BANNER_OUTSIDE = "CHANGES SOMETHING OUTSIDE"`.
   - Export `EFFECT_BANNER_READ_ONLY = "ONLY READS"`.
   - Implement `isReadOnlyExternalAction(config?: Record<string, unknown> | null): boolean`:
     - If `config?.readOnlyHint === true`, return `true`; if `false`, return `false`.
     - If `config?.tool_name` is a string matching read prefixes (`/^(read|get|list|search|fetch|query|describe|find|check|view|inspect)(_|[A-Z]|$)/i`), return `true`.
     - Otherwise return `false`.
   - Update `effectBannerFor(phaseType: string, config?: Record<string, unknown> | null): string | null`:
     - If `phaseType !== "external_action"`, return `null`.
     - If `isReadOnlyExternalAction(config)`, return `EFFECT_BANNER_READ_ONLY`.
     - Else return `EFFECT_BANNER_OUTSIDE`.
2. In `frontend/src/components/workflows/PhaseNodeCard.tsx`:
   - Update effect banner rendering:
     - If `effectBanner === EFFECT_BANNER_READ_ONLY`, style with `text-muted-foreground` (dim tone).
     - If `effectBanner === EFFECT_BANNER_OUTSIDE`, style with `text-warning` (warning tone).
     - Keep `data-testid="canvas-effect-banner"` and 9px bold wide-tracked geometry.
3. In `frontend/src/components/workflows/canvasModel.ts`:
   - In `buildPhaseData`, compute `effectBanner: effectBannerFor(phaseType, phase.config)` and pass it into `PhaseNodeData`.
4. Create/update unit tests in `frontend/src/components/workflows/__tests__/nodeEffectBanner.test.ts` and `PhaseNodeCard.test.tsx` verifying:
   - `read_wiki_structure` produces `ONLY READS` in dim tone.
   - Mutating tools (e.g. `post_message`, `create_ticket`, `send_email`, `update_record`) produce `CHANGES SOMETHING OUTSIDE` in warning tone.
   - Non-external phases produce `null`.
   - Totality over malformed/empty configs.
