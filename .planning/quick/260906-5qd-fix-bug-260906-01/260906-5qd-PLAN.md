<objective>
Move the classification rule-evaluation block out of `ingest_document` (the legacy synchronous
upload path) and into `enrich_for_ingest` — the single enrichment home BOTH ingest paths already
call — so that a file arriving through a connector watch or the durable queue is classified
exactly as an interactively-uploaded one is.

Purpose: closes `BUG-260906-01`. Automated folder watching is the v4.0 differentiator, and today
the only documents the filing engine never sees are the ones a person is least able to file by
hand. This is the FIFTH instance of one shape — two code paths serving one user-visible outcome,
one of them doing the work — and the fix is the same extraction that closed `BUG-260905-06`.

Output: the block living in `ingest_enrich.py`, deleted from `documents.py`, and an AGREEMENT
test (never a second per-path test) proving both paths produce the same suggestion.

⛔ SCOPE FENCE. The block MOVES; it is not rewritten. No UI, no migration, no change to
`classification_matcher`. First-match-wins (`D-118-3`) is UNCHANGED — `SEED-252`'s
many-rules-contributing / actually-move-the-file design is Phase 237 and is out of scope.
`_classification` stays a SUGGESTION: nothing here moves a document into a folder.
</objective>
