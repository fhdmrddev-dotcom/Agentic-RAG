# Quick Task 260405-s1e

## Goal

Two access-control fixes:
1. "Make private / Make global" menu item in folder tree is only visible to the folder owner
2. Uploading files into another user's public folder is blocked (frontend disabled state + backend 403 guard)

## Root Cause

`FolderNode.tsx` renders the toggle-global dropdown item unconditionally — it doesn't check `node.user_id` against the current user. The upload restriction has no ownership check at all (only a visibility check).

## Tasks

### Task 1 — Backend: enforce upload ownership in `documents.py`

**File:** `backend/app/api/documents.py`

In `upload_document`, replace the current folder visibility check (lines ~67-77) with an ownership check:

```python
if folder_id:
    folder_check = (
        supabase.table("folders")
        .select("id, user_id")
        .eq("id", folder_id)
        .maybe_single()
        .execute()
    )
    if not folder_check.data:
        raise HTTPException(status_code=404, detail="Folder not found")
    if folder_check.data["user_id"] != current_user["id"]:
        raise HTTPException(
            status_code=status.HTTP_403_FORBIDDEN,
            detail="Cannot upload to a folder you do not own",
        )
```

Note: Service role key sees all folders, so no visibility filter is needed — just a straight lookup + ownership check.

**Verify:** `POST /documents/upload` with `folder_id` pointing to another user's global folder returns 403.

### Task 2 — Frontend: add `currentUserId` prop to `FolderNode` and hide toggle-global for non-owners

**File:** `frontend/src/components/ingestion/FolderNode.tsx`

- Add `currentUserId: string` to `FolderNodeProps`
- Accept it in the destructure
- Add `const isOwner = node.user_id === currentUserId`
- Wrap the toggle-global `DropdownMenuItem` in `{isOwner && (...)}` so it only renders for the owner
- Pass `currentUserId` in the recursive `<FolderNode>` call for children

**Verify:** Non-owner sees no "Make private / Make global" item in the folder dropdown.

### Task 3 — Frontend: thread `currentUserId` through `FolderTree`

**File:** `frontend/src/components/ingestion/FolderTree.tsx`

- Add `currentUserId: string` to `FolderTreeProps`
- Accept it in the destructure
- Pass `currentUserId={currentUserId}` to every `<FolderNode>` instance

### Task 4 — Frontend: disable upload for non-owned folders in `IngestionPage` + `DocumentUpload`

**File:** `frontend/src/pages/IngestionPage.tsx`
- Import `useAuth`
- Add `const { user } = useAuth()`
- Compute `const canUploadToFolder = !selectedFolderId || !selectedFolder || selectedFolder.user_id === user?.id`
- Pass `currentUserId={user?.id ?? ""}` to `<FolderTree>`
- Pass `disabled={!canUploadToFolder}` to `<DocumentUpload>`

**File:** `frontend/src/components/ingestion/DocumentUpload.tsx`
- Add `disabled?: boolean` to `Props`
- When `disabled`, render the dropzone with a lock message instead of the upload prompt:
  ```
  <Lock className="h-8 w-8 text-muted-foreground/50" />
  <p className="text-sm font-medium text-muted-foreground">Read-only folder</p>
  <p className="text-xs text-muted-foreground mt-0.5">Only the folder owner can upload files here</p>
  ```
  Apply `pointer-events-none opacity-60 cursor-not-allowed` to the dropzone when disabled. Do NOT call `onUpload` when disabled.
- Import `Lock` from `lucide-react`

**Verify:** Selecting another user's global folder shows the disabled "Read-only folder" state. Selecting own folder shows normal upload.
