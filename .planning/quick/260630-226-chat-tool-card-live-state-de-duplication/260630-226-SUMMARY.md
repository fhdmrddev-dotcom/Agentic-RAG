# Quick Task 260630-226: Chat Tool-Card Live-State De-Duplication Summary

UI-only de-duplication of the chat live-execution surface (SEED-098): an ACTIVE
(running/preparing) tool now rests in the SAME calm one-line essence shape as a
finished tool — no auto-expanded heavy body, no show→collapse flicker — with its
live streaming body one click behind the chevron, plus the Variant B merged live
pill (verb + live ticking duration in ONE chip); and the three loose duplicate
lines below the run card (todo `see panel` pointers, `Skill activated`, the
bottom `Preparing code…` echo) are deleted.

## What Was Built

### Task 1 — Unify the active-tool shape (commit `e3ff8623`)
- **StatusPill.tsx**: additive `liveStartedAt?: number` prop. When
  `status === "running"` AND `liveStartedAt != null`, the pill renders a LIVE
  ticking duration inside the same chip (`running · 3.2s`) via an internal
  `useState` + `setInterval(250ms)` torn down on unmount / when the tool stops.
  When `liveStartedAt` is absent the pill is byte-identical to today. No color
  changes (preserves the shared component's contract).
- **ToolCallPanel.tsx**: `ToolEssenceLine` extended to render running (`Running
  {tool}` primary + optional `"{summary}"` + merged live pill) and preparing
  (`Preparing {tool}…` + `preparingDescription` + `preparing · X.X KB` when
  `argsBytesStreamed > 0`) states; done/interrupted unchanged. The collapse
  predicate flipped: `isCollapsedToEssence = (isFinished || isActive) &&
  !expandedSteps.has(stepKey)`, so an active tool rests collapsed by default and
  reveals its live body (ExecuteCodeBody / ToolArgsLivePanel / generic head+body)
  when its `stepKey` joins `expandedSteps`. All existing expand machinery
  (`expandedSteps` Set, `panelExpanded`, `lastPreparingIndex`, `tc-active-wrap` +
  `tc-bottom-shimmer`, the `i < activeIndex` step-summary branch, iteration
  dividers, dedup) preserved verbatim.

### Task 2 — Delete three loose duplicate lines (commit `37bd6d5c`)
- **MessageItem.tsx**:
  - (a) write_todos/workspace_write `see panel` pointers removed; `PausedRunCue`
    (ask_user) preserved. Unused `SeamPointer` import dropped (`type SeamKind`
    kept — reload-mode SeamCard path).
  - (b) `Skill activated: docx` line removed (in-card `Loading skill` SkillRow
    covers it). Unused `Zap` import dropped.
  - (c) bottom italic `Preparing code…/Synthesizing answer…` echo removed (RunCard
    header strip already carries the live verb + timer). Orphaned
    `stickyLabelRef` / `computedLabel` / `stickyBottomLabel` computation deleted;
    `isMessageStreaming` retained (still used by the live-seam + reload-seam
    gates). Terminal-state (timed_out / stopped) Square block + no-tools-yet
    thinking indicator preserved.
  - (Change 3) `message.activatedSkill` is no longer READ in the render path
    (`grep -n activatedSkill` → 0); the field stays intact in types +
    StreamsProvider.
