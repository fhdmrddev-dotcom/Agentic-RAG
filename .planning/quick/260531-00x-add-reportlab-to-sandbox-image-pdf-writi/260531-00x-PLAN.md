# Quick Task 260531-00x: Add reportlab to the sandbox image

## Problem
Operator hit: "attempted to generate the 1-page PDF report, but the sandbox is missing the reportlab package, so the file export failed." The sandbox image (`backend/Dockerfile.sandbox`) shipped 11 packages — `pypdf` is the only PDF lib and it only **reads** PDFs. There was **no PDF-writing library**, so any "generate a PDF" prompt had no engine.

## Tasks
### Task 1 — Add reportlab to the image
- **files:** backend/Dockerfile.sandbox, CLAUDE.md
- **action:** Add `reportlab==4.2.5` to the `RUN pip install` block; document it in the CLAUDE.md package list; bump the recommended image tag `075.1 → 075.1.1` so old cached containers don't shadow the new image.
- **verify:** `import reportlab` succeeds in the rebuilt image; a "generate a 1-page PDF" prompt produces a real .pdf via execute_code.
- **done:** sandbox can WRITE pdfs.

## Operator step (required — Docker)
Code/doc change is committed, but the image must be rebuilt by the operator:
```
docker build -f backend/Dockerfile.sandbox -t agentic-rag-sandbox:075.1.1 backend/
```
then set `SANDBOX_IMAGE=agentic-rag-sandbox:075.1.1` in `backend/.env`. Only **new** chats pick it up (sessions cached per thread_id until idle eviction, ~30 min).
