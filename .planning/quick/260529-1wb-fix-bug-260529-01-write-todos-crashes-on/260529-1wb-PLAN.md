<objective>
Fix BUG-260529-01: `write_todos` crashes with `'str' object has no attribute 'get'`
when a model emits the `todos` tool argument as a stringified JSON array (observed
on free OpenRouter llama-3.3-70b) or as a list containing non-dict items.

Purpose: weak / OpenRouter-proxied models that serialize nested tool args as strings
currently get an opaque "Tool execution failed" and loop until the agent step cap.
After this fix, valid stringified payloads succeed, and bad shapes return a friendly,
model-readable error enabling self-correction.

Output: coercion + guards in `_handle_write_todos`, defense-in-depth guard in
`replace_todos`, and a 3-case regression test that fails against current code.

Scope: backend only. Do NOT touch frontend or any Phase 086 artifacts.
</objective>
