Investigate why Enter key does not trigger folder creation/rename. The code appears correct on static analysis, so the bug is likely one of these:

**Investigation steps (in order):**

1. **Check for event interception**: Look for any parent component, global event listener, or library (shadcn Dialog, Radix Popover, etc.) that might be intercepting or preventing the keydown event from reaching the input. Search for `addEventListener("keydown"` or `onKeyDown` on parent wrappers.

2. **Check onBlur vs onKeyDown race**: In FolderCreateInput.tsx, the `onBlur` handler calls `onCancel()` when value is empty. Verify that when Enter is pressed on a non-empty value, `onBlur` does NOT fire before or simultaneously with `onKeyDown` in a way that unmounts the component before `onCommit` executes. If this is the issue, add `e.preventDefault()` in the Enter handler, or use a ref-based "committed" flag to prevent blur from canceling after Enter commits.

3. **Check async error swallowing**: In FolderTree.tsx `handleCreateCommit`, the try/catch only logs errors. Add `console.error` with the full error object temporarily. Check if `apiCreateFolder` is throwing (e.g., auth headers missing, 401/403 from backend).

4. **Check if onCommit/onCreateCommit is stale**: Verify the `handleCreateCommit` closure captures the correct `creatingInParentId` value. If `creatingInParentId` is null by the time Enter fires (e.g., blur already set it to null), the parentId will be null regardless.

**Most likely fix needed:**

Add `e.preventDefault()` to the Enter keydown handler in FolderCreateInput.tsx to prevent any default behavior or form submission side effects. Also add it in FolderNode.tsx rename input. Additionally, in FolderCreateInput.tsx, make the onBlur handler commit non-empty values (not just cancel empty ones) so that blur and Enter have consistent behavior:

In FolderCreateInput.tsx:
```typescript
onBlur={() => {
  const trimmed = value.trim()
  if (trimmed) {
    onCommit(trimmed, isGlobal)
  } else {
    onCancel()
  }
}}
onKeyDown={(e) => {
  if (e.key === "Enter") {
    e.preventDefault()
    const trimmed = value.trim()
    if (trimmed) onCommit(trimmed, isGlobal)
  }
  if (e.key === "Escape") onCancel()
}}
```
