# Quick Task 260322-26g: Improve Tool Call Display for ls/tree/grep/glob — Summary

**One-liner:** Progressive-disclosure result rendering for ls/tree/grep/glob in chat UI — collapsed shows summary counts, expanded shows structured file/folder listings with icons.

## What Was Done

Added rich result rendering to `ToolCallPanel.tsx` for the four Phase 5 search/navigation tools.

### Task 1 — Icons, labels, and arg summaries

- `toolIcon()`: added `FolderOpen` (ls), `GitBranch` (tree), `TextSearch` (grep), `FileSearch` (glob)
- `toolLabel()`: added "Listing folder", "Browsing folder tree", "Searching file contents", "Finding files by pattern"
- `toolSummary()`: extracts `args.path` for ls/tree, `args.pattern` for grep/glob; existing query/filename fallthrough preserved

### Task 2 — Structured result renderers

New components and helpers added inside `ToolCallPanel.tsx`:

- `resultSummary(name, parsed)` — one-line badge text: "2 folders, 5 documents" / "12 items" / "3 matches"
- `ToolResultBlock` — collapsible block below tool row; parses `tc.result` JSON defensively; shows error if `parsed.error`
- `LsResult` — two sections: folders (Folder icon + name + optional "(global)") then documents (FileText + filename + status badge color-coded green/yellow/red)
- `TreeResult` / `TreeNodeRow` — recursive indented hierarchy using inline `marginLeft`, depth guard at >3 renders "..."
- `GrepResult` — filename list with FileText icons, max-h-48 overflow-y-auto
- `GlobResult` — full path list (`m.path ?? m.filename`), same styling

Wire-up: `{tc.status === "done" && tc.result && !agentState && <ToolResultBlock tc={tc} />}` inserted between tool row and SubAgentBlock.
