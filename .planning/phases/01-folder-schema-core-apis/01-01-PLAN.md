Create the migration file with exactly this content:

```sql
-- Migration 013: Folder Schema (Phase 1)
-- Adjacency list for nested folders with global/per-user visibility

CREATE TABLE public.folders (
  id            uuid        PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id       uuid        NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  name          text        NOT NULL,
  parent_id     uuid        REFERENCES public.folders(id) ON DELETE CASCADE,
  is_global     boolean     NOT NULL DEFAULT false,
  created_at    timestamptz NOT NULL DEFAULT now(),
  updated_at    timestamptz NOT NULL DEFAULT now()
);

-- Indexes for fast lookups
CREATE INDEX folders_parent_id_idx ON public.folders(parent_id);
CREATE INDEX folders_user_id_idx ON public.folders(user_id);

-- Enable RLS
ALTER TABLE public.folders ENABLE ROW LEVEL SECURITY;

-- SELECT: owner sees their own + all global folders
CREATE POLICY "Users can view their own and global folders"
  ON public.folders FOR SELECT
  TO authenticated
  USING (auth.uid() = user_id OR is_global = true);

-- INSERT: users can only insert their own folders
CREATE POLICY "Users can insert their own folders"
  ON public.folders FOR INSERT
  TO authenticated
  WITH CHECK (auth.uid() = user_id);

-- UPDATE: users can only update their own folders
CREATE POLICY "Users can update their own folders"
  ON public.folders FOR UPDATE
  TO authenticated
  USING (auth.uid() = user_id);

-- DELETE: users can only delete their own folders
CREATE POLICY "Users can delete their own folders"
  ON public.folders FOR DELETE
  TO authenticated
  USING (auth.uid() = user_id);

-- Auto-update updated_at on change (reuses existing trigger function from migration 001)
CREATE TRIGGER set_folders_updated_at
  BEFORE UPDATE ON public.folders
  FOR EACH ROW EXECUTE PROCEDURE public.set_updated_at();
```

**File 1: `backend/app/api/folders.py`**

Create the CRUD router following the exact pattern from `threads.py`. Five endpoints:

1. **GET /folders** — List folders visible to the current user (owned + global). Uses two queries OR'd together since service role bypasses RLS:
   - Query 1: `.eq("user_id", current_user["id"])`
   - Query 2: `.eq("is_global", True)`
   - Combine results, deduplicate by id (in case user owns a global folder)
   - Order by `name` ascending

2. **GET /folders/{folder_id}/children** — List direct children of a folder. Filter: `.eq("parent_id", folder_id)` and apply same visibility logic (owned + global).

3. **POST /folders** — Create a folder. Accept `FolderCreate` body. Set `user_id` from `current_user["id"]`. If `body.parent_id` is provided, validate that the parent folder exists and is accessible (owned by user OR is_global). Return 201 with `FolderResponse`. Strip whitespace from name with `.strip()`.

4. **PATCH /folders/{folder_id}** — Rename a folder. Accept `FolderUpdate` body. Update only `name` field. Filter by `.eq("id", folder_id).eq("user_id", current_user["id"])`. Return 404 if no rows updated. Strip whitespace from name.

5. **DELETE /folders/{folder_id}** — Delete a folder. Filter by `.eq("id", folder_id).eq("user_id", current_user["id"])`. DB cascade handles children. No 404 check (matches threads.py pattern). Return 204.

if body.parent_id:

        .execute()
