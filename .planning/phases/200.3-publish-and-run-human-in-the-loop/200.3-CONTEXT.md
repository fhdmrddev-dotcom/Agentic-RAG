# Phase 200.3 Context: Publish & Run Human-in-the-Loop Workflows (SEED-164)

## Background & Scope
Workflows containing human checkpoints (`llm_human_input`) currently face two barriers:
1. The **Publish Gauntlet** refuses to publish them because the background synchronous golden run cannot pause for human input.
2. Drafts cannot be executed directly from the Workflow Studio / Builder because no "Test Run" button exists.

This phase implements `SEED-164` to allow publishing interactive workflows and adds direct draft testing to the builder.

---

## Locked Decisions

### 1. Golden Run Auto-Continue for Human Approval Steps (D-01)
- **Mechanism:** In `backend/app/services/harness/human_input.py`, when `ctx.is_golden_run` is `True`, `_exec_llm_human_input` immediately auto-continues:
  - If `options` are provided: uses `options[0]`.
  - If no `options`: uses `"Approved"`.
  - Attaches `_golden_run_mock: True` to output metadata.
- **Publish Gauntlet:** In `backend/app/services/harness/publish_service.py`, remove the rule in `_interactive_phase_failures` that blocks `llm_human_input`. Workflows with human checkpoints can now pass the publish gauntlet cleanly.

### 2. Live Run Interactivity Preserved (D-02)
- Real production runs (`is_golden_run=False`) are completely unaffected. They pause, emit SSE events, render the ask card with authored choices in `RunSpine.tsx`, and resume upon user click.

### 3. Builder Test Run Button (D-03)
- In `frontend/src/components/workflows/BuilderHeaderBar.tsx` (or `BuilderSaveRegion.tsx`), add a **▶ Test Run** button.
- Clicking **Test Run** saves the draft (if modified) and launches an interactive run (`POST /workflow-runs`), routing to the run view (`/workflows/runs/{run_id}`).

---

## Success Criteria
1. Workflows containing `llm_human_input` steps publish successfully without gauntlet refusal.
2. Published workflows with human approval steps appear on the library shelf with `▶ Run` enabled.
3. In the Workflow Builder, authors can click `▶ Test Run` to execute draft workflows directly.
4. All existing tests pass and count gate remains green.
