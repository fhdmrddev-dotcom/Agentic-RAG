- New failure value string: "template_fields_missing" (module constant FAILURE_TEMPLATE_FIELDS_MISSING in emit_cause.py).
- Composed string format (plain text, "\n" separated, no markdown list syntax):
  line 1: "This step failed after {N} attempt{s}:"  (N = number of records = sealed model calls, D-25)
  then one line per distinct kind: "• {k} attempt{s} — {sentence} {check line}"
  ordering: count descending, ties by the fixed KIND_ORDER tuple below. The frontend only adds `whitespace-pre-line`.
- Record shape (JSON-safe dict, one per sealed shot or terminal arm):
  {"attempt": int, "kinds": [str, ...], "missing": [str] (missing_fields only), "uncited": int, "invented": int, "detail": str (terminal kinds only, optional)}
