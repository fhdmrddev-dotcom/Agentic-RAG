<threat_model>
ASVS Level 1 Threat Assessment:
- **T-260-01 (Cross-Org Folder Leak via Active Expert)**: A malicious user sets `threads.active_expert_id` to an expert belonging to another org or referencing foreign folders.
  *Mitigation*: `run_producer.py` invokes `resolve_expert_bundle`, which performs two-phase tenant isolation (`PACK-04`) and strips any foreign folder IDs before populating `RunContext`.
- **T-260-02 (Unauthorized Expert Selection)**: An unentitled tenant calls PATCH `/threads/{id}` with an `active_expert_id`.
  *Mitigation*: PATCH endpoint verifies user org entitlement via `require_capability('experts')` when `active_expert_id` is passed.
- **T-260-03 (History Erasure Bug)**: Scoping corrupts or drops previous messages in the thread.
  *Mitigation*: Scoping strictly binds `effective_folder_ids` and `effective_tools`; history query `_history_q` in `agent_loop.py` is completely untouched.
</threat_model>
