<threat_model>
ASVS Level 1 Threat Assessment:
- **T-260-04 (UI State Desynchronization)**: Dismissing the chip locally fails to clear backend `active_expert_id`, leaving subsequent messages scoped unexpectedly.
  *Mitigation*: Dismiss handler issues `setThreadActiveExpert(threadId, null)` optimistically and handles error rollback if the network call fails.
- **T-260-05 (DOM Pollution / Unsafe Markup)**: Expert prompt suggestions containing malicious HTML strings rendered without escaping.
  *Mitigation*: React JSX automatically escapes string interpolations in title and prompt chips; no `dangerouslySetInnerHTML` is used.
</threat_model>
