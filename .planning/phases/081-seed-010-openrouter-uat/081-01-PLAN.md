## Model Registry
Both models are registered in `backend/app/config.py` MODEL_CAPABILITIES:
- `moonshotai/kimi-k2.5`: provider=openrouter, llm_call_timeout_seconds=900, max_output_tokens=65536
- `minimax/minimax-m2.7`: provider=openrouter, llm_call_timeout_seconds=600, max_output_tokens=131072

Both route through `openai_service.py` (OpenAI-compat path) via OpenRouter API using `OPENROUTER_API_KEY`.

## Timeout Machinery
- `config.py:416-459` — `_parse_llm_call_timeout_overrides()`: parses `model=seconds` CSV syntax, bounds [1, 3600], warns on tight budgets (<30s)
- `config.py:384-413` — `get_per_call_timeout()`: precedence = env override > MODEL_CAPABILITIES > DEFAULT_LLM_CALL_TIMEOUT_SECONDS (300s)
- `threads.py` agent loop: `asyncio.wait_for(timeout=per_call_budget)` wraps each LLM call. On timeout -> `runs.status='timed_out'`, `runs.error='timed_out: Xs per-call deadline exceeded at iteration N'`
