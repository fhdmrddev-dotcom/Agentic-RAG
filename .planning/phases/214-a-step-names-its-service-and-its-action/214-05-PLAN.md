```
{"code": <one of the five>, "phase": <phase slug>, "message": <backend-composed diagnostic>,
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a workflow definition → the publish gate | The gate decides whether a workflow may become live. **It is a safety gate**: everything it lets through will eventually send something to a vendor. |
| MCP server's `discovered_tools` snapshot → the gate's `tool_schemas` map | A schema supplied by a remote server decides which arguments the gate believes are required. |
| the golden run's resolved argument object → adapter schema validation | The object is validated but must NOT be sent (D-16). |

| T-214-05-02 | Tampering | a hostile MCP server's `inputSchema` weakening the gate | mitigate | The gate only ever ADDS refusals; a schema declaring nothing required produces no gaps but also grants nothing — the executor still projects onto the SAME schema and the adapters still fail closed on undeclared keys.
