## Decisions Made

- **Single `_upload_pipeline` helper for both routes** rather than separate `_upload_pipeline` + `_reingest_pipeline` siblings. Rationale: the `storage_path=""` sentinel cleanly distinguishes the two flows without branching helper bodies; keeps the test surface to one helper; matches the plan's recommendation in PATTERNS.md (smallest seam keeping ingest_document signature byte-identical).
- **`asyncio.run` + `asyncio.wait_for` inside the sync helper** rather than `threading.Timer` or `signal.alarm`. Rationale: preserves byte-for-byte parity with the 071.1 `/reextract` Layer 2 shape; the BackgroundTask runs on Starlette's anyio thread pool (no parent event loop), so spawning a child event loop with `asyncio.run` is the canonical way to use `asyncio.wait_for` from sync code. Cleaner than thread-level alarms and works identically on Windows + POSIX.
- **PyMuPDF fallback guards on `EXTRACTOR_PRIMARY` env** (not `body.engine` — there is no body.engine on /upload + /reingest). Rationale: matches D-071.1-04 "fallback fires on Docling-only timeout" — when EXTRACTOR_PRIMARY is anything other than 'docling', the fallback raises a clear error instead of silently picking PyMuPDF.
