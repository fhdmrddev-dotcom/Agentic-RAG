**1. [Rule 3 — Test infra adaptation] `vi.hoisted()` factory for memo test spies**

- **Found during:** Task 3 first GREEN run on `MarkdownRenderer.memo.test.tsx`.
- **Issue:** Initial test draft used top-level `const markedParseSpy = vi.fn(...)` and referenced it inside the `vi.mock("marked", () => ({ marked: { parse: markedParseSpy, ... } }))` factory. Vitest's transformer hoists `vi.mock` to the top of the module ABOVE the const declarations, producing `ReferenceError: Cannot access 'markedParseSpy' before initialization`.
- **Fix:** Switched to `vi.hoisted(() => ({ markedParse: vi.fn(...), sanitize: vi.fn(...) }))` pattern. `vi.hoisted` declarations are themselves hoisted alongside `vi.mock` factories, so the spies exist before the mock factory references them.
- **Files modified:** `frontend/src/__tests__/components/MarkdownRenderer.memo.test.tsx`, `frontend/src/__tests__/components/MessageItem.memo.test.tsx`.
