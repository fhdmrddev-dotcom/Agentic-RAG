| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-137-04 | Tampering | rating / proposal mutations | mitigate | Every mutation (rate/propose/approve/reject/rerun/force-promote) hits the owner-gated endpoint THEN re-fetches from the DB — no optimistic state (T-135-04); a card cannot show promoted/rated unless the server reconciled it. |
