## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-137-02 | Information Disclosure | cross-skill stale state | mitigate | The lifted `currentSkillRef` + per-fetch `requestedSkill` guard bails before any setState if the active skill changed mid-fetch (the exact BUG-260701-02 fix); the `[skillId]` effect clears prior readout/live/proposal/gate/cases so no prior skill's case labels leak into a new skill's run history. |
| T-137-04 | Tampering | rating / proposal mutations | mitigate | Every mutation (rate/propose/approve/reject/rerun/force-promote) hits the owner-gated endpoint THEN re-fetches from the DB — no optimistic state (T-135-04); a card cannot show promoted/rated unless the server reconciled it. |
| T-137-01 | Elevation of Privilege | publish gate / stepper feed | mitigate | EvalsTab passes the server `getPublishGate` response to LifecycleStepper untouched; it never recomputes `met` (D-07/054 one-truth lock). |

| T-137-05 | Injection (XSS) | eval output / reason render | mitigate | All eval output/reason/instruction/prompt text renders via the leaf components as React text nodes; no `dangerouslySetInnerHTML`. |
| T-137-SC | Tampering (supply chain) | npm install surface | accept | Zero new packages; slopcheck N/A. |
