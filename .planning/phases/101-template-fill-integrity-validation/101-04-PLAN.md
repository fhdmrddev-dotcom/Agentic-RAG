<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM field-map → tool argument | The model-emitted field-map is untrusted structured data crossing into the deterministic tool |
| template bytes → sealed sandbox | Template bytes (esp. untrusted uploads) are rendered inside the network-less sandbox, never the backend process |
| KB chunk content in field-map values → OOXML | Untrusted KB strings flow into the produced file (autoescape / python-docx escape) |
| sandbox stdout → handler | The verdict JSON crosses back from the sandbox; the handler must not trust a missing/garbled verdict as success |

| T-101-04-02 (T-097-07) | Spoofing | citation gate | mitigate | check_coverage runs BEFORE render; an uncited/invented field-map is rejected without rendering (D-08 class 1) |
