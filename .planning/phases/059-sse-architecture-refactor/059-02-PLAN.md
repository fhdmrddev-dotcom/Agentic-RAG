## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client (browser) → FastAPI route handler | Untrusted POST body crosses here; auth is handled by `get_current_user`; thread ownership re-checked via SELECT |
| route handler → producer task | In-process; closure captures `current_user`, `body`, `thread_id`, `supabase` — same trust domain |
| producer → asyncio.Queue | In-process; bounded by `maxsize=100` (backpressure prevents memory pressure) |
| consumer → ASGI send (sse-starlette) | sse-starlette runs `_listen_for_disconnect` as a sibling task; first finish cancels others |
| `asyncio.shield` boundary | Protects the DB write from external cancellation; does not protect from internal CancelledError (Pitfall 3) |
