# Phase 075.10 Plan 01: Fine-Grained `tool_args_progress` Emission Summary

**`tool_args_progress` SSE boundary lowered from hardcoded 5120 → configurable default 256 across all 4 providers (Anthropic + Google + OpenAI + OpenRouter); migration 049 + defensive settings helper + per-stream-invocation boundary capture.**

## Performance

- **Duration:** ~22 min
- **Started:** 2026-05-24T15:58:00Z (approx — first edit timestamp)
- **Completed:** 2026-05-24T16:19:56Z
- **Tasks:** 4 of 4 (T1–T4 code-complete; T5 is human-UAT, see below)
- **Files modified:** 4 backend files + 1 new migration

## Accomplishments

- Added `app_settings.chat_tool_args_progress_emit_boundary_bytes INTEGER DEFAULT 256` via migration 049 — operator can tune SSE emission cadence without code changes.
- Added `tool_args_progress_emit_boundary_bytes()` helper in `app.models.user_settings` — defensive settings read with 5120 fallback so streaming services never crash on a wedged settings table or rolled-back schema.
- Replaced hardcoded `5120` boundary at 3 sites:
  - `anthropic_service.py:254` (input_json_delta path, NATIVE provider only)
  - `google_service.py:482` (function_call args accumulation)
  - `threads.py:2227` + `:2236` (`_on_chunk_openai` callback shared by OpenAI native + OpenRouter, both branches inherit fix)
- Widened sliding-window tail slice (`args_so_far` payload) to `max(5120, boundary*4)` so per-emit context still ships meaningfully after boundary drop. Full cumulative buffer continues to flow via `code_so_far` per Plan 075.6 Req #1.
- For a 1 KB code-gen body at the new 256 B default: expected ≥ 4 `tool_args_progress` events per tool call (was ≤ 1) — closes the failure criteria #1, #2 in PLAN.md.

### Gate 3 — T5 Live UAT across 4 providers (G-4 lived-experience gate)

PLAN.md §Failure criteria + Task 5 mandate Chrome MCP + SSE intercept on each of the 4 providers exercising the 4-axis bandwidth from CLAUDE.md SC#10.

**Prompt for all four:** Send `execute_code "for i in range(10): print(i)"` (or any ~1 KB code-generation prompt — long enough to exercise multiple 256-byte boundaries).

| Provider | Model | Pass criteria |
|---|---|---|
| OpenAI | gpt-5.4 | SSE intercept: ≥ 3 `tool_args_progress` events between `tool_preparing` and `tool_start` — was 0 pre-075.10. Editor inset shows code visibly growing during preparing. |
