## Pattern Assignments

### `provider_gateway/events.py` (model/schema, streaming)

**Analog:** `google_service.py:1-19` (the canonical-event docstring — the template) + `anthropic_service.py:6-14`.

**Why this analog:** D-02 names a fixed event vocabulary (`delta` / `tool_preparing` / `tool_args_progress` / `tool_start` / `finish` / `usage` / `usage_delta`). `google_service.py`'s module docstring ALREADY documents this exact schema verbatim — it is the contract, not a thing to invent. Anthropic's docstring documents the same shape (older, narrower). Copy the schema FROM the docstring; do not re-derive.

**The canonical schema as it exists today** (`google_service.py:7-14` — copy these field names exactly):
```python
# Event schema (matches Anthropic path):
#   {"type": "delta",              "content": str}
#   {"type": "tool_preparing",     "id": str, "name": str, "index": int}
#   {"type": "tool_args_progress", "tool_index": int, "name": str, "args_so_far": str, "total_args_bytes_so_far": int}
#   {"type": "tool_start",         "id": str, "name": str, "args": dict}
#   {"type": "finish",             "finish_reason": str, "tool_calls": list[dict]}
#   {"type": "usage",              "input_tokens": int, "output_tokens": int}
#   {"type": "usage_delta",        "output_tokens": int}
```

**Two fields the docstring schema OMITS but the consumer consumes** (the lossless-superset requirement, CONTEXT D-02 discretion note):
- `code_so_far: str` on `tool_args_progress` — added Phase 075.6; consumed at `agent_loop.py:1508`, `:1621`, `:1923` (all three branches `.get("code_so_far", "")`). The `events.py` `ToolArgsProgressEvent` MUST carry it.
- `thought_signature: str` (Google base64 sig) — carried on `finish.tool_calls[]` and hydrated onto the buffer at `agent_loop.py:1644-1647`. The `events.py` `ToolStartEvent`/`FinishEvent.tool_calls` MUST carry it (else Gemini-3 400s on round 2+ — invariant I2/D-07).

**Recommended shape** (RESEARCH §Canonical Event Schema, lines 268-327): TypedDict-per-type `Union` named `GatewayEvent`. Discretion is the planner's (D-02) — TypedDict vs dataclass — but it MUST be a lossless superset. `calling_mode` is NOT an event — it rides alongside the stream (see dispatcher below, Pitfall 3).

### `provider_gateway/__init__.py` + `dispatcher.py` (service entrypoint, request-response → streaming)

**Analog:** `openai_service.create_adaptive_streaming_chat:1197` — copy its RETURN CONTRACT.

**Why this analog:** The dispatcher's whole job is to pick an adapter and return a stream the consumer can drain. The cleanest signature mirrors the one the consumer already destructures today (`stream, calling_mode = create_adaptive_streaming_chat(...)`, `agent_loop.py:1659`). RESEARCH Open Question 1 recommends `open_stream(provider, request) -> (AsyncIterator[GatewayEvent], CallingMode)` — Anthropic/Google adapters return `CallingMode.NATIVE`.

**The exact return shape to mirror** (`openai_service.py:1197-1205`):
```python
def create_adaptive_streaming_chat(
    messages: list[dict], tool_choice: str = "auto", model: str | None = None,
    user_settings: UserEffectiveSettings | None = None, tools_override: list[dict] | None = None,
    max_tokens: int | None = None,
) -> tuple:
    """Returns (stream, calling_mode). calling_mode indicates how to parse the response."""
```

**Critical — do NOT drop `calling_mode`** (Pitfall 3, L-3): the consumer NEEDS it post-drain for (a) `parse_structured_tool_calls(full_content)` (`agent_loop.py:1941`), (b) the inline `tool_args_progress` STRUCTURED skip (`:1878`), (c) the fallback injection (`:1669`). The 2nd-copy `task_service._consume_sync_stream` already drops it — that is exactly why the harness narrates tools as text off-OpenAI. The dispatcher MUST surface it.

**Hard constraint (SC#3 — no import cycle):** the gateway MAY import the raw-SDK service modules (`anthropic_service`, `google_service`, `openai_service`, `tool_parser`) — those are BELOW it in the dependency graph today. It MUST NOT import `agent_loop`/`threads.py` orchestration. `_emit`/`spawn` stay passed-in callables on the consumer side (preserve the callable-injection seam).
