<task type="auto" name="3. Implement database helpers in backend/app/db/entitlements.py">
<action>
Create `backend/app/db/entitlements.py`:
1. `get_tier_capabilities(pool: asyncpg.Pool, tier: str) -> set[str]`:
   Queries `SELECT capability FROM public.tier_capabilities WHERE tier = $1 AND enabled = true;`.
2. `is_capability_enabled_for_tier(pool: asyncpg.Pool, tier: str, capability: str) -> bool`:
   Queries `SELECT 1 FROM public.tier_capabilities WHERE tier = $1 AND capability = $2 AND enabled = true;`.
3. `get_minimum_tier_for_capability(pool: asyncpg.Pool, capability: str) -> str | None`:
   Queries available tiers enabling this capability, ordering by standard -> pro -> enterprise priority to return the lowest upgrade tier.
4. `resolve_org_entitlement(pool: asyncpg.Pool, org_id: str | UUID, capability: str) -> tuple[bool, str | None, str | None, str | None]`:
   - Reads `subscription_tier, add_ons FROM public.organizations WHERE id = $1;`.
   - If row is None: fails closed, returns `(False, None, None, "Organization not found")`.
   - Normalizes tier: `tier = (row["subscription_tier"] or "").strip().lower()`. If empty, defaults to `"standard"`.
   - Evaluates `add_ons`: checks if `capability` is in list or is a true value in dictionary. If yes, returns `(True, tier, None, "Granted via add_on override")`.
   - Checks `is_capability_enabled_for_tier(pool, tier, capability)`. If true, returns `(True, tier, None, None)`.
   - If false, resolves `min_tier = await get_minimum_tier_for_capability(pool, capability)` and returns `(False, tier, min_tier or "enterprise", "Capability not enabled for tier")`.
   - Wraps in try/except to fail closed on any database timeout/error: returns `(False, None, None, f"Database error: {err}")`.
</action>
