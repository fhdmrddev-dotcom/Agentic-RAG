<objective>
Implement the cross-worker run cancellation brake (L-01) using Redis pub/sub and cancellation state registry so that cancelling a workflow run halts the producer immediately across multi-worker deployments (WORKER_COUNT=2) and prevents any further provider calls.
</objective>

<threat_model>
- Race Conditions: A run may complete concurrently as a cancellation signal lands; `finish_run` and Redis registration must handle interleaving idempotently.
- Stranded Channels: Redis cancel listener tasks must be cleaned up on normal phase completion or timeout to avoid resource leaks.
- Silent Token Bleed: If cancellation only updates the DB status without aborting async producer loops, external API calls continue spending money; immediate task cancellation is mandatory.
</threat_model>
