## Phase Summary

Phase 075.3 converts the Path A hotfix from quick-task 260522-gdg into a permanent two-plan defensive solution.

**Plan 01** rewrites the inner-loop chunk handler `_on_chunk_openai` at `backend/app/api/threads.py:1800-1816` so a chunk that carries BOTH `chunk.usage` AND `delta.content` / `delta.tool_calls` is no longer dropped by the early-`return` at line 1816. The usage accumulator becomes provider-aware: Google = overwrite-last-wins (cumulative running totals per chunk); OpenAI / OpenRouter = `+=` (final-chunk-only emission). The Path A gate at `openai_service.py:893` (`if provider.lower() != "google": kwargs["stream_options"] = {"include_usage": True}`) is reverted to the unconditional pre-`ee3b1f9` shape so Google runs repopulate non-NULL `runs.input_tokens` / `runs.output_tokens`. Plan 01's FIRST task is a live probe (§3 below) that pins the Google accumulator strategy BEFORE any handler code lands.

**Plan 02** rewrites `get_model_capability` at `backend/app/config.py:157-159` so an unknown `model_id` returns an inferred provider + safe defaults instead of the current `{"provider": "unknown", "native_tools": False}` sentinel. Inference uses an ordered 5-pattern table; safe defaults follow D-075.3-07. A `model_capability_unknown` warning fires once per process per `model_id`. The `GET /api/settings` response is extended with a `verified_models: list[str]` (or equivalent per-model flag) so the Settings UI can render an "unverified" badge inline next to unregistered models in the main LLM dropdown.

The plans are independent (D-075.3-14); recommended order is Plan 01 first because it closes the user-visible Gemini empty-response bug currently mitigated by Path A.

**Primary recommendation:** Land Plan 01's probe-script first task, paste the result into `075.3-01-PLAN.md`, then implement the defensive handler in the SAME wave as the gate revert (they MUST ship together — see §2 below).

## Research Findings

### 1. Google OpenAI-compat usage shape (cumulative vs delta) — D-075.3-01 lock

**Verdict:** External documentation is INSUFFICIENT to lock this. The live probe defined in §3 is the only safe path. Strong prior evidence points to **cumulative running totals on every chunk** (overwrite-last-wins per D-075.3-02 default).

**Evidence from external sources:**

| Source | Trust | Finding |
|---|---|---|
| Google OpenAI-compat docs `https://ai.google.dev/gemini-api/docs/openai` | HIGH (official) | Shows `stream_options={'include_usage': True}` example. **Does NOT specify** whether per-chunk `usage` is cumulative or delta. `[CITED: ai.google.dev/gemini-api/docs/openai]` |
| Google AI Developers Forum thread #92785 (2025) | MEDIUM | Confirms `stream_options` is supported, requires explicit opt-in. **Silent on cumulative-vs-delta semantics.** `[CITED: discuss.ai.google.dev/t/92785]` |
| LiteLLM Issue #25389, llama_index Issue #18096 | MEDIUM | Both describe streaming-usage handling for OpenAI-compat providers, but neither pins Google's specific shape. `[CITED: github.com/BerriAI/litellm/issues/25389]` `[CITED: github.com/run-llama/llama_index/issues/18096]` |
| **Quick-task 260522-gdg LIVE CAPTURE** `260522-gdg-SUMMARY.md` lines 26-32 | **HIGH (in-repo live data)** | Captured: `chunk[1]: delta.content='Hello', has_usage=True` AND `chunk[2]: delta.content='! How can I help you today?\n', finish_reason='stop', has_usage=True`. **Confirms `usage` is present on EVERY chunk.** Does NOT pin whether the VALUES are cumulative or delta (only confirms presence). `[VERIFIED: in-repo live capture 2026-05-22]` |

**Why "cumulative running totals" is the strong prior (per D-075.3-02):**
1. Google's native Gemini API exposes `usage_metadata` on `GenerateContentResponse` which is documented as a running total over the conversation so far.
2. When Google's OpenAI-compat layer translates this into per-chunk `usage` objects, the natural-but-non-OpenAI behavior is to ship the running total on each emitted chunk (the translation layer doesn't know that OpenAI's contract says "only on the final chunk").
3. If it were per-chunk deltas, summing chunk-level `completion_tokens` for a "Hello! How can I help you today?" reply (2 chunks) would yield small numbers like 1 + 9 = 10. If cumulative, you'd see growing values like 1 (first chunk) → 10 (final chunk). The probe distinguishes these.

**Failure mode if wrong assumption ships:**
- If we ASSUME cumulative and Google is actually delta → `output_tokens_total` is the size of the LAST chunk only (severely undercount; bill-mismatch is the symptom).
- If we ASSUME delta (use `+=`) and Google is actually cumulative → `output_tokens_total` is approximately `n_chunks × final_total` (severe over-count).

Either way the symptom only surfaces when someone compares the DB to the provider invoice, which takes weeks. This is exactly the silent-corruption hazard the probe exists to eliminate.

**Confidence:** HIGH on the probe-first ordering (D-075.3-01). MEDIUM on the cumulative default (D-075.3-02) until the probe pins it. `[VERIFIED: in-repo live capture]` `[ASSUMED]` for the cumulative-not-delta default until probe runs.

### 4. Inference pattern regex precision

**Verdict:** Use an ordered list of `(re.Pattern, provider_str)` tuples. Case-insensitive prefix anchored at start.

**Recommended exact pattern table** (matches D-075.3-06 buckets, in this order — first match wins):

```python
# config.py — adjacent to MODEL_CAPABILITIES
import re

# D-075.3-06: pattern-based provider inference for unregistered model_ids.
# Ordered list — first match wins. Case-insensitive at the prefix anchor.
# Patterns chosen to match D-075.3-06 ROADMAP SC#4 spec + edge cases
# surfaced in Phase 075.3 research §4.
_INFERENCE_PATTERNS: list[tuple[re.Pattern[str], str]] = [
    # OpenAI: gpt-* family (gpt-4o, gpt-5.4, gpt-99-future) AND o-series (o1..o9, including o3-mini)
    (re.compile(r"^gpt-", re.IGNORECASE), "openai"),
    (re.compile(r"^o[1-9](-|$)", re.IGNORECASE), "openai"),
    # Anthropic: claude-* family
    (re.compile(r"^claude-", re.IGNORECASE), "anthropic"),
    # Google: gemini-* family
    (re.compile(r"^gemini-", re.IGNORECASE), "google"),
    # OpenRouter: any slash-bearing model_id (vendor/model shape)
    (re.compile(r"^[^/\s]+/[^/\s]+"), "openrouter"),
    # Fallback: anything else → ollama (local default, safest unknown bucket)
]
_INFERENCE_FALLBACK_PROVIDER: str = "ollama"
```

**Edge case coverage verified:**

| Input | Match | Reasoning |
|---|---|---|
| `gpt-4o` | openai | `^gpt-` ✓ |
| `gpt-99-future` | openai | `^gpt-` ✓ |
| `GPT-4o` (uppercase) | openai | `re.IGNORECASE` ✓ |
| `o1` | openai | `^o[1-9](-|$)` matches `o1$` ✓ |
| `o1-preview` | openai | `^o[1-9](-|$)` matches `o1-` ✓ |
| `o9-future-thing` | openai | `^o[1-9](-|$)` matches `o9-` ✓ |
| `o10` | (intentional miss) | `^o[1-9](-|$)` does NOT match `o10` because the second char is `1` and the third is `0` not `-` or end. Falls through to ollama. **Per D-075.3-06: "o1-o9" explicit, NOT "o*"** — `o10+` is out of spec, this is the correct behavior. |
| `claude-opus-4-7` | anthropic | `^claude-` ✓ |
| `claude-future-99` | anthropic | `^claude-` ✓ |
| `gemini-99-flash` | google | `^gemini-` ✓ (this is the planned negative-test ID) |
| `gemini-2.5-flash` | google | `^gemini-` ✓ |
| `moonshotai/kimi-k99` | openrouter | `^[^/\s]+/[^/\s]+` ✓ |
| `nodelta/no-prefix` | openrouter | `^[^/\s]+/[^/\s]+` ✓ |
| `meta-llama/llama-3.3-70b-instruct` | openrouter | `^[^/\s]+/[^/\s]+` ✓ |
| `random-garbage` | ollama (fallback) | no pattern matches |
| `llama3.2` | ollama (fallback) | no slash, no recognized prefix |
| `""` (empty) | ollama (fallback) | no patterns can match empty string |
| `None` | **must coerce or raise** | `re.search(pattern, None)` raises `TypeError`. **Plan 02 must guard.** |

**Critical edge case for `:exacto` quality suffix (D-075.3-13 alignment):**

Phase 074 added `lookup_key = model_id.removesuffix(":exacto") if model_id.endswith(":exacto") else model_id` to `_resolve_max_tokens` (openai_service.py:739). The inference path should NOT strip `:exacto` — the suffix is OpenRouter-specific, applied at request time (openai_service.py:909), not at the user's stored `llm_model` value. If a user did somehow put `moonshotai/kimi-k2.5:exacto` in their settings, the OpenRouter slash-pattern still matches first, so inference returns `openrouter`. **No change to inference patterns needed.**

**Boundary case: `None` / empty / whitespace model_id**

Recommend in `get_model_capability`:
```python
def get_model_capability(model_id: str) -> ModelCapability:
    # Registry hit (fast path, no inference)
    if model_id in MODEL_CAPABILITIES:
        return MODEL_CAPABILITIES[model_id]
    # Boundary guard — None, empty, or whitespace-only degrades to ollama bucket
    # (matches the "fallback to local-only default" intuition for non-sensible input)
    if not model_id or not model_id.strip():
        return _build_inferred_defaults(model_id or "", "ollama")
    # Inference fallback
    for pattern, provider in _INFERENCE_PATTERNS:
        if pattern.search(model_id):
            return _build_inferred_defaults(model_id, provider)
    return _build_inferred_defaults(model_id, _INFERENCE_FALLBACK_PROVIDER)
```

This satisfies D-075.3-17's boundary-case test branch ("must NOT crash; degrade to ollama bucket or raise a clear ValueError — locked at planner level"). Researcher recommendation: degrade silently rather than raise; the consumer (`resolve_calling_mode`, `_resolve_max_tokens`) already tolerates the empty/None case by short-circuiting on `model_id`.

### 5. `model_capability_unknown` log dedup implementation

**Verdict:** Module-level `set[str]` is safe under D-v2.5-02 (single uvicorn worker, CLAUDE.md project rule). Recommended placement: near `MODEL_CAPABILITIES` in `config.py`.

**Recommended implementation:**

```python
# config.py — adjacent to MODEL_CAPABILITIES and _INFERENCE_PATTERNS
# D-075.3-09: warn-once dedup. Module-level set is safe under the single-uvicorn-worker
# rule (D-v2.5-02 in CLAUDE.md). Each process starts empty; restart clears state.
# Multi-worker (D-PRD-12 / Phase 079) will need a different strategy (per-worker
# allowed; or move dedup to a Redis SET) — flag for revisit at that phase, not here.
_WARNED_UNKNOWN_MODEL_IDS: set[str] = set()


def _build_inferred_defaults(model_id: str, provider: str) -> ModelCapability:
    """Construct safe-default ModelCapability for an unknown model_id.

    Phase 075.3 D-075.3-07 / D-075.3-09. Caps follow:
      max_output_tokens: 8192 (openai/anthropic/google/ollama), 4096 (openrouter)
      llm_call_timeout_seconds: 90 (all)
      native_tools: True (big-3: openai/anthropic/google), False (openrouter/ollama)
    """
    _BIG_3 = {"openai", "anthropic", "google"}
    cap: ModelCapability = {
        "native_tools": provider in _BIG_3,
        "provider": provider,
        "llm_call_timeout_seconds": 90,
        "max_output_tokens": 4096 if provider == "openrouter" else 8192,
    }
    if model_id and model_id not in _WARNED_UNKNOWN_MODEL_IDS:
        _WARNED_UNKNOWN_MODEL_IDS.add(model_id)
        logger.warning(
            "model_capability_unknown model_id=%s inferred_provider=%s safe_defaults_applied=True",
            model_id, provider,
        )
    return cap
```

## Probe Script Spec

**Purpose:** Lock D-075.3-01 — pin Google's OpenAI-compat per-chunk usage shape as cumulative vs delta. MUST be the FIRST task in `075.3-01-PLAN.md`. Result pasted into PLAN.md before any handler code change.

**Recommended location:** `backend/scripts/probe_google_usage_shape.py` (one-shot, runnable, version-controlled — supersedes the inline-in-PLAN.md option because future regressions can re-run the same probe).

**Spec:**

```python
"""Phase 075.3 Plan 01 Task 1 — probe Google's OpenAI-compat usage shape.

Locks D-075.3-01: pins whether Google's `chunk.usage` carries cumulative running
totals (overwrite-last-wins) or per-chunk deltas (+=).

Usage:
    cd backend && source venv/bin/activate
    python scripts/probe_google_usage_shape.py

Output:
    Per-chunk raw usage values + a concrete cumulative-vs-delta verdict.

Cost: ~$0.001 (one Gemini 2.5 Flash call, "count to five" prompt, ~30 tokens).
"""
from __future__ import annotations

import os
from openai import OpenAI

# Reuse the same env config the backend uses — settings_override.json or
# .env, whichever the backend picks up. Probe runs OUT of the backend process
# but uses the same google_api_key surface.
from app.config import settings  # noqa: E402

def main() -> None:
    api_key = settings.google_api_key
    if not api_key:
        raise SystemExit("GOOGLE_API_KEY not set in backend env — populate before running probe.")

    client = OpenAI(
        api_key=api_key,
        base_url="https://generativelanguage.googleapis.com/v1beta/openai/",
    )

    print("Probing gemini-2.5-flash with prompt 'count to five'...")
    print()
    stream = client.chat.completions.create(
        model="gemini-2.5-flash",
        messages=[{"role": "user", "content": "count to five"}],
        stream=True,
        stream_options={"include_usage": True},
        max_tokens=200,
    )

    chunks_seen: list[dict] = []
    for i, chunk in enumerate(stream):
        usage = chunk.usage
        content = ""
        finish = None
        if chunk.choices:
            content = chunk.choices[0].delta.content or ""
            finish = chunk.choices[0].finish_reason
        row = {
            "i": i,
            "content_len": len(content),
            "content_preview": content[:30],
            "has_usage": usage is not None,
            "prompt_tokens": getattr(usage, "prompt_tokens", None) if usage else None,
            "completion_tokens": getattr(usage, "completion_tokens", None) if usage else None,
            "finish_reason": finish,
        }
        chunks_seen.append(row)
        print(
            f"chunk[{i:2d}]: "
            f"content_len={row['content_len']:3d} "
            f"has_usage={row['has_usage']} "
            f"p={row['prompt_tokens']} c={row['completion_tokens']} "
            f"finish={row['finish_reason']!r}"
        )

    print()
    print("=" * 60)
    print("VERDICT")
    print("=" * 60)

    completion_tokens_series = [
        c["completion_tokens"] for c in chunks_seen if c["completion_tokens"] is not None
    ]
    if not completion_tokens_series:
        print("INCONCLUSIVE: no chunk carried usage. Re-run with longer prompt.")
        return

    if len(completion_tokens_series) == 1:
        print(
            "INCONCLUSIVE: only one chunk carried usage. "
            "Google OpenAI-compat appears to follow strict OpenAI shape "
            "(usage on final chunk only). Sum-via-`+=` is safe — same as OpenAI."
        )
        return

    is_monotonic_increasing = all(
        completion_tokens_series[i] <= completion_tokens_series[i + 1]
        for i in range(len(completion_tokens_series) - 1)
    )
    final_val = completion_tokens_series[-1]
    sum_val = sum(completion_tokens_series)

    if is_monotonic_increasing and sum_val > final_val * 1.5:
        print("CUMULATIVE — overwrite-last-wins is required.")
        print(f"  Series: {completion_tokens_series}")
        print(f"  Final value (= correct total): {final_val}")
        print(f"  Sum-via-`+=` would yield:       {sum_val} (WRONG — over-count)")
        print()
        print("Plan 01 D-075.3-02 confirmed: Google branch MUST overwrite, NOT accumulate.")
    elif not is_monotonic_increasing or sum_val == final_val:
        print("DELTA — `+=` is required.")
        print(f"  Series: {completion_tokens_series}")
        print(f"  Sum (= correct total): {sum_val}")
        print()
        print("Plan 01 D-075.3-02 OVERTURNED: Google branch needs `+=` like OpenAI.")
    else:
        print(f"AMBIGUOUS: series={completion_tokens_series}")
        print("Manually inspect; may need longer prompt to disambiguate.")


if __name__ == "__main__":
    main()
```

**Prompt rationale:** "count to five" produces ~10-15 tokens of output across 2-4 chunks — enough to distinguish cumulative-vs-delta unambiguously without burning budget. "hi" (1-2 chunk reply) is too short — could yield "INCONCLUSIVE: only one chunk carried usage" branch.

### Inference-fallback `get_model_capability` (Plan 02)

```python
# backend/app/config.py — replaces lines 157-159
def get_model_capability(model_id: str) -> ModelCapability:
    """Return capability for a model_id.

    Phase 075.3 D-075.3-08: registry hit returns verified caps; registry miss
    falls back to pattern-based provider inference + safe defaults, with
    once-per-process warning log per D-075.3-09.
    """
    if model_id in MODEL_CAPABILITIES:
        return MODEL_CAPABILITIES[model_id]
    # Boundary: None / empty / whitespace degrades to fallback provider
    if not model_id or not model_id.strip():
        return _build_inferred_defaults(model_id or "", _INFERENCE_FALLBACK_PROVIDER)
    # Pattern inference
    for pattern, provider in _INFERENCE_PATTERNS:
        if pattern.search(model_id):
            return _build_inferred_defaults(model_id, provider)
    return _build_inferred_defaults(model_id, _INFERENCE_FALLBACK_PROVIDER)
```
