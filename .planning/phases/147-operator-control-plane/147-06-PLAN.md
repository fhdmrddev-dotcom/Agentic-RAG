- `MessageItem.tsx:570-576` — the stopped indicator only fires on `message.stopped || runStatus==='timed_out'`. `stopped` is live-only; on reload `runStatus==='cancelled'` IS present but the guard ignores it.

- `types/index.ts:163` — the type comment already says "'cancelled' renders 'Response stopped'". The render condition is the bug.
