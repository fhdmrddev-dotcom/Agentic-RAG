<objective>
Deliver the ADMIN-02 read surface: additive dependency-health probes on the existing
`/admin/backpressure` JSON, a cross-user active-runs list (`GET /admin/runs`) with
honest kind badges derived via the no-migration D-Q1 strategy, and the D-07 poll/visit
floor discipline (silent auto-poll GETs + one deliberate ledger row per visit and per
manual refresh). Every endpoint joins the existing `admin.py` `require_operator` router —
never a new router (the sole authority; no RLS backstop).

Purpose: The operator can watch live system health and every in-flight run without the
poll spamming the audit ledger, while the ledger stays an honest record of deliberate
human actions.
Output: `health_probe.py` + extended `admin.py` + tests.
</objective>
