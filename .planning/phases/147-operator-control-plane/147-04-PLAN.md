<objective>
Enforce the FLAG-01 capability kill-switches fail-closed at the two existing tool seams
(hide from schema + refuse in-flight, per D-04) for web_search / sandbox / self_improve,
gate the self-improvement proposer entry, and block NEW workflow launches at the kickoff
seam (D-05) while letting in-flight workflow runs finish. Every gate is a literal no-op
when its flag is on/absent so Deep Mode stays byte-identical (the Phase 091 whitelist
precedent; the red line: never fork the shared provider path).

Purpose: An operator can turn a misbehaving capability off and it stops for every user
within the TTL window — both for new runs (no schema advertisement) and in-flight calls
(a plain refusal the agent can relay), with zero behavior change when nothing is off.
Output: hide + refuse gates + proposer guard + workflow-launch block + tests.
</objective>
