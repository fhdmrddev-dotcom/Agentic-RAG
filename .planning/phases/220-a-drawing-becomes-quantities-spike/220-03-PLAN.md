# Plan 220-03: Takeoff & Quantities UI in DocumentDetailPanel

**Phase:** 220 — A Drawing Becomes Quantities — SPIKE  
**Goal:** Mount a "Takeoff & Quantities" section in the Library's `DocumentDetailPanel` when viewing `.dxf` documents, providing summary KPI cards, an itemized Bill of Quantities table with basis badges, interactive ambiguity resolution, and a CSV export action.

---

## 1. Context & Objectives

- **Contract:** `TAKEOFF-04`
- **Decisions:** `D-07`, `D-08`, `D-09`, `D-10` in `220-CONTEXT.md`
- **G-5 Touchpoints:** `frontend/src/components/metadata/DocumentDetailPanel.tsx`, `frontend/src/components/metadata/TakeoffSection.tsx`.

---

## 2. Implementation Steps

### Step 1: Create TakeoffSection Component
- Create `frontend/src/components/metadata/TakeoffSection.tsx`:
  - **Summary Card:**
    - Total Estimated Cost ($).
    - Counted Items total (units).
    - Ambiguous Items needing review count (with amber alert icon if > 0).
    - Unit system indicator (e.g. `Metric (mm)` or `Imperial (inches)`).
  - **Rate Sheet Picker / Run Match:**
    - Dropdown to pick an existing `.xlsx` rate sheet document from the Library and trigger matching.
  - **Bill of Quantities Table:**
    - Columns: `Item / Specification`, `Count / Measurement`, `Unit`, `Rate ($)`, `Amount ($)`, `Basis`, `Actions`.
    - **Basis Badges:**
      - `READ` (emerald pill — exact block count).
      - `MATCHED` (blue pill — single confident rate match).
      - `NEEDS REVIEW` (amber pill — ambiguous match with multiple candidate rate codes).
      - `UNPRICED` (muted gray pill — no matching rate item).
  - **Ambiguity Disambiguation Menu:**
    - For `NEEDS REVIEW` rows, render a select menu listing candidate rate codes with their descriptions and unit prices.
    - Selecting a candidate calls `resolveTakeoffItem()` and updates the table.
  - **Export Button:**
    - "Export Takeoff (CSV)" downloads a clean CSV file with headers: `Code`, `Description`, `Quantity`, `Unit`, `Rate`, `Amount`, `Basis`.

### Step 2: Mount TakeoffSection in DocumentDetailPanel
- In `frontend/src/components/metadata/DocumentDetailPanel.tsx`:
  - Detect if `doc.filename.toLowerCase().endsWith(".dxf")` or `doc.metadata?._takeoff`.
  - Add a **"Takeoff"** tab trigger alongside Metadata, Versions, Images, and Tables.
  - Mount `<TakeoffSection document={doc} onRefresh={onRefresh} />` inside the panel tab content.

### Step 3: Frontend API Client
- In `frontend/src/lib/api/takeoff.ts` (or `documents.ts`):
  - `matchTakeoff(docId: string, rateDocId: string)`
  - `resolveTakeoffItem(docId: string, itemKey: string, code: string)`
