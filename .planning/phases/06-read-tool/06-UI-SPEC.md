## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (text-sm) | 400 (regular) | 1.5 |
| Display | 28px | 400 (regular) | 1.2 |
| Label | 12px (text-xs) | 500 (medium) | 1.4 |
| Heading | 20px (text-xl, markdown h1 = 20px) | 500 (medium) | 1.3 |

Notes:
- Two weights only: 400 (regular) for Body and Display; 500 (medium) for Label and Heading.
- ToolCallPanel tool labels use 12px at weight 500 — matches Label role above.
- Read tool output displayed inside ToolCallPanel uses monospace 12px (matching existing `.markdown pre` pattern: `font-size: 0.78rem`, `font-family: ui-monospace, monospace`, `line-height: 1.6`).
- Line-numbered content: use monospace at 12px, line-height 1.6, matching the existing `markdown pre` token.

Source: `frontend/src/index.css` markdown styles, `ToolCallPanel.tsx` class audit.

## Interaction Contract

### read_document tool entry in ToolCallPanel

The `read_document` tool call appears as a row inside the existing ToolCallPanel expand/collapse block. It follows the same pattern as other tool rows.

**Running state:**
- Icon: `BookOpen` (lucide), 14px (`w-3.5 h-3.5`), `text-muted-foreground`
- Label: "Reading document" at 12px weight 500 `text-foreground/70`
- Summary arg displayed: document filename or document_id, truncated, `opacity-60`
- Status indicator: `Loader2` spinner 12px `animate-spin text-muted-foreground`

**Completed state:**
- Icon: `BookOpen`, 14px, `text-muted-foreground`
- Label: "Reading document" at 12px
- Summary: filename or document_id
- Status indicator: `CheckCircle2` 12px `text-green-500`

**Line-range output display (when start_line/end_line args present):**
- Show a collapsible sub-block (same pattern as SubAgentBlock)
- Sub-block header: "Lines {start}–{end}" at 12px `text-muted-foreground`
- Sub-block content: monospace pre-formatted text, 12px, line-height 1.6
- Max height: 256px (`max-h-64`) with vertical scroll via ScrollArea
- Line numbers rendered inline: `{line_number}: {content}` prefixed in `text-muted-foreground`, content in `text-foreground/80`
- Background: `bg-background/60 rounded-md border border-border/40`

**Full-document output display (no line range):**
- Same collapsible sub-block pattern
- Sub-block header: "Full document"
- Content follows same monospace + scroll treatment
- Max height: 256px to prevent context window flooding

### toolIcon mapping addition

```
if (name === "read_document") return <BookOpen className="w-3.5 h-3.5" />
```

### toolLabel mapping addition

```
if (name === "read_document") return "Reading document"
```

### toolSummary mapping addition

```
if (tc.args.document_id) return tc.args.filename ?? tc.args.document_id
```

## Accessibility

- All interactive buttons in ToolCallPanel must have `aria-label` or visible text
- `BookOpen` icon used alone in a button must have `aria-label="Read document"`
- Collapsible sub-blocks use `aria-expanded` on the trigger button
- Line-numbered content inside `<pre>` is screen-reader safe (plain text, no aria roles needed)
- Minimum touch target for expand/collapse buttons: 28px height (matches existing `h-7` pattern)
