# Phase 056.1 Plan 01: tool_preparing SSE Event + System Prompt Guard Rules Summary

tool_preparing SSE emitted in OpenAI/Anthropic/Structured paths to end 30–120s silence, plus two execute_code system prompt guard rules.

## Objective

Eliminate the 30–120 second silence window (confirmed via LangSmith) where the LLM streams `execute_code` arguments but the frontend shows no UI feedback. Add `tool_preparing` SSE events so the ToolCallPanel renders as soon as a tool name is known. Also harden SYSTEM_PROMPT with two rules preventing premature execute_code calls and monolithic scripts.

## What Was Built

### Task 1 — OpenAI path

- Added `_announced_tools: set[int] = set()` after `finish_reason: str | None = None` before the stream loop
- Inside `if tc.function and tc.function.name:` guard, after buffer name assignment, added:
  - `if idx not in _announced_tools:` → `_announced_tools.add(idx)` → yield `tool_preparing`
- Event fires as soon as the LLM names the tool in the delta stream, before any argument chunks arrive

### Task 2 — Anthropic path

- Inserted `yield tool_preparing` immediately after `_idx = len(tool_calls_buffer)` computation
- Fires **before** `tool_calls_buffer[_idx] = {...}` assignment
- Anthropic `tool_start` event delivers complete tool call, so no risk of incomplete name

### Task 3 — Structured mode

- Added a second `for idx, call in enumerate(structured_calls):` loop after the buffer population loop
- This loop yields `tool_preparing` for each call
- Positioned after buffer fill and before `full_content = ""` and `finish_reason = "tool_calls"`
- Two-loop design ensures all tools are buffer-registered before any events fire

### Task 4 — System prompt rules

Two new rules appended after "After analyze_document (Q&A task)" rule, before "## Confidence & hedging":

1. **Never call execute_code in the same response as search_documents, analyze_document, read_document, or web_search** — retrieve first, execute_code in NEXT iteration
2. **Keep execute_code scripts under 200 lines** — use data-driven loops; split into multiple calls if larger

All PROMPT-01 rules (lines 67–80) remain untouched.
