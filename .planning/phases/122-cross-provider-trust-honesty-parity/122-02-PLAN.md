<objective>
MP-01: chain `forced_emit`'s existing forcing modes into an ordered recovery ladder so a typed emit recovers instead of degrading to a silent empty result. Today `forced_emit` is a 2-rung shape (TIER-FORCE | TIER-COERCE) where a strict-400 short-circuits straight to `None` (BUG-260615-01). MP-01 inserts the proven-missing rung(s): the 4-rung ladder `force_strict → force(non-strict) → coerce → honest-fail`, resolved from the `emit_tier` Plan 01 added.

Because the ladder lives in `forced_emit` itself (D-122-01), ALL four consumers recover for free — workflow `llm_emit`/`render_template`, the Phase-102 judge, Phase-103 NL authoring, AND Phase-111 default-config metadata extraction (the live silent-extraction bug folds as a side effect).

Purpose: recovered-or-honest emission on every provider, no new machinery — every rung is an already-known-good mode the function already builds (RESEARCH "Key insight": ~30 lines of orchestration). The ladder is pure runtime recovery and NEVER mutates the registry (D-122-03).
Output: the rung-loop ladder in `forced_emit.py` + emit_rung telemetry + rung-descent/tier-scoping/default tests.
</objective>
