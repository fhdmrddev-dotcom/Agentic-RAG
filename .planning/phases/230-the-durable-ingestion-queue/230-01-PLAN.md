  category: Race Condition / Concurrent Claims
  component: claim_due_ingestion_jobs
  disposition: mitigated
  mitigation_plan: Use SELECT FOR UPDATE SKIP LOCKED inside an explicit async with con.transaction(): block with in-transaction status update to 'processing'. Prevents double-claiming across workers.

  category: Denial of Service / Poison Pill
  component: record_job_failure
  disposition: mitigated
  mitigation_plan: Enforce max_retries ceiling (default 3); jobs exceeding max_retries transition permanently to status='failed' rather than cycling indefinitely.
</threats>

    Create `backend/app/db/ingestion_jobs.py` implementing:
    1. `_CLAIM_COLUMNS = "id, document_id, user_id, org_id, status, stage, progress, retry_count, max_retries, last_error, error_details, next_run_at"`
    2. `async def claim_due_ingestion_jobs(pool: asyncpg.Pool, *, limit: int = 3, worker_id: str, now: datetime | None = None) -> list[dict]`:
       - Inside `async with pool.acquire() as con: async with con.transaction():`
       - `SELECT {_CLAIM_COLUMNS} FROM ingestion_jobs WHERE status IN ('pending', 'retry_queued') AND next_run_at <= COALESCE($2::timestamptz, now()) ORDER BY next_run_at LIMIT $1 FOR UPDATE SKIP LOCKED`
       - For each claimed row: `UPDATE ingestion_jobs SET status = 'processing', claimed_at = now(), claimed_by = $2, updated_at = now() WHERE id = $1`
       - Returns list of claimed job dicts.
    3. `async def update_job_progress(pool: asyncpg.Pool, job_id: UUID, *, stage: str, progress_patch: dict[str, Any]) -> None`:
       - `UPDATE ingestion_jobs SET stage = $2, progress = progress || $3::jsonb, updated_at = now() WHERE id = $1`
    4. `async def record_job_success(pool: asyncpg.Pool, job_id: UUID) -> None`:
       - `UPDATE ingestion_jobs SET status = 'completed', stage = 'completed', updated_at = now() WHERE id = $1`
    5. `async def record_job_failure(pool: asyncpg.Pool, job_id: UUID, *, error_message: str, error_details: dict[str, Any] | None = None, is_transient: bool = True, retry_delay_seconds: int = 5) -> str`:
       - Reads `retry_count` and `max_retries`.
       - If `is_transient` and `retry_count + 1 < max_retries`:
         `UPDATE ingestion_jobs SET status = 'retry_queued', retry_count = retry_count + 1, next_run_at = now() + ($3 || ' seconds')::interval, last_error = $4, error_details = $5::jsonb, updated_at = now() WHERE id = $1 RETURNING status`
       - Else:
         `UPDATE ingestion_jobs SET status = 'failed', stage = 'failed', retry_count = retry_count + 1, last_error = $4, error_details = $5::jsonb, updated_at = now() WHERE id = $1 RETURNING status`
    6. `async def pause_jobs_for_provider(pool: asyncpg.Pool, *, refusal_reason: str, error_details: dict[str, Any] | None = None) -> int`:
       - `UPDATE ingestion_jobs SET status = 'paused', last_error = $1, error_details = $2::jsonb, updated_at = now() WHERE status IN ('pending', 'retry_queued', 'processing')`
       - Returns count of paused rows.
    7. `async def resume_paused_jobs(pool: asyncpg.Pool) -> int`:
       - `UPDATE ingestion_jobs SET status = 'retry_queued', next_run_at = now(), updated_at = now() WHERE status = 'paused'`
       - Returns count of resumed rows.
    8. `async def insert_ingestion_job(pool: asyncpg.Pool, *, document_id: UUID, user_id: UUID, org_id: UUID | None = None) -> dict`:
       - Helper for queue enqueueing.
