## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---|---|---|---|
| Write-only field | A column is created and populated but never read, so the feature it exists for silently does not work (`claimed_at`) | blocking | Seam audit must ask *who reads this*, not only *who writes it* |
| Non-existent target path | `files_modified` names a directory that isn't there; the executor creates an orphan nothing mounts | blocking | Resolve every path against the filesystem at pre-flight |
| Uncollected test | A test authored outside the gate's `testpaths` runs never but reads as coverage | blocking | Name the gate; run it once to prove collection |
| Verdict cell disagreeing with its own evidence cell | Phase 228 marked `DEBT-03` ✅ PASS while its frontmatter and evidence both said operator-blocked | advisory | A requirement whose action never occurred cannot be green |
| Trusting a documented number | `REQUIREMENTS.md` said the backend baseline was 95 failed; measured, it is **71** | advisory | Re-measure before quoting; the doc was wrong, the plan was right |
