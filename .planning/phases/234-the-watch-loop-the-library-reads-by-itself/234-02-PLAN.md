2. Author `backend/app/services/watch_service.py`:
   - `WatchService.tick(pool)`: Poll loop claiming due watches via `db/watches.py`.
   - Concurrency guard (`QUEUE-03`): Respects active `leased_until` and records `skipped_still_running`.
   - Error isolation (`SEED-239`): Wraps each watch execution in isolated try/except, writing `last_error` on failure without breaking other watches.
   - Pagination loop over `adapter.list_files(folder_id)` producing a `SourceListing`, setting `complete = True` ONLY when `next_page_token is None` and zero exceptions occurred.
   - Diff pass against `connector_watch_items`:
     - **New files**: Mint `documents` row via `async_mint_document_row`, link `document_id` into `connector_watch_items` (`state='present'`), enqueue `ingestion_jobs` row via `insert_ingestion_job(pool, document_id=doc_id, user_id=user_id, org_id=org_id)`.
     - **Modified files**: Mint new document version via `async_mint_document_row`, update `connector_watch_items`, enqueue `ingestion_jobs`.
     - **Renamed / Moved / Re-shared files (SC#4)**: Recognized by matching `external_id`; updates `connector_watch_items.name`, `path_hint` and `documents.filename` without creating duplicate document rows or re-ingesting.
     - **Deleted files**: **ONLY if `listing.complete is True`** (`H-5` / `SRC-06`), mark `state='missing'`, `documents.source_state='missing_at_source'`, retaining the document row (`VIS-03`).
     - **Unshared / 403**: Mark `state='unauthorized'`, `documents.source_state='unauthorized_at_source'`.

<task_id>234-02-02</task_id>
<description>Implement WatchService in backend/app/services/watch_service.py</description>
<action>
Create `backend/app/services/watch_service.py`:
- Class `WatchService`:
  - `__init__(self, pool: asyncpg.Pool, settings: Any = None)`
  - `async def tick(self) -> int`: Claims due watches via `claim_due_watches(pool)`. Iterates claimed watches.
  - `async def sync_watch(self, watch: dict) -> dict`:
    - Resolves connection via `connector_service.get_connection(watch['connection_id'])`.
    - Reads connection visibility posture: `default_ingest_visibility = conn.get('default_ingest_visibility') or 'private'`.
    - Resolves adapter via `SourceRegistry.get(conn['service_id'])`.
    - Paginates through `adapter.list_files(conn, folder_id=watch['source_folder_id'])` until `next_page_token` is `None`, aggregating into `SourceListing`.
    - Sets `listing.complete = True` ONLY IF loop finished with `next_page_token is None` and no unhandled network errors occurred. If truncated or failed, `listing.complete = False`.
    - Loads existing items via `get_watch_items(pool, watch['id'])`.
    - Computes diff:
      - **New files** (in source listing, absent from DB):
        Fetch bytes via `filename, file_bytes, mime_type = await adapter.read_file(conn, item.id)`.
        Mint document row via keyword-only call:
        `mint_res = await async_mint_document_row(raw=file_bytes, filename=filename, mime_type=mime_type, user_id=str(watch['user_id']), supabase=supabase, folder_id=str(watch['library_folder_id']) if watch.get('library_folder_id') else None, org_id=str(watch['org_id']) if watch.get('org_id') else None, source_connection_id=str(watch['connection_id']), ingest_visibility=default_ingest_visibility, on_conflict="link")`.
        If `mint_res.is_duplicate`:
          # Duplicate in folder: link into watch items, but do NOT upload bytes and do NOT enqueue job
          Insert into `connector_watch_items` with `document_id = UUID(mint_res.document['id'])`, `state = 'present'`.
        Else:
          # New content: upload bytes to storage first (prevent BUG-260905-08 and splice_document 565f77499 refusal)
          `await run_in_threadpool(lambda: supabase.storage.from_("documents").upload(path=mint_res.storage_path, file=file_bytes, file_options={"content-type": mime_type, "upsert": "true"}))`
          Insert into `connector_watch_items` with `document_id = UUID(mint_res.document['id'])`, `state = 'present'`.
          Enqueue job: `await insert_ingestion_job(pool, document_id=UUID(mint_res.document['id']), user_id=UUID(str(watch['user_id'])), org_id=UUID(str(watch['org_id'])) if watch.get('org_id') else None)`.
      - **Modified files** (`external_id` matches, `source_version` or hash changed):
        Fetch bytes via `await adapter.read_file(conn, item.id)`, mint new version via keyword-only `async_mint_document_row`. If not duplicate, upload bytes to storage, update `connector_watch_items`, and enqueue `insert_ingestion_job`.
      - **Renamed / Moved / Re-shared files (SC#4)**:
        `external_id` matches existing item. If `name` or `path_hint` changed but content unchanged:
        Update `connector_watch_items.name = item.name`, `path_hint = item.path_hint`.
        Update `documents.filename = item.name` via SQL/Supabase.
        Do NOT mint duplicate document row and do NOT enqueue re-ingestion job.
      - **Deleted files** (in DB, absent from source listing):
        **STRUCTURAL ASSERTION (H-5 / SRC-06)**:
        If NOT `listing.complete`:
          `log.warning("Watch %s listing incomplete; suppressing missing status transitions (H-5)", watch['id'])`
        Else:
          For each deleted file: update item `state='missing'`, update document `source_state='missing_at_source'`, retain document row (`VIS-03`).
      - **Unshared files / 403**:
        Update item `state='unauthorized'`, update document `source_state='unauthorized_at_source'` (`VIS-04`).
    - Releases watch via `release_watch(pool, watch['id'], status='success')`.
  - Try/Except boundary around `sync_watch`: Catches exceptions per watch (`SEED-239`), logs, and calls `release_watch(pool, watch['id'], status='failed', error=str(e))`.
</action>
