## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SSE-path async → threadpool | Each `await aexec(...)` crosses the asyncio/thread boundary; the supabase query executes in an AnyIO worker thread, not the event loop thread. |
| User JWT → RLS at every DB call | Every wrapped `.execute()` must carry the user-scoped supabase client (per-request client with user JWT), not a service-role client. RLS is the enforcement layer. |
| `_persist_assistant_message` closure capture | The closure captures `current_user["id"]` and the request-scoped `supabase` client at coroutine creation time. If the request context were to leak across requests, an attacker could persist messages under another user's ID. |
