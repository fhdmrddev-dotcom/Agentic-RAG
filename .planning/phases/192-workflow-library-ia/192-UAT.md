  dead button on that row.

  have >1 version**, including `pm-weekly-status-report` (**4 versions**),
  `meridian-risk-summary-good-cc99c1b7` (3), and five more at 2.
  **B. The failure is swallowed — this is WR-03, hit in the wild.**
  `WorkflowsPage.tsx:511-513` — `catch (e) { console.error(...) }`. No toast, no inline error, no
  state change, no retry. Note the sibling `onUseStarter` (`:550-555`) **does** retry once on 409;
  `onTweak` has **no retry at all**, so it cannot even reach v3.
  **C. The wire cannot currently fix A on the frontend alone.** `PublishedWorkflow`
  (`api.ts:1364-1371`) carries `id · slug · name · definition? · is_mine? · is_system_global?` —
  **no `version`**. The client is not told the real version, so a correct `nextVersion` needs either
  a projected column on `/published` or a different product rule.

  `git log -S` on the offending line → authored in **`3adcb0ae` `feat(103-06)` — Phase 103**, last
