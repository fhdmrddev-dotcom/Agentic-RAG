| Boundary | Description |
|----------|-------------|
| user intent → destructive scope | `deleteWorkflowCascade` resolves a slug and destroys every version under it; `deleteWorkflowDraft` deletes one row. Routing a draft through the first destroys far more than the user asked for. |
| pointer users → touch users | A `title=` explanation is invisible on touch. D-14 makes the explanation an a11y contract instead. |
| one shared starter → many forkers | `UNIQUE(slug, version)` is GLOBAL across all users. A merged fork handler collides for the second person who forks the same starter. |
| user-authored `business_requirement` → the rendered card | The soul renders it; the search highlight marks it. Both must stay on the escaped-JSX-text path. |
