### Scenario 2 — *Open the composer's model dropdown on an unregistered model.* ✅ PASS

**"I'd recognise failure here" as:** it looks identical to a registered model — nothing says the
run will not call tools.

Driven through the component and through the live payload:
- An unverified model renders the amber `unverified` chip; a registered one renders none.
- A model the **operator added** renders **none** — it resolves `db_override`, i.e. they typed its

- For a tool-losing model the description reads: *"…tool calling is DISABLED for it. It will run as
  an ollama model in structured mode — search, code execution and every other tool are
  unavailable, and any tool call it tries will arrive as unreadable text. Add a row for it in the
  Model Registry…"*
- ⛔ The option is **still selectable** — a warning, never a refusal (`D-122-05` intact).
