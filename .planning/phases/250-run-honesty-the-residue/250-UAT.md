### B2 — `HONEST-02` cross-provider ⛔ **NOT DRIVEN, with the reason**

An empty-output run cannot be produced on demand per provider — it is the rare failure the bug
report describes, not an input. So no live per-provider row exists, and none is claimed.

**What IS established instead, and it is structural rather than sampled:** the taxonomy reads
**three run-scoped values and no provider value**, and a fence
(`test_250_run_honesty_agent_loop.py::test_2_5`) fails if the word `provider` ever appears in the
block's *structure* — read with strings AND comments stripped, so naming the provider in a
sentence the user reads stays legal while branching on it does not.

⚠ **ONE GENUINE CROSS-PROVIDER LIMITATION, STATED RATHER THAN HIDDEN:** `reasoning_delta` is
emitted by the **OpenAI-compat path only** (`provider_gateway/events.py`), so an Anthropic or
Google run that thought silently registers zero reasoning and lands on the third arm. That is why
the third arm is worded as an **observation** — *"nothing we could see came back"* — and never as
a claim about what the model did internally.
