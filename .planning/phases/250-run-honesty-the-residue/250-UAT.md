### A3 — the mirror-image control ✅ **DRIVEN, and it found a REAL BUG I had shipped**

**The check:** a row must never read `NOT TICKED` while the agent is working.

⛔ **THE FIRST ATTEMPT CRASHED THE ENTIRE PAGE TO WHITE.** Console:

```
Error: Rendered fewer hooks than expected. This may be caused by an accidental early return statement.
```

**Root cause, and it is mine.** The liveness read shipped as:

```ts
const isRunLive = useStreamingForThread(threadId) || useLoadingForThread(threadId)
```

**`||` SHORT-CIRCUITS.** The moment the first selector returns `true` — i.e. **the exact moment a
run starts** — the second hook is never called, React counts fewer hooks than the previous
render, and the whole app unmounts to a blank page.

⭐ **EVERY GATE WAS GREEN OVER IT.** 22 unit cases, the count gate, the ledger gate, the
typecheck. The reason is structural rather than careless: the suite replaces both selectors with
`vi.fn()`, and **a `vi.fn()` consumes no hook slot**, so React's hook accounting never sees the
violation. **A rendered test could not have caught this. Driving the app did, on the very
scenario the phase exists for.**

**Fixed:** the two hooks are called on their own lines and `||` combines their *values*. Pinned by
a new **source** fence — `TodosSection.test.tsx` → *"hooks are never short-circuited"* — which
scans the component source for a `use*()` call on the left of `||` / `&&` / `??`. ⭐ **Driven RED
against the exact shipped defect and the file restored md5-identical**; the guard is therefore
known to fire rather than merely present.

**Re-driven after the fix, with a recorder installed so the transient state could not be raced**
(120 ms sampler over the row's status text + animation class). Two independent sends, the full
round trip both times:

| | t | state |
|---|---|---|
| before | 0 s | `NOT TICKED` · no dot |
| run starts | +5.0 s | **`IN PROGRESS` · dot animating** |
| run ends | +13.5 s | `NOT TICKED` · no dot |

**Seen on screen too:** mid-run the panel read `Translate full document content to Arabic` —
**`IN PROGRESS`**, with the two not-yet-started rows reading **`PENDING`** (not `NOT TICKED` —
the live vocabulary is unchanged), while the chat showed `⏱ 7s · Step 0 · ● Streaming…` and a
Stop control, and the sidebar showed `1 running`.

⚠ **The stopped run also confirmed the widened gate incidentally:** pressing Stop ended the run

panel fully consistent, no running badge and no stop control left behind.
