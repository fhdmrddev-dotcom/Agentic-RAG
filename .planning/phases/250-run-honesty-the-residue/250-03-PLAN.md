<objective>
**The panel stops claiming a run is in progress, and stops telling a person their finished work is
unfinished.**

Two reports, one row. `BUG-260902-01`: a run ended seven minutes ago and the todo still reads
`IN PROGRESS` with a bouncing dot — *"a person reading the panel alone waits for something that
will never happen."* `BUG-260913-02`: the job finished perfectly and the row reads
`(run ended — not completed)` — the surface adjudicating work it cannot see.

⭐ **`SEED-105` planted this exact design on 2026-07-06, at a live operator UAT, and all three of
its re-open triggers have since fired** (`D-250-03`). This builds its items 1-3.
</objective>

<threat_model>
### Invariants

1. **A live run must NEVER read `NOT TICKED`.** The failure mode of this plan is the mirror of the
   bug it fixes: a row saying "not ticked" while the agent is working. `streamingThreads` is
   reassigned only on stream start/stop, but there is a reconnect/fetch window where it can read
   empty for a live run — hence `|| useLoadingForThread`. ⛔ A fence must drive the loading-only
   state and assert `IN PROGRESS`.

2. **Realtime is a hint, not truth (D-v2.5-03).** The display status is derived at render from
   store state that is itself reconciled on (re)connect. ⛔ No new fetch, no new effect, no
   `useState` in this component.

3. **The strip must be exact or it is worse than nothing.** A near-miss leaves
   `(run ended — not completed)` visible AND labels the row `NOT TICKED` — both lies at once. The
   marker's dash is an **em-dash (U+2014)** and it carries a **leading space**. The `?raw` fence
   is what keeps the two languages in lockstep.

4. **`DerivedRow` must get the same treatment from the same helper.** Derived items mirror tool
   activity; a derived `in_progress` row on a dead run is the identical lie. ⛔ Two copies of the
   rule is the drift this phase exists to close.

5. **A11Y (088-05 / A11Y-01).** Status conveyed by a visible word, colour additive only, panel-
   scoped AA tokens. `NOT TICKED` uses the existing `--panel-muted-foreground-dim`.
</threat_model>
