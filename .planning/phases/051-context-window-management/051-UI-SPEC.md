## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), badge inline padding |
| sm | 8px | Compact element spacing (`gap-2`, `p-2`) |
| md | 16px | Default element spacing (`gap-4`, `p-4`) |
| lg | 24px | Section padding (`py-6`) |
| xl | 32px | Layout gaps (`gap-8`) |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:

- `FieldRow` vertical padding: `py-3` (12px) — grid-aligned value closest to existing SettingsPage pattern
- Slider track height: 8px (`h-2`) — grid-aligned; visually acceptable weight for a slider track
- Info icon size: 12px (`h-3 w-3`) — matches existing `Cpu` icon size in MessageInput dropdown

**Accent (`--primary`) reserved exclusively for:**
1. Slider thumb color and filled track (`accent-primary` CSS property on `<input type="range">`)
2. Active toggle state (`bg-primary` on toggle pill)
3. Active provider card border/background tint (`border-primary/30`, `bg-primary/5`)
4. Active model "active" badge text (`text-primary`)
5. Info icon hover state (`hover:text-muted-foreground` → not primary; stays muted to avoid visual noise)

Note: The `Info` icon for model cards uses `text-muted-foreground/50` at rest and `text-muted-foreground` on hover. It does NOT use `text-primary` to avoid competing with the active-model badge.

## Interaction Contract

### Slider behavior

1. `context_window_max_tokens` slider at value 0 renders "Auto" in the readout (not "0").
2. Moving the slider from 0 to any positive value switches the hint from "Using model default ({N} tokens)" to "Overrides model default".
3. The displayed model default is read from `MODEL_INFO[activeModel]?.contextWindow` — if model not in lookup, hint shows "Using model default" without the token count.
4. Both sliders update local state on `onChange`; they do NOT fire an API call per tick. Save is deferred to the existing AI Model tab Save button.

### Model info tooltip behavior

1. Tooltip appears on hover of the `Info` icon only — pointer events on the model name text do not trigger it.
2. `e.stopPropagation()` on the Info icon's `onClick` prevents accidental model selection.
3. Tooltip does not appear on touch devices (hover-only) — acceptable given this is a desktop settings/chat UI.
4. If `MODEL_INFO[modelId]` is undefined, the `Info` icon is not rendered at all for that item.

### Sub-agent model dropdown behavior

1. First option is always "Auto (cheapest for provider)" with empty string value.
2. The model list is the same `models` array from the active provider (same source as main model selector).
3. Saving an empty string value clears any override and restores auto behavior.
