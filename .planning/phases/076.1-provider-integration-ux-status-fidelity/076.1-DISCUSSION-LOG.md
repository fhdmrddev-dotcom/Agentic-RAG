## Auto-scroll Strategy

### Q1: How should auto-scroll behave when user has manually scrolled away?

| Option | Description | Selected |
|--------|-------------|----------|
| Scroll only if at bottom (Recommended) | Only auto-scroll if user is within ~100px of bottom. Matches Claude.ai/ChatGPT. | ✓ |
| Always scroll to active tool | Force-scroll regardless of user position. Aggressive. | |
| Scroll + snap-back button | Auto-scroll + floating "Return to bottom" button. | |

**User's choice:** Scroll only if at bottom
**Notes:** Standard behavior across major chat platforms. Avoids the "yank-back" problem.

### Q2: What element should the viewport scroll TO?

| Option | Description | Selected |
|--------|-------------|----------|
| Tool panel body (Recommended) | scrollIntoView on ToolCallPanel body. Puts streaming code in viewport center. | ✓ |
| RunCard header (sticky) | Make RunCard header position:sticky. Tool panel scrolls below. | |
| Bottom of tool panel | Scroll to bottom edge — mimics terminal auto-scroll. | |

**User's choice:** Tool panel body
**Notes:** Centers the streaming code preview in viewport.
