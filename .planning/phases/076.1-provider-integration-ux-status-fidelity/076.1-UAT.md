## Additional Findings

### DeepSeek reasoning_content error
DeepSeek v4-flash returns `reasoning_content` in thinking mode. On the second LLM call (after tool execution), the API requires `reasoning_content` to be passed back in the conversation history. Our `openai_service.py` strips or ignores this field, causing: `LLM API error: Error code: 400 - 'The reasoning_content in the thinking mode must be passed back to the API.'`
This is a provider-specific bug, not a 076.1 scope issue. Should be tracked as a separate bug report or seed.
