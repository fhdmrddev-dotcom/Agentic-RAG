<objective>
Make "we published what we validated" structurally true instead of merely likely.

Purpose: SC#3 and the highest-value item in the phase. `publish_service` loads the
definition at stage 0, spends minutes on a golden run and a judge, then flips at stage 5 on
`status='draft'` **only**. Once autosave exists (186-06), an edit landing mid-gauntlet
publishes a definition that never passed the gauntlet. WR-03 is the double-publish guard,
not a dirty-draft guard.

Output: the stage-0 token carried to stage 5, a token-guarded flip, and a new honest
`blocked_stage` — `draft_changed` — with the golden run and every `harness_audit` row it
produced left untouched.

Zero migrations: `blocked_stage` is free-form metadata inside the `metadata` JSONB of the
already-registered `publish_blocked` event type (independently re-verified against
`supabase/migrations/114_...sql:36-49`). Unlike 185-13's `action_risk_pending`, nothing here
touches the `harness_audit` event_type CHECK.
</objective>
