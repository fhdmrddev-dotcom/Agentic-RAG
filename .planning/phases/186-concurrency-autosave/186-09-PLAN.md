<objective>
Close GAP-1 / CR-01: an edit made while a PATCH is in flight is silently dropped and the
surface files a `Saved ✓` receipt for a payload that predates it.

Purpose: this is the phase's central promise ("Never a false `Saved ✓`. A refusal — of any
kind — leaves the draft dirty") and the verification pass independently reproduced it false.

guard is currently scoped to a QUEUE FLAG (`pendingRef`); it must be scoped to WHAT WAS
WRITTEN.

Output: `performWrite` captures the payload's identity at snapshot time and refuses to file a
receipt unless the store still holds it; plus the regression test whose second edit's timer
does NOT mature during the first write's flight — the interleaving the shipped F9 test misses.
</objective>
