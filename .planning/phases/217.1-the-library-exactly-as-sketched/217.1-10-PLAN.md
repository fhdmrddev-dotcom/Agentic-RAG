**Gating — the shipped VANISH convention, not a disabled placeholder:**
```tsx
const featuresCtx = useEffectiveFeaturesOptional()
const canManage = featuresCtx?.features.model_management === true
```
(mirroring `ChatLayout.tsx:255-256`'s `visual_workflow_canvas` check). When `canManage` is false, the
three action buttons (`Change model`, `Re-index everything`, `Re-index selected`) render as ABSENT —
`nav-items.ts:63-75`'s `visibleNavItems` VANISH shape — never `disabled`. The FACTS (Vector store,
Embedding model, Folders numbers) render unconditionally; only the three buttons are gated.

**Cards — in-file shape, reusing `IndexingTab`'s own `Fact` primitive:**
`VectorStoreCard` = `Vectors` / `Chunks indexed` / `Documents with no vectors` / `Last indexed`.
`EmbeddingModelCard` = `Model` / `Dimensions` / `Provider` + the gated `Change model` button.
`FoldersIndexTable` = `Folder · Documents · Chunks · Vectors · Last indexed · Actions`, one row per
`folders[]` entry from `GET /library/index-summary`, the `Root` row rendering `–`/`–`/`never` when it has
zero chunks (D-217.1-31: `Root`, never `Uncategorized`). `Re-index selected` per row is gated on
`canManage` AND on whether the folder has chunks at all — per RESEARCH Open Question 1's recommendation,
a zero-chunk folder's Actions cell carries NO action (a control that cannot do its verb is what the `✕`
cut removed), while a stale-but-non-empty folder gets `Re-index selected`, and an already-current folder
(BE-3's distinguishable `remaining: 0` signal) renders the button but shows *"Already indexed with the
current model."* on click rather than a false success.

**`ReembedStatusCard` stays composed unchanged** (D-217-16) — do not touch it.

**One fetch, not three:** `IndexingTab` keeps its existing `useEffect` shape (`:47-70`) but points it at
the new `getIndexSummary()` client fn (create in `frontend/src/lib/api/library.ts`, following
`lib/api/knowledge.ts`'s existing client-fn shape) instead of `getReembedProgress()` for the three new
cards' data; `ReembedStatusCard` keeps its own self-fetch unchanged.
