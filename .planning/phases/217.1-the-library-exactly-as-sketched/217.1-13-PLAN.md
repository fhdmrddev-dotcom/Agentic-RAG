**Where the gate is declared:** `backend/app/models/user_settings.py:1193-1197`,
`_GOVERNED_FEATURES["governance_health"]`. **Where it is enforced (the security authority, unchanged by
this plan):**
```python
router = APIRouter(prefix="/document-governance", tags=["document-governance"],
                    dependencies=[Depends(require_visible("governance_health"))])
```
`document_governance.py:61-65` — router-level, covers all three routes, raises 403 (not 404) for a
non-operator when the feature is `"operators"`.

**Where it is consumed — render-only, the analog already shipped and exact:**
```tsx
// frontend/src/components/layout/ChatLayout.tsx:34, :255-256
import { useEffectiveFeaturesOptional } from "@/providers/EffectiveFeaturesProvider"
const featuresCtx = useEffectiveFeaturesOptional()
const canvasEnabled = featuresCtx?.features.visual_workflow_canvas === true
```
`useEffectiveFeatures` fails CLOSED to `{}` (`useEffectiveFeaturesProvider.ts:39-44`), so an unresolved
features map behaves like "no access" rather than "full access."

⛔ **Do NOT gate by catching the 403.** `lib/api/knowledge.ts:113-117` documents that `getGovBroken`/
`getGovUnclassified`/`getGovLowConfidence` throw a status-carrying `ApiError` specifically so a
mid-session tighten bounces gracefully — that is a RECOVERY path, not an authorization one. The gate must
prevent the CALL from firing at all when the feature is false, not catch its failure.

**The negative test, both sides, described concretely:**
1. **Backend (pytest):** monkeypatch `feature_audience`/equivalent to return `"operators"` for
   `governance_health`, and `is_operator` to `False`; assert all three `document-governance` routes return
   403. Non-vacuity control: with `is_operator=True`, the same three routes return 200. Model:
   `backend/tests/test_217_document_queries.py`'s call-log assertion shape.
2. **Frontend (vitest):** render `HealthSignalChips` with `features = {}` (the fail-closed map): assert
   `Broken links`/`Unclassified`/`Unsure metadata` are ABSENT, assert `Most found`/`Never found`/
   `Weak matches`/`Stale` are PRESENT (proving the gate is chip-level, not tab-level), and assert
   `getGovBroken`/`getGovUnclassified`/`getGovLowConfidence` were NEVER CALLED. Then re-render with
   `features = { governance_health: true }` and assert all seven present — the positive control without
   which the negative proves nothing.
