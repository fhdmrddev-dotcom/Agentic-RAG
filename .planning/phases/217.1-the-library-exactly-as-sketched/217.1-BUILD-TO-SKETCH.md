Five items. Everything else in this phase is front-end composition over data already fetched.

| # | change | serves |
|---|---|---|
| **BE-1** | migration: `document_chunks.embedded_at timestamptz`, written by the embed path **and** the re-embed path | `Last indexed` (Vector store + every Folders row). ⚠ `created_at` is the *chunking* time and does not move on a re-embed — using it would print a lie after the first re-index |

| **BE-5** | persist per-hit similarity as a key on the existing retrieval jsonb + `GET` it per document | `Average relevance` (LIB-07) |
| **BE-6** | ⚠ **the only new table**: `checked_queries` (`question`, `expected_document_id`, `last_rank`, `previous_rank`, `checked_at`) + CRUD + a rank evaluator that re-runs the shipped retrieval path and records where the expected document landed | the `CHECKED QUERIES` tile and table |

## Waves

**Wave 0 — the gate that let the first pass through.** Extend `drive.cjs --emit` to emit **composition**
assertions per screen: the ordered block list, each block's required child atoms, every named button.
Add a `sketch-composition` fence suite that mounts each tab body and asserts them by `data-*` hook,
**driven RED against the current tree first**. Without this, 217.1 drifts for the same reason 217 did —
a 200-assertion contract that asserts only text.

**Wave 1 — the four live defects.** Visible stage labels · plain-language error mapper (raw string behind
⌥ Technical-names) · `Needs attention` row with `Try again` · a dropzone on the Ingestion tab.

**Wave 2 — Ingestion becomes screen 008.** Sub-tabs · full dropzone + `Choose files` + folder picker ·
the four-card pipeline row (replacing the six) · the queue table · `History`.

**Wave 3 — Documents furniture.** Three stat tiles · breadcrumb · folder pill · chunk bar · expand
chevron · inline strip in Status · reason sentence · pager.

**Wave 4 — Views stops being the sidebar.** Card grid · rule-in-words · `New view` · the zero-match card.

**Wave 5 — Indexing's three cards.** BE-1, BE-2, BE-3 · Vector store · Embedding model + `Change model` +
`Re-index everything` · Folders table + `Re-index selected`.

**Wave 6 — Health, absorbed.** BE-4, BE-5 · ring · stacked chart with the third segment · four tiles ·
`MATCH STRENGTH` · seven chips renamed apart · per-document bars.

**Wave 7 — the merge's seams (Phase 218's own risk, and it is the sharpest thing here).**
Retire `Library Health` + `Governance` from the nav · **move the `governance_health` gate with the three
signals it guards, verified by a negative test, never by inspection** · **install the replacement fallback
for `ChatLayout.tsx:879` in the same commit** — `App.tsx:98` says a union member with no branch silently
renders Knowledge Health, so deleting it turns a mis-route into a blank screen.

**Wave 8 — the detail panel.** BE-6 not required here. `RETRIEVAL` block · `FOUND PER WEEK` · real
`Average relevance` · verify the shipped sections against screen 007's composition.

**Wave 9 — Checked queries.** BE-6 + the table + `Add a check`. Cut whole, or ship whole.
