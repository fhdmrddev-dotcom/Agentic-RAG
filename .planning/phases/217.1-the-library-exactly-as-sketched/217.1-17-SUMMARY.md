## Decisions

1. **Fourth verdict word is "Not found"** — a row with `checked_at` set but `last_rank: null` (checked but the doc didn't rank) gets its own honest verdict, never folded into Slipped/Holding. Tested distinctly.

2. **Rank cell is a sentence** — `was 2, now 6` / `ranked 2` / `not ranked` — never a bare number pair with no verb (the same honesty rule as the coverage ring).

3. **Reconcile-by-fetch after every mutation** — create/check/delete all re-fetch the list (D-v2.5-03), never trust an optimistic row.

4. **One fetch feeds tile + table** — `listCheckedQueries().length` is lifted to HealthTab's tile via `onTotalChange`, so the section's single fetch serves both consumers.

5. **Add-a-check immediately triggers `/check`** — so a new row has a rank on first render rather than sitting at "Not checked yet" indefinitely.
