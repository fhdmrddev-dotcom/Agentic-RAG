## Sampling Rate

- **After every task commit:** the touched suite **+** `node .planning/sketches/218-the-library-and-its-tabs/drive.cjs`. ⭐ The sketch driver reads the **live tree** and runs sub-second, so it catches a column reorder or a lost label in the same commit that causes it.
- **After every plan wave:** `GSD_VITEST_MAX_WORKERS=2 node scripts/vitest-count-gate.cjs` from the repo root · `npx tsc -p tsconfig.app.json --noEmit` · the backend suites that wave touched.
- **Before `/gsd:verify-work`:** count gate green · `drive.cjs` green **including the new composition assertions** · backend suite at or above baseline · **the G-4 browser drive complete**.
- **Max feedback latency:** < 20 s per task (sketch + one suite).

⚠ **If the gate reds, do NOT reach for `GSD_VITEST_MAX_WORKERS`.** Capture the failing filenames from the
gate's **own persisted JSON before re-running anything**, check each against `git diff --numstat <base> HEAD`,
and if a file is byte-unchanged and one of SEED-171's five, record it as an observation and move on.
⚠ **A red gate is sometimes REAL** — Phase 196 hit `failed 249` and every one was a genuine missing mock.
