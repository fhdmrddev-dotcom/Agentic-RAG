## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking issue] Same-stable-id re-seed blocked by FK RESTRICT ∩ immutability trigger — run-clear gated behind an explicit operator opt-in**

- **Found during:** Task 2 (first live run).
- **Issue:** Re-seeding the *exact* published id `00000000-...-0000000101a0` IN PLACE is mathematically impossible non-destructively given two intersecting live invariants: (a) `workflow_runs.definition_id` references the row with `ON DELETE RESTRICT`, and **4 superseded GAP-A live-UAT runs** (the documented "0 .docx across 4 runs", `101-LIVE-UAT-FINDINGS.md`) reference it → a bare `DELETE` of the definition raises `ForeignKeyViolation`; (b) the `workflow_definitions_block_published_update` BEFORE-UPDATE trigger blocks any in-place `UPDATE` of a published row's authored columns (incl. a status flip) → an in-place content change is also blocked. Same-id + content-change is therefore only reachable by first clearing the FK-referencing runs.
- **Fix:** The seeder clears ONLY the runs of THIS fixture definition id (scoped — never any other definition's runs; `workflow_phases` CASCADE, `threads.active_workflow_run_id` SET NULL, the INSERT-only `harness_audit` receipts have NO FK and are PRESERVED). Crucially, this run-history deletion is **GATED behind an explicit operator opt-in env flag `SEED_LLM_EMIT_CLEAR_RUNS=1`** — the seeder REFUSES (clean `SystemExit` with the exact remedy) if the flag is absent, so it NEVER silently deletes pre-existing run history the operator only authorized re-seeding around.
- **Files modified:** `backend/tests/fixtures/seed_llm_emit_fixture.py`.
- **Commit:** `09f27f74`.

**2. [Rule 2 - Missing data] Added `project_folder_id` to the definition + `uat_fixture_ids.json`**

- **Found during:** Task 2 (pre-write model probe).
- **Issue:** The D-13 gather phase declares `folder_scope`, which the `harness.py` `_folder_scope_requires_project` structural validator requires a `project_folder_id` for. The prior GAP-A fixture had neither; without `project_folder_id` the seeded JSON would fail `model_validate()`.
- **Fix:** Set `project_folder_id` to the bound risk folder (the gather scope is a subset of itself); emitted it to `uat_fixture_ids.json` for the live UAT / Task-3 smoke test.
- **Files modified:** `backend/tests/fixtures/seed_llm_emit_fixture.py`, `backend/tests/fixtures/uat_fixture_ids.json`.
- **Commit:** `09f27f74`.
