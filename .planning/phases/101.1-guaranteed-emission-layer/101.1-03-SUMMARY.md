# Phase 101.1 Plan 03: The `_exec_llm_emit` Forced-Emit Executor Summary

**The 6th harness executor (`_exec_llm_emit`) that composes the Plan 01 substrate + Plan 02 forced-emit core into a working `llm_emit` phase: it resolves the bound library template server-side (GAP-B, the model never selects it), runs a SEALED forced shot via `forced_emit` (never the open agent loop — the GAP-A root cause), runs the deterministic citation gate BEFORE render, renders via the EMITTER_REGISTRY post_processor re-dispatching the hardened `_handle_render_template` (one render code path), enforces the integrity gate, surfaces honest failures across 5 distinguishable states, and writes an INSERT-only `harness_audit` receipt at every transition — with Deep proven byte-identical (`render_template` reachable ONLY from a declaring `llm_emit` phase; `get_tools()` still omits it; `agent_loop.py` + `threads.py` untouched).**

## Audit-receipt transition list (D-12)

Per emit run, the executor writes INSERT-only `harness_audit` rows (keyed to `run_id` + `definition@version`, owner-scoped) at each transition:

| Transition | event_type | When |
|---|---|---|
| forced shot dispatched | `emit_forced` | always (the sealed forced call is sent) |
| NATIVE narration recovered | `emit_recovered` | only when `forced_emit.recovered_from_narration` (D-06 fired) |
| citation gate passed | `emit_validated` | the field-map cleared `check_coverage` (cited + not invented) |
| citation gate rejected (state b) | `emit_rejected` | uncited/invented — BEFORE render |
| rendered + integrity-clean (success) | `emit_rendered` | the deliverable produced (status ok) |
| integrity failed (state d) | `emit_integrity_failed` | non-opening / residual tokens — file NEVER persisted |
| model failed / no template / render error (states a/c/e) | `emit_failed` | honest terminal failure |

Each receipt carries the §4 metadata (tier, provider, model, forced, thinking=False, recovered_from_narration, gate_verdict, integrity_verdict, output_file{path, sha256, bytes}).
