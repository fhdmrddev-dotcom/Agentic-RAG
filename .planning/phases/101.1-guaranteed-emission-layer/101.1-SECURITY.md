# Phase 101.1 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| published WorkflowDefinition JSONB → phase config parse | stored/authored definition could carry unexpected keys in `llm_emit` config | workflow config JSON |
| workflow definition → emitter dispatch | a definition could NAME an emitter that does not exist or smuggle code | emitter name string |
| gateway adapter → provider API | a forcing param could be mistranslated and silently downgrade forcing | tool_choice / forcing params |
| narrated model output → recovered emission | untrusted model text parsed back as a structured object | model-generated text |
| validated field-map → sealed sandbox | cited DATA crosses into the render command | emission field-map |
| declaring llm_emit phase → render_template tool | tool must be unreachable outside a declaring phase (Deep byte-identical) | tool schema visibility |
| agent/run text → PhaseCard render | run-honesty event strings cross into the DOM | agent-supplied strings |
| flat field-map → docxtpl context | normalized flat shape feeds the render command | emission data |
| emit transition → SSE wire / audit row | sub-events reuse the shared one-XADD path; every transition writes an owner-scoped immutable receipt | run events / audit receipts |
| migration DDL → live DB | a malformed ALTER could weaken audit immutability or block valid kinds | schema DDL |
| seeded definition / AssetRef → published row / Storage | malformed definition or cross-user template binding | fixture JSON / Storage paths |
| model → forced emit args | provider error or malformed tool-JSON crosses here | tool-call JSON |
| rendered bytes → JSONB persist | binary file bytes cross into a text-typed JSONB delta column | deliverable bytes |
| model out_filename → workspace path | model-influenced output name could collide with the uploaded template | filenames |
| client → raw-bytes route | authed user requests workspace file bytes; cross-user/expired access must 404 | file bytes |
| producer SSE → panel store | a background run's phase_substep must not corrupt the viewed thread's rail | SSE events |
