<objective>
LIB-04, second half: tables rendered as tables, image descriptions, and the questions that found the
document.

Purpose: `DocumentList` renders `table_count` and `image_count` as bare numbers while the real
content sits untouched in `document_tables` / `document_images` — the ledger calls that *"the largest
single instance of the buried-capability finding."* This plan is that finding's answer.

⚠ And "tables as tables" was left to Claude's discretion, so it was researched rather than guessed:
an extracted table is arbitrary USER DATA whose columns are all meaningful, so the shipped
`CsvTablePreview` scroll-container pattern is right and `IngestionPage`'s column-shedding pattern is
wrong — shedding a column of a user's own table deletes exactly what they opened the panel to see.

Output: one shared table renderer extracted from `CsvTablePreview` (caps, scroll container and empty
arm included), three more lazily-mounted sections, and a suite that drives the wide-table and
hostile-content cases.
</objective>
