## Decisions Made

- **Option A (per-function decorator) over Option B (PG_AVAILABLE + seeded_thread)** for the Task 3 skipif fix. The test file requires only Docker reachability, not Postgres seeding — the lighter Option A pattern is sufficient and matches Phase 074 D-074-11 precedent.
- **Safety-net counter scope: increments include trailing-partial flush emits.** When the `_done` branch flushes a trailing partial line, the counter increments so the safety-net correctly does NOT double-emit if that trailing line was the only output. If the counter were only incremented inside `drain_step`'s emits, a single-line cell with no trailing newline would trigger both the partial-flush emit AND the safety-net consolidation — duplicate output on the wire.
- **drain_step at module scope (not nested inside the route handler)** so unit tests can `from app.api.threads import drain_step` directly without instantiating the FastAPI app or its dependency tree.
