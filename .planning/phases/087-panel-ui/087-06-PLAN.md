<objective>
Re-architect the workspace-panel layout so the chat|panel split is a single ChatLayout-level CSS grid, lift the panel open/rail/hidden state up to ChatLayout so a persistent chat-header toggle can host it (and the pulsing-amber-dot pending indicator), and strip the leaked DevTwoPaneMock debug overlay from production.

Closes UAT gaps 1, 2, 3, 4, and 7 (one cohesive layout change + one surgical removal). Gap 7 (dead band) is resolved automatically by the grid hoist in gap 1.

Purpose: The shipped panel is content-driven (overflows when chat is wide, leaves a right-gap when chat is narrow, shifts position per thread), a debug harness leaks into prod, and a hidden panel is unreachable by mouse. This plan realizes the locked panel-shell design contract (D1: three-column push/split app grid `52px nav | 1fr chat | 30% panel`) instead of the self-referential aside hack.

Output: A stable, flush-right ~30% panel with zero horizontal overflow in every state, a persistent and discoverable reopen control, and a clean production tree.
</objective>

<design_contract_note>
panel-shell.md D1 specifies the app-level three-column grid:
  `grid-template-columns: 52px 1fr var(--panel-w, 30%)` with the panel column animating to `0` (hidden) / `52px` (rail).
The shipped build put a self-referential `grid-template-columns: 0 clamp(300px,30%,420px)` INSIDE the WorkspacePanel aside (Pitfall-3 workaround), where the 30% resolves against the aside's own indefinite flex width and collapses to the 300px floor. The fix is to HONOR the original contract: hoist the chat|panel split to ChatLayout's level so the panel column resolves against the real row width and the chat YIELDS the panel's width (centering within its own 1fr column → fixes the dead band too).

NavPanel is a fixed 52px flex item already; you may either (a) make the chat+panel region a 2-column sub-grid inside the existing flex `<main>` row, or (b) convert the whole `<div className="flex h-screen">` row to a 3-column grid `[NavPanel 1fr-of-its-own auto] [chat 1fr] [panel track]`. Prefer the minimal change that keeps NavPanel, the mobile drawer (`fixed` overlay — unaffected by the row layout), and `<main>`'s content untouched. The panel track is `clamp(300px,30%,420px)` (open) | `52px` (rail) | `0` (hidden), with `motion-safe:transition-[grid-template-columns] duration-300`.
</design_contract_note>
