### 3. Hidden state has no reopen affordance
expected: When the panel is hidden, a persistent, discoverable control re-opens it.
result: issue
reported: "After Ctrl+./⌘. hides the panel (gridTemplateColumns '0px 0px', opacity 0), the ONLY way to reopen by mouse is the in-chat 'open panel ↗' seam pointer — which only exists in threads that have a visible panel-owned tool event. On a thread with no such event (e.g. a pure-prose thread, or after scrolling the event out of view), the hidden panel is unreachable by mouse; only the undiscoverable Ctrl+. shortcut brings it back. There is no persistent workspace toggle button anywhere in the chrome (confirmed: the only panel-open button in the whole document is the content-dependent seam pointer)."
severity: major
