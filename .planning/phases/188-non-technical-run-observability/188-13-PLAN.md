| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-188-13-01 | Spoofing (of evidence) | a keyless or misrouted SC#10 row | mitigate | Keys are probed first; the effective provider is read back from `runs`; a mismatch is ⛔ with the reason, never a PASS. |
| T-188-13-02 | Repudiation | rows recorded without observation | mitigate | Every row requires a recorded observation; a scenario not run is `pending`, and owed rows are stated as a decision with the first row to run named (G-7's honesty clause). |
