# Plan 035-04: Fix PDF Image Extraction (pdfplumber stream bytes)

## Gap Being Closed

Test 5 — PDF Image Extraction + Vision Description  
`extract_pdf_images` silently returns empty for all PDFs because `img_obj.get("stream", b"")` never yields usable image bytes from pdfplumber image dicts.

## Root Cause

`backend/app/services/multimodal_service.py` line 142:

```python
img_bytes = img_obj.get("stream", b"")
if not img_bytes:
    continue
```

pdfplumber's `page.images` returns dicts derived from pdfminer's LTImage objects. The `"stream"` key, when present, is a `pdfminer.pdftypes.PDFStream` object — not raw bytes. Two failure modes:

1. Key absent → returns `b""` → `if not img_bytes` is True → skipped
2. Key is PDFStream → `io.BytesIO(pdfstream_obj)` raises `TypeError` → caught by inner `except Exception: continue` → skipped

Result: zero images ever processed.

## Fix

Replace lines 142–143 in `extract_pdf_images` with proper PDFStream handling:

```python
stream_obj = img_obj.get("stream")
if stream_obj is None:
    continue
try:
    img_bytes = stream_obj.get_data() if hasattr(stream_obj, "get_data") else bytes(stream_obj)
except Exception:
    continue
if not img_bytes:
    continue
```

### Task 2 — Update unit test for `extract_pdf_images`

**File:** `backend/tests/unit/test_multimodal_extraction.py`

The existing `test_pdf_images_stored` test mocks `extract_pdf_images` at the orchestrator level — it does not exercise the stream-bytes fix. Add a focused unit test:

```python
def test_extract_pdf_images_reads_stream_bytes(tmp_path):
    """extract_pdf_images must call stream.get_data() when stream is a PDFStream-like object."""
    # Minimal test: mock pdfplumber.open to return one image dict
    # with a stream object that has get_data(), verify image is returned
    from unittest.mock import MagicMock, patch
    import io, base64
    from PIL import Image as PILImage

    # Build a 60x60 white PNG as fake stream data
    buf = io.BytesIO()
    PILImage.new("RGB", (60, 60), color=(255, 255, 255)).save(buf, format="PNG")
    png_bytes = buf.getvalue()

    mock_stream = MagicMock()
    mock_stream.get_data.return_value = png_bytes

    mock_img = {"width": 60, "height": 60, "stream": mock_stream}
    mock_page = MagicMock()
    mock_page.images = [mock_img]

    mock_pdf = MagicMock()
    mock_pdf.__enter__ = lambda s: s
    mock_pdf.__exit__ = MagicMock(return_value=False)
    mock_pdf.pages = [mock_page]

    with patch("pdfplumber.open", return_value=mock_pdf):
        from app.services.multimodal_service import extract_pdf_images
        results = extract_pdf_images(b"fake-pdf-bytes")

    assert len(results) == 1
    assert results[0]["width"] == 60
    assert results[0]["height"] == 60
    assert results[0]["b64_png"]  # non-empty base64
    mock_stream.get_data.assert_called_once()
```
