The default preserves `EmitFieldMap` → byte-identical for every existing emit caller. The two judge callers pass `schema_model=JudgeVerdict`. While in these files, fold in WR-05 (a shared `resolve_judge_model` helper so the in-run validator resolves the same registry default the publish path does), IN-01 (drop unused function-local imports in `publish_workflow`), and IN-04 (`_judge_golden_output` forwards owner_settings instead of `user_settings=None`).

Purpose: Without CR-01, the QUAL-01 hard blocker is a structural wall that blocks every publish, and the GATE-01 `llm_judge_rubric` kind can never pass. This is the keystone — plans 07/08/09 build on a real verdict path.
