**T12 — driven in `backend/venv` (Python 3.12.6):**
```
CRLF    RAISED: ValueError -> Header values may not contain linefeed or carriage return characters
LF-only RAISED: ValueError -> Header values may not contain linefeed or carriage return characters
To CRLF RAISED: ValueError -> Header values may not contain linefeed or carriage return characters
```
All three attempts raise at `__setitem__`, **before anything is serialised**. So:
1. compose with `email.message.EmailMessage`, set headers via `msg["Subject"] = …` — the stdlib
   guard IS the mitigation, and **a regex over the subject is the WRONG answer**: it duplicates
   a stronger check, will disagree with it at some edge, and can be widened later
2. never call `smtplib.sendmail(from, to, raw_string)` — use `smtp.send_message(msg)`
3. validate ENVELOPE recipients separately: `msg["To"]` is a header, the SMTP `RCPT TO` envelope
   is a different channel. Parse each with `email.utils.parseaddr` and require a single
   `local@domain` with no control characters
