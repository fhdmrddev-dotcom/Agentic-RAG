The four MEASURED holes in a bare `not ip.is_global` (research §R14, driven):
`224.0.0.1` multicast · `64:ff9b::7f00:1` NAT64 · `::ffff:0:7f00:1` IPv4-TRANSLATED (SIIT —
`ipv4_mapped` returns `None`) · `fec0::1` IPv6 site-local. Hole 3 is the one that would have
shipped: `::ffff:0:0/96` (mapped) and `::ffff:0:0:0/96` (translated) differ by one 16-bit group.

Host matching (research §R15, driven) — `h = host.lower().rstrip(".")`, then
`h == suffix or h.endswith("." + suffix)`. **The leading dot is the whole mechanism and its
absence is the CVE.** Match against `httpx.URL(u).host`, NEVER the raw URL string:

```
https://slack.com@evil.com/api/   host='evil.com'    ← userinfo bypass
https://evil.com#slack.com        host='evil.com'    ← fragment bypass
https://slack.com.evil.com/api/   host='slack.com.evil.com'
https://xn--slck-hoa.com/         host='slåck.com'   ← ⚠ httpx IDNA-DECODES
```

The contract sentence to copy with the noun swapped (`secret_cipher.py:1-6`): *"No `Fernet(...)`
is constructed anywhere else in the app"* → *"No HTTP or SMTP client is constructed anywhere
