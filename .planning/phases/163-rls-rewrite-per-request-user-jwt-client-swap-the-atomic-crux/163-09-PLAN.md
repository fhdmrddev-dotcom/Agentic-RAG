Purpose: these paths are the legitimate exceptions to the user-JWT swap (D-05). Without the explicit-org wrapper + widened filters, a background writer could touch cross-org rows even after RLS is live — so the org scope must be app-enforced here.

Output: the three async writers running org-aware service-role.
</objective>
