<objective>
Give a first-party capability connection the same thing an MCP connection already has: a list of
named, described, schema-carrying actions. Nothing about sending changes; nothing is deleted; the
closed set is not opened.

Purpose: SC#1 ("the actions offered are the tools that service advertises") and SC#2 ("presents as a
service with named actions") are impossible until a legacy connection HAS advertised tools. This
plan produces them, and it produces the mechanical agreement that stops them going stale.

Output: a new `connectors/descriptors.py`, a two-key-wider sanitizer, and two new backend test files.
</objective>
