<objective>
Take the verb out of every place it ORGANISES — the create form's category chooser, the picker's
capability-scoped read, the node form's three-verb radio group — and put the connection's own tool
list in its place. The verb stays on the row as an attribute; it stops being an axis.

Purpose: SC#1 and SC#3 are UI truths and cannot be made true by the API alone. D-211-12 additionally
requires the tool-list readers to stop gating on `mcp_server_url`, or plan 211-01's descriptors ship
where no surface can display them — this project's built-but-unreachable signature.

Output: the minimum UI change that makes SC#1 and SC#3 true, with **no layout change** (D-211-07),
plus the negative fence, the cross-plan seam test, and the ledger rows this phase owes.
</objective>
