<objective>
Build the net-new `skill_proposer_service.py` — the structural sibling of the Trigger Tuner's
`build_candidates`. It (1) assembles the D-02 evidence bundle from a source eval run (failed +
`not_measured` cases with prompt/expected/both-arms/verdict, human ratings with the judge-PASS x
human-DOWN disagreement rows weighted as the TOP cue, passing cases as "don't break these" anchors,
plus the latest Tuner-run signal as optional context) and (2) forces ONE schema-bound `SkillProposal`
emission on the resolved builder model.

Purpose: Turn eval evidence into a single reviewable instruction-body edit — the core of the loop.
Output: `skill_proposer_service.propose(...)` + its unit tests.

Honors D-01 (paid spend user-initiated — this service is only called from the on-demand propose route),
D-02 (full bundle, disagreement top cue), D-03 (`resolve_skill_builder_model`, never the judge/hardwired),
D-04 (one proposal per call).
</objective>
