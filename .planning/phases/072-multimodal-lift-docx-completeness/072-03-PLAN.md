    ```python
    def vision_sweep_images_pdf(
        raw: bytes,
        *,
        vision_client=None,
        app_settings=None,
    ) -> list[ImageData]:
        """Per-page rasterize + vision-LLM "list figures + bboxes" sweep (D-072-01 REVISED).

        Opt-in via app_settings.extraction_image_engine_pdf='vision_sweep'. Default
        engine remains 'pymupdf_full' (the cheap-fast in-process path).

        Pipeline per page:
          1. Rasterize via in-process PyMuPDF (page.get_pixmap(dpi=150)). AGPL
             in-process per D-PRD-07 + D-071.3-11. Per-page rasters are naturally
             bounded near ~1200x1600 px at 150 DPI — no caller-side downscale via
             `_downscale_b64_for_vision` is invoked. Provider limits are met.
          2. Caption pre-filter: skip the vision-LLM call on pages with no
             Figure/Table/Chart caption (D-072-11).
          3. Page-cap: stop after app_settings.vision_sweep_max_pages (D-072-11).
          4. Vision-LLM call returns structured JSON listing figure bboxes
             (0-1 page-relative coords). Parsed via Pydantic; malformed responses
             degrade to empty figure list.
          5. PIL.Image.crop each detected bbox; encode as PNG b64.
          6. Content-hash dedup via _dedup_images_by_hash (Plan 02 helper) catches
             figures spanning page breaks or repeated logos.

        Cost trade-off: ~$3-5 per 75-page thesis at OpenAI gpt-4o vision rates.
        Operator opts in via app_settings.

        Vision model source (BLOCKER 4 resolution): read EXCLUSIVELY from
        `app_settings.llm_model`. No env-var fallback to app.config.settings —
        keeps tests deterministic and removes implicit env coupling.

        Failure mode:
          - vision_client is None OR app_settings is None: log warning, return [].
          - llm_model not set on app_settings: log warning, return [].
          - Vision-LLM raises (rate-limit / network): per-page catch, continue.
          - JSON malformed: per-page catch, parse to empty list, continue.
          - Page rasterize fails: per-page catch, continue.
        """
        if vision_client is None or app_settings is None:
            log.warning(
                "vision_sweep_images_pdf: missing vision_client or app_settings; "
                "returning []. Configure app_settings.llm_api_key to enable."
            )
            return []

        max_pages = int(getattr(app_settings, "vision_sweep_max_pages", 20) or 20)
        # BLOCKER 4: read vision_model ONLY from app_settings.llm_model.
        # NO env-var fallback to app.config.settings.vision_model.
        vision_model = getattr(app_settings, "llm_model", None)
        if not vision_model:
            log.warning("vision_sweep: no llm_model on app_settings; returning []")
            return []

        import fitz  # noqa: PLC0415 — AGPL in-process per D-PRD-07
        from PIL import Image as PILImageLocal  # noqa: PLC0415

        prompt_text = (
            "List every figure, chart, table, or distinct visual element in this page. "
            "For each, return a JSON object with bbox (x1, y1, x2, y2 in "
            "page-relative 0-1 coords), kind (figure/chart/table/diagram), and "
            "a one-line caption. Return JSON: "
            '{"figures": [{"bbox":[x1,y1,x2,y2], "kind":"...", "caption":"..."}]}. '
            'Return {"figures": []} if no visual elements.'
        )

        doc = fitz.Document(stream=raw, filetype="pdf")
        try:
            results: list[ImageData] = []
            pages_called = 0
            global_idx = 0

            for page_num, page in enumerate(doc, start=1):
                if pages_called >= max_pages:
                    log.debug("vision_sweep: page-cap %d reached", max_pages)
                    break

                try:
                    page_text = page.get_text() or ""
                except Exception as exc:  # noqa: BLE001
                    log.warning("vision_sweep: page %d get_text failed: %s", page_num, exc)
                    page_text = ""
                if not _CAPTION_REGEX.search(page_text):
                    log.debug("vision_sweep: page %d caption-filter skipped", page_num)
                    continue

                try:
                    pix = page.get_pixmap(dpi=150)
                    page_png = pix.tobytes("png")
                except Exception as exc:  # noqa: BLE001
                    log.warning("vision_sweep: page %d rasterize failed: %s", page_num, exc)
                    continue

                page_b64 = base64.b64encode(page_png).decode("ascii")

                try:
                    resp = vision_client.chat.completions.create(
                        model=vision_model,
                        messages=[{
                            "role": "user",
                            "content": [
                                {"type": "text", "text": prompt_text},
                                {
                                    "type": "image_url",
                                    "image_url": {
                                        "url": f"data:image/png;base64,{page_b64}",
                                        "detail": "high",
                                    },
                                },
                            ],
                        }],
                        max_tokens=2000,
                        response_format={"type": "json_object"},
                        stream=False,
                    )
                    pages_called += 1
                    content = resp.choices[0].message.content or "{}"
                except Exception as exc:  # noqa: BLE001
                    log.warning("vision_sweep: page %d LLM call failed: %s", page_num, exc)
                    continue

                try:
                    parsed = _PageFigures.model_validate_json(content)
                except Exception as exc:  # noqa: BLE001
                    log.warning(
                        "vision_sweep: page %d response unparseable: %s; content=%r",
                        page_num, exc, content[:200],
                    )
                    continue

                if not parsed.figures:
                    continue

                try:
                    page_pil = PILImageLocal.open(io.BytesIO(page_png)).convert("RGB")
                except Exception as exc:  # noqa: BLE001
                    log.warning("vision_sweep: page %d PIL decode failed: %s", page_num, exc)
                    continue

                pw, ph = page_pil.size
                for fig in parsed.figures:
                    try:
                        b = fig.bbox
                        if len(b) != 4:
                            continue
                        left = max(0, int(b[0] * pw))
                        upper = max(0, int(b[1] * ph))
                        right = min(pw, int(b[2] * pw))
                        lower = min(ph, int(b[3] * ph))
                        if right <= left or lower <= upper:
                            continue
                        crop = page_pil.crop((left, upper, right, lower))
                        if max(crop.width, crop.height) < 50:
                            continue
                        out_buf = io.BytesIO()
                        crop.save(out_buf, format="PNG")
                        crop_b64 = base64.b64encode(out_buf.getvalue()).decode("ascii")
                        results.append(
                            ImageData(
                                page=page_num,
                                image_index=global_idx,
                                b64_png=crop_b64,
                                width=crop.width,
                                height=crop.height,
                                bbox={
                                    "x1": b[0], "y1": b[1], "x2": b[2], "y2": b[3],
                                    "kind": fig.kind,
                                    "caption": fig.caption,
                                },
                            )
                        )
                        global_idx += 1
                    except Exception as exc:  # noqa: BLE001
                        log.warning(
                            "vision_sweep: page %d figure crop failed: %s",
                            page_num, exc,
                        )
                        continue

            warn_threshold = float(
                getattr(app_settings, "vision_sweep_estimated_cost_warn_usd", 5.0) or 5.0
            )
            est_cost = round(pages_called * 0.05, 2)
            if est_cost >= warn_threshold:
                log.warning(
                    "vision_sweep: estimated cost $%.2f >= warn threshold $%.2f "
                    "(pages_called=%d).",
                    est_cost, warn_threshold, pages_called,
                )
            log.info(
                "vision_sweep: pages_called=%d figures_detected=%d est_cost=$%.2f",
                pages_called, len(results), est_cost,
            )

            from app.services.multimodal_service import _dedup_images_by_hash  # noqa: PLC0415
            return _dedup_images_by_hash(results)
        finally:
            doc.close()
    ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| storage→vision-LLM | Raw PDF bytes from Supabase Storage are rasterized then sent to the configured LLM provider (OpenAI/Anthropic/etc.). Adversarial user-uploaded content could contain text in figures attempting prompt injection of the structured JSON response |
| vision-LLM-response→pydantic-parser | LLM-generated JSON is parsed by Pydantic; malformed/oversized responses are an attack surface |
| operator→migration | Operator pastes raw SQL into Supabase Studio — if migration file is tampered with between Task 3 and Task 4, malicious SQL could land in the database |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-072-03-01 | T (Tampering) | adversarial figure text in user-uploaded PDF attempts prompt injection of vision_sweep structured JSON response | medium | mitigate | Pydantic schema (_PageFigures with strict types: list[float] bbox, str kind, str caption) enforces shape. Malformed responses log a warning and drop the page (no propagation). Caption text is stored but not executed; it flows into bbox dict → document_images.bbox → never used as a string template in SQL or system prompts downstream. |
| T-072-03-02 | D (Denial of service) | adversarial PDF with 1000+ pages triggers vision_sweep cost runaway | medium | mitigate | D-072-11 page cap via `app_settings.vision_sweep_max_pages` (default 20) hard-stops the loop. Caption pre-filter (caption-regex on `page.get_text()`) further reduces calls on text-heavy pages without figures.
