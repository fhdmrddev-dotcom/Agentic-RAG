## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user turn (`body.content`) → embedding input | Untrusted text used only as embed input; the query vector is bound as an RPC param, never string-interpolated. |
| `match_skills` RPC → injected system prompt | The ranked set must be exactly this user's owner+global enabled skills — no cross-user leak. |
| eval-override seam | The pre-filter must not alter the tuple branch nor let eval inputs bleed into the live None branch. |
| hot-path turn → detached self-heal backfill | `kick_skill_backfill` spawns a background task; it must never block the turn, propagate a failure, or fire outside the over-budget None branch. |
