# Plan 215-02: OAuth Authorization Code Grant Engine & API

## Tasks

### Task 1: OAuth Service Engine
- Create `backend/app/services/connectors/oauth.py`:
  - `generate_pkce_pair()`: Creates cryptographically secure `code_verifier` (43-128 chars base64url) and `code_challenge` (SHA256).
  - `generate_oauth_state(connection_id, user_id, provider)`: Produces HMAC-SHA256 signed `state` token with 10-minute expiry.
  - `verify_oauth_state(state)`: Validates signature and TTL, returning payload or raising ValueError.
  - `build_authorization_url(provider, connection_id, user_id, custom_client_id, custom_scopes)`: Builds Google / Microsoft consent URL.
  - `exchange_code_for_tokens(provider, code, code_verifier, redirect_uri, client_id, client_secret)`: Performs SSRF-safe token exchange via `egress.send_pinned_http`.
  - `fetch_user_profile(provider, access_token)`: Retrieves user email & display name from `/userinfo` or Graph `/v1.0/me`.
  - `store_tokens(db, connection_id, token_data, profile_data)`: Encrypts `access_token` and `refresh_token` via `encrypt_secret` (`enc:v1:`) and upserts `public.connector_tokens`.

### Task 2: OAuth API Router Endpoints
- In `backend/app/api/connectors.py`:
  - `GET /api/connectors/oauth/authorize`: Generates authorization URL, caches PKCE verifier, returns `{ authorization_url }`.
  - `GET /api/connectors/oauth/callback`: Validates `state`, retrieves PKCE verifier, exchanges code for tokens, saves encrypted credentials, and redirects user to `${FRONTEND_URL}/settings/connections?connected=true&id=${connection_id}`.

### Task 3: Unit Tests
- Create `backend/tests/unit/test_oauth_service.py`:
  - Test PKCE generation and SHA256 challenge verification.
  - Test state signing and tampering rejection.
  - Test mocked token exchange and `enc:v1:` encryption verification.
