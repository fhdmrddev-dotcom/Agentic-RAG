gradient-primary CSS (from index.css line 96):
```css
.gradient-primary { background: linear-gradient(135deg, hsl(239 84% 67%), hsl(258 90% 66%)); }
```
The inline style uses `backgroundImage` (not `background` shorthand) to avoid overriding the `background-color` fallback that `bg-muted` provides on the div when disabled. The `background-image` property takes precedence over `background-color` in CSS, but setting it via style only when enabled means disabled state cleanly falls back to the `bg-muted` className.
