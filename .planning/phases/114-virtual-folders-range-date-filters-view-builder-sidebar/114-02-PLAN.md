<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller (JWT) → resolve route | The caller's identity scopes both query legs; a global view must resolve over the caller's own visible set, never the view owner's |
| filter value → query builder | Filter values cross into PostgREST builder calls; must ride as bound params |
| count path → DB | A count must not reveal the existence/total of docs the caller cannot see |
