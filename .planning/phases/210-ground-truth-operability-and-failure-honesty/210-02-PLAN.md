<objective>
Implement scheduler honesty, realistic default token/duration budgets, circuit-breaker cancellation surfacing, and trigger route hardening (CONN-10, CONN-11), closing BUG-260826-06, BUG-260826-07, and BUG-260826-03.
</objective>

<threat_model>
- T-210-03 (String Scalar Definition Deserialization Trap): On 261 of 291 workflow rows in live Postgres, `definition` is stored as a jsonb string scalar. `scheduler_service.py`'s bare `WorkflowDefinition.model_validate(row["definition"])` crashes with TypeError/ValidationError and 500s. Mitigation: Add `if isinstance(raw, str): raw = json.loads(raw)` before `model_validate`, mirroring `publish_service.py`.
- T-210-04 (False CORS Errors on Unhandled 500): When a 500 is unhandled, FastAPI's CORS middleware is bypassed, producing browser CORS errors that disguise the real backend exception. Mitigation: Catch trigger exceptions and return structured `ScheduleTriggerResult(launched=False, detail=str(exc))`.
- T-210-05 (Premature Circuit Breaker Disarming): A 50k token budget was measured 3.6x too low on a single retrieval step (181k tokens). Mitigation: Raise default to 500,000 tokens / 1,800s, synchronizing backend and frontend.
</threat_model>
