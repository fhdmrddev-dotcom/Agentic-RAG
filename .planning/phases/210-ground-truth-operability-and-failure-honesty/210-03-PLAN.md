<objective>
Implement embedding and retrieval failure honesty (RAG-09), closing BUG-260815-05 so that provider outages (429 quota exhaustion, auth errors) are never reported as "nothing was retrieved (0 sources)".
</objective>

<threat_model>
- T-210-07 (Conflation of Provider Outage with Empty KB): When embedding generation fails (429 insufficient quota, connection failure), `_handle_search_documents` catches the exception. If the validator gate only checks `output.citations`, the gate reports *"nothing was retrieved (0 sources) — this step reads your documents and must show where its answer came from"*. Mitigation: `tool_dispatcher` writes `ctx.retrieval_status = "provider_error"` and `ctx.retrieval_error = str(exc)` on `ctx`; `_validate_citations_required` inspects `ctx` directly (avoiding any dependency on `phase_types.py`).
- T-210-08 (Join Seam / Parallel Wave Deadness): If tool_dispatcher and validator_kinds are tested only in isolation, key naming mismatches fail open silently. Mitigation: Provide `test_retrieval_failure_honesty.py` executing `_handle_search_documents` into `_validate_citations_required` with zero mocking between them.
</threat_model>

    2. In `backend/app/services/harness/validator_kinds.py`:
       - In `_validate_citations_required(output: dict, config: dict, ctx)`:
         - When `mode == "retrieved_and_cited"`:
           - First check if `ctx` indicates a provider failure:
             ```python
             if getattr(ctx, "retrieval_status", None) == "provider_error" or output.get("retrieval_status") == "provider_error":
                 provider_name = getattr(ctx, "embedding_provider", None) or output.get("embedding_provider") or "embedding provider"
                 err_msg = getattr(ctx, "retrieval_error", None) or output.get("retrieval_error") or "provider refused request"
                 return GateResult(
                     False,
                     f"citations_required: document search failed because the {provider_name} returned: {err_msg} — "
                     "this is a provider failure, not an empty knowledge base",
                 )
             ```
           - If not a provider error and `not (output.get("citations") or [])`:
             ```python
             return GateResult(
                 False,
                 "citations_required: nothing was retrieved (0 sources) — this step "
                 "reads your documents and must show where its answer came from",
             )
             ```
