<objective>
Wire the Plan 01 classifier into the live `execute_code` path and add the per-run
repeat-guard that structurally kills the BUG-260707-02 loop (D-03). This is the
load-bearing SC#2 mechanism: (1) post-hoc, on a classifier hit, append a
permanent-framed `runtime_gap` note to the model-facing `llm_content` AND record
the failed token in a run-scoped set; (2) pre-flight, if an incoming call
references a token already in that set, short-circuit with the honest message and
NEVER touch the sandbox. The set is threaded exactly like `new_file_hashes_in_run`
(by-reference, run-scoped, fresh for sub-agents) so it survives across agent-loop
iterations (Pitfall 1) and never bleeds across runs/sub-agents (Pitfall 6 / T-142-05).

Purpose: even a weak model that ignores the honest framing cannot burn more than
one real dead sandbox call per gap token per run.
Output: the reshape + guard in `_handle_execute_code`, the `ToolContext` field, the
agent_loop/task_service threading, and `test_142_repeat_guard.py`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sandbox stderr/exit → `_handle_execute_code` result builder | Untrusted output crosses into the reshape/guard. |
| incoming `code` arg → pre-flight guard | Model-controlled string checked for already-failed tokens. |
| run-scoped set shared across iterations / sub-agents | State-sharing boundary between parent and sub-agent contexts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-142-01 | Tampering / Repudiation | reshape appends to llm_content | mitigate | Reshape ONLY on a `_classify_runtime_gap` hit (Plan 01 allowlist); classifier miss → raw stdout/stderr pass through unchanged. Verified by an existing execute_code test staying byte-identical. |
| T-142-04 | DoS (unbounded set growth) | `ctx.dead_gap_tokens_in_run` keys | mitigate | Only KNOWN_MISSING allowlist tokens are ever `.add`-ed → the set is bounded by the allowlist size regardless of attacker input. |
| T-142-05 | Tampering (cross-run/sub-agent state bleed) | run-scoped set threading | mitigate | By-reference set init once per run; FRESH `set()` for sub-agents (Pitfall 6); `None` default = literal no-op for every unwired caller (byte-identical Deep/harness). |

No package-manager installs in this plan → no T-142-SC supply-chain checkpoint applies.
