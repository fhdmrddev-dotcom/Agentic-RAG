<objective>
Add the pure detection substrate that every later 142 plan consumes: a single
bounded classifier `_classify_runtime_gap(code, stdout, stderr, exit_code) -> GapHit | None`
plus the fixed module-level allowlists and the authored `GAP_MESSAGES` wording.
This is honesty-only (D-01/D-02) — it decides WHETHER a sandbox failure is one of
the three known runtime gaps (G-A/G-B/G-C) and, if so, WHICH permanent-framed
message to surface. It changes no runtime behavior on its own (nothing calls it
yet — Plan 02 wires it in).

Purpose: isolate the single correctness-critical piece (threat T-142-01: never
suppress a real error) into one pure, exhaustively-tested helper before any
control-flow change consumes it.
Output: the classifier + constants + `GAP_MESSAGES` in `tool_dispatcher.py`, and
`test_142_runtime_gap.py` proving both the hits AND the mandatory pass-throughs.
