<objective>
Build the read-model foundation for the skill publish gate: the append-only override-record
table (migration 084), the Pydantic contracts (`PublishGate`, `TogglePublishBody`), and the ONE
gate-compute helper `compute_publish_gate(...)` that every enforcement + UI surface reads. This
plan is the "define contracts + read model" wave — it computes gate state but does NOT yet enforce
it (Plan 02) or render it (Plan 03).

Purpose: The gate is a *read model over already-honest data* (the eval substrate shipped in
132-135). Migration 081 already writes `passed_count`/`measured_count` at run finalize using a rule
byte-identical to D-03; this plan promotes that non-authoritative default into the authoritative
publish rule (D-03) and binds it to the skill's current instructions by content-equality (D-04),
the ONLY approach correct under BOTH a manual edit AND the 135-promotion near-duplicate-version trap.

Output: migration 084 (applied live), `publish_gate_service.py`, the two models, and the test
module (scaffold + gate-compute coverage) that Plan 02 extends.
</objective>
