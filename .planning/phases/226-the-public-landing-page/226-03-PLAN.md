<threat_model>
ASVS L1 Threat Assessment:
- Threat: Denial of service via animation loop CPU/memory exhaustion on client machines.
  Mitigation: Use lightweight hardware-accelerated CSS transforms (`translate3d`, `scale`, `opacity`) and `@keyframes`. All animations respect `prefers-reduced-motion: reduce` by zeroing transition durations and setting `animation-play-state: paused`.
- Threat: Unsanitized DOM injection in scene storyboards.
  Mitigation: Components use pure React JSX elements with static SVG icons and safe text bindings. No `dangerouslySetInnerHTML`.
</threat_model>
