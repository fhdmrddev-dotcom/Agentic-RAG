| T-124-01 | Tampering / Elevation (XSS) | `WorkflowSoul.tsx` / `PhaseSpine.tsx` rendering `business_requirement`, phase names, input keys, deliverable label | mitigate | Render every authored string as a plain React text child (auto-escaped). No hidden atom, no fabricated deliverable. |
| T-124-04 | Information disclosure (new data exposure) | the whole module | accept | No new data exposure: every field read (`business_requirement`, `inputs`, `phases`) is already owner-scoped and already returned by the existing reads. This plan adds NO API, NO fetch, NO widening — pure presentation over data already in scope. |
