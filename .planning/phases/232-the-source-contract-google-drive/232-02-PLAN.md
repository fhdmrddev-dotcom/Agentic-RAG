<objective>
Implement the Google Drive Source Adapter (`SRC-02`, D-232-01, D-232-05):
1. Create `backend/app/services/sources/adapters/google_drive.py` implementing `SourceAdapter`:
   - Registered under `google` and `google_workspace`.
   - `browse`:
     - Root view: Returns virtual root nodes `"My Drive"` (id: `root`) and `"Shared Drives"` (id: `shared_drives`).
     - `"shared_drives"` view: Calls `GET https://www.googleapis.com/drive/v3/drives` returning accessible shared drives as folders with `drive_id`.
     - Specific folder view: Queries folders within `folder_id`, with `supportsAllDrives=true` and `includeItemsFromAllDrives=true`.
   - `list_files`:
     - Lists non-folder files in `folder_id` with `supportsAllDrives=true` and `includeItemsFromAllDrives=true`.
   - `read_file`:
     - Fetches metadata, exports native Docs/Sheets to PDF, downloads binary files with 25MB ceiling.
     - Preserves `_google_error_reason` safe enum extraction (`error.status`, `error.errors[].reason`, `error.details[].reason`).
   - `check`:
     - Probes token and Drive accessibility, returning `SourceHealth`.
2. Add Google Drive adapter to the conformance suite in `test_source_adapter_conformance.py`.
3. Author dedicated unit tests in `test_google_drive_adapter.py` asserting shared drives discovery, pagination, and error handling.
</objective>

<action>
Author `google_drive.py`:
- Import `SourceAdapter`, `SourceNode`, `SourceFile`, `BrowsePage`, `FilePage`, `SourceHealth`, and `SourceRegistry`.
- Register under `"google"` and `"google_workspace"`.
- Implement `_google_error_reason` extracted and preserved from `cloud_storage.py`.
- Implement `browse`:
  - If `folder_id is None` or `folder_id == "virtual_root"`: Return `BrowsePage(items=[SourceNode(id="root", name="My Drive", kind="folder"), SourceNode(id="shared_drives", name="Shared Drives", kind="folder")])`.
  - If `folder_id == "shared_drives"`: Call `GET /drives?pageSize=100` via `send_pinned_http("drive_read", ...)`, returning each drive as `SourceNode(id=drive['id'], name=drive['name'], kind='drive', drive_id=drive['id'])`.
  - If `folder_id`: Query `/files` with `q="'{folder_id}' in parents and mimeType = 'application/vnd.google-apps.folder' and trashed = false"`, `supportsAllDrives=True`, `includeItemsFromAllDrives=True`, `corpora='allDrives'`.
- Implement `list_files`:
  - Query `/files` with `q="'{folder_id}' in parents and mimeType != 'application/vnd.google-apps.folder' and trashed = false"`, `supportsAllDrives=True`, `includeItemsFromAllDrives=True`.
- Implement `read_file`:
  - Metadata lookup, export for `application/vnd.google-apps.document` and `spreadsheet`, binary download for other types through `send_pinned_http("drive_read", ...)` capped at 25MB.
- Implement `check`:
  - Calls `GET /about?fields=user` to verify token validity.
</action>
