<task_id>232-01-01</task_id>
<description>Create base contract models, SourceAdapter protocol, and SourceRegistry in backend/app/services/sources/base.py</description>
<action>
Create package `backend/app/services/sources/` and author `base.py`:
- Pydantic models / Dataclasses:
  - `SourceNode`: `id: str`, `name: str`, `kind: str` ('folder' | 'drive'), `drive_id: str | None = None`, `has_children: bool = True`, `parent_id: str | None = None`.
  - `SourceFile`: `id: str`, `name: str`, `mime_type: str`, `size: int | None = None`, `modified_at: str | None = None`, `drive_id: str | None = None`.
  - `BrowsePage`: `items: list[SourceNode]`, `next_page_token: str | None = None`.
  - `FilePage`: `files: list[SourceFile]`, `next_page_token: str | None = None`.
  - `SourceHealth`: `ok: bool`, `error: str | None = None`, `details: dict[str, Any] = field(default_factory=dict)`.
- Abstract class `SourceAdapter(ABC)`:
  - `@abstractmethod async def browse(self, connection: Any, folder_id: str | None = None, page_token: str | None = None) -> BrowsePage`
  - `@abstractmethod async def list_files(self, connection: Any, folder_id: str | None = None, recursive: bool = False, page_token: str | None = None) -> FilePage`
  - `@abstractmethod async def read_file(self, connection: Any, file_id: str) -> tuple[str, bytes, str]`
  - `@abstractmethod async def check(self, connection: Any) -> SourceHealth`
- `SourceRegistry`:
  - Register mapping `_adapters: dict[str, type[SourceAdapter]] = {}`.
  - Class methods: `register(service_id: str)`, `get_adapter(connection_or_service_id: Any) -> SourceAdapter | None`, `is_source_supported(service_id: str) -> bool`, `list_supported_services() -> list[str]`.
</action>
<verify>

</verify>
</task>
