<objective>
Close three backend HONESTY defects from the 123.1 live-UAT audit (backlog §2): the tuner's scoreboard and its persisted attribution can fabricate measurements that did not happen.

- **TT-05** (vacuous 1.0): an empty `should_fire` set makes `_score_axis([], True)` return 1.0 — a fabricated perfect recall. `_score_axis` returns 1.0 for an empty axis (so a vacuous axis "does not drag the score down"), but for the TOP-LEVEL fires/no_false axes that 1.0 is read as a real measurement. Render an empty axis honestly (a sentinel the frontend shows as "n/a"), never a fabricated 1.00.
- **TT-12** (all-error column counted as measured): when EVERY held-out classify call for a provider raised (all-400 from a bad provider, all-timeout), the cell still scored 0.0/0.0 and `target_count=len(targets)` counted it as a real "measured" model. Track the error count per cell, mark a cell "unmeasured" when ALL classify calls raised, and EXCLUDE unmeasured cells from `target_count` / the "measured on N models" attribution.
- **TT-15** (drift risk): `cell_score` recomputes `(fires+no_false)/2` that `build_cell` already stored in `cell["score"]` — two sources of truth. Make `cell_score` return `cell.get("score", recompute)` so it is the single stored value.

This is BACKEND-ONLY (service + route + tests). The frontend "unmeasured" RENDER and the `_emit_tuner` cell payload consumption are handled by the run-UX plans (123.1-07/08) that follow on the same files.

Purpose: The scoreboard never reports a score that wasn't measured; the attribution count never over-counts.
Output: An honest empty-axis sentinel, per-cell error accounting, an unmeasured-aware `target_count`, a single-source `cell_score`, and non-vacuous tests.
</objective>
