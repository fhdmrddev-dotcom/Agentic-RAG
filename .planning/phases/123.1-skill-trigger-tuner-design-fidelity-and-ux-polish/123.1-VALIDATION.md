## Sampling Rate

- **After every task commit:** Run the relevant quick command (`pytest ...test_skill_tuner_routes.py -x` for backend; `npm test -- <Component>` for frontend).
- **After every plan wave:** Run the full suite (backend integration+unit + frontend `npm test`).
- **Before `/gsd:verify-work`:** Full suite must be green, PLUS the SC#10 regression check (single live cross-provider tuner run + chat-path smoke).
- **Max feedback latency:** ~120 seconds.
