<objective>
Close four run-resilience / honesty defects from the 123.1 live-UAT audit (backlog §2) so the run surface never lies or flashes:

- **TT-09** (swallowed getSeededCases error / "0 cases"): a `getSeededCases` failure silently sets `cases=[]`, so the editor shows "0 cases", the cost-preview reads "0 cases × N models", and the POST sends `cases=[]` (the backend then auto-seeds server-side and scores generic off-topic). The "live docx 0 cases" symptom. Fix: on fetch failure, surface a non-fatal inline note, log the swallowed error, and make the empty state HONEST ("couldn't load seeded cases" — not a silent zero). (The `total` field + the cap are already delivered by 123.1-05; this is the swallowed-error half only.)
- **TT-12 render half**: 123.1-06 marks an all-error provider cell `measured: false` / `score: null`. The scoreboard must render that honestly ("could not measure" / n/a), never a fabricated 0.00 or a 1.00 axis.
- **TT-14** (flash on done): `setScoreboard(null)` at startRun + LiveRunCard unmounting on 'done' before `getTunerResults` resolves shows a brief empty pane; replay from '0' can regress lanes. Fix: keep LiveRunCard mounted through a 'reconciling' sub-state; don't null the scoreboard if a durable latestRun is shown.
- **TT-16** (scary red on a succeeding run): reconcile depends on `getTunerResults`, which 404s until the whole job finishes; ~10s × MAX_RECONNECTS=20 can exhaust during a stall, flipping `runPhase='error'` though the job persists 201. Fix: poll durable `getTunerLatest` too; while the run is verifiably active don't count toward the cap; on exhaustion keep `runPhase='running'` + an honest "still running, reopen to load" (never a hard red error for a run that persists).

Purpose: The live-run surface stays honest under failure, completion, and reconnect stalls — no fabricated zeros, no empty flash, no false-red for a run that succeeds.
Output: An honest seeded-fetch note, an unmeasured-cell render, a reconciling sub-state (no flash), and a durable-poll reconnect path that never falsely fails a persisting run.
</objective>
