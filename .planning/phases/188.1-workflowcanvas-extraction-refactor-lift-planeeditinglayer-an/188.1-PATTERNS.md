## 1. Sibling-module convention in `frontend/src/components/workflows/`

**Measured naming rule (10 non-component `.ts` modules, zero exceptions):** non-component modules are
**camelCase** `.ts` (`canvasModel.ts`, `canvasNudge.ts`, `definitionOps.ts`, `deriveTier.ts`,
`nodePresentation.ts`, `phaseVocabulary.ts`, `runVocabulary.ts`, `soulData.ts`, `verdictModel.ts`,
`builderStore.ts`). Components are **PascalCase** `.tsx`. There is **no** kebab-case and **no**
`lib/` subdirectory in this tree. → `editAffordance.ts` is exactly on-convention.

**Export style:** always **named exports**, `export const` / `export function` / `export interface`
declared inline. No default export in any non-component module. No `const X = {...}` +
`export { X }` at the foot.

**Constant-table style — two shipped forms, pick by whether a key-union exists:**

- Plain `Record<string, T>` when keys are open (`nodePresentation.ts:71`, `soulData.ts:43`).
- `as const satisfies Record<Union, Shape>` when a key union exists (`nodePresentation.ts:190`).
- Bare `as const` for a fixed anonymous shape — which is what `EDIT_AFFORDANCE` already is
  (`WorkflowCanvas.tsx:378`) and what `DETOUR` uses (`FlowEdge.tsx:135`). **Move it verbatim; no
  `satisfies` upgrade.**

## 3. Docblock conventions

**The house format, invariant across all 9 files read this session:**

1. Line 1-3: `Phase <NNN>-<PP> Task <N> (<decision ids> · <req/sketch ids>) — <ModuleName>.`
2. Blank comment line, then a **SHOUTED one-sentence thesis** (`THE CANVAS NODE PRESENTATION
   TABLES, in one copy.` / `THE `＋` MENU.` / `THE ONE HOME FOR THE COSMETIC VERTICAL NUDGE`).
3. Sectioned prose under `── Section name ──` rules or ALL-CAPS lead-ins
   (`STATE OF THE EXTRACTION`, `EXTENSIBILITY SEAM #1`, `⚠ TWO CORRECTIONS`).
4. Explicit **contract paragraphs** — purity, totality, module-scope, colour budget — each stating
   *which shipped test keeps the claim honest*.
5. `⚠` marks a correction to a previously-false claim, kept in place rather than deleted.

`PhaseNodeCard.tsx:1-16` (the 185-08 docblock pass) is the canonical example:

```typescript
/**
 * Phase 184-03 Task 2 (D-184-06, Wave-0 G-5 extraction, sketch 137-B/137-D) —
 * PhaseNodeCard.
 *
 * THE PHASE CARD, PURELY PRESENTATIONAL. Every value it paints arrives as a prop;
 * it reads no context, fetches nothing, owns no state, and — the whole point of
 * D-184-06 — **imports NOTHING from the canvas graph library**. It therefore renders
 * under a plain `render()` with no provider (proved in `PhaseNodeCard.test.tsx`), and
 * Phase 188 can reuse the same card outside a `ReactFlowProvider`.
 *
 * The graph-library boundary lives one file away, in `PhaseNode.tsx`: ...
 * This file's zero-graph-library property is machine checked by a `?raw` source guard
 * (the `canvasModel.purity.test.ts:14-17` house idiom) carrying a positive control, so
 * the guard is falsifiable rather than vacuous.
 */
```

`FlowEdge.tsx:97-105` is the tree's own statement of the *exact* constraint SC#3 names. The new
modules' docblocks should state it in this register (it explains the mechanism and the failure

```typescript

 * `WorkflowCanvas`'s own `EDIT_AFFORDANCE` derives them from — rather than importing
```

## 5. `Object.hasOwn` / own-guard precedent

**Measured: `Object.hasOwn` occurs ZERO times in `frontend/src`.** The tree has **two** shipped
guards, both spelled `Object.prototype.hasOwnProperty.call(...)`. Using `Object.hasOwn` would be a
*new* spelling — allowed by `tsconfig.app.json` (ES2023) but with no in-tree precedent. **Report
this to the planner as a fork, not a settled matter.**

**Form A — the guard clause** (`frontend/src/lib/phaseState.ts:76-79`). Preferred when the whole
function is the lookup:

```typescript
export function phaseStatusFromDb(raw: string): Phase["status"] {
  if (!Object.prototype.hasOwnProperty.call(DB_PHASE_STATUS, raw)) return "unknown"
  return DB_PHASE_STATUS[raw]
}
```

**Form B — the `own()` helper + `??` fallback** (`frontend/src/components/workflows/runVocabulary.ts:84-88`),
with its docblock at `:72-83`. Confirms research's landmine: **module-private (`function own`, no
`export`) and typed to `CanvasReading`**, so it is not a drop-in for `phaseType: string` or
`verdict`:

```typescript
function own<T>(table: Record<string, T>, reading: CanvasReading): T | undefined {
  return Object.prototype.hasOwnProperty.call(table, reading)
    ? (table as Record<string, T>)[reading]
    : undefined
}
```

Its call form (`:95`): `return own(RUN_READING_WORD, reading) ?? RUN_READING_WORD.unknown`

**The shared docblock rationale both guards carry** — reuse this wording, it is the house argument:

```typescript
 * ⚠ THE OWN-PROPERTY GUARD IS NOT CEREMONY, and it was measured RED before it was
 * written. `DB_PHASE_STATUS` is a plain object literal, so it INHERITS `constructor`,
 * `toString`, `__proto__` and friends. A bare index-and-coalesce therefore returns a
 * FUNCTION (or `Object.prototype`) for those keys — never nullish, so the coalesce
 * never fires ... totality is a property of the function, not of its current callers.
```

### The `PhaseNodeCard.test.tsx:373` constraint, verified at both ends

Site 1 today (`PhaseNode.tsx:149`): `const tint = ICON_TINT[data.phaseType] ?? DEFAULT_TINT`

The control block (`PhaseNodeCard.test.tsx:368-374`) requires **three** literal forms to survive in
`PhaseNode.tsx`, not one:

```typescript

    expect(phaseNodeSource).toMatch(
      /import[^;]*\b(ICON_TINT|DEFAULT_TINT)\b[^;]*from\s+["'][^"']*nodePresentation["']/,

    expect(phaseNodeSource).toMatch(/ICON_TINT\[/)
    expect(phaseNodeSource).toMatch(/DEFAULT_TINT\s*[,)\]]/)
```

**Measured, so the planner does not have to guess:** `DEFAULT_TINT` appears at `PhaseNode.tsx:83`
(inside the import list, followed by a comma) and `:149`. The third control is therefore satisfied

```typescript

  ? ICON_TINT[data.phaseType]
  : DEFAULT_TINT
```

**Sites 2-5 have no such control** and are free to use either form; Form A (guard clause) fits
`PhaseCard.tsx:53` / `:257` if the lookup is wrapped, Form B fits `PhaseNodeCard.tsx:396` / `:689`
where a `?? fallback` already reads naturally. Research logged sites 2-5 as un-audited (A7, MEDIUM
