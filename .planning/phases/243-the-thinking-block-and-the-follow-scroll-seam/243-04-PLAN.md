<objective>
Make the thinking block look like the operator-approved mockup: the model's own prose, in the body
font, as real paragraphs, with no nested scrollbar inside a scrolling conversation — and a label
that says how long it thought only when that is honestly known.

Purpose: criterion 1's acceptance bar is `.planning/sketches/234-the-thinking-block/index.html`,
**the file, not a description of it**. Sketch-to-build drift is the named failure mode, and this is
the plan where it would happen. V1's whole diff is four classes, one size step, real paragraphs, a
clamp, and one label — and `243-CONTEXT.md` reproduces that diff table verbatim precisely so a plan
cannot wander from it.

⚠ **And this plan carries the phase's one genuine design gap.** The sketch computes its label from
the character count (`index.html:338`, `Math.round(chars / 180)`). **That is a demo affordance so
the mockup has a plausible number at every Scale setting — porting it ships a duration derived from
string length**, which is the same sin as the `count` the fold control already forbids, one unit
over. There is no persisted source to swap in: `messages.reasoning_content` is the only reasoning
column and `RunCard`'s elapsed machinery measures the WHOLE run including every tool call. So the
span is measured live, and when it is not known the surface **deliberately differs from the bar** —
a historical message reads `Thinking` where the mockup reads `Thought for 6 seconds`.
**An undeclared difference from the bar is drift; a declared one with a reason is a decision.**

Output: V1's surface, a clamp that self-removes, an honest label, and a stated difference from the
mockup.
</objective>
