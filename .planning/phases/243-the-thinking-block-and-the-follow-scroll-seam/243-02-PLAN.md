<objective>
Take the reasoning fold out of `RunCard` and mount it from `MessageItem` for both message shapes,
so that the 31% of reasoning that has never been drawn is drawn — and so that there is one renderer
of it rather than two.

it does not: `RunCard.tsx:478-502` is the ONLY renderer of `reasoningContent` in the codebase, and
`MessageItem.tsx:359-361` mounts `RunCard` only on a tool-bearing turn. **Removing a gate reveals
nothing, because the component that would do the revealing is never mounted.** The fix is a
component boundary, and it is simultaneously `RunCard.tsx`'s G-5 discharge — a fourth concern
leaving a file whose ledger section already names three.

Output: `ThinkingBlock.tsx`, mounted unconditionally, with 243-01's net passing across the move and
the one declared-defect case inverted.

clamp, `"Thought for N seconds"` — is **243-04**, deliberately, so that this move can be proven
byte-neutral before anything about it changes.
