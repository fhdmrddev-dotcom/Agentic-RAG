Create `frontend/src/lib/activeViewReachability.ts` exporting an interface `ReachabilityReport`
(fields: `members: string[]`, `branched: string[]`, `unbranched: string[]`, `fallbackIsLast:
boolean`) and a function `activeViewReachability(appSource: string, layoutSource: string):
ReachabilityReport`.

Parse both inputs with `ts.createSourceFile` from the `typescript` package (already a
devDependency), `ScriptTarget.Latest`, `setParentNodes` false, `ScriptKind.TSX`. ⛔ Do NOT use a
regular expression over the source text as the primary mechanism — D-262-04 and research P-2 record
that a code measurement must not be satisfiable by a comment, and a `grep`-shaped check over
`App.tsx` counts the member name wherever prose repeats it. The AST sees declarations only.

For members: walk for a `TypeAliasDeclaration` named `ActiveView`, require its type to be a
`UnionTypeNode`, and collect each `LiteralTypeNode` whose literal is a `StringLiteral`. Throw a
named error if the alias is absent or the collected list is empty.

For branches: walk every `BinaryExpression` whose operator is `EqualsEqualsEqualsToken`, whose left
side is an `Identifier` named `activeView`, and whose right side is a `StringLiteral`; collect the
literal text. This catches `activeView === "workflow-run" && canvasEnabled` because the comparison
is a sub-expression. Throw if the collected list is empty.

`unbranched` is the members not present in `branched`, order preserved.

For `fallbackIsLast`: record the maximum `node.getStart`-equivalent position (use `node.pos`
consistently for both) of the collected `activeView === "…"` comparisons, and the position of the
`JsxSelfClosingElement`/`JsxOpeningElement` whose tag name is `UnknownViewFallback`. `fallbackIsLast`
is true when the fallback element is present AND its position is greater than that maximum. If no
`UnknownViewFallback` element is found, `fallbackIsLast` is false (never true-by-absence).

Create `frontend/src/lib/__tests__/activeViewReachability.test.ts` importing `App.tsx?raw` and
`ChatLayout.tsx?raw` (the `?raw` import precedent is `renameFence.test.ts`). Cases, in this order:

`export function ChatLayout` respectively, so a sweep of the wrong file cannot read as a pass;

union string, checked against the shipped layout, yields `unbranched` equal to that one member;
(3) the shipped pair yields an empty `unbranched` and `members.length >= 12`;
(4) the shipped pair yields `fallbackIsLast === true`;
(5) a synthetic layout with the fallback element moved above the last comparison yields
`fallbackIsLast === false`;
(6) the vacuity refusals — an app source with no `ActiveView` alias throws, and a layout source with
no `activeView === ` comparison throws.

Run case (2) FIRST and capture its failing output against a checker stub that returns an empty
