## Scope (must-have)

### S1 — Diagnose `ERR_INCOMPLETE_CHUNKED_ENCODING` consumer drop

**Symptom:** During Phase 061 UAT (Chrome MCP session 2026-05-03, run `f4b2b8cc-c643-4107-9f4a-70e715641b63`), the SSE stream from `POST /threads/{id}/messages` errored at the consumer side ~11s into a 60s run with `ERR_INCOMPLETE_CHUNKED_ENCODING` and `TypeError: network error`. The producer completed cleanly (4 tools, runs row marked `completed`, terminal sentinel landed in stream, 1393 events buffered, TTL=600 applied), and the persisted assistant message was correct (1114 chars of clean answer text).

**What to investigate:**
- Is the consumer's `event_consumer()` generator at `backend/app/api/threads.py:2065` raising mid-yield?
- Is `sse_starlette.EventSourceResponse(ping=15)` keep-alive firing during long inter-event gaps?
- Is something in the high-volume `sub_agent_delta` flow (981 events in this run) saturating a buffer between `redis.xread` and the SSE writer?
- Is the Vite dev proxy interfering?
- Reproduction script: navigate to a thread with the dev PDF library, ask any RAG question that triggers a sub-agent (`*Fahed*` topics work), watch DevTools network tab.

**Pass criteria:** root cause documented in `061.1-DIAGNOSIS.md`; either fixed in place OR formally deferred with reasoning to Phase 063 (frontend reattach masks it anyway).

### S2 — Fix the 5 integration test-pattern races

**Symptom:** In `backend/tests/integration/`:
- `test_061_runs_table.py::test_runs_lifecycle_row` — UPDATE call_args_list empty
- `test_061_ttl.py::test_failed_run_expires_60s` — same race on EXPIRE
- `test_061_hard_timeout.py::test_120s_timeout_fires_full_finally` — race on finalizer
- `test_061_producer_survives_disconnect.py::test_producer_continues_after_consumer_disconnect` — race
- `test_059_disconnect.py::test_normal_stream_unchanged` — race on producer completion

The producer's `_shielded_finalize` (steps 3 UPDATE → 4 EXPIRE → 5 ZREM) continues running on a detached task after the test's `aiter_lines()` exhausts. Tests inspect mocks immediately after the loop, before `_shielded_finalize` finishes.

**Reference fix pattern:** `test_059_disconnect.py::test_agent_task_SURVIVES_on_disconnect` PASSES because it explicitly `await asyncio.sleep(5)` after disconnect. Use the same pattern (or look up the producer task in `RUN_TASKS` and await it) in the failing tests.

**Pass criteria:** all 5 tests pass deterministically (no `pytest --count=10` flakes).

### S3 — Code-review deferred items

**WR-01** (consumer cursor `$` race) — `backend/app/api/threads.py:2104`. Consumer transitions from replay-cursor (last_id=actual_entry_id) to tail-cursor (`"$"`) after replay drains. Race window: events produced between the empty xread and the tail subscribe are silently missed. Fix: keep the last-seen entry id and use it as the tail-phase cursor instead of `"$"`.

**WR-04** (test sleep race in `_drive_sse_until_disconnect`) — replace fixed sleeps with deterministic await on the producer task.

**WR-06** (conftest mock missing `upsert` chaining) — add `b.upsert.return_value = b` in `_make_table_builder`.

**WR-07** (redis-py upper bound `<8` too broad) — change `requirements.txt` pin to `redis>=5.2,<6` (next major bump should be intentional).

**IN-01..04** — coupling/maintainability nits. Address opportunistically in the same PR if cheap; defer otherwise.

**Pass criteria:** each item either fixed (with test where applicable) or formally deferred in `061.1-SUMMARY.md` with reasoning.
