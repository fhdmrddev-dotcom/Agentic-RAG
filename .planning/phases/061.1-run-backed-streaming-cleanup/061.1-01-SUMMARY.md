## Decisions Made

See `key-decisions` in frontmatter. Highlights:

- **WR-01 fix shape:** drop the `last_id = "$"` reset entirely. last_id carries forward from replay (last yielded entry id, or `'0'` if replay drained empty). XREAD with a past id + BLOCK semantically matches `$` for keep-alive purposes without the race window.
- **IN-03 cache pattern:** function attribute (`_persist_assistant_message._cached_id`) — cleaner than a closure-captured mutable container (`list`/`dict`) and avoids reaching outer scope. The `nonlocal _message_persisted` boolean guard remains; the plan's M6 acceptance only forbids `nonlocal _persisted_msg_id`.
- **IN-04 layout:** keep `event_consumer` in `threads.py` at module level. File is ~2200 lines post-extraction, well under the 2500-line threshold from CONTEXT D-061.1-10. No sibling `_event_consumer.py` needed; sibling-file extraction is reversible if Phase 062 (Replay & Tail API) wants to share the consumer with new endpoints.
- **Test signature:** `event_consumer(redis, run_id, settings)` — drop the `deadline_seconds` kwarg from the plan's pseudocode. Compute deadline inside the function so D-061-12 deadline arithmetic is locally readable. The plan recommended this signature explicitly; the cursor-race test invocations were written to match.
