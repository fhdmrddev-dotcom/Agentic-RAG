<objective>
Build a first-class email ingestion pipeline for Outlook (.msg) and internet email (.eml) files, extracting headers into structured metadata (EML-01), stripping quoted replies for clean retrieval chunks, and extracting attachments with document relationships (EML-02).
</objective>

<threat_model>
- Malformed / Obfuscated Email Bodies: HTML payloads with unclosed tags or malicious script tags must be safely converted to plaintext.
- Attachment Bomb / Infinite Recursion: Only extract direct attachments, sanitize attachment filenames, and enforce max size constraints.
- Header Injection / Encodings: Headers with RFC 2047 encoded words (=?UTF-8?B?...?=) must be decoded safely without crashing on invalid charsets.
- Retrieval Poisoning: Trailing forwarded/replied threads must be stripped so repeated quotes do not inflate search ranking.
</threat_model>

<tasks>
1. **Task 1 (Email Extraction Service & Parsers)**:
   Create `backend/app/services/email_extraction_service.py`:
   - `ParsedEmail` dataclass with `headers`, `subject`, `sender`, `to`, `cc`, `date`, `body`, `clean_body`, `attachments` (list of `(filename, mime_type, bytes)`).
   - `strip_quoted_replies(body: str) -> str`: regex/heuristic cleaner for Outlook/Gmail/Apple Mail quote headers and leading `>` quote blocks.
   - `parse_eml_bytes(raw: bytes) -> ParsedEmail`: using standard library `email` package with RFC 2047 decoding and HTML fallback.
   - `parse_msg_bytes(raw: bytes) -> ParsedEmail`: using `extract-msg` with RTF/HTML/plain body extraction and attachment extraction.

2. **Task 2 (Wire into Ingestion Pipeline & Allowed MIME Types)**:
   Update `backend/app/api/documents.py`:
   - Add `message/rfc822`, `application/vnd.ms-outlook`, `application/x-msg` to `ALLOWED_MIME_TYPES`.
   - Add `.msg` and `.eml` to `_EXT_MIME_OVERRIDES`.
   - Route email MIME types in `extract_text` and `_upload_pipeline` to use `email_extraction_service`.
   - Populate email metadata (`DocumentMetadata`) and ingest any extracted attachments into `documents` / `document_relationships`.

3. **Task 3 (Comprehensive Unit Tests)**:
   Create `backend/tests/unit/test_email_ingestion.py`:
   - Test RFC-822 `.eml` with headers, utf-8 subject, and plain text.
   - Test `.eml` multipart with HTML body and attachment.
   - Test `.msg` parsing via mock or synthesized msg bytes.
   - Test `strip_quoted_replies` on Outlook ("From: ... Sent: ...") and standard ("On ... wrote:") formats.
   - Test attachment extraction and relationship creation.
</tasks>
