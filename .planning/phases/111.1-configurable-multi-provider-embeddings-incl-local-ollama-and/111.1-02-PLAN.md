<objective>
Close BUG-260616-01 (the local-model data-egress trap) with the three D-09 backend routing fixes.
Today a slashed local id (`google/gemma-3-4b`) is name-inferred to `openrouter` and document text
ships to the cloud with a green result; even when the provider is forced to a local one, the
OpenRouter quality-mangling 500s the local server.

Purpose: This is the security headline of the phase (V9/V10 data egress). The fix is structural —
route by an explicit `(provider, model)` pair, make `forced_emit` local-aware, and gate the
OpenRouter mangling on the resolved provider. Live-proven 2026-06-16: once bypassed, a 12B local
model (`gemma-4-12b-qat`) extracts correctly through the real engine.
Output: edits to `documents.py` (extraction routing), `forced_emit.py`, `openai_service.py`, and
a guard in `config.py`.
</objective>
