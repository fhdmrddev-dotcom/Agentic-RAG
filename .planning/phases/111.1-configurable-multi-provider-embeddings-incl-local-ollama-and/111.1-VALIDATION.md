## Cross-Provider / Local UAT Matrix (project UAT scoreboard recipe)

> This phase touches retrieval + provider routing, so the 4-axis bandwidth applies, adapted to embedders. Authored here in VALIDATION.md, NOT in PLAN.md tasks.

| Axis | Required coverage for 111.1 |
|------|------------------------------|
| Cross-embedder (cloud) | OpenAI (default) **+** one non-OpenAI cloud embedder (e.g. Google `gemini-embedding-001`) embed + serve search with relevant cited results |
| Local-embedder | At least one of Ollama `:11434` / LM Studio `:1234` embeds chunks + queries + serves search (privacy axis; closes the SEED-048 SPOF live) |
| Switch + re-embed | OpenAI → local switch fires D-03 confirm → background re-embed → search recovers (graceful-dip honesty visible per sketch 026) |
| Local extraction routing (BUG-260616-01) | A local model selected for extraction stays local (NOT shipped to OpenRouter) — **verified by endpoint, not just a green result** (data-egress regression guard) |
| Long-doc / many-chunk | A ≥ 50-chunk document fully re-embeds via the batched job; search returns correct cited results after completion |
