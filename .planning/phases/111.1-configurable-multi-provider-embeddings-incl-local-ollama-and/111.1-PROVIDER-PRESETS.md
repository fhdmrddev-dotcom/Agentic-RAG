A model ID is marked **`[LIVE-VALIDATED YYYY-MM-DD]`** ONLY if it was confirmed served on
that provider's live `/models` (or a running local server) during this curation. Otherwise
it is **`[UNVERIFIED — pin shape, curate at availability]`** — the picker SHAPE ships regardless
(D-07), but the exact ID is NOT blind-pinned as "confirmed".

## Cross-cutting facts (load-bearing)

- pgvector fixes the `document_chunks.embedding` column dimension at table-create. **A model change
  with different dims is a RE-EMBED (Plan 05 + `resize_embedding_column`), NOT a hot-swap.** The
  picker surfaces each preset's dims so the operator sees the re-embed cost before committing (EMBED-06 / D-03).
- The shipped zero-config default STAYS `text-embedding-3-small` / 1536 (**D-08** — no surprise re-embed on upgrade).
- Every cloud target below is reached through ONE client: `get_embedding_client` (OpenAI Python SDK, swap `base_url`).
  Local providers relax the API key to a dummy (`ollama` / `lm-studio`); the LM Studio `base_url` is
  **NOT double-appended** (it already ends in `/v1`).
- **Never** pass `dimensions=` as a forced global cap (D-01) — it truncates strong models and throws away accuracy.
- Default `retrieval_match_threshold = 0.3` and confidence buckets `0.54 / 0.38` were calibrated for
  `text-embedding-3-small` (Phase 076, N=121). They are **NOT portable** (Pitfall 4 / D-11/D-12) — each preset
  carries its own recommended defaults; for UNVERIFIED embedders the OpenAI defaults are a *starting point only*,
  to be tuned per embedder (auto-calibration is deferred — RESEARCH).

## Picker shape contract (Plan 06)

- The picker is the rerank-provider `<select>` pattern generalized (`SettingsPage.tsx:959-967`).
- Selecting a preset auto-fills `embedding_base_url` + `embedding_model` + `embedding_dimensions` +
  the recommended `retrieval_match_threshold` + `confidence_bucket_high/medium`; all stay editable
  (advanced overrides — EMBED-03).
- Local presets relax the key to the dummy (`ollama` / `lm-studio`); the LM Studio base_url is used AS-IS.
- A model/dims change fires the **destructive re-embed confirmation** (EMBED-06 / D-03, sketch 025) BEFORE commit.
- UNVERIFIED IDs ship as editable defaults the operator confirms/corrects at first use — never silently authoritative.
