### `match_document_chunks` (MODIFY via 073, D-10)

**Analog:** self, `supabase/full-schema.sql:120-137`.

**Current function (verified):**
```sql
CREATE FUNCTION public.match_document_chunks(query_embedding public.vector, match_user_id uuid, match_count integer DEFAULT 5, match_threshold double precision DEFAULT 0.3, metadata_filter jsonb DEFAULT NULL::jsonb, p_folder_ids uuid[] DEFAULT NULL::uuid[]) RETURNS TABLE(...)
    LANGUAGE plpgsql SECURITY DEFINER
    AS $$
BEGIN
  RETURN QUERY
  SELECT dc.id, dc.document_id, dc.content, dc.chunk_index,
         1 - (dc.embedding <=> query_embedding) AS similarity
  FROM public.document_chunks dc
  JOIN public.documents d ON d.id = dc.document_id
  WHERE dc.user_id = match_user_id          -- RLS scope (V4 - keep)
    AND 1 - (dc.embedding <=> query_embedding) > match_threshold
    AND d.is_latest = true
    AND (metadata_filter IS NULL OR d.metadata @> metadata_filter)
    AND (p_folder_ids IS NULL OR d.folder_id = ANY(p_folder_ids))
  ORDER BY dc.embedding <=> query_embedding
  LIMIT match_count;
END;
$$;
```

**D-10 change:** add a `p_embedding_model text DEFAULT NULL` parameter and a filter `AND (p_embedding_model IS NULL OR dc.embedding_model = p_embedding_model)`. The caller (`retrieval_service._vector_search`, `:45-56`) passes the currently-configured model. Half-re-embedded (stale-model) chunks are filtered out = the graceful-dip recall reduction (D-04). NEVER compares across vector spaces (Pitfall 2). Keep `dc.user_id = match_user_id` (RLS, V4).

CREATE FUNCTION public.resize_embedding_column(new_dim integer) RETURNS void
    LANGUAGE plpgsql SECURITY DEFINER

  EXECUTE format('ALTER TABLE public.document_chunks ALTER COLUMN embedding TYPE vector(%s) USING NULL', new_dim);

**Analog (threadpool rule):** `retrieval_service.py:35-44` - `embed_texts` is a SYNC HTTP call; MUST go through `run_in_threadpool` (SEED-065 / D-v2.5-01), and likewise every supabase-py call inside the job.

**Job shape (D-04/D-05, from RESEARCH skeleton - all seams verified):**
```python
async def reembed_job(supabase, user_id, app_settings):
    current = app_settings.embedding_model
    if dims_changed:  # only on a true dims change
        await run_in_threadpool(lambda: supabase.rpc(
            "resize_embedding_column", {"new_dim": app_settings.embedding_dimensions}).execute())
    while True:  # resumable: same stale predicate each pass
        batch = await run_in_threadpool(lambda: supabase.table("document_chunks")
            .select("id, content").eq("user_id", user_id)          # RLS scope (V4)
            .neq("embedding_model", current).limit(BATCH).execute())  # IS DISTINCT FROM <current>
        if not batch.data:
            break
        vectors = await run_in_threadpool(embed_texts,
            [r["content"] for r in batch.data], user_settings=app_settings)
        for row, vec in zip(batch.data, vectors):  # write replacement THEN tag (D-05 non-destructive)
            await run_in_threadpool(lambda: supabase.table("document_chunks")
                .update({"embedding": vec, "embedding_model": current,
                         "embedding_dimensions": app_settings.embedding_dimensions})
                .eq("id", row["id"]).execute())
```

## Shared Patterns

### env_attr=None app_settings field (applies to: user_settings.py, settings.py, migration 073)
**Source:** `backend/app/models/user_settings.py:485-509`
App-config settings (provider, thresholds) get `_val(row, "<col>", None, <default>)` - the `None` 2nd arg means NO env fallback (CLAUDE.md: env vars are secrets/infra only). True secrets with an env fallback pass the column name as the 2nd arg instead (see `:460-463`). All four new 111.1 settings use the `None` form.

### save_app_settings (applies to: all settings writes)
**Source:** `backend/app/models/user_settings.py:223-267`
Established asyncpg `UPDATE app_settings ... WHERE id='global'` path with `_is_valid_api_key` sentinel guard (`:234`) and `KEY_PLACEHOLDER` skip (`:232`) - never echoes keys, never writes NULLs. New columns flow through automatically (SET clause built from `updates` dict keys). Reuse as-is; do NOT hand-roll raw SQL.

### Local-provider routing (applies to: config.py, forced_emit.py, embedding client)
**Source:** `backend/app/config.py:743-759` (`resolve_llm_provider`)
`(provider) -> base_url + dummy key` already solved for LLMs. Ollama appends `/v1`; LM Studio does NOT (its URL already ends `/v1`). Dummy keys: `"ollama"` / `"lm-studio"`. Mirror this everywhere embedding/extraction resolves a local endpoint. NEVER infer the endpoint from the model-name string (BUG-260616-01).

### run_in_threadpool for blocking I/O (applies to: re-embed job, any new supabase-py/embed call in async)
**Source:** `backend/app/services/retrieval_service.py:35-44`
`embed_texts` and supabase-py are SYNC; running them on the event loop froze serving (SEED-065). Always `await run_in_threadpool(fn, ...)`. MANDATORY per D-v2.5-01.

### Migration apply + regen (applies to: migration 073)
**Source:** `supabase/migrations/072_*.sql` + CLAUDE.md
`ADD COLUMN IF NOT EXISTS`; apply by pasting into the Supabase SQL editor (or psycopg2-direct to `:54322`) - NEVER `supabase db push`/`db reset` (preserves the ~19 dev docs). Then `bash scripts/regenerate-full-schema.sh` (no reset). Live read-back verification = [BLOCKING] gate (mirror Phase 111 Plan 05; analog `test_111_settings_readback.py`).

### RLS scoping (applies to: re-embed job, match_document_chunks) - SECURITY
**Source:** `supabase/full-schema.sql:129` (`WHERE dc.user_id = match_user_id`)
Re-embed job MUST `eq("user_id", user_id)`; `match_document_chunks` keeps `dc.user_id = match_user_id`. `document_chunks` RLS verified live (full-schema.sql RLS policies). The cross-user-re-embed threat must be live-tested (V4).

### Data-egress control (applies to: D-09 #1/#2/#3) - SECURITY HEADLINE
**Source:** the three D-09 fixes above (config.py:362, openai_service.py:1448-1456, forced_emit.py:260-275)
Local document text must NEVER silently route to a cloud endpoint. The structural cure = explicit stored `(provider, model)` pairing + skip name-inference + local-aware forced_emit + gate OpenRouter mangling on `provider=="openrouter"`. **Verify by endpoint, not by a green result** (BUG-260616-01). Live proof exists at `scripts/_uat111/`.
