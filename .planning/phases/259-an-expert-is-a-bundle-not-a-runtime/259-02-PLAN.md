           Query `folders` table for ids in `bundle['knowledge_folder_ids']`.
           A folder is admitted to `effective_folder_ids` IF `org_id == caller_org_id`.

         - Validates `required_connections`:
           Query `connector_connections` table for services/capabilities in `bundle['required_connections']` for `caller_org_id`.
           Connections not configured in caller org are noted/stripped.
         - Returns `ResolvedExpertBundle`.
