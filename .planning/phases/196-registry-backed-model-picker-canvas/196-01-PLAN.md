type, operator control.

local LM Studio row and `gemini-3.6-flash`, the exact id SEED-135 measured silently degrading a run —
read `coerce` forever with **no knob to correct it**, and a picker that surfaced that would tell the
truth about a value nobody can fix.

client row type, and the registry tab's first enum control.

`emit_tier` to the overlay list, ships, and the value is NULL for every row forever because the column
does not exist."* The seven artifacts ship together or not at all.
