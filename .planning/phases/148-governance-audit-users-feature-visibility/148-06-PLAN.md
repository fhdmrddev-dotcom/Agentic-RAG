## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-148-01 | Information Disclosure | platform browse/export | mitigate | Delegates to 148-04's scoped/paginated/capped queries; both cross-user reads record audit.view_platform / audit.export (never silent); refused export writes no receipt. |
| T-148-02 | Elevation | disable | mitigate | GoTrue ban_duration="876600h" + reused _cancel_run_internals in-flight cancel; the app-layer ban check (148-02) closes the JWT window. |
| T-148-04 | Denial of Service | disable / revoke | mitigate | Server-side self-guard (409) before the ban write / before delegating revoke — the operator cannot lock themselves out (Pitfall 7). |
| T-148-03 | Tampering | PUT /admin/visibility | mitigate | feature+audience validated against code allowlists (400 before write); set_feature_visibility only serializes the enum record (JSONB codec, asyncpg $N). |
| T-148-06 | Integrity | visibility write | mitigate | set_feature_visibility uses the atomic JSONB `||` merge (148-02) — no lost-update clobber under concurrent toggles. |
| T-148-SC | Tampering | pip installs | accept | Zero new packages. |
