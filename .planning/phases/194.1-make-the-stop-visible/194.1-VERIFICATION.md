## 3. ⚠ What is NOT claimed

**RUN-01 is deliberately UNTICKED.** `REQUIREMENTS.md` is byte-unchanged, verified at this commit.

The requirement reads *"A user can stop a running workflow at any point, **and the run reports honestly
that it was stopped**."* This phase delivered the first clause completely. The second fails on roughly
**half** of stops at the shipped `WORKER_COUNT=2`, because `finish_run` is an unconditional status write
with no terminal guard (**L-01**, inherited from Phase 194, recorded there as FAILED SC#2).

⚠ **Making the stop VISIBLE made that lie MORE visible, and that is correct.** The surface now honestly
shows `⊘ Stopping this run…` and then `✓ Complete` on the affected half. A dedicated fence
(`StreamsProvider.stopping.test.ts`, plant P4) **reds against any attempt to suppress it**. The lie is a
boundary to state, never a defect to hide.

⚠ **L-01 has no roadmap home.** `194.1-DEFERRED.md` §1 records it as *"an OWED PHASE… insert it as soon
as 194.1 lands"*, and milestone phases 195–198 cover none of it. **Inserting that phase is the next
action this verification owes.**
