## §0 The base SHA — asserted, not assumed

| Property | Value |
|---|---|
| **Capture commit (`git rev-parse HEAD`)** | **`a9e7d10c7ddc91e17b9ef5547eb6da749677c696`** |
| Plan-set measurement SHA (`f9e55b6d…`) | `f9e55b6db33606fca77ee84ce8ef3da3153d09e2` |
| Descent | `git merge-base --is-ancestor f9e55b6d… HEAD` → **exit 0** |
| Source drift | `git diff --name-only f9e55b6d… HEAD -- frontend/src backend/app scripts supabase` → **EMPTY** |

⚠ **THE PLAN'S OWN ACCEPTANCE TEXT IS SUPERSEDED HERE, AND THE ORIGINAL IS LEFT STANDING RATHER THAN
OVERWRITTEN.** `194.1-01-PLAN.md`'s task-1 acceptance criterion reads *"`git rev-parse HEAD` printed and
equal to `f9e55b6d…`"*. **That test cannot pass and was never meant to**: the plan set's own commits
(`5f1df776` the plan write, `186fa4a` the amendment, `c66e234d`, `a9e7d10c` the state record) moved HEAD
past `f9e55b6d` before any executor could run. The plan's own `<action>` body states the correct
property two paragraphs above that criterion — *"What matters is NOT that HEAD equals that SHA … but
that the worktree descends from it and that no source file this plan quotes has moved since"* — and
phase commit `186fa4a` (*"base assertion is descent-plus-no-source-drift, not SHA equality"*) ratifies
it. **The descent property is what was asserted, and it holds.**

⚠ **THE WORKTREE FORKED FROM THE WRONG BASE AND WAS CORRECTED — recorded because this project has
measured it repeatedly (12/12 worktrees in Phase 192; again on a single worktree 2026-08-14) and a
silent correction is indistinguishable from it never happening.** On arrival this worktree's HEAD was
`fda79214` — *"Merge develop into master — BUG-260809-02 canvas business_requirement input"* — whose
`git merge-base HEAD a9e7d10c` returned `3781a3fe`, i.e. **HEAD did not descend from the dispatched
base at all**; it was a `master` merge commit, not a `develop` tip. Corrected with
`git reset --hard a9e7d10c…`, then re-asserted: `git rev-parse HEAD` → the base exactly, and
`git diff --numstat <base> HEAD -- frontend/src backend/app` → **EMPTY**. Every `file:line` quoted by
this phase's artifacts is therefore valid **as measured**, and no line number needed re-derivation.
