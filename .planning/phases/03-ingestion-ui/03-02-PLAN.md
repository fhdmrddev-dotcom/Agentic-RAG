    **FolderNode component (frontend/src/components/ingestion/FolderNode.tsx):**

    Props interface:
    ```typescript
    interface FolderNodeProps {
      node: FolderNode  // from @/lib/folderTree
      depth: number
      selectedFolderId: string | null
      expandedIds: Set<string>
      editingId: string | null
      deletingId: string | null
      onSelect: (id: string) => void
      onToggleExpand: (id: string) => void
      onStartRename: (id: string, currentName: string) => void
      onCommitRename: (id: string, newName: string) => void
      onCancelRename: () => void
      onStartDelete: (id: string) => void
      onConfirmDelete: (id: string) => void
      onCancelDelete: () => void
      onCreateSubfolder: (parentId: string) => void
    }
    ```

    Rendering logic:
    - Outer div: `style={{ paddingLeft: ${depth * 12}px }}` for tree indentation (12px per level per UI-SPEC spacing exception)
    - Row container: `flex items-center gap-1.5 py-1 px-2 rounded-md cursor-pointer group` with conditional `bg-accent text-accent-foreground` when `node.id === selectedFolderId`, else `hover:bg-accent`
    - Chevron area (16px wide): If `node.children.length > 0`, render `ChevronDown` (expanded) or `ChevronRight` (collapsed). Click toggles expand. If no children, render empty 16px spacer.
    - Icon area: Always render `<Folder className="h-4 w-4 shrink-0" />`. If `node.is_global`, also render `<Globe className="h-4 w-4 shrink-0 text-muted-foreground" />` after the Folder icon.
    - Name: `<span className="text-sm truncate flex-1">{node.name}</span>`
    - Hover actions (visible on group-hover): `<Pencil className="h-3.5 w-3.5" />` and `<Trash2 className="h-3.5 w-3.5" />` wrapped in `Tooltip` components. Button size: `h-7 w-7 p-0`. Use `opacity-0 group-hover:opacity-100` for show-on-hover.

    Inline rename state: When `editingId === node.id`, replace the name span with:
    ```tsx
    <input
      ref={editInputRef}
      value={editValue}
      onChange={(e) => setEditValue(e.target.value)}
      onBlur={() => onCommitRename(node.id, editValue.trim())}
      onKeyDown={(e) => {
        if (e.key === "Enter") onCommitRename(node.id, editValue.trim())
        if (e.key === "Escape") onCancelRename()
      }}
      className="flex-1 px-1 py-0.5 text-sm bg-background border rounded outline-none"
      autoFocus
    />
    ```

    Inline delete confirmation: When `deletingId === node.id`, render below the row:
    ```tsx
    <div className="ml-8 py-1 px-2 text-xs text-muted-foreground flex items-center gap-2">
      <span>Delete {node.name} and all its contents? This cannot be undone.</span>
      <Button variant="destructive" size="sm" className="h-6 text-xs px-2" onClick={() => onConfirmDelete(node.id)}>Delete</Button>
      <Button variant="ghost" size="sm" className="h-6 text-xs px-2" onClick={onCancelDelete}>Cancel</Button>
    </div>
    ```

    Recursion: If expanded and has children, map over `node.children` rendering `<FolderNode>` with `depth={depth + 1}` passing all the same callback props.

    **FolderTree component (frontend/src/components/ingestion/FolderTree.tsx):**

    Props interface:
    ```typescript
    interface FolderTreeProps {
      folders: Folder[]
      selectedFolderId: string | null
      onSelectFolder: (id: string | null) => void
      onCreateFolder: (name: string, parentId: string | null) => Promise<Folder>
      onRenameFolder: (id: string, name: string) => Promise<void>
      onDeleteFolder: (id: string) => Promise<void>
    }
    ```

    Internal state:
    - `expandedIds: Set<string>` — starts with empty set (depth > 1 collapsed per UI-SPEC). Top-level folders (depth 0) are always visible (roots of tree).
    - `editingId: string | null` — which folder is being renamed
    - `editValue: string` — current rename input value
    - `deletingId: string | null` — which folder is showing delete confirmation
    - `creatingInParentId: string | "root" | null` — which parent is showing the create input

    Header: `<div className="flex items-center justify-between px-2 mb-2">` with:
    - `<span className="text-[10px] font-medium uppercase tracking-wider text-muted-foreground/60">Folders</span>` (matches Sidebar section label pattern)
    - `<Tooltip><TooltipTrigger asChild><button className="h-7 w-7 ..." onClick={() => setCreatingInParentId(selectedFolderId ?? "root")}><Plus className="h-4 w-4" /></button></TooltipTrigger><TooltipContent>New Folder</TooltipContent></Tooltip>`

    Root node: A special clickable row `"Root"` that clears folder selection (`onSelectFolder(null)`). Highlighted when `selectedFolderId === null`.

    Tree body: Call `buildFolderTree(folders)` and render each root as `<FolderNode depth={0} ... />`.

    Empty state (when `folders.length === 0` and no create input active):
    ```tsx
    <div className="text-center py-6">
      <p className="text-sm font-medium">No folders yet</p>
      <p className="text-xs text-muted-foreground mt-1">Create a folder to organize your documents.</p>
    </div>
    ```

    Create input: When `creatingInParentId` is set, render `<FolderCreateInput>` at the appropriate position. On commit, call `onCreateFolder(name, parentId === "root" ? null : parentId)`. On cancel, set `creatingInParentId` to null.

    Error handling: Wrap `onCreateFolder`, `onRenameFolder`, `onDeleteFolder` calls in try/catch. On error, use `console.error` for now (error toasts are not in scope for this phase per UI-SPEC — only inline error messages specified in copywriting contract). Optionally show the error inline near the action.
