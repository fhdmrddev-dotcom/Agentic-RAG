<threat_model>
### Security & Reliability Invariants (ASVS L1)
1. **Unauthenticated RPC Execution (TM-248-03):**
   - Invariant: No `SECURITY DEFINER` function in the database may be executed by the `anon` role over PostgREST `/rest/v1/rpc/<name>`.
2. **The PUBLIC Grant Trap (D-248-08 / CLAUDE.md):**
   - Invariant: For Group A functions carrying `=X/postgres`, `REVOKE ... FROM PUBLIC` must precede role revokes; otherwise `anon` inherits execute silently from PUBLIC.
3. **Trigger Execution Availability (D-248-09):**
   - Invariant: Trigger functions invoked on table row events must not break when execute is revoked from DML callers. This must be tested across all 6 triggers, specifically including `handle_new_user` (signup flow).
4. **RLS & App Execution Continuity:**
   - Invariant: `current_user_org_ids` (147 policy references), `current_user_has_permission`, `connection_doc_is_visible`, `folder_is_org_shared`, and search RPCs (`match_document_chunks`, `keyword_search_chunks`, `match_skills`) retain EXECUTE for `authenticated` and `service_role`.
</threat_model>
