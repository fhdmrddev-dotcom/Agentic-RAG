**File:** `backend/app/db/rates.py:220-222` (`summary_query`) · `:288-291` (`daily_query`) ·

**Failure scenario** (concrete, measured, not hypothetical). Operator opens `/admin/spend`, All

Two collateral surfaces move with it, both measured:
- **the daily chart's "Unrated Volume" bars** now total **675** across 89 buckets (was 332), so the

(`summary_query`'s CTE already selects `rate.input_cost_per_million`; `daily_query`'s CTE does not
and must add it.) Then surface `unmeasured_runs_count` as the third state the ledger already
renders, and fix `rates.py:362` to key `spend_usd` off `is_fully_rated` rather than `rated_count`.
⛔ **Whatever the choice, one number must not be produced by two different definitions on one page** —
that is the defect, and it is the same defect as F-3.

### WR-11: The new "defensive coercion" turns a malformed `effective_at` into silent `now()` pricing — i.e. it silently restores CR-01 rather than failing

**File:** `backend/app/db/rates.py:45-53`

**What is wrong.** `except Exception: effective_at = None` falls through to
`effective_ts = effective_at or datetime.now(timezone.utc)` (`:55`), and `except Exception: org_id =
None` widens the scope to global rates. Neither logs. A value the caller *supplied* is discarded and
replaced with a different, wrong one, and the only visible effect is a wrong dollar figure.

**Failure scenario.** Any producer that hands this a timestamp shape `fromisoformat` does not accept
(a PostgREST format change, a ` UTC`-suffixed string, an empty string from a NULL column) prices the
run at today's rate — the exact 10× divergence CR-01 just fixed — with a green suite and no log line.

**Evidence** — driven inside a rolled-back transaction with a reprice in place
(old rate `0.30/1.20`, new rate `3.00/12.00` effective `now()`); `model_rates` 53 before, 53 after:

```
effective_at=datetime object        -> rate 0.300000/1.200000    ✅ correct (past price)
effective_at=good ISO string        -> rate 0.300000/1.200000    ✅
effective_at=Z-suffixed string      -> rate 0.300000/1.200000    ✅
effective_at=UNPARSEABLE string     -> rate 3.000000/12.000000   ⛔ silently priced at now()
effective_at=empty string           -> rate 3.000000/12.000000   ⛔
org_id=garbage string               -> rate 0.300000             ⛔ silently global-scoped
```

**Fix.** Coerce, or refuse — never substitute:

```python
if isinstance(effective_at, str):
```
