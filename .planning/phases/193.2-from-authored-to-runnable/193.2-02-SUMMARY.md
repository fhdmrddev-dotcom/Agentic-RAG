## Deviations from Plan

### ⚠ 1. [Finding — the most consequential] CORRECTION C-7: `harness_audit.metadata` is a DOUBLE-ENCODED jsonb STRING, so RESEARCH's decisive query cannot return what RESEARCH reports

**Found during:** Task 1, §1, running RESEARCH's second query verbatim.

**Issue:** `select … metadata->>'blocked_stage' … where event_type='publish_blocked'` returns
**`None` on all 32 rows**. RESEARCH reports `blocked_stage: structural_gate` for the 2026-08-07 row.

**Measured cause:**
```
select jsonb_typeof(metadata), count(*) … → ('string', 32)     -- NOT 'object'. Every row.
select distinct jsonb_object_keys(metadata) … → psycopg2.errors.InvalidParameterValue:
                                                cannot call jsonb_object_keys on a scalar
```
The column holds a jsonb **string scalar whose text is itself a JSON document**. `->>'key'` on a
scalar is NULL *by definition*. The working accessor is `metadata #>> '{}'` followed by a JSON parse.

**Resolution:** both recorded, neither overwriting the other. **RESEARCH's VALUE is CONFIRMED** —
through the working accessor the 2026-08-07 row does read `structural_gate`, and the full stage tally
over 32 rows is `structural_gate` 11 · `judge` 10 · `business_requirement` 7 · `golden_run_error` 2 ·
`draft_changed` 1 · `already_published` 1. Only the **command** credited with producing it is wrong.

⚠ **This is the jsonb string-scalar trap on a new surface** (this project already records it for
`definition->'phases'`, which "silently returns 0 rows"). **A NULL that reads like "the field is
empty" is indistinguishable from "you asked the wrong way"** — the same class of failure this phase
exists to fix in user-facing copy, appearing in our own diagnostics. **`193.2-10` inherits the
warning**: its OQ-1 `publish_blocked` re-check is safe on `count(*)` (which keys on `event_type`, a
real column) but must use `#>> '{}'` if it inspects `blocked_stage`.

**⚠ The D-10 conclusion is UNAFFECTED.** The count of `publish_blocked` on 2026-08-15 is 0
regardless of how `metadata` is shaped.
