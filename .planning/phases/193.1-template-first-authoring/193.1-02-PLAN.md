<objective>
Build D-05's stateless read: a route that takes the **bytes**, returns the **field names**, and
persists nothing — so a template can be supplied before a workflow exists.

Purpose: the shipped upload door is `POST /workflows/{definition_id}/template` and requires a saved
workflow. At describe time there is no workflow. This is the missing producer, and it is the piece
that makes 165-C's approved filled states reachable at all.

Output: one new route beside its two siblings, one shared name-assembly function so the two doors
cannot disagree about the same document, and a backend suite whose harness is deliberately SMALLER
than its analog's — because that shrinkage IS the security property.
</objective>
