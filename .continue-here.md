### The one architectural change that matters

**`backend/app/services/ingest_enrich.py` is new and is now the ONLY home of the metadata + vision
step.** Both ingest paths call it — `ingest_document` directly, the queue path through
`run_in_threadpool`. It exists because Phase 230's durable queue ran its own chunk/embed loop with
**no metadata step at all**, so every upload after that cutover completed with no title, no date, no
chunk header and no vision transcription.

⚠ **`run_in_threadpool` is load-bearing**: `enrich_for_ingest` calls `asyncio.run` internally, and
awaiting it inside the loop would raise into its own broad `except` and degrade to `metadata=None` —
re-creating the bug in a form that looks like a working call.

## ⚠ The four bugs, and the one lesson that connects them

**All four were the same shape: two code paths serving one outcome, and only one of them did the
work.** 5,600 tests missed every one, because both paths had tests and **no test asserted the paths
AGREE**. The operator found each by using the product.

1. **06** — the queue had no metadata step (found: *"recent files have no metadata, old ones do"*).
2. **07** — a failed extraction wrote `None` over good metadata. The queue path already guarded it;
   the legacy path did not.
3. **08** — a storage failure logged a warning and carried on, so a document completed with no bytes.
   Fixed at `/upload`, then found **unfixed one level down** in `splice_document` and closed there.
4. **12** (found by Gemini, in MY code) — the `07` guard checks `metadata_dict is not None`, but the
   image branch runs `metadata_dict = metadata_dict or {}` **upstream of it**, so for an image the
   guard could never fire. Their fix captures `enrichment_degraded` before that branch.

⭐ **The rule this session earned:** when two paths serve one user-visible outcome, test the
AGREEMENT, not each path. `backend/tests/unit/test_ingest_enrich_shared.py` is that test.

## Traps this session hit — do not repeat

1. ⛔ **A BACKUP/RESTORE CYCLE CLOBBERED THE OTHER AGENT'S UNCOMMITTED WORK.** Planting defects with
   `cp file /tmp/bak` … `cp /tmp/bak file` reverted Gemini's live `_storage_safe` edit. Caught, restored,
   and their hunks deliberately left unstaged. **With two sessions in one tree, one belongs in a worktree.**
2. ⛔ **A 403 PROVES ROUTING, NOT SERIALIZATION.** I tested `/sources/watches` unauthenticated, got a
   clean 403, and concluded "the endpoint works". The real bug was a `ResponseValidationError` on the
   **authenticated** response (a non-nullable `last_status` against a NULL row) → a 500 that never gets
   CORS headers → Chrome says `TypeError: Failed to fetch`. **My preflight-cache hypothesis was wrong;
   Gemini found it.** Always drive the authenticated path.
3. ⚠ **A fence satisfied by a COMMENT is not a fence** — and the inverse: a fence BROKEN by a comment
   is a bad fence. Both happened. Strip comments before asserting on source.
4. ⚠ **A planted defect found a hole in my own test**: deleting the vision `drawing` arm left all 23
   tests GREEN, because the fixture fell under the scan threshold and passed through the WRONG arm.
   **A threshold classifier needs a fixture per ARM plus an assertion that it lands in that arm.**
5. ⚠ **The count gate is unreadable with two agents on the box** — measured 8, then 21, then 9, then 1
   failures on the same tree. Capture failing filenames from the gate's persisted JSON BEFORE
   re-running, then run in-scope suites explicitly.
6. ⚠ **Heredocs break on apostrophes/`\n`** — use the Write tool for long content. Bit me twice.
7. ⚠ **Windows console is cp1252**: printing `⚠` or Arabic crashes a script. Use `PYTHONIOENCODING=utf-8`.
