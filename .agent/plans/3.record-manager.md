# Module 3: Record Manager

**Complexity: ✅ Simple** — Single-pass executable, narrow change surface.

## Context

Naive ingestion re-embeds identical files every time they're uploaded, wasting embedding API calls and bloating the `document_chunks` table with duplicates. Module 3 fixes this by computing a SHA-256 hash of file content on upload and using it to:
- Skip re-ingestion of already-completed identical files
- Automatically replace stale chunks when a file is re-uploaded with changed content

## Decision Tree (upload handler)

```
hash matches completed doc  →  Case 1: return existing, HTTP 200 (skip)
same filename, diff hash    →  Case 2: delete old doc + re-ingest new
neither                     →  Case 3: new file, existing behavior
hash matches failed doc     →  falls through to Case 3 (retry allowed)
```

**After reading raw bytes (before `extract_text`), add:**

```python
content_hash = hashlib.sha256(raw).hexdigest()

# Case 1: exact duplicate already completed
existing = supabase.table("documents").select("*").eq("user_id", current_user["id"]).eq("content_hash", content_hash).eq("status", "completed").limit(1).execute()
if existing.data:
    response.status_code = status.HTTP_200_OK
    return existing.data[0]

# Case 2: same filename, different content → replace
stale = supabase.table("documents").select("id, file_path").eq("user_id", current_user["id"]).eq("filename", file.filename).neq("content_hash", content_hash).limit(1).execute()
if stale.data:
    try:
        supabase.storage.from_("documents").remove([stale.data[0]["file_path"]])
    except Exception:
        pass
    supabase.table("documents").delete().eq("id", stale.data[0]["id"]).execute()
```

### `frontend/src/hooks/useDocuments.ts`
Update `upload` callback to handle duplicate signal and pass it up:
```typescript
const upload = useCallback(async (file: File): Promise<{ isDuplicate: boolean }> => {
  setUploading(true)
  try {
    const { doc, isDuplicate } = await uploadDocument(file)
    setDocuments((prev) => {
      if (prev.some((d) => d.id === doc.id)) return prev
      return [doc, ...prev]
    })
    return { isDuplicate }
  } finally {
    setUploading(false)
  }
}, [])
```

## Verification

1. **Duplicate detection:** Upload same file twice → second response is HTTP 200, no new row in `documents`, no new rows in `document_chunks`, UI shows "already up to date" notice.
2. **Update (re-ingestion):** Upload file, modify it, re-upload same filename → old document row gone, new row created and goes through pending → processing → completed. Old chunks deleted.
3. **Failed retry:** Upload a file that fails ingestion, re-upload same content → new document row created, re-ingestion attempted.
4. **New file:** Upload a completely new file → 201 Created, normal ingestion flow unchanged.
5. **Existing rows:** Run `GET /documents` after migration — no 422 errors, `content_hash` is `null` for pre-existing rows.
