
# Module 8: Sub-Agents

**Complexity:** ⚠️ Medium — Coordinated backend + frontend changes, but each follows established patterns.

## Context

The RAG app currently has a single-level agent loop: user message → LLM with tools → dispatch tool → second LLM call → response. Module 8 adds a sub-agent that handles full-document analysis tasks (summarize, compare, critique) where chunk-based retrieval is insufficient. The main agent detects these scenarios via a new `analyze_document` tool, fetches the entire document content, and spawns an isolated sub-agent LLM call with that content as context. The frontend gets new SSE events to display tool call activity and streaming sub-agent output in collapsible panels.

## Task 1: Add `fetch_full_document` and `resolve_document_id` to `retrieval_service.py`

**File:** `backend/app/services/retrieval_service.py`

Add two new public functions:

1. **`resolve_document_id(filename, user_id, supabase) -> str | None`**
   * Query `documents` table with case-insensitive `ilike` match on `filename` + `user_id` filter
   * Return the document `id` or `None`
2. **`fetch_full_document(document_id, user_id, supabase) -> dict | None`**
   * Query `documents` table for the row (ownership check via `user_id`)
   * Query `document_chunks` ordered by `chunk_index` for all chunks of that document
   * Concatenate all chunk `content` fields with `"\n\n"`
   * Return `{"document_id": ..., "filename": ..., "metadata": ..., "content": <full_text>}` or `None`

## Task 4: Create Sub-Agent Service

**New file:** `backend/app/services/sub_agent_service.py`

**Function:** `run_sub_agent(document_content, document_filename, task, model, user_settings) -> Generator[str, None, None]`

1. Build focused system prompt: `"You are a document analysis assistant. You have the full text of '{filename}'. Analyze it carefully and cite specific sections/quotes."`
2. Truncate `document_content` to 100,000 chars (~25K tokens) with note if truncated. Add `SUB_AGENT_MAX_CHARS = 100000` to `config.py`.
3. Build messages:
   ```
   [system, {"role": "user", "content": f"Document:\n\n{content}\n\n---\nTask: {task}"}]
   ```
4. Call `get_llm_client(user_settings).chat.completions.create(model=..., messages=..., stream=True)` — no tools.
5. Yield each `delta.content` chunk.
6. Decorate with `@traceable(name="sub-agent", run_type="llm")`.

## Task 5: Wire Sub-Agent into Main Agent Loop + Emit Tool SSE Events

### 5a: Emit `tool_start`/`tool_end` for ALL Tool Calls

Wrap each tool dispatch iteration with:

```python
yield f"data: {json.dumps({'type': 'tool_start', 'name': tool_name, 'args': args})}\n\n"
# ... existing tool execution ...
yield f"data: {json.dumps({'type': 'tool_end', 'name': tool_name})}\n\n"
```

### 5b: Add `analyze_document` Branch

In the tool dispatch loop, add:

```python
elif tool_name == "analyze_document":
    doc_id = resolve_document_id(args["filename"], current_user["id"], supabase)
    if not doc_id:
        tool_result = f"Document '{args['filename']}' not found."
    else:
        doc = fetch_full_document(doc_id, current_user["id"], supabase)
        if not doc:
            tool_result = f"Could not retrieve content for '{args['filename']}'."
        else:
            yield sub_agent_start SSE event (filename, task)
            sub_agent_content = ""
            for chunk in run_sub_agent(doc["content"], doc["filename"], args["task"],
                                       model=body.model, user_settings=user_settings):
                sub_agent_content += chunk
                yield sub_agent_delta SSE event (chunk)
            yield sub_agent_done SSE event
            tool_result = sub_agent_content
```

### 5c: Handle Sub-Agent Errors

Wrap in `try/except` — on failure, set `tool_result = "Sub-agent analysis failed: {error}"` and emit `sub_agent_done`.

**Add imports:** `resolve_document_id`, `fetch_full_document` from `retrieval_service`; `run_sub_agent` from `sub_agent_service`.
