# Module 7: Additional Tools — Text-to-SQL + Web Search

⚠️ **Medium** — Two new tools, one new migration, loop dispatch changes, plus multi-file upload (frontend only). Each piece is self-contained.

## Context

Module 7 extends the single-tool agentic loop (currently only `search_documents`) into a multi-tool agent. The LLM gains two new capabilities:

1. **`query_documents`** — Text-to-SQL over the user's documents table. Answers structured questions like "how many PDFs do I have?" or "list documents from 2024" without doing a semantic search.
2. **`web_search`** — Tavily API fallback for information not in the user's documents. Includes attribution (title + URL) in results.

The existing agentic loop already iterates over all tool calls in a single response, so parallel multi-tool calls are handled without a loop restructure. We just add new dispatch branches and conditionally include tools based on config.

3. **Multi-file upload** — frontend-only change. The backend already handles concurrent uploads correctly (each file is an independent request + background task). No backend or migration changes needed.

### Phase 2: Supabase Migration

**`backend/supabase/migrations/012_query_documents_fn.sql`**

```sql
CREATE OR REPLACE FUNCTION query_user_documents(sql_query text)
RETURNS jsonb
LANGUAGE plpgsql
SECURITY INVOKER  -- RLS applies: user only sees their own rows
AS $$
DECLARE
  result jsonb;
  clean_query text;
BEGIN
  clean_query := trim(sql_query);

  -- Injection guard: SELECT only, no semicolons
  IF lower(clean_query) NOT LIKE 'select%' THEN
    RAISE EXCEPTION 'Only SELECT queries are permitted';
  END IF;
  IF position(';' IN clean_query) > 0 THEN
    RAISE EXCEPTION 'Query must be a single statement (no semicolons)';
  END IF;

  EXECUTE format('SELECT jsonb_agg(t) FROM (%s) t', clean_query)
    INTO result;

  RETURN COALESCE(result, '[]'::jsonb);
END;
$$;

-- Grant execution to authenticated users
GRANT EXECUTE ON FUNCTION query_user_documents(text) TO authenticated;
```

`SECURITY INVOKER` means the function runs with the calling user's role, so Supabase RLS policies on `documents` (e.g. `user_id = auth.uid()`) automatically scope results.

### Phase 3: New Services

**`backend/app/services/web_search_service.py`**
- `web_search(query: str, api_key: str, max_results: int = 5) -> str`
- POST to `https://api.tavily.com/search` with `httpx` (sync, consistent with `rerank_service.py`)
- Returns formatted string: each result as `**Title**\nURL: ...\nSnippet...` separated by `---`
- Decorated with `@traceable(name="web_search")` for LangSmith
- Raises `RuntimeError` on HTTP errors (caught in the tool dispatch loop)

**`backend/app/services/sql_service.py`**
- `query_documents(sql_query: str, user_id: str, supabase) -> str`
- Client-side validation (SELECT only, no semicolons) — defence-in-depth before the DB call
- Calls `supabase.rpc("query_user_documents", {"sql_query": sql_query}).execute()`
- Returns results as a markdown table if ≤ 10 rows, else JSON truncated to 20 rows with a note
- Returns "No results." for empty result sets
- Raises `ValueError` for invalid query, `RuntimeError` on DB errors

### Phase 5: Threads — System Prompt + Tool Dispatch

**`backend/app/api/threads.py`**

**System prompt update** — add tool routing guidance:
```
Tools available:
- search_documents: semantic search over document content (use for conceptual/content questions)
- query_documents: SQL query over document metadata (use for structured questions: counts, file types, dates)
- web_search: live web search (use only when the answer is clearly not in uploaded documents; always cite sources with URL)
```

**Tool dispatch** — extend the existing tool execution loop (currently only handles `search_documents`):

```python
for tc in tool_calls_buffer:
    tool_name = tc["function"]["name"]
    args = json.loads(tc["arguments"])

    try:
        if tool_name == "search_documents":
            metadata_filter = args.get("metadata_filter") or None
            tool_result = search_documents(...)  # existing
        elif tool_name == "query_documents":
            tool_result = query_documents(args["query"], current_user["id"], supabase)
        elif tool_name == "web_search":
            tool_result = web_search(args["query"], settings.tavily_api_key, settings.web_search_max_results)
        else:
            tool_result = f"Unknown tool: {tool_name}"
    except Exception as e:
        logger.error(f"Tool {tool_name} failed: {e}")
        tool_result = f"Tool execution failed: {str(e)}"

    messages.append({"role": "tool", "tool_call_id": tc["id"], "content": tool_result})
```

New imports: `from app.services.web_search_service import web_search` and `from app.services.sql_service import query_documents`.
