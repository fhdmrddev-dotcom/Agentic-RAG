summary: >-
  Syrel has no HTTP rate limits today; what exists is per-run token caps (a run pauses when it
  reaches its cap), tier entitlements and an operator spend ledger. Rate limits are not available
  today; per-organisation limits are planned (SEED-345) and API access beyond a signed-in user is
  the Open Platform plan (SEED-013). See Errors for the responses a refusal returns.
