Open **Library** from the rail. The Library has five tabs: **Documents**, **Views**, **Ingestion**, **Indexing** and **Health**. This page covers the Documents tab, where you will spend most of your time.

![The Library Documents tab with the folder tree and document table](/docs-assets/shots/library-documents.png)

## Folders

The folder tree on the left shows every folder you can see: your own, and folders other members have shared with your organisation. Folders can be nested to any depth.

- **Create, rename, move or delete** a folder from the tree. Deleting a folder deletes everything inside it.
- **Share with org** makes a folder you own, and every document in it, readable by every member of your organisation. **Make private** undoes it. A shared folder is marked "Shared with org".
- On a phone, open the tree with the **Folders** button above the list.

## Documents

Selecting a folder lists its documents. The top level holds documents that are not in any folder.

- **Add documents** with the upload area or the cloud import beside it. You can add documents only to a folder you own. See [Adding documents](/docs/use/library/ingestion).
- **Move** a document to another folder.
- **Versions.** Uploading a file with the same name as an existing document creates a new version. The document shows a version badge, citations name the version, and older versions drop out of search once the new one is ready. You can restore an older version, and delete one version or all of them.
- **Re-ingest** a document to read it again with the current extraction settings.
- **Open the detail panel** by selecting a document. It shows the document's details with a confidence chip on each field, its text, tables and images, the questions that found it, its links to other documents and any filing suggestion. See [The document panel](/docs/use/library/document-detail).

A document placed by a connected source (for example a watched Google Drive folder) says so in its detail panel, so you can tell it from something a person uploaded.

## What Syrel can see

Syrel searches exactly the documents you can see — your own and those in folders shared with your organisation. A chat can be narrowed further to one folder; see [Limiting a chat to a folder](/docs/use/chat-scope).

## Coming in v4.5

The Documents tab gains a **Find documents | Ask** switch for finding documents by what they are (type, owner, dates, fields, links, version state). That is part of v4.5, which has not shipped. See [Finding a document](/docs/use/library/find).
