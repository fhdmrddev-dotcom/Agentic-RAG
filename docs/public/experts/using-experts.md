You can start a chat with an Expert from the [catalog](/docs/experts/catalog), or invite one into a chat you already have.

## Inviting an Expert

1. In the composer, open the Expert invite and pick an Expert.
2. Before it joins, Syrel shows what changes. For a **restricted** Expert it lists which of the chat's documents the Expert will not read. Until that statement is ready, there is no invite button.
3. Confirm. A chip in the composer shows the active Expert.

If the Expert needs a connection your organisation has not set up, the invite says **Requires** that service — **not connected** — and offers to connect it, rather than letting the Expert fail partway through an answer.

## What changes in the chat

- The chat keeps every tool it had and gains the Expert's skills and connections. An Expert never removes a tool.
- The Expert's starter prompts ("Try asking…") appear so you can see what it is good at.
- Knowledge follows the Expert's folder rule: a biased Expert reads the chat's folder plus its own; a restricted Expert reads only its own folders.

## Swapping or removing an Expert

A chat has one active Expert. Choosing a different one replaces it, and removing it returns the chat to normal. Each change writes a note into the chat saying what the next turn will and will not use, and the note is still there after you reload. Wait for an answer to finish before changing the Expert.

## Asking a second Expert

To bring in a different Expert without losing the current one, start a new chat scoped to the other Expert from the current chat. Syrel summarises the first chat and carries the summary over, and each chat keeps its own active Expert.

> **Note:** The handoff summary has been proven live on one AI provider. On some providers it can miss parts of its instructions, so read it before relying on it.
